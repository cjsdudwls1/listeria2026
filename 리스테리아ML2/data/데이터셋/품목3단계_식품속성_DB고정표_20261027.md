## 1. 규칙

1. **원문 → 숫자**: 3차(`notebook/06_품목_식품속성.py` parse_food)와 같음. 단일 숫자 = 그 값(표기 `단일값`), 범위(`~`, `-` 등) = 가운데 값(`중앙`), `<`·`>`·`≤`·`≥`·이상·이하·초과·미만 = 경계값(표기 `미만`·`초과`·`이하`·`이상`), 숫자 뒤 부등호(`0.98<`)는 방향을 뒤집어 읽음, `-` 처럼 숫자로 읽히지 않는 글 = 값 없음. 음수로 읽히는 원문도 값 없음(aw·pH·염도는 음수가 될 수 없음 — 사용자 2026-10-27, 영양강화 밀가루 aw `-0.85`). 범위 가운데 값은 소수 12자리로 맞춤(부동소수 오차만 없앰).
2. **aw 는 `aw_source` = `original` 행만**: `ba_data.t_aw_cl` 1,316행 중 65행 제외(아래 3절). ph·na 는 출처 칸이 없어 `aw_source` 와 관계없이 표 값 그대로 씀.
3. **하위 코드**: `ba_data.t_prdlst_cl` 의 `hrnk_prdlst_cd`(상위_품목_코드)를 따라 내려가 그 코드 아래에 있는 모든 코드(자기 자신 제외). `lv` 무관, `vald_end_dt` 가 지난 코드도 포함.
4. **대표값**(aw·ph·na 마다 따로):
   - ① `자기값`: 3단계 코드(`train_prdlst_code_2`) 자체의 `t_aw_cl` 값
   - ② `하위중앙`: ①이 없으면, 하위 코드 중 값이 있는 코드들의 값의 중앙값(코드마다 한 번 — `t_aw_cl` 은 코드당 1행). 개수가 짝수면 가운데 두 값의 평균. 소수 12자리로 맞춤.
   - ③ `2단계값`: ②도 없으면, 그 3단계와 시료에서 짝지어진 2단계 코드(`train_prdlst_code`) 자체의 `t_aw_cl` 값(2단계의 하위 코드는 보지 않음). 한 3단계가 2단계 여럿과 짝이면 시료 수 최다 짝 — 이번 시료에서는 그런 3단계 **0개**.
   - ④ `결측`: 셋 다 없으면 null.
5. **표기 칸 `aw_label`·`ph_label`·`na_label`**: ①·③ 은 쓴 값의 표기(`단일값`·`중앙`·`이상`·`이하`·`초과`·`미만`), ② 는 새 범주 `하위중앙`, ④ 는 null(3차 표와 같이 null 로 저장 — 모델에 넣을 때 `결측` 범주로 바꾸는 것도 3차와 같음). `하위중앙` 은 중앙값을 낸 하위 코드 값들의 표기가 섞여 있어도(부등호·범위 포함) 숫자만으로 중앙값을 냄.
6. **덧붙인 칸**: `{aw,ph,na}_rule` = 위 ①~④ 중 쓴 규칙(`자기값`·`하위중앙`·`2단계값`·`결측`), `{aw,ph,na}_n_sub` = `하위중앙` 일 때 중앙값에 쓴 하위 코드 수(그 밖은 null). 앞 9칸은 3차 표와 칸 이름·자료형·순서가 같아 바꿔 끼울 수 있음.
7. **생장 범위 표**: `make_ranges.py` 3) 과 같은 계산(그림 값 aw 한계 0.90~0.997·최적 0.97, pH 한계 4.0~9.6·최적 7.0, 경계 포함, 결측 → null, float32). 표기가 중앙·부등호·하위중앙이어도 숫자 그대로 씀. 칸·자료형·메타데이터 형식은 3차와 같고 `inputs`·`script`·`description` 만 바꿈.
8. 값은 원문 그대로: 결측 채움·단위 변환·이상값 삭제 없음.
