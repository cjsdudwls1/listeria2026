# GAP(농산물우수관리) 인증 — 출처

- 받은 날: 2026-10-19
- 받은 방법: 농림축산식품 공공데이터포털(data.mafra.go.kr) 데이터 상세 화면의 파일 내려받기(로그인 없이 됨). 받은 파일은 이름만 바꾸고 내용은 손대지 않음.
- 출발점 문서: 식품안전지수 길라잡이 PPT 49장(GAP 정보서비스, 국립농산물품질관리원, http://www.gap.go.kr/portal/bizgap/propelCurrentState.do → 농산물우수관리인증 → 추진현황 → GAP인증현황), 50장(분모: 2018 농림축산식품 주요통계 '경지이용상황'). PPT 지표 상세표에는 지표번호 RA-3 '경지면적 중 GAP 인증 농산물 재배면적 비율'로 적혀 있음. 엑셀 protocol 의 원자료 시트에는 'R1 경지면적 중 GAP 인증 농산물 재배면적 비율', 가중치 시트에는 'R 1 유기/무농약 농산물 재배면적 비율'로 이름이 다름.
- gap.go.kr 추진현황 화면의 'GAP인증현황 — 연도별 현황' 표는 전국 1줄/년(연도, 인증품목, 인증기관, 관리시설, 인증건수, 농가수, 재배면적)뿐이라 받지 않음(2026-10-19 화면에 2025년 값까지 있음: 인증건수 13,077, 농가수 124,881, 재배면적 135,669ha).
