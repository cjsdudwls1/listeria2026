## ⑥ 판단이 필요한 점

1. **새 파일 놓는 자리** — 02 의 `SAMPLE` 경로가 `리스테리아ML\data\listeria_data.parquet` 로 박혀 있다. 옛 파일을 다른 이름으로 옮기고 새 파일을 같은 이름으로 둘지, 02 의 경로를 바꿀지.
2. **칼럼이 다르면** — 빠지거나 이름이 바뀐 칼럼은 ①의 '칼럼마다 읽는 스크립트'가 멈춘다. 이름을 맞춰 넣을지(값은 그대로), 스크립트를 고칠지. 새로 생긴 칼럼은 02 가 시료_시군구에 그대로 넘긴다 → 쓸지 말지.
3. **기준일이 2026-06-30 을 넘으면** — 시험 기간은 `모델 학습시 유의사항.md` 에 2025-07-01 ~ 2026-06-30 고정으로 적혀 있다. 그런데 3차 `cfg3.py` 는 `dates.data_end` 가 비어 있으면 시료의 가장 늦은 기준일로 시험 1년과 겹 3개를 다시 계산한다(끝이 늦어지면 시험 해가 밀림). 고정 규칙을 지키려면 `config3.json` `dates.data_end` = `2026-06-30`. 1·2차 코드는 1차 `config.py` 의 `TEST_END = 2026-06-30` 을 넘는 행이 있으면 `data.assign_split` 에서 멈춘다(1·2차를 다시 돌릴 때만 문제).
4. **'학습 기간 끝 2024-06-30' 이 코드에 박힌 곳** — 02 `TRAIN_END`(옹진군 좌표), 06 `TRAIN_END`(식품 속성 최빈값), 1차 `config.py` `TRAIN_END`·`VAL_START`·`VAL_END`·`TEST_START`·`TEST_END`, 2차 `e2ae.py`(AE 정상 행 = 기준일 ≤ 2024-06-30), 2차 `e2cfg.py` 고위험 품목 기대값(`GROUP_EXPECTED`·`GROUP_C4_EXPECTED_TRAIN_SAMPLES` — 다르면 '다름' 표시만, 멈추지 않음), 3차 `cv.py` 의 학습 분할 날짜(지금 `cfg3.py` 로 옮기는 중). 3차는 학습 자료 끝이 2025-06-30, 겹 1 학습 끝이 2022-06-30 이다. 06·02 를 그대로 둘지, 3차 날짜에 맞출지(맞추면 겹마다 식품 속성표가 달라짐).
5. **02 가 멈출 때** — 시군구를 못 정한 새 행이 사유 A~D 에 안 맞으면 멈춘다. 새 사유와 처리(삭제 또는 대응표 추가)를 사용자가 정한다. 대응표(`data\시군구_코드_대응표.xlsx`)는 (주소, 코드) 짝이 똑같을 때만 걸리므로 새 주소는 대응표에 없다.
6. **DB 접속** — 01 은 공용 DB 에 읽기 전용으로 접속한다. 기간이 늘었거나 새 법정동 코드가 법정동 표에 없을 때만 필요하고, 그때도 사용자 허락을 받는다.
7. **옹진군 대표 좌표** — 학습 기간 옹진군 시료 좌표의 중앙값이라 시료가 바뀌면 달라질 수 있다. 달라지면 03·05 를 다시 돌린다(옹진군 칸만 바뀜).
8. **SPI 파일 갱신** — 지금 CSV 는 2026-10-06 까지다. 새로 받으려면 기상자료개방포털 로그인이 필요하고(사용자 작업), 05 의 입력 파일 이름도 바꿔야 한다.
9. **캐시 지우기** — 3차 입력 캐시와 2차 기상 요약 캐시는 이름표가 다른 표의 변화를 알아채지 못한다. 지울 목록(③)을 사용자가 확인한 뒤 지운다.
10. **새 품목 코드** — 새 3단계 코드는 06·생장 범위 품목표에 새 줄이 생긴다(다시 만들면 됨). 새 2단계 코드(C 로 시작)가 생기면 HACCP 유효 구간표를 다른 세션에 다시 요청한다. 3차는 고위험 품목을 겹마다 그 겹 학습 자료로 다시 고른다.
11. **제품명 정규식** — 옛 학습 기간으로 고른 21개를 그대로 쓴다(제품명 세션 회신). 새 자료로 다시 고를지는 따로 정한다.
12. **3차 사양의 숫자** — `사양_20261020.md` 1절 표의 겹별 검출(230·196·164)은 옛 파일 기준이다. 새 수치로 표를 고칠지.
13. **옛 판과 값 비교** — ⑤의 '겹치는 날짜 값이 같은지'는 비교 스크립트가 아직 없다(시료 파일 비교만 있음). 만들지 정한다.
