# 제품명 변수(N0·N2) 검증 근거 (2026-10-19)

C4·제품명 실험 코드 검증 때(독립 검증 에이전트) 만든 스크립트와 결과를 작업 임시 폴더에서 옮겨 둔 것입니다. 스크립트 안의 경로는 그때 임시 폴더 기준입니다.

## 1. 그날 시료 수와의 관계 (N2·N0 이 검사량 정보를 간접적으로 담음)
- 근거: `v1_report.json` 의 `count_proxy`, 계산 = `v1_indep.py` 169~190행.
- 단위x날짜 행 291,812개(학습·검증·시험 전체)에서:
  - N0(TF-IDF) 0 아닌 칸 수 vs 그 행 시료 수(n_rows): 스피어만 순위상관 0.507
  - N2(뭉치 멀티핫) 켜진 뭉치 수 vs 시료 수: 0.496
  - 시료 수 vs 검출 여부: 0.065
- 시료 수별 검출률(`y_rate_by_n_samples`): 1건 0.157%(192,075행) … 6건 이상 2.25%(19,156행).
- N2 켜진 뭉치 수별 검출률(`y_rate_by_n2count`): 0개 0.12%(219,586행) … 4개 이상 3.21%(5,010행).
- n_rows 자체는 입력에 없음(`v1_report.json` `N0_keys.n_rows_eq_n_samples` = 그 행 시료 수와 같음을 확인한 칸).

## 2. TF-IDF 어휘·idf 가 학습 기간 시료로만 정해졌는지
- 근거: `v4_idf_report.json`(글자 어휘 300개), `v4b_idf_word_report.json`(낱말 1그램 180개), 계산 = `v4_idf_period.py`, `v4b_idf_word.py`.
- 가정: 문서 = 시료 1건의 제품명(소문자, 연속 공백 하나로), idf = scikit-learn smooth 식(ln((1+N)/(1+df))+1).
- 글자 어휘 300개: 학습 기간 시료(mnfctur_de ≤ 2024-06-30, N = 458,572)로 계산한 idf 와 최대 차이 8.9e-16(300/300 일치).
  전 기간(N = 628,517) 중앙 차이 0.060, 학습+검증(N = 541,677) 0.033 으로는 맞지 않음.
- 낱말 1그램 180개(토큰 규칙은 추정): 학습 기간 중앙 차이 0.001, 전 기간 0.093, 학습+검증 0.057 → 학습 기간과 맞음.
- 결론: 어휘·idf 는 학습 기간 시료로 정해짐(검증·시험 정보 유입 없음). 단위x날짜 행을 문서로 본 idf(`v1_report.json` `idf_test`)는 맞지 않음 - 문서 단위는 시료 1건.
- 코드 쪽 설명(e2nb.py·표 '설정' 시트 N0 줄)의 '확인 필요' 문구는 결과 기록(code_md5)을 바꾸지 않으려고 고치지 않았음 - 이 문서가 근거.
