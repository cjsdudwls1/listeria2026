### 1-2. 지표
| 지표 | 정의 |
|---|---|
| PR-AUC | sklearn `precision_recall_curve` → `auc`(trapz, `drop_intermediate` False), 동점은 정답과 무관한 순서로 풀어 쌍마다 한 점(부록 A-12), threshold 는 원 예측값 |
| h 별 PR-AUC | h 마다 채점 쌍으로 계산, 검출 0건·전부 검출인 h 는 NaN |
| 구간 가중 PR-AUC(주 지표) | 0.5 × 평균(h 1~20) + 0.3 × 평균(h 21~40) + 0.2 × 평균(h 41~60), NaN 인 h 는 그 구간 평균에서 뺌, 구간이 통째로 NaN 이면 남은 구간 가중치를 합 1 로 다시 나눔. 고르기·반복 수·튜닝 목표·보고 모두 이것 |
| 60일 통 PR-AUC | 모든 (시료, h) 쌍을 이어 한 번 계산 |
| 부적합률 대비 배수 | 구간 가중 PR-AUC ÷ (h 별 검출 비율을 같은 가중으로 합친 값), 60일 통 PR-AUC ÷ 전체 쌍 검출 비율 |
| threshold 지표 | test 쌍 전체 Recall·Precision·F2·혼동행렬(TP·FN·FP·TN), Recall 은 test 쌍 전체와 구간 가중(h 별 Recall 의 구간 평균(검출 0건 h 는 NaN, 구간 NaN 재가중은 구간 가중 PR-AUC 와 같음)을 0.5·0.3·0.2 로, 같은 threshold) 둘 다 보고 |
| 상위 q% 포착률 | 상위 q%(1·5·10·20) 쌍이 잡은 검출 ÷ 전체 검출(동점은 위 규칙으로 없음) |

- threshold: 모든 fold validation 예측(모든 h, 씨앗 평균 판은 씨앗 평균)을 합쳐 Recall ≥ 0.8 인 값 중 Precision 최대 → refit 모델 test 예측에 그대로. threshold 용 fold validation 예측은 refit 과 같은 공통 반복 수 N 으로 따로 뽑음(같은 fold 모델, 트리 수만 다르게 — 추가 학습 없음), CV 점수는 교차 N. refit 은 공통 반복 수 N, fold 별 교차 N·최적 N·train 행 수와 공통 반복 수 N 을 설정 덤프에 기록
- 동점: 모든 점수 비교(고르기·채택·반복 수·튜닝 채택) = 소수 4자리 반올림 뒤 비교, 같으면 상승 아님. 같을 때 반복 수 N = 작은 쪽, threshold = Precision → Recall → 큰 값, 판·설정·상위 3개 = 판의 학습 횟수(부록 A-12) 적은 쪽 → 판 이름 순, 4-c 품목 = 검사 수 많은 쪽 → 코드 순, Theil's U 칼럼 = 고유값 수 적은 쪽 → 이름 순
- 동점 많은 판: 가장 큰 동점 묶음 ≥ CV validation 쌍의 1% 면 표에 '동점 많음' 표시, 후보 그대로(부록 A-12)

### 1-3. 보고 형식
- 단계마다 판 목록·고르기 규칙을 그 단계 test 채점 전에 적어 둠, test 를 본 뒤 추가한 판은 기록만(고르기 대상 아님)
- test 막기: test 예측 생성·저장은 단계마다 허용, test 정답(y) 채점은 각 단계가 끝난 뒤 보고 때만(3-3 바퀴별 test 는 단계 3 끝난 뒤 한꺼번에), 고르는 코드가 test 정답(y)을 읽으면 멈춤
- 단계별 표: 칼럼은 부록 A-12, test 점수는 국내 + 해외 전체 하나, 표마다 기준 줄, 표 주석·단계별 그림은 부록 A-13
- 표마다 '같은 validation 으로 고른 횟수'(누적) 적음 — 셈법·딥러닝 값을 물려받는 판 표시(부록 A-12)
- 사람이 정하는 판단(줄이기 목록·3-3 단위 빼기 여부·§9 회신 반영)은 CV·시간 자료만 보고 정함(test 점수 안 봄), 기본값(§8 줄이기 (가)·(나) 순서·§8 3-3 단위 빼기 기본·§9 회신 전 기본값)을 따르고 바꿀 때만 이유 기록, 판단마다 시점·본 자료(단계 0 의 나라별 표·Theil's U 재현 포함)·그때까지 본 test 보고 목록 기록. 단계 0 뒤에 생긴 구현 세부는 그 세부가 영향을 주는 단계의 test 채점 전에 기록. §9 회신이 그 단계 test 보고 뒤에 와서 판이 바뀌면 그 판은 기록만(고르기 대상 아님)
- 마지막: 단계 1 → 최종 대표 판(대표 판 = 단계마다 CV 1위 판) test 변화 표 1개 + 최종 모델 test 전체 지표 + 최종 모델 보조 표·좌표 차이 민감도(부록 A-12). 판 이름 = 단계-판(예: 1-CAT-W060-sum / 1-CAT-W060-raw, 4-b)

- train 행: d ≤ train 끝인 시료마다 h 1개, T = d − h. h = `lims_data_key` md5 해시로 1~60 배정(부록 A-1, 해외 행 추가 전후 국내 h 불변), 모든 fold·refit·딥러닝에 같이 씀
- 부스팅 반복 수: 모든 fold 최대 2,000 반복·같은 학습률 → fold validation 구간 가중 PR-AUC 를 10 ~ 200 은 10 트리마다, 그 뒤 50 트리마다(56개 시점). fold f 점수 = 교차 N(자기 점수로 안 고름), refit = 공통 반복 수 N(행 수가 늘어도 그대로), 추가 학습 없음
- 학습률: XGBoost·LightGBM 기본값, CatBoost = fold 별 자동 학습률 평균(읽는 법 부록 A-12) → 그 값으로 모든 fold·refit 학습. RF·ExtraTrees·로지스틱은 기본 설정, 반복 수 고르기 없음. refit: d ≤ 2025-06-30 전체로 CV 에서 고른 설정·N·학습률 그대로 재학습 → test 1회(부스팅 refit 도 최대 2,000 반복까지 학습한 뒤 트리 수 지정 예측 — 규칙 판·-n 판이 같은 refit 모델을 각자의 N 으로 씀). 새 판(단계 2~8)도 같은 함수. ④ 는 예외 — 라이브러리 기본 반복 수, 반복 수 고르기·트리 수 지정 채점 없음

## 4. 기상 입력
### 4-1. window
- [S, E]: S ~ T−1 = 관측, T ~ E = 예보(운영 땐 예보값, 예보 길이 = 발표 당일 포함 11일). 학습 땐 관측값, validation·test 쌍도 예보 칸 = 관측값(완전 예보 가정). h ≤ 11 이면 E = d − 1, h ≥ 12 면 E = T + 10 이고 T+11 ~ d−1 의 g 일은 window 밖(입력 없음). 원천 공개 지연 시 관측·예보 경계는 부록 A-13
- 일 단위 변수 전부(기상 19·습도·이슬점·SPI·단기 파생·생장식·생장 범위 기상) = E 끝. 토양 검정·외부 지표 = T−1 기준(§5), 이력·타겟 인코딩 = C 기준(§5-1)
- 한 설정 안에서는 모든 h 가 같은 W. 시간 칼럼: 트리 = h·g 둘 다(⑦-T 는 g 만, 2-1 표 AE·VAE 는 트리 갈래 1위 설정의 숫자 칼럼이라 h·g 둘 다), 딥러닝·결합 모델 = g 만(② 는 없음, 부록 A-8). 관측 일수 = max(0, W − min(h, 11)), 검산 예시는 부록 B-7

### 4-2. 요약값·원값·시퀀스·결측
- 요약(변수마다): E 부터 거꾸로 10일 구간 평균 W/10 개(b01 = E−9 ~ E, b02 = E−19 ~ E−10, …) + window 평균·표준편차(ddof 0)·최소·최대·기울기, NaN 무시, 관측·예보 칸을 한 줄로 이어 계산. 기울기 = window 날짜(일)에 대한 최소제곱 기울기(단위/일, NaN 뺌)
- 원값: lag001 = E, lag002 = E−1, …, lagW = S(이름은 E 기준). 시퀀스(딥러닝): S ~ E 시간순 W일. 요약 판 = 요약 칼럼만, 원값 판 = lag001~lagW 만, WX1(SPI) window 칼럼도 판의 방식을 따름, 다른 파생(WX2~WX7)은 방식 무관
- 이동평균 차감: a_t = x_t − ([t − N_ma, t − 1] 평균(t 제외), 값 있는 날만 평균 — 다 결측이거나 x_t 결측이면 a_t 결측) → window 평균·최근 10일 평균·최댓값(NaN 무시, 값 있는 날 0 이면 결측), 칼럼 이름 `<변수>_anom{N_ma}_*`. 트리 N_ma ∈ {5, 7, 15, 30} 은 단계 3-1b, 딥러닝 채널 N_ma = 30(단계 8 튜닝 범위)
- 결측: XGBoost·LightGBM·CatBoost·RF·ExtraTrees 는 NaN 그대로(0 이 실제 값인 강수·지중온도 포함 0 채움 금지). 로지스틱·딥러닝은 그 모델 train 평균·표준편차(NaN 빼고)로 표준화 → 결측 0 → 결측 표시 칼럼·채널 = 그 모델 train 에 결측이 있는 칼럼(표준화 통계와 같게 모델마다 — 같은 행 모델을 여러 fold 에 같이 써도 그 모델 것 그대로). soil_t_nas·no2·co·so2 는 해외 행에서 늘 결측 — 그 결측 표시는 '해외 구조적 결측' 1칼럼으로 합침(해외 행의 soil_t_nas·no2·co·so2 칼럼별 결측 표시 = 0, 합친 '해외 구조적 결측' 칼럼만 1), 국내 행 결측은 칼럼마다 표시. 목록에 없는 칼럼의 결측 = 0(표시 없음), 그 칼럼 목록 기록

- 2-1 이상 점수: AE·VAE × 표·시퀀스 4종(부록 A-8), train 불검출 행만, 전역 블록 OOF + 엄격 OOF. 표 입력 = 트리 갈래 1위 설정의 숫자 칼럼(window 칼럼·h·g, 표준화·결측 0 + 표시), 시퀀스 = 딥러닝 갈래 1위(1-2 블록 5 순위 1위 구조·W_DL)의 W_DL. 원 점수 = AE 복원 MSE·VAE 음의 ELBO, (시료, h) 쌍마다. 단독 판 CV·threshold = 엄격 OOF 의 fold train 전체 모델 예측, PR-AUC·test 보고(후보 아님). 이상 점수 = 원 점수의 robust z(모델 사이 크기 맞춤, 식·기준 행 부록 A-8)
- 2-2 스태킹: 트리 상위 3개마다 5판(설정 그대로, 부스팅은 반복 수만 다시)

  - (b) 트리 입력 + 딥러닝 상위 3개 확률 3칼럼 + 이상 점수 4칼럼
  - (c) 트리 입력 + 이상 점수 4칼럼
  - (d) 트리 입력 + ⑥(시계열만 딥러닝) 확률 2칼럼(엄격 OOF)
  - (e) LIMS 입력(범주 5 + h·g) 트리 + ⑥ 확률 2칼럼(엄격 OOF) — 기상 window 없이 시계열 예측만 붙인 판
- 2-3 앙상블(추가 학습 없음): (시료, h) 쌍마다 확률 단순 평균 — 트리 상위 3개 평균 / 트리 상위 3 + 딥러닝 상위 3 평균. CV = 구성 트리 교차 N 예측 평균, threshold = 공통 반복 수 N 예측 평균(딥러닝 = 엄격 OOF 예측)
- 2-4 결합 모델: 결합-기본·결합-VAE(§7), 시간순 3 fold + refit(다른 모델 입력으로 안 쓰여 블록 OOF 없음) → 최종 고르기 후보
### 단계 3. 파생변수
- 모델: §6 대상 규칙으로 고른 구조의 트리 모델(알고리즘·W·입력 방식 고정, 부스팅은 반복 수만 다시), 딥러닝 부분 고정. 앙상블이 단계 3 대상이면 대표 트리 하나로 판정(부록 A-12)
- 3-1 k: 이력 그룹(HIS1~HIS4)만 더한 판으로 k ∈ {10, 30, 50, 100, 200} 비교 / 3-1b N_ma: 차감 칼럼만 더한 판으로 N_ma ∈ {5, 7, 15, 30} 비교 / 3-2 §5 후보 전부 넣은 판 / 3-4 전부 넣은 판·최종 판 refit·test(단계 3 최종 판 = 3-3 끝 판과 3-R 기준 중 CV 1위)
- 3-3 변수 빼기(그룹 빼기 → 단위 빼기): 시작 판 = 3-2 판, 빼기 단위 149·그룹 G = 47(기상 9 + 비기상 38) — 단계 0-8 에서 확정, 단위·그룹·중요도 계산·기록은 부록 A-5(기호 A-12), 기한 확인·줄이기 = §8 줄이기 (나)
  - 중요도: 시작 판과 채택 있던 바퀴 끝마다 그룹 칼럼을 `h_block` 으로 섞는 permutation importance(3 fold × 섞기 M 회 — M·I·ψ_f·π 정의 부록 A-5). 3 fold 모두 ψ_f ≥ 0.8 이고 3M 칸 평균 I > 0 인 그룹은 그 바퀴 시도 안 함
  - 나머지를 π 낮은 순(같으면 평균 I 낮은 순 → 그룹 번호, 바퀴 안 순서 고정)으로 그룹째 빼고 3 fold 재학습(N 다시, 학습 씨앗 1개) → CV 평균 상승 + 3 fold 중 2개 이상 상승이면 채택(새 기준), 아니면 되돌림. 채택 없는 바퀴에서 그룹 빼기 끝(최대 20바퀴)
  - 단위 빼기: 남은 다단위 그룹의 단위 전체를 한 줄(π 낮은 순 → 평균 I 낮은 순 → 단위 번호)로 세워 그룹 빼기와 같은 규칙(단위 중요도·건너뛰기·채택 규칙·채택 없는 바퀴에서 끝, 최대 20바퀴)으로, 그룹 마지막 단위는 안 뺌, 할지는 §8 3-3 단위 빼기 기본대로
- 3-R 리서치팀 변수 비교(기준 = 3-R 기준): 3-R1 = 기준 + t3·rain_lag2·wind_lag2·rain_mean25·solar_23·trange7·rh1·td1 + 축사 4칼럼, 3-R2 ~ 3-R10 = 기준 + 하나씩(앞 8개 각각 + 축사 4칼럼 묶음). 3-R1 에선 칼럼별 중요도 + 리서치 변수 전체 한 그룹 중요도 + 각 변수가 속한 기상 그룹 중요도(중요도 계산법 = 부록 A-5 와 같음). 이 변수들은 3-2 후보에도 들어가며 빼기 결과(그룹째 빠짐·단독으로 빠짐·남음)를 칼럼마다 기록(딥러닝 칼럼이 있을 때 부록 A-12)
### 단계 4. 다운사이징
- 줄이기 칼럼: fold 1~3·refit train 각각으로 Theil's U = U(y | x)(칼럼이 검출을 설명하는 정도) 계산(칼럼별 고유값 수·고유값 비율 같이). 줄이기 칼럼 = 그 fold(refit) train 의 Theil's U 1위 — fold 마다 따로 정함(CV 가 검증하는 것은 '그 train 의 1위 칼럼으로 줄이기' 절차), 칼럼별 Theil's U 표는 fold·refit 마다 저장, 대상 칼럼은 부록 A-6
- 줄이기: fold train 기간에 검출 0건인 줄이기 칼럼 값의 행을 train 에서 뺌(제품명은 문자열 그대로), 검출 1건 이상인 값은 남김, validation·test 는 전부(학습에 없던 제품도 그대로 예측). 이력·타겟 인코딩은 §5-1 규칙대로, CatBoost 는 범주 칼럼을 스무딩 검출률 숫자로 넣음(부록 A-6)
  - 점수 0·1 판정: 줄이기 전 fold(refit) train 의 3단계 품목 집계로, 검출 0 품목 = 점수 0, 검출만 있는 품목 = train 에서 빼고 점수 1(판정·적용 세부, 규칙 판과 -n 판의 N·threshold 구분 부록 A-12)
  - 4-a·4-a0·4-b·② 마다 같은 모델의 원 예측 그대로인 판(4-a-n·4-a0-n·4-b-n·②-n)도 후보(학습 없음)
- 4-a: 줄인 train + 단계 3 최종 판 설정, 줄인 train 행에 h 1~60 전부. 미리보기 = 단계 1 직후 트리 갈래 1위 설정으로 4-a 1판(고르기에 안 씀, 보고용, test 채점은 단계 4 보고 때) / 4-a0: 줄인 train + 시료당 h 1개(h 1~60 복제 효과를 보는 대조 판(4-a 와 h 만 다름)) / 4-S0(단계 3 최종 판 예측에 점수 0·1 덮어쓰기만 — 검출만 있는 품목의 train 행 빼기는 없음): 학습 없음, 기록용, 후보 아님
- 4-b: 4-a + SMOTENC(fold·refit train 안에서만, (h, `src_route`, season) 칸마다 양성 20%, 범주·범주에서 정해지는 칼럼은 출발 행 값 — 부록 A-6). 4-a·4-a0·4-b 의 딥러닝 값·이상 점수 = 엄격 OOF 로 만듦(부록 A-12)
- 4-c 고위험 품목 모델: fold train 검출 비중(그 품목 검출 ÷ 전체 검출) 상위 5개 3단계 품목의 시료만으로 학습·채점 — 4-c = 단계 3 최종 판 입력, 4-c-L = LIMS 입력만(범주 5 + h·g), 같은 시료의 단계 3 최종 판과 PR-AUC 로 비교 보고(세부 부록 A-12)
- 산출: 판별 CV·refit·test, fold 별 줄인 행·검출 수, Theil's U 표, 보고 세부 부록 A-12
### 단계 5·6. 손 교수 방식
- 해 = d 의 달력 연도. 5: fold train 의 해마다 양성 전부 + 그해 음성 무작위 4 × 양성 수 / 6: 해마다 그해 양성 전부 + 그해 양성 수 × 4 개 음성을 '그해 양성이 나온 칸(3단계 × 시군구, 해외 3단계 × 나라)' 들의 그해(d 가 그해인) 음성 풀에서 무작위, 모자라면 풀 전부. 5·6 모두 refit train 에도 같은 규칙
- 공통: 씨앗 번호(0~4) = 음성 뽑기·모델 학습 모두 그 번호, 씨앗 0~4 예측 평균, 반복 수 N 은 씨앗 0~4 평균 예측 곡선으로 §3 함수 1회, 단계 3 최종 판 설정(반복 수만 다시), 이력·인코딩(§5-1), validation·test 전부 예측
### 단계 7. 타겟 인코딩 단독
- 7-a: 단위 (3단계, `sgg`) 스무딩 검출률 p̂_u 를 그대로 점수로(공식 부록 A-3), 길이 1년·5년·전체와 k_u·k_p3 ∈ {10, 30, 50, 100, 200} 은 7-a CV 로. C 규칙(§5-1)이라 validation·test 쌍은 모든 h 같은 값
- 7-b: 7-a 에서 고른 (길이, k_u, k_p3) 의 p̂_u·p̂_p3 2칼럼(§5-1)만 넣은 트리(단계 3 최종 판 알고리즘, 기본 설정, 반복 수만)

- 딥러닝: 대상 판에 딥러닝 확률 칼럼이 있거나 대상이 트리 + 딥러닝 앙상블일 때만 그 딥러닝 모델(상위 3개면 3개, (d)·(e) 면 ⑥ 2종)을 튜닝, 이상 점수(AE·VAE)는 튜닝 안 하고 그대로, 딥러닝 단독 후보(1-2 상위 3·⑥·⑦-D)는 튜닝 안 함. 튜닝 = 시도 20회(N_ma·손실 포함, 범위·설정 부록 A-7)

  - 고른 설정으로 8-TD 만들기·튜닝 검증 쌍과 겹치는 블록 기록(부록 A-12). 할지·도구는 §9(회신 전 = 안 함)

## 7. 딥러닝
### 7-1. 입력·예측
- 입력 = 기상 시퀀스(x_seq)·정적 칼럼(x_static)·지역·품목 범주 임베딩(x_cat)(② 는 부록 A-8 ② 입력 목록), 채널·칼럼 구성·범주 번호표(OOV)·결측 표시 채널·표준화 통계는 부록 A-8

### 7-3. 블록 OOF·엄격 OOF
- 전역 블록(d 기준): 1 = 2015-04-07 ~ 2017-06-30, 2 = 2017-07-01 ~ 2019-06-30, 3 = 2019-07-01 ~ 2021-06-30, 4 = 2021-07-01 ~ 2023-06-30, 5 = 2023-07-01 ~ 2025-06-30. 블록마다 나머지 4블록으로 학습한 모델이 그 블록 시료 예측(전역 블록 OOF)
- 엄격 OOF(딥러닝 값이 들어가는 모든 CV — 스태킹·앙상블·단계 3~8·최종 고르기): fold f 마다 train 행 값 = fold train 안 블록 OOF, validation 값 = fold train 전체로 학습한 모델
  - fold 안 블록 = 전역 블록 경계를 fold train 끝에서 자름, 같은 행으로 학습하는 모델은 한 번만 학습해 같이 씀(부록 A-12). 대상 = 딥러닝 상위 3개 + 이상 점수 4종 + ⑥ 2종(추가 판 ④ 도 같은 규칙), 횟수는 부록 A-9
- refit·test 값 = 전역 블록 OOF(train 행) + test 전 전체 학습 모델(test 행, 2015-04-07 ~ 2025-06-30)
- 블록 5 대조 판(순위·튜닝에 쓰인 시료의 딥러닝 값을 결측으로 둔 판) — 조건·횟수 부록 A-12

- WX3(생장식): θ = 날마다 avg_temp. mean = window 평균, mean10 = 최근 10일(E−9 ~ E) 평균, sum = window 합, npos = γ_T(θ) > 0 인 날 수
  - 계수 = `리스테리아ML2\data\데이터셋\리스테리아 생장식.xlsx` 시트 '(완료) 리스테리아 모노사이토제네스' 값 그대로: Silva 2020 온도 F6(Tmin −1.273·Topt 37.26·Tmax 45.12)·pH F26(4.303·7.085·9.483)·aw F19(0.894·0.995, awmax 1.00 = D6 식 안)·µopt J6(0.409), Tienungoon 2000 온도 F15·상수 0.536·Tmax 48(D15·J15)·aw F21·pH F28(Scott A·L5 두 균주, 값은 아래 표), Ivanek 2009 F41(−1.79·0.13). 구현 참고 = git 42365bb 의 `리스테리아ML2\exp\2_고도화\src\e2fg.py`
  - γ_T(θ) = (θ − Tmax)(θ − Tmin)² ÷ {(Topt − Tmin)[(Topt − Tmin)(θ − Topt) − (Topt − Tmax)(Topt + Tmin − 2θ)]}, Tmin < θ < Tmax 밖 0. γ_aw = 같은 꼴(aw·awmin·awopt·awmax). γ_pH = (pH − pHmax)(pH − pHmin) ÷ [(pHopt − pHmin)(pH − pHopt) − (pHopt − pHmax)(pHmin − pH)], 범위 밖 0

  - gr2 = µmax = µopt·γ_T(θ)·γ_pH·γ_aw 와 P_scottA·P_L5 = 1 ÷ (1 + e^(−z)), z = b0 + b1·ln(θ − Tmin) + b2·ln²(θ − Tmin) + b3·ln{1 − e^(0.536(θ − 48))} + b4·ln(aw − awmin) + b5·v + b6·v², v = ln(1 − 10^(pHmin − pH)), z 의 Tmin·awmin·pHmin = Tienungoon 균주별 값(Silva 값 아님, 아래 표), 젖산 항 0, 로그 안이 0 이하면 P = 0 → 각각 요약 3(mean·mean10·max) = 9칼럼

- 단계 1-2 예측 범위: 전역 블록 OOF·엄격 OOF·test 모델·트리 train 행(자기 h) 예측은 상위 3개만(40 설정의 블록 5 모델은 fold 2·3 채점 쌍과 구조별 1위 test 만 예측, 줄이기는 §8). 단계 4 판(4-a·4-a0·4-b)·① 의 train 행은 fold 안 블록·전역 블록 모델로 (시료, 그 행의 h) 전부 추론(4-a·4-b = h 1~60, 4-a0 = 자기 h, ① = h 1), 이상 점수도 같게. 산출: 구조 × W_DL 점수 표, 상위 3개 test, 상위 3개 OOF·test 예측((시료, h) 60가지)
- 단계 3 대상에 딥러닝 칼럼(확률·이상 점수)이 있을 때(§6 단계 3): 3-3·3-R 표에 '기준 판에 딥러닝 칼럼 있음' 표시, 3-R1 을 딥러닝 칼럼 빼고 한 번 더(3 fold + refit = 4, 기록용, 후보 아님)
- 단계 3 대상이 앙상블일 때: 단계 3 판정·3-R·단계 4~7 은 대표 트리(구성 트리 중 단계 1 CV 1위) 하나로(단계 8 점수는 다음 줄), 3-R 표의 기준 = 대표 트리 단독 점수(리서치팀 보고도 같음), '3-3 끝 판 vs 3-R 기준' 비교·3-4·최종 후보는 다른 구성 트리를 같은 변수(자기 설정, 반복 수만 다시)로 다시 학습한 앙상블 CV·test 로. 단계 4~7 보고의 '단계 3 최종 판' 비교는 대표 트리의 단계 3 최종 변수 판 점수로. 단계 8 대상이 앙상블이면 대표 트리만 튜닝하고 다른 구성 트리는 그 앙상블의 구성 트리 그대로 두며(다시 학습 안 함), 8-T 앙상블 표에 대표 트리 단독의 튜닝 전후 CV·구성 모델별 예측 분위수를 같이 적음
- 단계 8 점수(§6 단계 8): 시도·채택·8-T·8-TD 점수는 대상 판과 같은 방식으로 계산 — 점수 0·1 규칙은 대상 판을 따름(규칙 판이면 덮어쓴 예측, -n 판이면 원 예측), 앙상블이면 시도·채택 판정은 대표 트리 단독 CV·8-T·8-TD 판 점수는 앙상블 CV, 씨앗 평균 판이면 시도는 씨앗 0, 채택 직전 '고른 설정 대 기본 설정' 을 씨앗 0~4 평균 CV 로 한 번 더 비교(고른 설정 씨앗 학습은 부록 A-9 미포함 +16 에 들어 있음). 딥러닝 칼럼은 빼고 튜닝하므로 대상 판에 딥러닝 칼럼이 있으면 첫 시도(기본 설정)도 칼럼을 뺀 입력으로 3 fold 학습
- 점수 0·1 판정(§6 단계 4): 줄이기 전 fold train(refit 은 줄이기 전 refit train)의 3단계 품목 집계로 판정(줄이기 칼럼과 무관) — 검사 1건 이상·검출 0 인 3단계 품목 = 점수 0, 검사 1건 이상·불검출 0 인 품목(검출만 있음) = train 에서 빼고 점수 1. 점수 0 품목의 train 행은 줄이기 칼럼 규칙대로(남은 행은 학습에 씀), validation·test 예측 = 0. 검출만 있는 3단계 품목 빼기와 검출 0건 줄이기 칼럼 값 빼기는 둘 다 줄이기 전 fold train 으로 센 뒤 함께 적용. 규칙 판(4-a·4-a0·4-b·②, 규칙을 따른 ①·⑤) = 덮어쓴 예측으로 반복 수 곡선·교차 N·공통 반복 수 N·threshold / -n 판 = 원 예측으로
- 단계 4 보고(§6 단계 4): fold 별 점수 0·1 규칙에 걸린 품목 수·validation·test 쌍 수·검출 수·비율(점수 0 묶음·점수 1 묶음 따로), threshold ≤ 0(점수 0 묶음 값)이면 전부 양성 판정 — 표에 표시·담당자 알림, '단계 3 최종 판과의 차이에 점수 0·1 규칙·(CatBoost 면) 범주 인코딩 변경이 섞임' 한 줄
- 4-c·4-c-L(§6 단계 4): refit·test 의 5개 품목 = refit train 기준 상위 5개. 단계 3 최종 판 그대로(줄이기·점수 0·1 없음, 시료당 h 1개, CatBoost 범주 그대로)에 품목만 제한, 채점·threshold 는 그 품목 쌍으로 §1-2 규칙(threshold 지표는 자기 threshold 로 따로), 4-c-L 은 4-c 와도 비교. 보고 = fold 별 상위 5 품목 목록·fold 별 점수를 같이 적고, 표 주석에 'CV 평균은 품목을 고르는 절차의 성능'
- fold 안 블록(§7-3) = 전역 블록 경계를 fold train 끝에서 자름: fold 1 = 블록 1·2·3 + 2021-07-01 ~ 2022-06-30(4블록), fold 2 = 블록 1~4, fold 3 = 블록 1~4 + 2023-07-01 ~ 2024-06-30(5블록)
- 같은 행 모델 재사용(§7-3): d ≤ 2021-06-30 모델 = fold 1 넷째 블록(2021-07-01 ~ 2022-06-30) OOF = fold 2 블록 4 OOF, d ≤ 2023-06-30 모델 = fold 2 fold train 전체 = fold 3 다섯째 블록(2023-07-01 ~ 2024-06-30) OOF = 전역 블록 5 OOF(= 단계 1-2 블록 5 모델)
- 최종 모델 보조 표(§1-3, 고르기에 안 씀): 최종 모델 test 를 품목 묶음 × 국내·해외별로도 채점. 품목 묶음 = 농산물(1단계 식물성)·축산물·수산물(1단계 동물성의 2단계 축산물·수산물)·가공식품(1단계 가공식품)·기준규격외·그 밖·'코드없음', 1단계 = `p2` 를 `ba_data.t_prdlst_cl.hrnk_prdlst_cd` 로 따라 올라간 최상위 분류
- 좌표 차이 민감도(§1-3, 1개, 학습 없음): 최종 모델 test 의 국내 행 예보 칸(T ~ E) 날마다 단계 0-3 에서 잰 시군구·변수별 평균 차이를 더하고, SPI 예보 칸·WX2~WX6 은 다시 계산, 딥러닝 값·시퀀스는 test 모델로 다시 추론(학습 없음), 해외 행은 그대로
- 학습률 읽기(§3): CatBoost 는 fold 마다 iterations = 2,000 으로 학습을 시작해 첫 반복 뒤 콜백으로 멈추고 정해진 learning_rate 를 읽음(학습 횟수 아님)
- 범주 처리(§6 단계 1-1): 범주 칼럼 전부(범주 5·season·aw_label, aw_label null = '결측' 범주 — 부록 A-4) — XGBoost·LightGBM = pandas category(범주 목록 = 그 모델 train 값, 없던 값 = 결측; XGBoost `enable_categorical=True`, LightGBM 범주 칼럼 지정), CatBoost = 문자열, RF·ExtraTrees = 정수 번호 1칼럼(번호 = 코드 문자열 정렬 순, 그 모델 train 값으로, 학습에 없던 범주 NaN), 로지스틱 = 원핫(없던 범주 전부 0)
- 단계 8 딥러닝 튜닝 뒤(§6 단계 8): 고른 설정으로 전역·엄격 OOF 다시 → 8-TD. 튜닝 검증 쌍과 겹치는 블록(fold 1 넷째 블록·fold 2·3 블록 4·전역 블록 4) OOF 의 PR-AUC 를 튜닝 전후로 기록, 대조 판은 아래 줄

- Theil's U 대상 칼럼·해외 나라 코드 원천(부록 A-2 순서의 원천마다)이 검사 결과에 따라 채워지는지 단계 0 에서 칼럼·원천별 빈 칸 비율을 검출·불검출로 나눠 대조(fold 1 train(d ≤ 2022-06-30) 시료로 정하고, 나머지 d ≤ 2025-06-30 은 확인만 — test 정답 안 봄) — 결과에 따라 채워지는 것으로 보이면 담당자 확인 뒤 대상·순서에서 뺌

### B-7. window 검산 예시

### B-9. 받아들인 한계(보고서에 적음)
- 같은 3 fold 로 여러 번 고름 → CV 가 높게 나오는 쪽: '같은 validation 으로 고른 횟수'(§1-3)·fold 1 단독 순위(§6 최종 고르기)·단계별 test(§1-3)
- 딥러닝 순위(블록 5) 시료의 딥러닝 값, 최종 판이 튜닝한 딥러닝 값(8-TD)을 쓰면 튜닝 검증 시료의 딥러닝 값이 train 에 들어감: 대조 판(§7-3)
- 분할·블록 경계 gap 0일(§3)
- 딥러닝 조기 종료는 날짜 무관 무작위 10%(부록 A-8)
- ExtraTrees 는 NaN 행을 무작위 방향으로 보냄(결측 방향을 학습 안 함)
- 해마다 T 05-02 ~ 06-30 은 채점 안 됨 — h 구간마다 보는 계절이 다름(h 1~20 엔 5월 하순 ~ 6월 d, h 41~60 엔 7월 ~ 8월 중순 d 가 없음)(§3)
- OOV 행은 학습 때 한 번도 안 나와 처음 나온 시군구·나라·품목 예측은 학습되지 않은 값(부록 A-8)
- 블록 모델마다 결측 표시 채널 구성이 다를 수 있음(부록 A-8)
- 예보 칸 = 관측값(완전 예보 가정) → test 는 예보 오차가 없는 경우의 점수 — 좌표 차이 민감도로 관측 위치 차이만 확인(예보 오차는 못 잼, §1-3)
- 실제 예보에 없는 변수는 운영 때 예보 칸을 따로 채워야 함(0-3 목록)
- ② 는 한 입력으로 모든 h 를 내므로 E = T — 예보 칸 T+1 ~ T+10 은 안 씀(부록 A-8)
- 3-3 중요도·채택이 모두 fold validation 기준(부록 A-5)
- Theil's U 는 고유값 많은 칼럼 쪽으로 기움: 표에 고유값 수 같이(§6 단계 4)
- 토양검정 값은 검정일 기준(DB 등록 지연은 모름)
- SMOTENC 합성 행의 생장식 칼럼은 기상 보간과 정확히 맞지 않음(gr2 는 식품값이 들어가 출발 행 값)
- SMOTENC 이웃은 시군구·품목이 달라도 됨 — 합성 양성은 출발 행의 지역·품목 값에 다른 시료 쪽으로 보간된 기상이 붙은 조합(부록 A-6)
- CatBoost 범주 숫자 인코딩의 효과만 따로 보는 판은 없음(부록 A-6)
- 씨앗 1개 학습(단계 5·6 제외)
- fold 안 블록 OOF 는 앞뒤 블록으로 학습(과거만이 아님) — train 행 딥러닝 값이 validation 값보다 좋게 나올 수 있음(§7-3)
- 딥러닝 확률은 모델마다 눈금이 조금 다를 수 있음(이상 점수만 robust z 로 맞춤)(§6 단계 2-1·부록 A-8)
- 자료 시작 쪽 train 행의 1년·5년 이력은 짧은 기간으로 계산(C = 2015-06-30 이면 1년도 약 85일치)(HIS2 만 창 길이 환산, §5-1·부록 A-3)
- 기상청 SPI(관측 날)의 적합 기준 기간에 T 뒤 해가 들어 있을 수 있음(0-3 에서 확인)
- 2020년 자료연도 친환경 비율의 분모는 2019년 경지면적과 같음(X1)
- CatBoost `has_time` = False — train 안 범주 통계에 같은 train 안 다른 날 정답이 섞임(B-1)
- 해외 기상은 나라 좌표 1곳·국내는 3곳 평균이라 정의가 다름, 해외 검출이 적음(fold 1 validation 해외 검출 4)(§4-4·§3)
- d 기준일이 섞임(`date_basis` 제조일·의뢰일·선적일)(§2-1) / 국내 SPI 는 T 에서 기상청 값과 우리 식 값을 그냥 이어 붙여 값이 튈 수 있음(§4-5)
- validation·test 행 이력은 fold 끝 값(해 뒤쪽일수록 오래된 값)(§5-1) / 섞기(permutation)는 현실에 없는 조합을 만듦(부록 A-5)
- h ≥ 12 면 R ≠ d 라 단기 파생의 '며칠 전' 뜻이 달라짐(§5) / 식품 고정표 aw 결측이 많음(단계 0 에서 셈)(§5-2)
- SPI 감마 적합 기간이 7.5년으로 짧음(§4-5) / 단계 8 튜닝은 딥러닝 칼럼을 뺀 입력에서 고른 설정(§6 단계 8)
- 3-3 채택의 'fold 2개 이상 상승' 은 교차 N 을 서로 공유해 완전히 독립된 확인은 아님(§3)
- 교차 N 은 나머지 두 fold(뒤 기간 포함)로 고름 — 앞 fold 점수에 뒤 기간 validation 정보가 들어감(§3)
- 옹진군 대표 좌표는 기존 산출물(전 기간 시료 좌표 중앙값) 그대로(부록 A-2)
- 튜닝 학습률 하한 0.01 은 반복 2,000 상한에서 덜 학습될 수 있음(부록 A-7)
- refit·4-a·4-b 는 train 행이 늘어도 공통 N·CatBoost 학습률 그대로 — test 가 덜 학습된 쪽일 수 있음(fold 별 최적 N·train 행 수는 설정 덤프)
- 결과 등록이 판정에 따라 늦는지(예: 검출 확인 검사)는 시료 파일에 등록일이 없어 못 봄 — test 끝 3개월 검출이 덜 들어왔을 수 있음(§3)
- threshold 를 뽑는 공통 반복 수 N 도 같은 validation 으로 고른 값이라 Recall ≥ 0.8 이 낙관적일 수 있음 — test Recall 로 확인(§1-2·§3)
- soil_moist 의 음수·50.0 은 원값 그대로(원자료 유지 — 바꾸려면 담당자 승인), 결측 코드라면 표준화·window 요약·SMOTENC 보간이 끌릴 수 있음(§4-3)
- Focal 비교는 Logloss 로 고른 설정(scale_pos_weight 포함)에 손실만 바꿔 Focal 에 불리할 수 있음(§6 단계 8)
- 이력·타겟 인코딩은 d(제조일 등) ≤ C 인 시료로 모음 — 검사·결과가 C 뒤인 시료도 들어감(시료 파일에 검사·등록일 없음, 결과 시차 반영 안 함과 같은 쪽의 한계)(§5-1)
- RR1 은 좌표가 국내면 제조국 칸을 보지 않고 국내 행으로 옮김(78행·검출 0)(§2-2)
- 동점 묶음이 큰 판(7-a·점수 0·1 판)은 u_tie 한 번의 순서로 점수가 정해짐 — 1위와 0.001 안이면 다시 채점해 기록만, 고르는 규칙은 그대로(부록 A-12)
- SMOTENC 는 양성 2~5개 칸에서도 음성의 25% 까지 합성 — 몇 안 되는 양성을 거의 복제한 합성 행이 많아질 수 있음(부록 A-6)
- ① 은 여러 판 중 고른 최종 모델과 h = 1 점수로 비교 — 고른 효과로 ① 에 불리하게 기울 수 있음, 표의 '같은 validation 으로 고른 횟수' 를 같이 봄(§6 추가 판)
