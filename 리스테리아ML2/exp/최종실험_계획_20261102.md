| 약어 | OOF = 학습에 안 쓴 행에 대한 예측, TE = 타겟 인코딩, WOE = 검출·불검출 비율의 로그 차, F2 = Recall 을 두 배 무겁게 본 F 점수, TPE = Optuna 기본 탐색 방식, ELBO = VAE 목적함수, 음의 ELBO = VAE 손실(재구성 MSE + KL) = 이상 점수의 원 점수(클수록 이상), SMOTENC = 범주가 섞인 자료용 SMOTE(소수 쪽 합성), AE·VAE = 자기부호화기·변분 자기부호화기 |

### 1-2. 지표
| 지표 | 정의 |
|---|---|
| PR-AUC | sklearn `precision_recall_curve` → `auc`(trapz, `drop_intermediate` False), 동점은 정답과 무관한 순서로 풀어 쌍마다 한 점(부록 A-12), threshold 는 원 예측값 |
| h 별 PR-AUC | h 마다 채점 쌍으로 계산, 검출 0건·전부 검출인 h 는 NaN |
| 구간 가중 PR-AUC(주 지표) | 0.5 × 평균(h 1~20) + 0.3 × 평균(h 21~40) + 0.2 × 평균(h 41~60), NaN 인 h 는 그 구간 평균에서 뺌, 구간이 통째로 NaN 이면 남은 구간 가중치를 합 1 로 다시 나눔. 고르기·반복 수·튜닝 목표·보고 모두 이것 |
| 60일 통 PR-AUC | 모든 (시료, h) 쌍을 이어 한 번 계산 |
| 부적합률 대비 배수 | 구간 가중 PR-AUC ÷ (h 별 검출 비율을 같은 가중으로 합친 값), 60일 통 PR-AUC ÷ 전체 쌍 검출 비율 |
| threshold 지표 | test 쌍 전체 Recall·Precision·F2·혼동행렬(TP·FN·FP·TN), Recall 은 test 쌍 전체와 구간 가중(h 별 Recall 의 구간 평균(검출 0건 h 는 NaN, 구간 NaN 재가중은 구간 가중 PR-AUC 와 같음)을 0.5·0.3·0.2 로, 같은 threshold) 둘 다 보고 |
| 상위 q% 포착률 | 상위 q%(1·5·10·20) 쌍이 잡은 검출 ÷ 전체 검출(동점은 위 규칙으로 없음) |

- threshold: 모든 fold validation 예측(모든 h, 씨앗 평균 판은 씨앗 평균)을 합쳐 Recall ≥ 0.8 인 값 중 Precision 최대 → refit 모델 test 예측에 그대로. 1·2차(③·④·⑤ 1·2차 몫 포함) = 그 fold 모델 예측을 합쳐 이 규칙(반복 수 고르기가 없으니 공통 N 따로 없음). 3차: threshold 용 fold validation 예측은 refit 과 같은 공통 반복 수 N 으로 따로 뽑음(같은 fold 모델, 트리 수만 다르게 — 추가 학습 없음), CV 점수는 교차 N. refit 은 공통 반복 수 N, fold 별 교차 N·최적 N·train 행 수와 공통 반복 수 N 을 설정 덤프에 기록
- 동점: 모든 점수 비교(고르기·채택·반복 수·튜닝 채택) = 소수 4자리 반올림 뒤 비교, 같으면 상승 아님. 같을 때 반복 수 N = 작은 쪽, threshold = Precision → Recall → 큰 값, 판·설정·상위 3개 = 판의 학습 횟수(부록 A-12) 적은 쪽 → 판 이름 순, 4-c 품목 = 검사 수 많은 쪽 → 코드 순, Theil's U 칼럼 = 고유값 수 적은 쪽 → 이름 순
- 동점 많은 판: 가장 큰 동점 묶음 ≥ CV validation 쌍의 1% 면 표에 '동점 많음' 표시, 후보 그대로(부록 A-12)

### 1-3. 보고 형식
- 단계마다 판 목록·고르기 규칙을 그 단계 test 채점 전에 적어 둠, test 를 본 뒤 추가한 판은 기록만(고르기 대상 아님)
- test 막기: test 예측 생성·저장은 단계마다 허용, test 정답(y) 채점은 각 단계가 끝난 뒤 보고 때만(2-3 바퀴별 test 는 2차 끝난 뒤 한꺼번에), 고르는 코드가 test 정답(y)을 읽으면 멈춤
- 단계별 표: 칼럼은 부록 A-12, test 점수는 국내 + 해외 전체 하나, 표마다 기준 줄(7-a)·1차 베이스라인 줄(2차부터)·2차 베이스라인 줄(3차부터), 표 주석·단계별 그림은 부록 A-13
- 표마다 '같은 validation 으로 고른 횟수'(누적) 적음 — 셈법 부록 A-12
- 사람이 정하는 판단(줄이기 목록·2-3 단위 빼기 여부·§9 회신 반영)은 CV·시간 자료만 보고 정함(test 점수 안 봄), 기본값(§8 줄이기 (가)·(나) 순서·§8 2-3 단위 빼기 기본·§9 회신 전 기본값)을 따르고 바꿀 때만 이유 기록, 판단마다 시점·본 자료(단계 0 의 나라별 표·부록 B-6 의 fold 1 train 점검 포함)·그때까지 본 test 보고 목록 기록. 단계 0 뒤에 생긴 구현 세부는 그 세부가 영향을 주는 단계의 test 채점 전에 기록. §9 회신이 그 단계 test 보고 뒤에 와서 판이 바뀌면 그 판은 기록만(고르기 대상 아님), 회신 상대에게 test 점수는 회신을 받은 뒤에만 보여 줌
- 마지막: 1차 베이스라인 → 2차 베이스라인 → 3차 단계별 대표 판(대표 판 = 단계마다 CV 1위 판) → 최종 모델 test 변화 표 1개 + 최종 모델 test 전체 지표 + 최종 모델 보조 표·좌표 차이 민감도(부록 A-12). 판 이름 = 단계-판(예: 1-CAT-W060-sum / 1-CAT-W060-raw, 4-b)

## 4. 기상 입력
### 4-1. window
- [S, E]: S ~ T−1 = 관측, T ~ E = 예보(운영 땐 예보값, 예보 길이 = 발표 당일 포함 11일). 학습 땐 관측값, validation·test 쌍도 예보 칸 = 관측값(완전 예보 가정). h ≤ 11 이면 E = d − 1, h ≥ 12 면 E = T + 10 이고 T+11 ~ d−1 의 g 일은 window 밖(입력 없음). 원천 공개 지연 시 관측·예보 경계는 부록 A-13
- 일 단위 변수 전부(기상 19·습도·이슬점·SPI·단기 파생·생장식·생장 범위 기상) = E 끝. 토양 검정·외부 지표 = T−1 기준(§5), 이력·타겟 인코딩 = C 기준(§5-1)
- 한 설정 안에서는 모든 h 가 같은 W. 시간 칼럼: 트리 = h·g 둘 다(⑦-T 는 g 만, 7-b·⑤ 는 자기 칼럼만이라 없음, ① 은 없음), 딥러닝·결합 모델 = g 만(② 와 3-1 AE·VAE 는 없음 — 표 AE·VAE 는 h·g 를 뺀 숫자 칼럼(h 는 무작위 배정이라 복원 대상에서 뺌), 시퀀스 AE·VAE 는 x_seq 만, 부록 A-8). 관측 일수 = max(0, W − min(h, 11)), 검산 예시는 부록 B-7

### 4-2. 요약값·원값·시퀀스·결측
- 요약(변수마다): E 부터 거꾸로 10일 구간 평균 W/10 개(b01 = E−9 ~ E, b02 = E−19 ~ E−10, …) + window 평균·표준편차(ddof 0)·최소·최대·기울기, NaN 무시, 관측·예보 칸을 한 줄로 이어 계산. 기울기 = window 날짜(일)에 대한 최소제곱 기울기(단위/일, NaN 뺌)
- 원값: lag001 = E, lag002 = E−1, …, lagW = S(이름은 E 기준). 시퀀스(딥러닝): S ~ E 시간순 W일. 요약 판 = 요약 칼럼만, 원값 판 = lag001~lagW 만, WX1(SPI) window 칼럼도 판의 방식을 따름, 다른 파생(WX2~WX7)은 방식 무관

- 결측: XGBoost·LightGBM·CatBoost·RF·ExtraTrees 는 NaN 그대로(0 이 실제 값인 강수·지중온도 포함 0 채움 금지). 로지스틱·딥러닝은 그 모델 train 평균·표준편차(NaN 빼고)로 표준화 → 결측 0 → 결측 표시 칼럼·채널 = 그 모델 train 에 결측이 있는 칼럼(표준화 통계와 같게 모델마다 — 같은 행 모델을 여러 fold 에 같이 써도 그 모델 것 그대로). soil_t_nas·no2·co·so2 는 해외 행에서 늘 결측 — 그 결측 표시는 '해외 구조적 결측' 1칼럼으로 합침(해외 행의 soil_t_nas·no2·co·so2 칼럼별 결측 표시 = 0, 합친 '해외 구조적 결측' 칼럼만 1), 1차는 soil_t5~t30·풍향 sin·cos 도 해외 구조적 결측에 넣음(DB 값만이라), 국내 행 결측은 칼럼마다 표시. 목록에 없는 칼럼의 결측 = 0(표시 없음), 그 칼럼 목록 기록

- 1-3 정하기: 트리 window = 1-1 CV 1위 설정의 (W, 입력 방식), 딥러닝 window = 1-2 CV 1위 W_DL(2·3차 모든 딥러닝·⑥·⑦), 1차 베이스라인 = 70 설정 중 CV 1위, 2차 기준 알고리즘 A = 1-1 CV 1위 설정의 알고리즘. 산출 = 알고리즘 × W × 입력 표(70 설정 CV·test 전부)
### 2차(단계 2)
- 공통: 1차 window 고정, 기상 = 2차 기상(해외 = Open-Meteo 로 채운 표), 알고리즘 = 1차 4종, 기본 설정(튜닝·반복 수 고르기 없음), 모든 판 3 fold + refit·test(2-3 바퀴 안 시도 판은 채택 있던 바퀴의 기준 판만 refit)
- 2-0 기준 판: A 의 1차 최고 설정을 2차 기상으로 다시 학습(파생변수 없음) — 2-1·2-1b·2-2 의 출발 판, 2-R 기준
- 2-1 k: 2-0 에 이력 그룹(HIS1~HIS4)만 더한 판으로 k ∈ {10, 30, 50, 100, 200} 비교 / 2-1b N_ma: 2-0 에 차감 칼럼만 더한 판으로 N_ma ∈ {5, 7, 15, 30} 비교
- 2-2 전부 넣은 판: 2-0 입력 + §5 후보 전부(L1 은 §9 확인 뒤에만)를 4 알고리즘 각각(LSTM 입력 = 부록 A-8 2차 입력)
- 2-3 변수 빼기(그룹 빼기 → 단위 빼기): 모델 = A, 시작 판 = A 의 2-2 판, 재학습·중요도 = 기본 설정 fold 모델(교차 N 없음), 빼기 단위 149·그룹 G = 47(기상 9 + 비기상 38, L1 을 빼면 145·43 — §9) — 단계 0-8 에서 표를 만들고 L1 여부는 2-2 시작 직전 확정, 단위·그룹·중요도 계산·기록은 부록 A-5(기호 A-12), 기한 확인·줄이기 = §8 줄이기 (나)
  - 중요도: 시작 판과 채택 있던 바퀴 끝마다 그룹 칼럼을 `h_block` 으로 섞는 permutation importance(3 fold × 섞기 M 회 — M·I·ψ_f·π 정의 부록 A-5). 3 fold 모두 ψ_f ≥ 0.8 이고 3M 칸 평균 I > 0 인 그룹은 그 바퀴 시도 안 함
  - 나머지를 π 낮은 순(같으면 평균 I 낮은 순 → 그룹 번호, 바퀴 안 순서 고정)으로 그룹째 빼고 3 fold 재학습(기본 설정, 학습 씨앗 1개) → CV 평균 상승 + 3 fold 중 2개 이상 상승이면 채택(새 기준), 아니면 되돌림. 채택 없는 바퀴에서 그룹 빼기 끝(최대 20바퀴)
  - 단위 빼기: 남은 다단위 그룹의 단위 전체를 한 줄(π 낮은 순 → 평균 I 낮은 순 → 단위 번호)로 세워 그룹 빼기와 같은 규칙(단위 중요도·건너뛰기·채택 규칙·채택 없는 바퀴에서 끝, 최대 20바퀴)으로, 그룹 마지막 단위는 안 뺌, 할지는 §8 2-3 단위 빼기 기본대로
- 2-R 리서치팀 변수 비교(모델 = A, 기준 = 2-R 기준): 2-R1 = 기준 + t3·rain_lag2·wind_lag2·rain_mean25·solar_23·trange7·rh1·td1 + 축사 4칼럼, 2-R2 ~ 2-R10 = 기준 + 하나씩(앞 8개 각각 + 축사 4칼럼 묶음). 2-R1 에선 칼럼별 중요도 + 리서치 변수 전체 한 그룹 중요도 + 각 변수가 속한 기상 그룹 중요도(중요도 계산법 = 부록 A-5 와 같음). 이 변수들은 2-2 후보에도 들어가며(L1 은 §9 확인 뒤에만) 빼기 결과(그룹째 빠짐·단독으로 빠짐·남음)를 칼럼마다 기록(L1 이 2-2 후보에 안 들어가면(확인 전 포함) '해당 없음')
- 2-4 2차 최종 판: 2-3 끝 변수 묶음을 4 알고리즘에(A 는 2-3 끝 판 그대로)
- 2차 베이스라인 = 2-0·2-2(4판)·2-4(4판) 9판 중 CV 1위, 3차 변수 묶음 = 2차 베이스라인 판의 변수 묶음
### 3차 공통(단계 3-0 ~ 8, 추가 판)

### 단계 3-0. 알고리즘 넓히기
- 트리 6종 = XGBoost·LightGBM·CatBoost(§3 반복 수 규칙 — 같은 변수 묶음의 2차 판과 반복 수 규칙만 다름, 그런 2차 판이 없는 알고리즘은 비교 안 함) + RandomForest·ExtraTrees·LogisticRegression(기본 설정, max_iter 2,000 — 수렴용 수치 설정, 튜닝 아님, 판마다 수렴 여부(`n_iter_`) 기록) / 딥러닝 4구조 = LSTM(3차 변수 묶음의 2차 LSTM 판 재사용, 없으면 학습 4)·GRU·트랜스포머 인코더·LSTM + attention(1차 W_DL, 기본 설정, §7) — 모두 3 fold + refit·test
- 산출 = 트리 상위 3개(알고리즘별 1판, CV 순), 딥러닝 상위 3개(CV 순) → 딥러닝 상위 3개에 전역 블록·엄격 OOF 추가(§7-3, 예측 범위 부록 A-12)
### 단계 3-1 ~ 3-4. 상위 모델 결합
- 3-1 이상 점수: AE·VAE × 표·시퀀스 4종(입력·구조 부록 A-8), train 불검출 행만, 전역 블록 OOF + 엄격 OOF. 원 점수 = AE 복원 MSE·VAE 음의 ELBO, (시료, h) 쌍마다. 단독 판 CV·threshold = 엄격 OOF 의 fold train 전체 모델 예측, PR-AUC·test 보고(후보 아님). 이상 점수 = 원 점수의 robust z(모델 사이 크기 맞춤, 식·기준 행 부록 A-8)
- 3-2 스태킹: 트리 상위 3개마다 5판(설정 그대로, 부스팅은 반복 수만 다시)
  - (a) 트리 입력 + 딥러닝 상위 3개 확률 3칼럼
  - (b) 트리 입력 + 딥러닝 상위 3개 확률 3칼럼 + 이상 점수 4칼럼
  - (c) 트리 입력 + 이상 점수 4칼럼
  - (d) 트리 입력 + ⑥(시계열만 딥러닝) 확률 2칼럼(엄격 OOF)
  - (e) LIMS 입력(범주 5 + h·g) 트리 + ⑥ 확률 2칼럼(엄격 OOF) — 기상 window 없이 시계열 예측만 붙인 판
- 3-3 앙상블(추가 학습 없음): (시료, h) 쌍마다 확률 단순 평균 — 트리 상위 3개 평균 / 트리 상위 3 + 딥러닝 상위 3 평균. CV = 구성 트리 교차 N 예측 평균, threshold = 공통 반복 수 N 예측 평균(딥러닝 = 엄격 OOF 예측)
- 3-4 결합 모델: 결합-기본·결합-VAE(§7, 시계열 window = 1차 W_DL), 시간순 3 fold + refit(다른 모델 입력으로 안 쓰여 블록 OOF 없음) → 최종 고르기 후보
### 단계 4. 다운사이징
- 줄이기 칼럼: fold 1~3·refit train 각각으로 Theil's U = U(y | x)(칼럼이 검출을 설명하는 정도) 계산(칼럼별 고유값 수·고유값 비율 같이). 줄이기 칼럼 = 그 fold(refit) train 의 Theil's U 1위 — fold 마다 따로 정함(CV 가 검증하는 것은 '그 train 의 1위 칼럼으로 줄이기' 절차), 칼럼별 Theil's U 표는 fold·refit 마다 저장, 대상 칼럼은 부록 A-6
- 줄이기: fold train 기간에 검출 0건인 줄이기 칼럼 값의 행을 train 에서 뺌(제품명은 문자열 그대로), 검출 1건 이상인 값은 남김, validation·test 는 전부(학습에 없던 제품도 그대로 예측). 이력·타겟 인코딩은 §5-1 규칙대로, CatBoost 는 범주 칼럼을 스무딩 검출률 숫자로 넣음(부록 A-6)
  - 점수 0·1 판정: 줄이기 전 fold(refit) train 의 3단계 품목 집계로, 검출 0 품목 = 점수 0, 검출만 있는 품목 = train 에서 빼고 점수 1(판정·적용 세부, 규칙 판과 -n 판의 N·threshold 구분 부록 A-12)
  - 4-a·4-a0·4-b·② 마다 같은 모델의 원 예측 그대로인 판(4-a-n·4-a0-n·4-b-n·②-n)도 후보(학습 없음)
- 4-a: 줄인 train + 단계 4 대상 판 설정, 줄인 train 행에 h 1~60 전부. 미리보기 = 1차 직후 1-1 트리 1위 설정으로 4-a 1판(반복 수는 3차 규칙, 고르기에 안 씀, 보고용, test 채점은 단계 4 보고 때) / 4-a0: 줄인 train + 시료당 h 1개(h 1~60 복제 효과를 보는 대조 판(4-a 와 h 만 다름)) / 4-S0(단계 4 대상 판 예측에 점수 0·1 덮어쓰기만 — 검출만 있는 품목의 train 행 빼기는 없음): 학습 없음, 기록용, 후보 아님
- 4-b: 4-a + SMOTENC(fold·refit train 안에서만, (h, `src_route`, season) 칸마다 양성 20%, 범주·범주에서 정해지는 칼럼은 출발 행 값 — 부록 A-6). 4-a·4-a0·4-b 의 딥러닝 값·이상 점수 = 엄격 OOF 로 만듦(부록 A-12)
- 4-c 고위험 품목 모델: fold train 검출 비중(그 품목 검출 ÷ 전체 검출) 상위 5개 3단계 품목의 시료만으로 학습·채점 — 4-c = 단계 4 대상 판 입력, 4-c-L = LIMS 입력만(범주 5 + h·g), 같은 시료의 단계 4 대상 판과 PR-AUC 로 비교 보고(세부 부록 A-12)
- 산출: 판별 CV·refit·test, fold 별 줄인 행·검출 수, Theil's U 표, 보고 세부 부록 A-12
### 단계 5·6. 손 교수 방식
- 해 = d 의 달력 연도. 5: fold train 의 해마다 양성 전부 + 그해 음성 무작위 4 × 양성 수 / 6: 해마다 그해 양성 전부 + 그해 양성 수 × 4 개 음성을 '그해 양성이 나온 칸(3단계 × 시군구, 해외 3단계 × 나라)' 들의 그해(d 가 그해인) 음성 풀에서 무작위, 모자라면 풀 전부. 5·6 모두 refit train 에도 같은 규칙
- 공통: 씨앗 번호(0~4) = 음성 뽑기·모델 학습 모두 그 번호, 씨앗 0~4 예측 평균, 반복 수 N 은 씨앗 0~4 평균 예측 곡선으로 §3 함수 1회(CatBoost 학습률도 씨앗 0~4 × fold 자동 학습률 평균 1개를 모든 씨앗·refit 에), 단계 4 대상 판 설정(반복 수만 다시), 이력·인코딩(§5-1), validation·test 전부 예측, 씨앗 0 단독 예측의 CV·test 도 같이 적음(씨앗 0 곡선으로 교차 N·공통 N·threshold 를 따로 정함 — 같은 모델에서 트리 수만 바꿔 학습 추가 없음, 다른 판과 뽑기 방식을 비교할 때는 이 줄을 주 비교로, 씨앗 평균 효과를 빼려고)
### 단계 7. 타겟 인코딩 단독
- 7-a: 단위 (3단계, `sgg`) 스무딩 검출률 p̂_u 를 그대로 점수로(공식 부록 A-3), 길이 1년·5년·전체와 k_u·k_p3 ∈ {10, 30, 50, 100, 200} 은 7-a CV 로. C 규칙(§5-1)이라 validation·test 쌍은 모든 h 같은 값
- 7-b: 7-a 에서 고른 (길이, k_u, k_p3) 의 p̂_u·p̂_p3 2칼럼(공식 부록 A-3)만 넣은 트리(h·g·범주 없음, 단계 4 대상 판 알고리즘, 기본 설정, 반복 수만)
### 단계 8. 튜닝·불균형(마지막)
- 대상: 3차 공통의 단계 8 대상 규칙. 딥러닝 칼럼(딥러닝 확률·이상 점수 칼럼 전부) 빼고 튜닝(튜닝 뒤 다시 붙임). 씨앗 평균 판(5·6)은 고른 설정만 씨앗 0~4. 시도·채택·8-T·8-TD 점수 = 대상 판과 같은 방식(부록 A-12)
- Optuna TPE(씨앗 42) 100회, 목표 = CV 평균 구간 가중 PR-AUC, 첫 시도 = 라이브러리 기본 설정 그대로(범위·bootstrap_type 밖 값이어도). 시도 점수·채택·최종 비교 모두 §3 교차 N 규칙. 채택 = 시도 중 CV 1위(기본 설정보다 낮으면 기본 유지). 탐색 범위 부록 A-7
- 판(둘 다 3 fold + refit, 후보): 8-T = 트리 튜닝 설정(딥러닝 칼럼이 있으면 기존 딥러닝 값을 다시 붙이고 N 다시), 손실 Logloss 기본 — Focal 비교는 8-T 에서(손실만 Focal(γ 2·α 0.75)로 바꾼 판 3 fold + refit, 대상이 CatBoost·지원될 때, CV 가 높으면 채택) / 8-TD = 8-T 의 딥러닝 확률 칼럼을 튜닝한 모델 값으로 바꾼 판(이상 점수는 그대로, N 다시), 대상이 앙상블이면 딥러닝 구성 예측을 튜닝한 모델 예측으로 바꾼 평균, 단계 8 딥러닝 튜닝을 했을 때만

## 7. 딥러닝
### 7-1. 입력·예측
- 입력 = 기상 시퀀스(x_seq)·정적 칼럼(x_static)·지역·품목 범주 임베딩(x_cat)(② 는 부록 A-8 ② 입력 목록), 채널·칼럼 구성·범주 번호표(OOV)·결측 표시 채널·표준화 통계는 부록 A-8
- 시퀀스는 (시료, h) 쌍마다 만듦: 국내 SPI 채널이 과거 = 기상청 값, T 부터 = 우리 식이라 이음 위치(T)가 h 마다 다름. 학습 행 = 자기 h 로 만든 시퀀스, 예측 = (시료, h) 60가지(트리 train 행 값 = 그 행 h(단계 4·① 은 그 판 train 행의 h 전부), validation·test = 쌍의 h). 모델 입력 시간 칼럼은 g 만(② 와 3-1 AE·VAE 는 없음)

### 7-2. 구조·학습
- 구조: LSTM(1-2·2차·3-0)·GRU(3-0)·LSTM + attention(3-0·⑥)·트랜스포머 인코더(3-0·⑦-D)·GRU + attention(⑥)·AE·VAE(3-1)·결합-기본·결합-VAE(3-4)·60칸 신경망(②) — 층 구성·학습 설정 부록 A-8

### 7-3. 블록 OOF·엄격 OOF
- 전역 블록(d 기준): 1 = 2015-04-07 ~ 2017-06-30, 2 = 2017-07-01 ~ 2019-06-30, 3 = 2019-07-01 ~ 2021-06-30, 4 = 2021-07-01 ~ 2023-06-30, 5 = 2023-07-01 ~ 2025-06-30. 블록마다 나머지 4블록으로 학습한 모델이 그 블록 시료 예측(전역 블록 OOF)
- 엄격 OOF(딥러닝 값이 들어가는 모든 CV — 3-2 스태킹·3-3 앙상블·단계 4~8·최종 고르기): fold f 마다 train 행 값 = fold train 안 블록 OOF, validation 값 = fold train 전체로 학습한 모델
  - fold 안 블록 = 전역 블록 경계를 fold train 끝에서 자름, 같은 행으로 학습하는 모델은 한 번만 학습해 같이 씀(부록 A-12). 대상 = 3-0 딥러닝 상위 3개 + 이상 점수 4종 + ⑥ 2종(추가 판 ④ 도 같은 규칙), 횟수는 부록 A-9
- refit·test 값 = 전역 블록 OOF(train 행) + test 전 전체 학습 모델(test 행, 2015-04-07 ~ 2025-06-30)
- 8-TD 대조 판(튜닝에 쓰인 시료의 딥러닝 값을 결측으로 둔 판) — 조건·횟수 부록 A-12

- 거리² = (P ÷ |J|) × Σ_{j∈J} ((x_j − y_j) ÷ σ_j)² + 범주 불일치 수 × 1. 숫자 칼럼 = 보간 칼럼: J = 두 행 모두 값 있는 보간 칼럼(J 가 비면 이웃 후보에서 뺌), P = σ_j > 0 인 보간 칼럼 수, σ_j = 그 칸 안 양성 행 표준편차(0 이거나 계산 안 되면 그 칼럼은 J·P 모두에서 뺌), 범주 불일치 = `sido`·`sgg`·`p2`·`p3` 중 다른 칼럼 수, 불일치 1 = 표준화 뒤 표준편차 중앙값²(SMOTENC 원 방식)
- 보간 칼럼 = 기상 window 칼럼·WX1·WX2·gr1·gr3·WX5·WX6·rg 기상 12·딥러닝 값·이상 점수(합성 전에 붙인 엄격 OOF 값): 둘 다 있으면 x + λ(y − x), 한쪽만 있으면 그 값, 둘 다 없으면 NaN

- '같은 validation 으로 고른 횟수'(§1-3) = 그 판 앞까지 같은 3 fold 로 CV 점수를 낸 모든 판·설정 수의 누적(1차 70 설정부터 — 2-3 시도·7-a 격자 75·Optuna 시도·Focal 포함, 반복 수 56 시점은 안 셈), 실험 로그에서 자동으로 셈
- 판별 학습 횟수(§1-2 동점): 트리 판 3 fold + refit = 4, 5·6 = 20, 딥러닝 단독·결합 = 그 모델 학습 수, 앙상블·-n = 0, 7-a = 0, ④ = 118, 다른 판 입력용 딥러닝 값 학습은 안 셈
- 3-3 앙상블 대조(§6 단계 3-3): 3-3 앙상블마다 백분위 평균(각 모델 예측을 백분위로 바꿔 평균 — 기준 분포는 fold validation 은 그 채점 쌍, test 는 CV validation 예측을 합친 분포로 고정) 대조 — 기록용(학습 없음, 후보 아님), 3-3 표에 구성 모델별 예측 분위수(5·50·95%) 같이
- 3-0 딥러닝 예측 범위: 전역 블록 OOF·엄격 OOF·트리 train 행(자기 h) 예측은 딥러닝 상위 3개만. 단계 4 판(4-a·4-a0·4-b)·① 의 train 행은 fold 안 블록·전역 블록 모델로 (시료, 그 행의 h) 전부 추론(4-a·4-b = h 1~60, 4-a0 = 자기 h, ① = h 1), 이상 점수도 같게. 산출: 구조별 점수 표, 상위 3개 OOF·test 예측((시료, h) 60가지)
- 단계 4 대상이 앙상블일 때: 단계 4~7 은 대표 트리 하나로(구성 트리 중 3-0 CV 1위), 단계 8 은 다음 줄. 단계 8 대상이 앙상블이면 대표 트리만 튜닝하고 다른 구성 트리는 그 앙상블의 구성 트리 그대로 두며(다시 학습 안 함), 8-T 앙상블 표에 대표 트리 단독의 튜닝 전후 CV·구성 모델별 예측 분위수를 같이 적음. 단계 4~7 표에는 대표 트리 단독(3-0 판, 학습 추가 없음) 줄을 비교 기준으로 같이 넣음
- 단계 8 점수(§6 단계 8): 시도·채택·8-T·8-TD 점수는 대상 판과 같은 방식으로 계산 — 점수 0·1 규칙은 대상 판을 따름(규칙 판이면 덮어쓴 예측, -n 판이면 원 예측), 앙상블이면 시도·채택 판정은 대표 트리 단독 CV·8-T·8-TD 판 점수는 앙상블 CV, 씨앗 평균 판이면 시도는 씨앗 0, 채택 직전 '고른 설정 대 기본 설정' 을 씨앗 0~4 평균 CV 로 한 번 더 비교(고른 설정 씨앗 학습은 부록 A-9 미포함 +16 에 들어 있음). 딥러닝 칼럼은 빼고 튜닝하므로 대상 판에 딥러닝 칼럼이 있으면 첫 시도(기본 설정)도 칼럼을 뺀 입력으로 3 fold 학습. 앙상블 대상이면 채택 직전 '튜닝 설정 앙상블 대 기본 설정 앙상블' CV 도 기록(학습 추가 없음)
- 점수 0·1 판정(§6 단계 4): 줄이기 전 fold train(refit 은 줄이기 전 refit train)의 3단계 품목 집계로 판정(줄이기 칼럼과 무관) — 검사 1건 이상·검출 0 인 3단계 품목 = 점수 0, 검사 1건 이상·불검출 0 인 품목(검출만 있음) = train 에서 빼고 점수 1. 점수 0 품목의 train 행은 줄이기 칼럼 규칙대로(남은 행은 학습에 씀), validation·test 예측 = 0. 검출만 있는 3단계 품목 빼기와 검출 0건 줄이기 칼럼 값 빼기는 둘 다 줄이기 전 fold train 으로 센 뒤 함께 적용. 규칙 판(4-a·4-a0·4-b·②, 규칙을 따른 ①·⑤) = 덮어쓴 예측으로 반복 수 곡선·교차 N·공통 반복 수 N·threshold / -n 판 = 원 예측으로
- 단계 4 보고(§6 단계 4): fold 별 점수 0·1 규칙에 걸린 품목 수·그 품목들의 train 검사 수 분포·validation·test 쌍 수·검출 수·비율(점수 0 묶음·점수 1 묶음 따로), threshold ≤ 0(점수 0 묶음 값)이면 전부 양성 판정 — 표에 표시·담당자 알림, '단계 4 대상 판과의 차이에 점수 0·1 규칙·(CatBoost 면) 범주 인코딩 변경·(앙상블이면) 앙상블 → 대표 트리가 섞임' 한 줄. -n 판 표 주석 = 'train 은 검출만 있는 품목을 뺀 것(규칙 판과 같은 모델)' — 규칙만의 효과는 4-S0 으로 따로 보고
- 4-c·4-c-L(§6 단계 4): refit·test 의 5개 품목 = refit train 기준 상위 5개. 단계 4 대상 판 그대로(줄이기·점수 0·1 없음, 시료당 h 1개, CatBoost 범주 그대로)에 품목만 제한(부스팅은 반복 수만 다시 — 그 품목 fold validation 쌍으로 §3 함수), 채점·threshold 는 그 품목 쌍으로 §1-2 규칙(threshold 지표는 자기 threshold 로 따로), 4-c-L 은 4-c 와도 비교. 보고 = fold 별 상위 5 품목 목록·fold 별 점수를 같이 적고, 표 주석에 'CV 평균은 품목을 고르는 절차의 성능'
- fold 안 블록(§7-3) = 전역 블록 경계를 fold train 끝에서 자름: fold 1 = 블록 1·2·3 + 2021-07-01 ~ 2022-06-30(4블록), fold 2 = 블록 1~4, fold 3 = 블록 1~4 + 2023-07-01 ~ 2024-06-30(5블록)
- 같은 행 모델 재사용(§7-3): d ≤ 2021-06-30 모델 = fold 1 넷째 블록(2021-07-01 ~ 2022-06-30) OOF = fold 2 블록 4 OOF, d ≤ 2023-06-30 모델 = fold 2 fold train 전체 = fold 3 다섯째 블록(2023-07-01 ~ 2024-06-30) OOF = 전역 블록 5 OOF
- 최종 모델 보조 표(§1-3, 고르기에 안 씀): 최종 모델 test 를 품목 묶음 × 국내·해외별로도 채점. 품목 묶음 = 농산물(1단계 식물성)·축산물·수산물(1단계 동물성의 2단계 축산물·수산물)·가공식품(1단계 가공식품)·기준규격외·그 밖·'코드없음', 1단계 = `p2` 를 `ba_data.t_prdlst_cl.hrnk_prdlst_cd` 로 따라 올라간 최상위 분류
- 좌표 차이 민감도(§1-3, 1개, 학습 없음): 최종 모델 test 의 국내 행 예보 칸(T ~ E) 날마다 단계 0-3 에서 잰 시군구·변수별 평균 차이를 더하고, SPI 예보 칸·WX2~WX6 은 다시 계산, 딥러닝 값·시퀀스는 test 모델로 다시 추론(학습 없음), 해외 행은 그대로

### B-9. 받아들인 한계(보고서에 적음)
- 같은 3 fold 로 여러 번 고름 → CV 가 높게 나오는 쪽: '같은 validation 으로 고른 횟수'(§1-3)·fold 1 단독 순위(§6 최종 고르기)·단계별 test(§1-3)
- 1·2차는 라이브러리 기본 반복 수 — 3차 판과의 차이에 반복 수 고르기 효과가 섞임(3-0 부스팅 판과 같은 변수 묶음의 2차 판이 있는 알고리즘만 따로 봄)
- 1차 해외 기상은 DB 값만이라 해외 행에 빈 변수·기간이 많음 — 2차와의 차이에 채운 기상의 효과가 섞임(2-0 판으로 따로 봄)
- window 는 1차 4 알고리즘으로만 찾음 — 3-0 의 다른 알고리즘은 자기에게 맞는 window 를 따로 찾지 않음
- 2차 변수 고르기는 기준 알고리즘 A 하나로 — 다른 알고리즘엔 그 변수 묶음을 그대로 씀
- 1·2차 CatBoost(③·④·⑤ 1·2차 몫 포함)는 학습률이 학습마다 자동값이라 fold 모델과 refit 의 학습률이 다름 — fold 예측으로 뽑은 threshold 가 refit 예측 크기와 어긋날 수 있음, fold 별·refit 실제 학습률을 설정 덤프에 적고 표 주석에 표시(§3·부록 A-13)
- 5·6 은 씨앗 0~4 예측 평균(5개 모델 평균)이라 씨앗 1개 판보다 유리 — 단계 8 대상·최종 고르기가 5·6 쪽으로 기울 수 있음(뽑기 방식 효과는 씨앗 0 단독 줄로 따로 봄, §6 단계 5·6)
- 점수 0·1 판정에 최소 검사 수가 없어 검사 1~2건 품목도 0·1 로 굳음 — 규칙 판 점수가 작은 표본에 흔들릴 수 있음(-n 판이 대조, 부록 A-12)
- 해외 남반구 나라는 계절 범주가 실제와 반대(보정 없음) — SMOTENC 칸·CatBoost 범주 인코딩·계절 그룹에 그대로 쓰임(§5 WX7)
- 단계 4 CatBoost 범주 숫자 인코딩은 7-a 에서 고른 k_p3 와 전체 기간을 범주 칼럼마다 그대로 씀 — 범주별로 따로 검증하지 않고, 이 인코딩 효과만 따로 보는 판도 없음(부록 A-6)
- 트리 앙상블(3-3)은 확률 단순 평균이라 눈금이 큰 모델(부스팅·RF·ExtraTrees·로지스틱 사이) 쪽으로 쏠릴 수 있음 — 구성 모델별 예측 분위수를 3-3 표에 같이 적음(부록 A-12)
- ⑥·⑦ 의 '시계열만' 입력에도 결측 표시 채널(해외 구조적 결측 포함)·NaN 패턴으로 국내/해외 정보가 들어감 — 3-2 (e) 해석에도 같음(§6 추가 판)
- 단계 4·5·6 처럼 train 양성 비율을 바꾸는 판은 fold·refit 마다 줄인(뽑은) 양이 달라 예측 크기가 달라짐 — 합친 threshold 의 test Recall·Precision 이 어긋날 수 있음, 이 판들은 합친 threshold 로 본 fold 별 Recall 을 표에 같이 적음(§1-2·부록 A-12)
