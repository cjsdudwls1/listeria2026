## 요약(순서대로 읽기)
1. 목적: 리스테리아 검출을 운영 단위(국내 시군구·해외 나라 × 품목 2·3단계)로 1~60일 앞(h)까지 예측한다. d = 시료 기준일, T = d − h = 예측하는 날이다.
2. 자료: LIMS 시료 676,520건(검출 1,969)을 국내·해외 한 모델로 쓴다. 학습 행은 시료 1건에 h 1개이고, 단계 4 의 h 1~60 판(트리 부분)과 그 위에 쌓은 판만 예외다(16).
3. 평가: 시간순 3 fold CV(val)로 고른다. test 1년은 모든 차수의 판을 채점해 기록만 하고, 딥러닝 튜닝만 1년 검증(test 와 다른 2021-07 ~ 2022-05, 모든 fold validation 보다 앞)으로 고르는 예외다.
4. 지표: h 1~20·21~40·41~60 구간별 평균 PR-AUC(trapz)를 0.5·0.3·0.2 로 가중한 구간 가중 PR-AUC 이고, threshold 는 Recall 0.8 이상 중 Precision 이 가장 높은 값이다.
5. 준비(단계 0): 행 수 대조, 기상·파생변수 표, 평가 틀을 만들고, 시간을 재서 예상 끝 날짜를 보고한다.
6. 1차 입력: LIMS 기본(시도·시군구·품목·국내/해외 + h·g, g = window 끝 다음 날부터 d 까지 날 수)과 식정원 DB 기상 19변수다. 해외는 DB 값만 쓴다. window 끝 = min(d, T + 10)(d 당일도 예보 칸)이고, 예보 칸은 관측값으로 대신한다.
7. 1차 알고리즘: CatBoost·XGBoost·LightGBM(라이브러리 기본 설정)과 LSTM(정해 둔 기본 구조)이다. 튜닝과 반복 수 고르기는 하지 않는다.
8. 1차 window: 트리 3종 × W 10~100 × 원값·요약 통계 = 60 설정, LSTM W 10~100 = 10 설정이다.
9. 1차 결과: 70 설정의 CV·test 표를 남긴다. CV 1위가 1차 베이스라인(이후 모든 표의 비교 기준 — 7-a "기준 줄"과 다름)이 되고, 그 1위의 W 를 트리·딥러닝 모든 판의 window 로 고정한다(트리 입력 방식은 1위가 트리면 그 방식, LSTM 이면 그 W 의 트리 1위 방식).
10. 단계 2 준비(2차 맨 앞): 2차 입력은 1차 입력에 나머지 모든 변수(검출 이력·SPI·차감·생장식·생장 범위·단기 기상·습도·이슬점·계절·식품·토양·지하수·친환경·축사)를 더한 것이다(해외 기상은 Open-Meteo 로 채운 표, 축사는 전체 농장 수 — 자료 없는 곳은 빈칸). 1차 window·라이브러리 기본 설정 그대로, A(그 W·입력 방식의 트리 설정 중 CV 1위 알고리즘)의 (W, 입력 방식) 판을 2차 기상으로 다시 학습한 2-0 판을 만들고, 이력 k(A 로)·차감 길이(A·LSTM 따로)를 고르고, 리서치팀 변수를 따로 비교한다(비교만).
11. 2차 사슬(12~18 을 차례로 — 12·13 은 판정 없이 첫 현재 최고 판(1등)을 정함): 14~18 은 단계마다 후보(쌓는 후보 = 기법을 더한 판·3-0b 상위 트리 스태킹·앙상블)를 만들어 val 이 현재 최고 판보다 오르면 채택해 새 현재 최고 판으로 삼고, 안 오르면 버린다(test 는 기록만, 한 단계에서는 쌓는 후보 1위 → 교체 후보 1위 순으로 한 번씩). 교체 후보(⑥·⑦ 시계열만(14)·④ LIMS 만 스태킹과 3-2 (e)(15)·② 60칸 출력(16))는 이기면 현재 최고 판이 되지만 그 위에 3-1~3-3 을 쌓지 않는다. 트리 대상 판(3-1·② 입력·4-c-L 의 바탕)은 채택된 판 가운데 교체 후보가 아닌 트리·스태킹·앙상블 판 중 가장 최근 것(없으면 3-0b 끝 판 트리 중 CV 1위)이고, 단계 4~6·8(다운사이징·손 교수 방식·튜닝)은 그때의 현재 최고 판에 — 교체 후보여도 — 한다.
12. 3-0 알고리즘 넓히기: RF·ExtraTrees·로지스틱·1차 4 알고리즘·GRU·트랜스포머·LSTM + attention·TCN·결합 모델 2종(결합-기본·결합-VAE — 정형 Dense 갈래 + 기상 시계열 갈래) 13종을 1차 window·변수 전체로 비교한다(부스팅 반복 수 고르기 시작). 13 판이 3-0b 의 시작 판이다.
13. 3-0b 구조별 변수 빼기: 13 판마다 자기 3-0 판에서 시작해 중요도 낮은 변수 묶음·단위를 하나씩 빼 CV 평균이 오르고 3 fold 중 2개 이상 오를 때만 뺀다(딥러닝·결합 모델도 같은 규칙, 부스팅은 반복 수 고르기를 켠 채). 끝 판마다 그 구조의 변수 묶음이 되고, 끝 판 전부 중 CV 1위가 첫 현재 최고 판이다.
14. ⑥·⑦ 시계열만: 기상 시퀀스만(기상·차감·SPI 채널 전부) 넣은 딥러닝 3종(⑥ — LSTM + attention·GRU + attention·TCN)과, 같은 시계열 정보를 넣은 트리·트랜스포머(⑦)를 교체 후보로 본다.
15. 3-1~3-3 결합: 트리 대상 판에 AE·VAE 이상 점수 더하기(3-1 — +AE·+VAE·+둘 다 3 후보), 상위 트리 스태킹((e) = LIMS 입력 트리 + ⑥ 확률 3칼럼, 교체 후보)과 LIMS 만 스태킹 ④(3-2), 앙상블(3-3)을 차례로 본다. 딥러닝 상위 3개(스태킹 확률 칼럼·앙상블 구성)는 딥러닝·결합 모델 끝 판 전부 중 CV 순이다.
16. 단계 4 다운사이징: 현재 최고 판에서, Theil's U 1위 칼럼의 검출 없는 값의 행을 빼고 4-a(h 1~60)·4-a0(h 1개)로 학습한다(원 예측 그대로 — SMOTENC 와, 학습 기간에 검출 없는 품목 0·검출만 있는 품목 1 로 점수를 덮는 판은 뺌). ① 당일 예측(h = 1 비교만)·② 60칸 출력(교체 후보)도 이때 본다. 미리보기 4-a(2-1 뒤, 보고용)도 있다.
17. 단계 5·6 손 교수 방식: 현재 최고 판에서 해마다 양성 전부와 음성 4배를 뽑는 2종이고(5 = 그해 음성 전체에서, 6 = 그해 양성이 나온 품목 3단계 × 시군구 칸의 음성에서), 씨앗 5번의 예측 평균을 쓴다. 단계 4·5·6 모두 현재 최고 판의 딥러닝 값 모델까지 줄인·뽑은 자료로 다시 학습한다.
18. 단계 8 튜닝·불균형(맨 끝 — 모든 실험이 끝나 확정된 판의 성능 끌어올리기): 단계 시작 때 현재 최고 판에 Optuna 100회(트리 부분, 검출 행 가중치 포함) → Focal 손실(CatBoost 부분) → AutoKeras(딥러닝 부분)를 차례로 하고, val 이 오를 때만 채택한다. ② 는 튜닝 안 하고, 트리 튜닝은 딥러닝 칼럼을 빼고 한 뒤 다시 붙인다.
19. 비교만(채택 대상 아님): ③ 시료 무작위 나누기(1차 뒤), ⑧ 정형만(3-0b 뒤 — 3-0b 트리 1위 판에서 기상 8그룹(계절은 남김)을 뺀 판, 기상의 추가 예측력), 고위험 품목 모델(단계 4 — 4-c = 현재 최고 판을 상위 5 품목 시료로, 4-c-L = 트리 대상 판 알고리즘의 LIMS 입력만 판), 7-a 타겟 인코딩 단독(단계 7 — 학습 없이 과거 검출률(품목 3단계 × 지역, test 는 train+val 기간)을 그대로 확률로 쓰는 계산, 모든 표의 기준 줄로 두어 머신러닝 판이 이보다 나은지 본다)(전체 목록 §6 최종 모델 고르기).

## 1. 예측 대상·평가
### 1-1. 정의·용어
- d = 대상일(시료 기준일), h = 예측 시차 1~60, T = d − h, W = 기상 window 길이(10~100, 10일 간격)
- E = window 끝 = min(d, T + 10)(d 당일도 예보 칸), S = 시작 = E − W + 1, g = window 끝 다음 날부터 d 까지 날 수 = d − E = max(0, h − 10), R = 단기 파생 기준점 = min(d, E + 1)
- C = 이력·타겟 인코딩 기준일 = T 직전 06-30(T 가 07-01 ~ 12-31 이면 그해 06-30, 01-01 ~ 06-30 이면 전해 06-30)
- y = 시료 `judge_result`(검출 1·불검출 0, 해외도 시료 단위), 평가 행 = (시료, h) 쌍, validation·test = T ∈ 채점 범위인 (시료, h) 쌍 전부(§3) — 목표 = 검사한 시료가 검출될 확률(어느 단위·날짜를 검사할지 고르는 치우침은 보정 안 함)
- 기호: f = fold 번호(1~3), k = 이력 스무딩 상수(단계 2-1), k_u·k_p3 = 7-a 스무딩 상수(단위 쪽·3단계 쪽), N_ma = 이동평균 차감 길이, p0·m·s_all·n_all = §5-1(그 밖 기호는 부록 A-12, 용어·약어는 부록 A-14)

### 1-2. 지표
| 지표 | 정의 |
|---|---|
| PR-AUC | sklearn `precision_recall_curve` → `auc`(trapz, `drop_intermediate` False), 동점은 정답과 무관한 순서로 풀어 쌍마다 한 점(부록 A-12), threshold 는 원 예측값, sklearn 기본(같은 값 묶음) PR-AUC 도 같이 기록(고르기엔 안 씀) |
| h 별 PR-AUC | h 마다 채점 쌍으로 계산, 검출 0건·전부 검출인 h 는 NaN |
| 구간 가중 PR-AUC(주 지표) | 0.5 × 평균(h 1~20) + 0.3 × 평균(h 21~40) + 0.2 × 평균(h 41~60), NaN 인 h 는 그 구간 평균에서 뺌, 구간이 통째로 NaN 이면 남은 구간 가중치를 합 1 로 다시 나눔. 고르기·반복 수·튜닝 목표·보고 모두 이것 |
| 60일 통 PR-AUC | 모든 (시료, h) 쌍을 이어 한 번 계산 |
| 부적합률 대비 배수 | 구간 가중 PR-AUC ÷ (h 별 검출 비율을 같은 가중으로 합친 값), 60일 통 PR-AUC ÷ 전체 쌍 검출 비율 |
| threshold 지표 | test 쌍 전체 Recall·Precision·F1·F2·혼동행렬(TP·FN·FP·TN), Recall 은 test 쌍 전체와 구간 가중(h 별 Recall 의 구간 평균(검출 0건 h 는 NaN, 구간 NaN 재가중은 구간 가중 PR-AUC 와 같음)을 0.5·0.3·0.2 로, 같은 threshold) 둘 다 보고 |
| 상위 q% 포착률 | 상위 q%(1·5·10·20) 쌍이 잡은 검출 ÷ 전체 검출(동점은 위 규칙으로 없음) |

- threshold: 모든 fold validation 예측(모든 h, 씨앗 평균 판은 씨앗 평균)을 합쳐 Recall ≥ 0.8 인 값 중 Precision 최대 → refit 모델 test 예측에 그대로. 1차·단계 2 준비 판(③·④ 포함) = 그 fold 모델 예측을 합쳐 이 규칙(반복 수 고르기가 없으니 공통 N 따로 없음). 2차 사슬: threshold 용 fold validation 예측은 refit 과 같은 공통 반복 수 N 으로 따로 뽑음(같은 fold 모델, 트리 수만 다르게 — 추가 학습 없음), CV 점수는 교차 N. refit 은 공통 반복 수 N, fold 별 교차 N·최적 N·train 행 수와 공통 반복 수 N 을 설정 덤프에 기록
- 동점: 모든 점수 비교(고르기·채택·반복 수·튜닝 채택) = 소수 4자리 반올림 뒤 비교, 같으면 상승 아님. 같을 때 반복 수 N = 작은 쪽, threshold = Precision → Recall → 큰 값, 판·설정·상위 3개 = 판의 학습 횟수(부록 A-12) 적은 쪽 → 판 이름 순, 4-c 품목 = 검사 수 많은 쪽 → 코드 순, Theil's U 칼럼 = 고유값 수 적은 쪽 → 이름 순
- 동점 많은 판: 가장 큰 동점 묶음 ≥ CV validation 쌍의 1% 면 표에 '동점 많음' 표시, 후보 그대로, 채택 비교 때 현재 최고 판과 0.001 안이면 u_tie 를 바꿔 다시 채점해 기록, 채택된 판이 동점 많으면 알림(부록 A-12)

### 1-3. 보고 형식
- 단계마다 판 목록·고르기 규칙을 그 단계 test 채점 전에 적어 둠, test 를 본 뒤 추가한 판은 기록만(고르기 대상 아님)
- test 막기: test 예측 생성·저장은 단계마다 허용, test 정답(y) 채점은 각 단계가 끝난 뒤 보고 때만(3-0b 바퀴별 test 는 3-0b 끝난 뒤 한꺼번에), 고르는 코드가 test 정답(y)을 읽으면 멈춤
- 단계별 표: 칼럼은 부록 A-12, test 점수는 국내 + 해외 전체 하나, 표마다 기준 줄(7-a)·1차 베이스라인 줄(2차부터)·현재 최고 판 줄(3-0b 뒤), 표 주석·단계별 그림은 부록 A-13
- 표마다 '같은 validation 으로 고른 횟수'(누적) 적음 — 셈법 부록 A-12
- 사람이 정하는 판단(문서의 '담당자 확인')은 CV·시간 자료만 보고 정함(test 점수 안 봄), 판단마다 시점·본 자료(단계 0 의 나라별 표·부록 B-6 의 d ≤ 2021-06-30 점검 포함)·그때까지 본 test 보고 목록 기록. 단계 0 뒤에 생긴 구현 세부는 그 세부가 영향을 주는 단계의 test 채점 전에 기록
- 마지막: 1차 베이스라인 → 3-0b 1위(첫 현재 최고 판) → 채택한 기법마다 → 튜닝 → 최종 모델 val·test 변화 표 1개 + 최종 모델 test 전체 지표 + 최종 모델 보조 표·좌표 차이 민감도(부록 A-12) + 최종 모델 입력 변수 표(칼럼·정의·원천·갱신 주기)(8-T(대상이 트리 하나·딥러닝 칼럼 없음·씨앗 평균 판 아님일 때) 상승은 고르기와 같은 점수의 비교로 표시). 판 이름 = 단계-기법-알고리즘(-W·입력 방식)(예: 1-CAT-W060-sum, 3-0b-CAT-g03, 3-2a-CAT, 3-3-T3D3, 4-a-CAT, 5-CAT·6-CAT, 8-T-CAT, 8-TD-<바탕>), 같은 이름이면 끝에 -2·-3

- 부스팅 반복 수: 모든 fold 최대 2,000 반복(모든 2차 사슬 부스팅 판에서 교차 N·공통 N 이 마지막 시점(최대 반복)이면 표에 "상한" 표시하고 알림("상한" 표시 판이 채택 판정에 들어가면 그대로 판정하고 기록·알림 — 최대 반복은 0-9 에서만 늘림), 0-9 측정에서 그 fold 최적 N 이 마지막 시점이면 최대 반복을 2배씩(4,000 → 8,000 …) 늘려 다시 잼, 마지막 시점이 아닐 때까지(기록, 상한 16,000 — 넘으면 "상한" 표시로 기록하고 진행) — 알고리즘마다 따로 정함(늘린 값은 그 알고리즘의 모든 2차 사슬 부스팅 학습(fold·refit·단계 8 시도·Focal)에 씀))·같은 학습률 → fold validation 구간 가중 PR-AUC 를 10 ~ 200 은 10 트리마다, 그 뒤 50 트리마다(56개 시점). 교차 N(fold f) = 나머지 두 fold 의 56 시점 구간 가중 PR-AUC 평균 곡선에서 가장 높은 시점(같으면 작은 N), 공통 N = 세 fold 평균 곡선에서 가장 높은 시점, fold f 점수 = 교차 N(자기 점수로 안 고름), refit = 공통 반복 수 N(행 수가 늘어도 그대로), 추가 학습 없음(최대 반복을 늘리면 2,000 뒤에도 50 트리마다 채점, 시점 수 기록)
- 학습률: XGBoost·LightGBM 기본값, CatBoost = fold 별 자동 학습률 평균(읽는 법 부록 A-12) → 그 값으로 모든 fold·refit 학습. RF·ExtraTrees·로지스틱은 기본 설정, 반복 수 고르기 없음. refit: d ≤ 2025-06-30 전체로 CV 에서 고른 설정·N·학습률 그대로 재학습 → test 1회(부스팅 refit 도 그때의 최대 반복까지 학습한 뒤 트리 수 지정 예측). 2차 사슬 판(단계 3~8)도 같은 함수(단계 8 의 시도·8-T 판과 8-T 채택 뒤의 Focal 판은 Optuna 가 뽑은 learning_rate 그대로(그 CatBoost 가 기본 유지면 대상 판의 학습률) — 첫 시도·기본 유지로 끝난 판·8-T 미채택 때의 Focal 판은 대상 판의 학습률 그대로). ③·④ 는 예외 — 라이브러리 기본 반복 수(CatBoost 학습률도 학습마다 자동값, ④ 의 단계 8 튜닝도 learning_rate 는 탐색 안 함), 반복 수 고르기·트리 수 지정 채점 없음

## 4. 기상 입력
### 4-1. window
- [S, E]: S ~ T−1 = 관측, T ~ E = 예보(운영 땐 예보값, 예보 길이 = 발표 당일 포함 11일). 학습 땐 관측값, validation·test 쌍도 예보 칸 = 관측값(완전 예보 가정). h ≤ 10 이면 E = d(d 당일 = 예보 칸), h ≥ 11 이면 E = T + 10 이고 T+11 ~ d 의 g 일은 window 밖(입력 없음). 원천 공개 지연 시 관측·예보 경계는 부록 A-13
- 기상 19·SPI·생장식·생장 범위 기상 = E 끝, 단기 파생·습도·이슬점(WX5·WX6) = R − 1 끝(§5). 토양 검정·외부 지표 = T−1 기준(§5), 이력·타겟 인코딩 = C 기준(§5-1)
- 한 설정 안에서는 모든 h 가 같은 W. 시간 칼럼: 트리 = h·g 둘 다(⑦-T 는 g 만, ① 은 없음), 딥러닝·결합 모델 = g 만(② 와 3-1 AE·VAE 는 없음 — 표 AE·VAE 는 h·g 를 뺀 숫자 칼럼(h 는 무작위 배정이라 복원 대상에서 뺌), 시퀀스 AE·VAE 는 x_seq 만, 부록 A-8). 관측 일수 = max(0, W − min(h + 1, 11)), 검산 예시는 부록 B-7

- 단계 4~6 을 현재 최고 판에 하는 법: 트리·스태킹 판 = 트리 부분을 줄인·뽑은 자료로(아래 단계 4·5·6 규칙), 딥러닝 단독·결합 모델 = 그 모델을 줄인·뽑은 자료로 다시 학습(h 1~60 복제(4-a)는 트리만 — 딥러닝은 4-a0 처럼 h 1개), 앙상블 = 구성마다 그 방식으로 다시 학습해 다시 평균, ④ 처럼 여러 모델 판 = 모델마다(OOF 블록 §7-3 그대로, ④ 는 기본 반복 수 그대로 — §3 — 블록 모델은 뒤의 딥러닝 값 모델과 같은 규칙(블록마다 다시 정함·재사용 없음)으로). 다른 판 입력용 딥러닝 값 모델(딥러닝 확률·이상 점수·⑥)도 그 판의 줄인·뽑은 자료로 다시 학습 — 전역 블록 OOF·엄격 OOF(§7-3)를 그 자료로 다시 만듦(4-a·4-a0·① 은 같은 줄인 자료라 한 벌, 5·6 은 방식·씨앗마다) — 블록 OOF 모델마다 검출 0건 값 판정·해마다 양성 수·양성 칸을 그 모델의 학습 블록 시료로만 다시 정함(검출 0건 값·양성 수·양성 칸에는 예측할 블록의 정답을 안 씀) — 줄이기 칼럼(Theil's U 1위)·4-c 품목은 그 fold(refit) 것 그대로
### 단계 3-0. 알고리즘 넓히기

### 단계 3-0b. 구조별 변수 빼기
- 구조 13종(3-0 의 13 판) 각자 자기 3-0 판에서 시작해 그룹 빼기 → 단위 빼기(딥러닝·결합 모델도 같은 규칙). 재학습·중요도 = 부스팅이면 §3 반복 수 규칙(재학습·fold 점수 = 교차 N, 중요도 = 교차 N 트리 예측), 그 밖은 기본 설정 fold 모델, 학습 씨앗 1개, k·N_ma 는 2-1·2-1b 값 그대로. 빼기 단위 110·그룹 G = 44(기상 9 + 비기상 35) — 표 = 단계 0-8, 단위·그룹·중요도 계산·기록은 부록 A-5(기호 A-12). 바퀴 안 시도 판은 3 fold 만, 채택 있던 바퀴의 기준 판만 refit·test
  - 중요도: 시작 판과 채택 있던 바퀴 끝마다 그룹 칼럼을 `h_block` 으로 섞는 permutation importance(3 fold × 섞기 M 회 — M·I·ψ_f·π 정의 부록 A-5). 3 fold 모두 ψ_f ≥ 0.8 이고 3M 칸 평균 I > 0 인 그룹은 그 바퀴 시도 안 함
  - 나머지를 π 낮은 순(같으면 평균 I 낮은 순 → 그룹 번호, 바퀴 안 순서 고정)으로 그룹째 빼고 3 fold 재학습 → CV 평균 상승 + 3 fold 중 2개 이상 상승이면 채택(새 기준), 아니면 되돌림. 채택 없는 바퀴에서 그룹 빼기 끝(바퀴 상한 없음)
  - 단위 빼기: 남은 다단위 그룹의 단위 전체를 한 줄(π 낮은 순 → 평균 I 낮은 순 → 단위 번호)로 세워 그룹 빼기와 같은 규칙(단위 중요도·건너뛰기·채택 규칙·채택 없는 바퀴에서 끝)으로, 그룹 마지막 단위는 안 뺌, 늘 함
- 끝 판(그 구조의 마지막 기준 판 — 바퀴 안에서 오를 때만 빼므로 자기 3-0 판보다 val 이 낮지 않음)마다 그 구조의 변수 묶음. 첫 현재 최고 판 = 끝 판 전부 중 CV 1위(고르기와 같은 점수, 따로 한 판정 아님)
- 산출 = 끝 판 전부의 점수·변수 묶음, 트리 상위 3개(트리 6 끝 판 중 CV 순, 알고리즘별 1판)·딥러닝 상위 3개(딥러닝·결합 모델 끝 판 전부 중 CV 순) — 3-2·3-3 용, 각자 자기 변수 묶음. 딥러닝 상위 3개에 전역 블록·엄격 OOF 추가(3-0b 끝 판으로, §7-3, 예측 범위 부록 A-12)
### 단계 3-1 ~ 3-3. 상위 모델 결합
- 3-1 이상 점수: AE·VAE × 표·시퀀스 4종(입력·구조 부록 A-8), train 불검출 행만, 전역 블록 OOF + 엄격 OOF. 원 점수 = AE 복원 MSE·VAE 음의 ELBO, (시료, h) 쌍마다. 단독 판 CV·threshold = 엄격 OOF 의 fold train 전체 모델 예측, PR-AUC·test 보고(비교만). 이상 점수 = 원 점수의 robust z(모델 사이 크기 맞춤, 식·기준 행 부록 A-8). 3-1 판 = 트리 대상 판 + 이상 점수 묶음 3 후보 — +AE 2칼럼(표 AE·시퀀스 AE)·+VAE 2칼럼(표 VAE·시퀀스 VAE)·+4칼럼, 셋 다 쌓는 후보(셋 중 CV 1위를 현재 최고 판과 판정)
- 3-2 스태킹: 3-0b 트리 상위 3개(설정 그대로, 부스팅은 반복 수만 다시)를 각자 현재 입력으로 다시 학습한 트리마다 5판((a)~(d) = 그 트리의 현재 입력(= 트리 입력), (e) = LIMS 입력, 교체 후보) — 같은 판이 되면 학습 없이 다시 씀(예: 3-1 채택 뒤의 (a)·(b), 3-1 판과 같은 (c))
  - (a) 트리 입력 + 딥러닝 상위 3개 확률 3칼럼
  - (b) 트리 입력 + 딥러닝 상위 3개 확률 3칼럼 + 이상 점수 묶음(3-1 후보 중 CV 1위 묶음, 채택 여부와 무관)
  - (c) 트리 입력 + 이상 점수 묶음((b) 와 같음)
  - (d) 트리 입력 + ⑥(시계열만 딥러닝) 확률 3칼럼(엄격 OOF)
  - (e) LIMS 입력(범주 5 + h·g) 트리 + ⑥ 확률 3칼럼(엄격 OOF) — 기상 window 없이 시계열 예측만 붙인 판
- 3-3 앙상블(트리 = 3-2 (a)~(d) 가 채택됐으면 그 방식의 3-2 트리 3개(학습 없이 다시 씀), 아니면 3-0b 트리 상위 3개를 각자 현재 입력으로 학습한 판 — 같은 판(3-0b 끝 판·3-1·3-2 판)이 있으면 다시 쓰고 없으면 학습): (시료, h) 쌍마다 확률 단순 평균 — 트리 상위 3개 평균 / 트리 상위 3 + 딥러닝 상위 3 평균. CV = 구성 트리 교차 N 예측 평균, threshold = 공통 반복 수 N 예측 평균(딥러닝 = 엄격 OOF 예측)
### 단계 4. 다운사이징

### 단계 5·6. 손 교수 방식
- 해 = d 의 달력 연도. 뽑는 자료 = 현재 최고 판의 train(줄였으면 줄인 train, h 규칙은 그 판 그대로, 트리의 범주는 단계 4~6 범주 숫자 인코딩(부록 A-6)). 5: 해마다 양성 전부 + 그해 음성 무작위 4 × 양성 수(모자라면 그해 음성 전부) / 6: 해마다 그해 양성 전부 + 그해 양성 수 × 4 개 음성을 '그해 양성이 나온 칸(3단계 × 시군구, 해외 3단계 × 나라)' 들의 그해(d 가 그해인) 음성 풀에서 무작위, 모자라면 풀 전부. 5·6 모두 refit train 에도 같은 규칙. 뽑기는 시료 단위 — 뽑은 시료에 그 판의 h 규칙(4-a 트리 부분이면 h 1~60) 적용, 뽑은 양성·음성 수는 해마다 기록. 5·6 은 한 단계 — 둘 다 같은 현재 최고 판의 train 에서 만들고, 둘 중 val 1위를 현재 최고 판과 비교. ② 가 현재 최고 판이면 ② 를 뽑은 자료로 다시 학습(출력 60칸·자기 h 칸 손실 그대로) — 그렇게 만든 5·6 판도 ② 처럼 단계 8 튜닝 안 함
- 공통: 씨앗 번호(0~4) = 음성 뽑기·모델 학습 모두 그 번호, 씨앗 0~4 예측 평균, 반복 수 N 은 씨앗 0~4 평균 예측 곡선으로 §3 함수 1회(CatBoost 학습률도 씨앗 0~4 × fold 자동 학습률 평균 1개를 모든 씨앗·refit 에), 현재 최고 판 설정(반복 수만 다시, 학습 자료만 뽑은 자료로 바꿈), 이력·인코딩(§5-1), validation·test 전부 예측, 씨앗 0 단독 예측의 CV·test 도 같이 적음(씨앗 0 곡선으로 교차 N·공통 N·threshold 를 따로 정함 — 같은 모델에서 트리 수만 바꿔 학습 추가 없음, 씨앗 평균 효과를 뺀 뽑기 방식 보고용 — 판정은 2차 공통)

### 단계 8. 튜닝·불균형(마지막)
- 대상 = 단계 시작 때의 현재 최고 판(단계 안에서 안 바꿈 — 모든 실험이 끝나 확정된 판의 성능 끌어올리기) — 튜닝할 부분은 시작 판 기준으로 정하고, 판정 상대는 그때의 현재 최고 판. 차례: 트리 부분(앙상블이면 구성 트리마다, ④ 면 기본 트리 6종마다 — 메타 로지스틱은 튜닝 안 함(고른 설정의 OOF 로 다시 학습))에 Optuna(8-T) → CatBoost 부분에 Focal → 딥러닝 부분에 AutoKeras(8-TD) 차례로, 각각 그 앞까지 채택한 판 위에 만들어 val 이 오를 때만 채택(딥러닝 단독·결합 모델이면 8-TD 만, ② 는 튜닝 안 함). 트리 튜닝은 딥러닝 칼럼(딥러닝 확률·이상 점수 칼럼 전부) 빼고 한 뒤 다시 붙임. 대상이 씨앗 평균 판(5·6)이면 고른 설정만 씨앗 0~4. 점수 방식은 부록 A-12
- Optuna 100회(첫 시도 = 대상 판 설정 그대로(라이브러리 기본 설정 + max_iter·반복 수·학습률 규칙)(범위·bootstrap_type 밖 값이어도 — 후보 비교에만 넣고 TPE 이력에는 안 넣음) + TPE(씨앗 42) 99회, 검출 행 가중치 scale_pos_weight·class_weight 탐색 포함 — 불균형 처리), 목표 = CV 평균 구간 가중 PR-AUC. 시도 점수·최종 비교 모두 §3 교차 N 규칙(④ 는 부록 A-12). 튜닝 설정 = 시도 중 CV 1위(그래서 대상이 트리 하나·딥러닝 칼럼 없음·씨앗 평균 판 아님이면 8-T 채택 = 기본보다 높은 시도가 있음 — 고르기와 같은 점수의 비교, 그 밖은 시도 점수와 판정 점수가 다름)(기본 설정보다 낮으면 기본 유지) — 상위 5개 시도의 CV 표를 함께 보고. 탐색 범위 부록 A-7. 시도나 고른 설정 학습(8-T refit·딥러닝 칼럼 다시 붙인 판·Focal 판·④ 의 OOF·메타 다시 만들기·5·6 씨앗 1~4 학습)이 멈추면 부록 B-1 규칙대로 그 시도·그 판부터 다시(건너뛰거나 실패로 넘기지 않음, float32·디스크 기반·m 은 바꾸지 않음)
- 판(3 fold + refit): 8-T = 트리 튜닝 설정(딥러닝 칼럼이 있으면 기존 딥러닝 값을 다시 붙이고 N 다시), 손실 Logloss / Focal = 그 앞까지 채택한 판(8-T 채택 때 8-T 판)의 CatBoost 손실만 Focal(γ 2·α 0.75)로 바꾼 판(CatBoost·지원될 때, 앙상블이면 구성 트리 중 CatBoost 에만) / 8-TD = 그 앞까지 채택한 판의 딥러닝 확률 칼럼을 튜닝한 모델 값으로 바꾼 판(이상 점수는 그대로, N 다시), 그 앞까지 채택한 판이 앙상블이면 딥러닝 구성 예측을 튜닝한 모델 예측으로 바꾼 평균, 대상이 딥러닝 단독·결합 모델이면 튜닝한 설정의 그 모델 — 튜닝 못 한 모델의 확률 칼럼·앙상블 구성 예측은 원 값 그대로, 하나라도 튜닝되면 8-TD 판을 만들고 전부 못 하면 8-TD 없음(기록)
- 딥러닝 = AutoKeras 후보 20(시도 19 + 기본 설정, 설정 부록 A-7): 대상의 딥러닝 — 딥러닝 확률 칼럼의 모델(상위 3개면 3개, (d)·(e) 면 ⑥ 3종)·앙상블의 딥러닝 구성·딥러닝 단독·결합 모델, 이상 점수(AE·VAE)는 튜닝 안 함
  - 자료 = d ≤ 2021-06-30 학습(표준화 통계도 이 기간), 검증 채점 쌍 = T ∈ 2021-07-01 ~ 2022-05-01 인 (시료, h) 쌍 전부(구간 가중) — 모든 fold validation 보다 앞, 고른 뒤 전체로 다시 학습
  - 고른 설정으로 8-TD 만들기·튜닝 검증 쌍과 겹치는 블록 기록(부록 A-12)

## 7. 딥러닝
### 7-1. 입력·예측
- 입력 = 기상 시퀀스(x_seq)·정적 칼럼(x_static)·지역·품목 범주 임베딩(x_cat)(② 는 부록 A-8 ② 입력 목록), 채널·칼럼 구성·범주 번호표(OOV)·결측 표시 채널·표준화 통계는 부록 A-8
- 시퀀스는 (시료, h) 쌍마다 만듦: 국내 SPI 채널이 과거 = 기상청 값, T 부터 = 우리 식이라 이음 위치(T)가 h 마다 다름. 학습 행 = 자기 h 로 만든 시퀀스, 예측 = (시료, h) 60가지(트리 train 행 값 = 그 행 h(단계 4·① 은 그 판 train 행의 h 전부), validation·test = 쌍의 h). 모델 입력 시간 칼럼은 g 만(② 와 3-1 AE·VAE 는 없음)

### 7-2. 구조·학습
- 구조: LSTM(1-2·2-1b·3-0)·GRU(3-0)·LSTM + attention(3-0·⑥)·트랜스포머 인코더(3-0·⑦-D)·TCN(3-0·⑥)·GRU + attention(⑥)·AE·VAE(3-1)·결합-기본·결합-VAE(3-0)·60칸 신경망(②) — 층 구성·학습 설정 부록 A-8

### 7-3. 블록 OOF·엄격 OOF
- 전역 블록(d 기준): 1 = 2015-04-07 ~ 2017-06-30, 2 = 2017-07-01 ~ 2019-06-30, 3 = 2019-07-01 ~ 2021-06-30, 4 = 2021-07-01 ~ 2023-06-30, 5 = 2023-07-01 ~ 2025-06-30. 블록마다 나머지 4블록으로 학습한 모델이 그 블록 시료 예측(전역 블록 OOF)
- 엄격 OOF(딥러닝 값이 들어가는 모든 CV — 3-1 판·3-2 스태킹·3-3 앙상블·그 뒤 모든 단계): fold f 마다 train 행 값 = fold train 안 블록 OOF, validation 값 = fold train 전체로 학습한 모델
  - fold 안 블록 = 전역 블록 경계를 fold train 끝에서 자름, 같은 행으로 학습하는 모델은 한 번만 학습해 같이 씀(부록 A-12). 대상 = 3-0b 딥러닝 상위 3개 + 이상 점수 4종 + ⑥ 3종(추가 판 ④ 도 같은 규칙), 횟수는 부록 A-9
- refit·test 값 = 전역 블록 OOF(train 행) + test 전 전체 학습 모델(test 행, 2015-04-07 ~ 2025-06-30)
- 8-TD 대조 판(튜닝에 쓰인 시료의 딥러닝 값을 결측으로 둔 판) — 조건·횟수 부록 A-12

## 8. 계산·기록
- 순서: 단계 0 → 1-1(CPU)·1-2(GPU) 나란히(둘 다 0-1·0-3 의 공개 지연·0-4·0-5·0-7·0-9 뒤, 1-1 보고는 0-10 기준 줄 뒤) → 1-3(A·window 로 남은 일정 다시 추정해 알림) → ③(1차 뒤) → 2-0 → 2-1·2-1b → 미리보기 4-a(2-1 뒤) → 2-R → 3-0 → 3-0b → 딥러닝 상위 3개 전역·엄격 OOF(3-0b 끝 판으로) → ⑥·⑦·⑧ → 3-1 → 3-2(④ 같이) → 3-3 → 4(①·②) → 5·6 → 7 정식 보고 → 8 → 최종 모델

I = fold validation 쌍으로 계산한 섞기 전 − 섞은 뒤 구간 가중 PR-AUC. ψ_f = fold f M 회 중 I > 0 비율, π = 3M 칸(3 fold × M) 중 I > 0 비율, 기준 ψ_f ≥ 0.8, I > 0·ψ_f·π 판정은 반올림 없이
- 기록: 바퀴마다 그룹 × fold × r 의 I·ψ_f·π·남김·시도·채택, 기준·후보 fold 별 점수, 채택 있던 바퀴마다 기준 판 refit 1회 → test 예측(채점은 3-0b 끝난 뒤). 보고 때 다른 그룹의 비슷한 칼럼(기온 ↔ 지중온도, 1년·5년 검출률 ↔ WOE)은 서로 메워 중요도가 낮게 나온다고 적음
- 최종 모델 안 순열 중요도(부록 A-10): 대상 = 리서치 칼럼 9개 중 최종 모델 입력에 남은 것(칼럼마다)·리서치 변수 전체 한 묶음·부록 A-5 그룹 중 최종 모델 입력에 칼럼·채널이 있는 그룹 전부. 칼럼마다 = 같은 이름 칼럼만 섞음(구성 모델 입력·딥러닝 x_static 의 같은 칼럼 — 원 변수에서 나온 다른 칼럼·채널은 안 섞음, 그 칼럼의 결측 표시 칼럼도 같은 순열), 묶음·그룹 = 속한 칼럼·채널 전부. 섞는 칼럼·채널이 여러 구성 모델(트리·딥러닝 확률·이상 점수를 만드는 모델 포함) 입력에 있으면 모두 같은 순열로 섞고, 구성 모델을 섞인 입력으로 다시 추론(학습 없음, 이상 점수의 robust z 기준값(중앙값·IQR)은 원래 값 고정)해 스태킹·앙상블 예측을 다시 만듦, 딥러닝 확률·이상 점수 칼럼 자체는 섞는 대상 아님, 씨앗 평균 판은 씨앗 0~4 예측 평균

  - 2차 딥러닝(3-0·3-0b 의 딥러닝 5구조·결합 모델 2종 — 3-1 시퀀스 AE·VAE 는 이 x_seq 만): x_seq = 2차 기상 19 + 차감 19채널(N_ma = 2-1b 딥러닝 값, 원 변수마다) + SPI3·SPI6(표준화, 결측 0) + 결측 표시, x_static = g ÷ 50·`src_route`·계절 원핫 4칸·해외 구조적 결측 1칼럼 + 그 판 변수 묶음의 표 칼럼 중 시퀀스가 아닌 것(HIS1~HIS4·WX3~WX6 요약·FD1·SO1·X1·X2·L1 — window 요약 칼럼은 W_DL window 로 다시 계산, 표준화·결측 0 + 표시, FD1 의 aw_label 은 '결측' 범주 포함 원핫), x_cat 같음 — 채널·칼럼은 그 판 변수 묶음에 든 것만(3-0 = 전부, 3-0b 뒤 = 그 구조의 변수 묶음, 3-1 시퀀스 AE·VAE = 트리 대상 판 변수 묶음의 시퀀스 채널): 기상·SPI 채널 = 그 변수의 window 단위가 남으면, 차감 채널 = 그 변수의 차감 칼럼(요약 3칼럼 또는 원값 lag) 중 하나라도 남으면, 계절 원핫 = season 이 남으면, 표 칼럼 = 그 칼럼의 단위가 남으면 넣음
  - ⑥·⑦-D = x_seq(2차 딥러닝, 기상·차감·SPI 채널 전부) + g ÷ 50·해외 구조적 결측 1칼럼(§4-2). 결합 모델 = 2차 딥러닝 입력 그대로(정형 갈래 = x_static + x_cat 임베딩, 시계열 갈래 = x_seq)
  - AE·VAE 표 입력 = 트리 대상 판(그 판의 현재 입력)의 숫자 칼럼에서 h·g 를 뺀 것(단계 4~6·4-c 에서 다시 학습할 때도 3-1 때 칼럼 목록 그대로 — 단계 4~6 범주 숫자 인코딩 칼럼은 안 넣음)(§4-2 딥러닝 규칙: 표준화·결측 0 + 결측 표시 칼럼(해외 구조적 결측 1칼럼 포함), 복원 대상 = 입력 전체)
- 전부 결측·분산 0 변수는 표준화 생략·0
- 범주 번호표 = `sido`·`sgg`(국내 256 + 해외 나라 코드)·`p2`·`p3` 전체 범주로 고정, 모델마다 그 모델 train 에 없는 범주 → OOV(임베딩 벡터 0 고정). 표준화 통계 = 모델마다, 결측 표시 채널 = §4-2 의 그 차수 목록
- 이상 점수(§6 단계 3-1) = robust z = (원 점수 − 기준 중앙값) ÷ 기준 IQR(IQR = 기준 행 원 점수의 75% 분위 − 25% 분위, IQR = 0 이면 기준 표준편차로 나눔(그것도 0 이면 1)), 기준 = 그 모델의 조기 종료용 (`sgg`, d) 묶음 10% 중 불검출 행(가중치 학습엔 안 쓰고 에폭 고르기에만 쓴 행) — 순서·꼬리 유지, 모델 사이 크기 차이를 맞춤

- 모든 딥러닝 판 손실 = 이진 교차엔트로피, 배치 1024 — 교수님 practice 코드의 Focal 손실·batch 32 와 다름(담당자 결정 — 불균형 처리는 맨 끝 단계 8 에서만)
- 같은 수거 건·같은 제품이 train 과 채점에 겹치는지 따로 세지 않음 — 시간순 분할이라 같은 날 수거 건은 함께 들 수 없고, 같은 제품이 다른 해에 다시 검사되는 것은 운영과 같은 상황(담당자 결정 — 제품명은 다운사이징 행 고르기에만 써서, 교수님 고도화 계획서의 같은 제품 중복 점검과 다름)
- 제품명은 다운사이징 행 고르기(Theil's U 줄이기 칼럼)에만 쓰고 모델 입력(TF-IDF 등)에는 넣지 않음(담당자 결정 — 교수님 08 다운사이징 코드·고도화 계획서 기준 모델의 제품명 피처와 다름)
- 스태킹·이상 점수·딥러닝 확률의 OOF 는 과거만이 아니라 앞뒤 블록으로 만듦(교수님 고도화 계획서의 '시간 순서 OOF' 와 다름)

### A-12. 판별 예측·블록 세부
- 기호(§1-1 에 없는 것): I·π·ψ_f·r·M·G = 단계 3-0b 중요도 기호(부록 A-5, M = 섞기 횟수), θ = 생장식 온도 입력·γ_T·γ_pH·γ_aw·v = 생장식 항(부록 A-3)
- PR-AUC 동점 풀기(§1-2): PR-AUC·상위 q%(정렬 위에서 ⌈q% × 쌍 수⌉ 쌍) 는 쌍마다 한 점씩(동점 없이) 계산 — 정렬 = 원 예측값(float64) 큰 순 → 같으면 u_tie(부록 A-1) 작은 순. 이 순위를 점수(쌍 수 − 순위)로 바꿔 `precision_recall_curve`·`auc(recall, precision)`. threshold(§1-2)는 같은 값 묶음을 함께
- 동점 많은 판(§1-2): 모든 판에서 세 fold validation 예측(2차 사슬 부스팅은 CV 점수와 같은 교차 N 예측)을 합쳐 같은 원 예측값 묶음을 셈 → 가장 큰 동점 묶음 크기·그 안 검출 비율 기록, 가장 큰 동점 묶음 크기 ÷ CV fold validation 쌍 전체 ≥ 1% 면(test 는 기록만) 표에 '동점 많음(원 예측값 기준)' 표시(기준 줄 7-a 도 이 규칙으로), 후보 그대로(빼지 않음). 다시 채점(§1-2) = u_tie 를 md5(`lims_data_key`|h|1) 로 바꿔 한 번 더 채점해 순위·채택이 그대로인지 기록(규칙은 그대로), 1차·단계 2 준비 고르기에서도 동점 많은 판이 CV 1위와 0.001 안이면(1위면 2위와) 다시 채점하고 CV 1위가 동점 많으면 확정 전 알림
- 단계별 표 칼럼(§1-3): 단계·판 | 입력·모델 | CV 구간 가중(평균) | fold 1~3 | 같은 validation 으로 고른 횟수 | test 구간 가중 | test h 1~20·21~40·41~60 평균 | test 60일 통 | 공통 d 범위(08-30 ~ 05-02) 구간 가중(CV·test, 보조, 고르기에 안 씀) | 배수(구간 가중·60일 통) | threshold | Recall(test 쌍 전체·구간 가중) | Precision | F1·F2 | TP·FN·FP·TN | 상위 q% 포착률(q = 1·5·10·20) | (단계 4·5·6 판) 합친 threshold 의 fold 별 Recall
- '같은 validation 으로 고른 횟수'(§1-3) = 그 판 앞까지 같은 3 fold 로 CV 점수를 낸 모든 판·설정 수의 누적(1차 70 설정부터 — 3-0b 시도·7-a 격자 75·Optuna 시도·Focal 포함, 반복 수 56 시점은 안 셈 — 표 주석에 "반복 수 고르기(판마다 56 시점)는 셈에서 빠짐" 표시), 실험 로그에서 자동으로 셈
- 판별 학습 횟수(§1-2 동점): 트리 판 3 fold + refit = 4, 5·6 = 20, 딥러닝 단독·결합 = 그 모델 학습 수, 3-0b 끝 판 = 4(바퀴 학습 안 셈), 앙상블 = 0, 7-a = 0, ④ = 118, 다른 판 입력용 딥러닝 값 학습은 안 셈
- 3-3 앙상블 대조(§6 단계 3-3): 3-3 앙상블마다 백분위 평균(각 모델 예측을 백분위로 바꿔 평균 — 기준 분포 = 채점하는 쌍 자신의 예측 — fold validation 은 그 fold 채점 쌍, test 는 test 채점 쌍) 대조 — 기록용(학습 없음, 비교만, 운영에서는 이 기준 분포를 만들 수 없음), 3-3 표에 구성 모델별 예측 분위수(5·50·95%) 같이
- 3-0b 딥러닝 예측 범위: 전역 블록 OOF·엄격 OOF·트리 train 행(자기 h) 예측은 딥러닝 상위 3개만. 단계 4~6 판·① 의 train 행은 그 자료로 다시 학습한 fold 안 블록·전역 블록 모델로 (시료, 그 행의 h) 전부 추론(4-a = h 1~60, 4-a0 = 자기 h, ① = h 1), 이상 점수·⑥ 3종(3-2 (d)·(e) 입력)도 같게(4-a 면 h 1~60). 산출: 구조별 점수 표, 상위 3개 OOF·test 예측((시료, h) 60가지)
- 현재 최고 판이 앙상블일 때(단계 4~6·8): 단계 4~6·8 표에 구성 모델별 기법 전후 CV·구성 모델별 예측 분위수·백분위 평균 앙상블 CV(대조)를 같이 적음
- 단계 8 점수(§6 단계 8): 시도·8-T·Focal·8-TD 점수는 대상 판과 같은 방식으로 계산 — 대상이 앙상블이면 시도 고르기는 구성 트리마다 그 트리 단독 CV, 8-T·Focal 판 점수는 다시 평균한 앙상블 CV, 대상이 씨앗 평균 판이면 시도의 뽑기·모델 학습 씨앗 = 0(Optuna TPE 씨앗 42 는 그대로, AutoKeras 는 부록 A-7), 채택 직전 '고른 설정 대 기본 설정' 을 씨앗 0~4 예측을 평균한 뒤 매긴 CV 로 한 번 더 비교(고른 설정 씨앗 학습은 부록 A-9 미포함 +16 에 들어 있음) — 고른 설정이 오르지 않으면(같음 포함) 기본 유지(현재 최고 판과 판정 안 함, 판정 tag = 기본 유지), 오르면 그 판으로 그때의 현재 최고 판과 판정. 딥러닝 칼럼은 빼고 튜닝하므로 대상에 딥러닝 칼럼이 있으면 첫 시도(대상 판 설정)도 칼럼을 뺀 입력으로 3 fold 학습. 대상이 앙상블이면 채택 직전 '튜닝 설정 앙상블 대 기본 설정 앙상블' CV 도 기록(학습 추가 없음). ④ 가 대상이면 시도 고르기 = 기본 트리마다 그 트리 단독 fold validation CV(반복 수·learning_rate = 라이브러리 기본값 그대로 — ④ 규칙, learning_rate 는 탐색에서 뺌, §3 교차 N 안 씀), 판 점수 = 고른 설정으로 OOF 블록(§7-3)·메타 로지스틱을 다시 만든 ④ CV, Focal 도 ④ 의 CatBoost 에 같은 방식(OOF 다시)
- 단계 4~6 보고(§6 단계 4·5·6): 표에 현재 최고 판이 단계 4~6 판이 아니고 트리 부분이 있으면 '현재 최고 판과의 차이에 범주 인코딩 변경(단계 4~6 범주 숫자 인코딩)이 섞임' 한 줄, 줄이기·뽑기 뒤 train 에 없는 범주값의 validation·test 쌍 수·검출 수·그 쌍만의 점수를 fold 별로 기록
- 4-c·4-c-L(§6 단계 4): refit·test 의 5개 품목 = refit train 기준 상위 5개. 4-c 세부 = 줄이기 없음, 시료당 h 1개, 부스팅은 반복 수만 다시(그 품목 fold validation 쌍으로 §3 함수), 채점·threshold 는 그 품목 쌍으로 §1-2 규칙(threshold 지표는 자기 threshold 로 따로), 4-c-L 은 4-c 와도 비교. 보고 = fold 별 상위 5 품목 목록·fold 별 점수·상위 5 품목 밖 검출 수·전체 검출 중 비중(fold 별·test)을 같이 적고, 표 주석에 'CV 평균은 품목을 고르는 절차의 성능'
- fold 안 블록(§7-3) = 전역 블록 경계를 fold train 끝에서 자름: fold 1 = 블록 1·2·3 + 2021-07-01 ~ 2022-06-30(4블록), fold 2 = 블록 1~4, fold 3 = 블록 1~4 + 2023-07-01 ~ 2024-06-30(5블록)
- 같은 행 모델 재사용(§7-3): d ≤ 2021-06-30 모델 = fold 1 넷째 블록(2021-07-01 ~ 2022-06-30) OOF = fold 2 블록 4 OOF, d ≤ 2023-06-30 모델 = fold 2 fold train 전체 = fold 3 다섯째 블록(2023-07-01 ~ 2024-06-30) OOF = 전역 블록 5 OOF — 줄인·뽑은 자료로 학습하는 모델(단계 4~6·4-c 의 다시 학습한 값 모델·④ 의 블록 트리, 그 위 단계 8 의 값 모델 고른 설정)은 fold·refit 마다 학습 행이 달라 재사용 안 함: fold f 블록 모델·전역 블록 모델 = 줄이기·뽑기 전 행 중 그 모델의 학습 블록 시료로 다시 정한 줄인·뽑은 행(§6 2차 공통), fold f train 전체 모델 = fold f 의 줄인·뽑은 행, test 전 모델 = refit 의 줄인·뽑은 행
- 최종 모델 보조 표(§1-3, 고르기에 안 씀): 최종 모델 test 를 품목 묶음 × 국내·해외별로도 채점. 품목 묶음 = 농산물(1단계 식물성)·축산물·수산물(1단계 동물성의 2단계 축산물·수산물)·가공식품(1단계 가공식품)·기준규격외·그 밖·'코드없음', 1단계 = `p2` 를 `ba_data.t_prdlst_cl.hrnk_prdlst_cd` 로 따라 올라간 최상위 분류. 단위별 시료 수 구간(예: 하위·중간·상위 3분위)별 test 점수도
- 좌표 차이 민감도(§1-3, 1개, 학습 없음): 최종 모델 test 의 국내 행 예보 칸(T ~ E) 날마다 단계 0-3 에서 잰 시군구·변수별 평균 차이를 더하고, SPI 예보 칸·WX2~WX6 은 다시 계산, 딥러닝 값·시퀀스는 test 모델로 다시 추론(학습 없음), 해외 행은 그대로
- 학습률 읽기(§3)(2차 사슬): CatBoost 는 fold 마다 iterations = 2,000(최대 반복을 늘려도 2,000 고정)으로 학습을 시작해 첫 반복 뒤 콜백으로 멈추고 정해진 learning_rate 를 읽음(학습 횟수 아님)
- 범주 처리(§6 1·2차 모든 트리 판 — 부록 A-6 의 판(4-a·4-a0·미리보기·①·5·6·그 위 단계 8 판의 트리)은 단계 4~6 범주 숫자 인코딩(부록 A-6)): 범주 칼럼 전부(범주 5·season·aw_label, aw_label null = '결측' 범주 — 부록 A-4) — XGBoost·LightGBM = pandas category(범주 목록 = 그 모델 train 값, 없던 값 = 결측; XGBoost `enable_categorical=True`, LightGBM 범주 칼럼 지정), CatBoost = 문자열, RF·ExtraTrees = 정수 번호 1칼럼(번호 = 코드 문자열 정렬 순, 그 모델 train 값으로, 학습에 없던 범주 NaN), 로지스틱 = 원핫(0/1 그대로 — 표준화는 숫자 칼럼만, 없던 범주 전부 0)
- 단계 8 딥러닝 튜닝(AutoKeras) 뒤(§6 단계 8): 고른 설정으로 전역·엄격 OOF 다시 → 8-TD. 튜닝 검증 쌍과 겹치는 블록(fold 1 넷째 블록·fold 2·3 블록 4·전역 블록 4) OOF 의 PR-AUC 를 튜닝 전후로 기록, 대조 판은 아래 줄
- 8-TD 대조 판(§7-3): 최종 판이 8-TD 딥러닝 값을 쓸 때만, 튜닝 검증 시료(d 2021-07-02 ~ 2022-06-30) train 행의 딥러닝 값을 결측으로 둔 판 1회(3 fold + refit = 4, 기록만, 비교만)

### B-9. 받아들인 한계(보고서에 적음)
- 같은 3 fold 로 여러 번 고르고 기법마다 채택을 정함 → CV 가 높게 나오는 쪽: 채택 수·'같은 validation 으로 고른 횟수'(§1-3)·채택한 판의 fold 1 단독 상승 여부(참고용 — fold 1 도 교차 N·CV 평균에 들어가 독립 확인 아님)(§6 최종 모델)·단계별 test(§1-3)
- 2차 사슬은 앞에서 채택한 기법 위에서만 다음 기법을 보므로 순서에 따라 결과가 달라질 수 있음(정해 둔 순서)
- 1차 판·단계 2 준비 판·④ 는 라이브러리 기본 반복 수 — 2차 사슬 판과의 차이에 반복 수 고르기 효과가 섞임(④ 는 채택 비교에 그 차이가 섞임)
- 1차 해외 기상은 DB 값만(2015-01-01 전 NaN)이라 해외 행에 빈 변수·기간이 많음 — 2차와의 차이에 채운 기상의 효과가 섞이고(2-0 판으로 따로 봄), 2차부터 2014-04-07 ~ 12-31 을 Open-Meteo 로 채워 2015 년 초 d 해외 행의 window·차감 앞쪽 날 처리가 국내(2014 년에 닿으면 RR8 로 제외)·1차와 다름(§4-4)
- window 는 1차 4 알고리즘 결과로 하나만 정함 — 트리·딥러닝·3-0 의 다른 구조 모두 자기에게 맞는 window 를 따로 찾지 않음
- 구조마다 변수 묶음이 달라 3-2·3-3 의 구성 구조끼리 입력이 다름
- 3-0·3-0b 안에서 반복 수 고르기는 부스팅 3종만 — 첫 현재 최고 판·상위 3개가 부스팅 쪽으로 기울 수 있음
- 현재 최고 판이 딥러닝 단독·결합 모델·교체 후보면 3-1 은 트리 대상 판에 적용해 비교 — 효과가 있어도 채택되기 어려움(트리 판 전후로 기록)
- 현재 최고 판이 앙상블이면 단계 4~6·8 기법이 구성 모델 확률 크기를 바꿔 단순 평균 안 무게가 바뀜 — 판정에 기법 효과와 무게 변화가 섞임(백분위 평균 대조로 따로 봄)
- 현재 최고 판이 앙상블이면 단계 8 시도는 구성 트리마다 단독 CV 로 골라 앙상블에 가장 좋은 설정과 다를 수 있음(튜닝 앙상블 대 기본 설정 앙상블 CV 기록)
- ② 가 현재 최고 판이면(② 를 다시 학습한 5·6 판도) 단계 8 튜닝 안 함(트리 없음, 60칸 출력·줄인 자료 학습이라 AutoKeras 규칙 밖)
- 단계마다 test 를 보고하므로 뒤 단계의 사람 판단이 이미 본 test 에 영향받을 수 있음 — 판단마다 본 test 보고 목록 기록(§1-3)
- 1차·단계 2 준비 CatBoost(③·④ 포함)는 학습률이 학습마다 자동값이라 fold 모델과 refit 의 학습률이 다름 — fold 예측으로 뽑은 threshold 가 refit 예측 크기와 어긋날 수 있음, fold 별·refit 실제 학습률을 설정 덤프에 적고 표 주석에 표시(§3·부록 A-13)
- 5·6 은 씨앗 0~4 예측 평균(5개 모델 평균)이라 씨앗 1개 판보다 유리 — 5·6 채택이 5·6 쪽으로 기울 수 있음(뽑기 방식 효과는 씨앗 0 단독 줄로 따로 봄, §6 단계 5·6)
- 해외 남반구 나라는 계절 범주가 실제와 반대(보정 없음) — 범주 처리(단계 4~6 범주 숫자 인코딩 포함)·계절 그룹에 그대로 쓰임(§5 WX7)
- 단계 4~6 범주 숫자 인코딩은 2-1 에서 고른 k 와 전체 기간을 범주 칼럼마다 그대로 씀 — 범주별로 따로 검증하지 않고, 이 인코딩 효과만 따로 보는 판도 없음(부록 A-6)
- 트리 앙상블(3-3)은 확률 단순 평균이라 눈금이 큰 모델(부스팅·RF·ExtraTrees·로지스틱 사이) 쪽으로 쏠릴 수 있음 — 구성 모델별 예측 분위수를 3-3 표에 같이 적음(부록 A-12)
- ⑥·⑦ 의 '시계열만' 입력에도 결측 표시 채널·해외 구조적 결측 칼럼(⑥·⑦-D)·NaN 패턴(⑦-T)으로 국내/해외 정보가 들어감 — 3-2 (e) 해석에도 같음(§6 추가 판)
- ⑧ 은 기상이 있는 상태에서 고른 변수 묶음에서 기상만 빼므로 기상과 겹쳐 빠진 비기상 칼럼이 돌아오지 않음 — 기상의 추가 예측력이 크게 나올 수 있음(§6 추가 판)
- 단계 4·5·6 처럼 train 양성 비율을 바꾸는 판은 fold·refit 마다 줄인(뽑은) 양이 달라 예측 크기가 달라짐 — 합친 threshold 의 test Recall·Precision 이 어긋날 수 있음, 이 판들은 합친 threshold 로 본 fold 별 Recall 을 표에 같이 적음(§1-2·부록 A-12)
- h 는 해시로 무작위 배정이라 y 와 관계없고, h ≤ 10 은 입력이 거의 같음(완전 예보 가정) — 트리가 h 로 나누면 잡음을 배울 수 있음(§3·§4-1)
- k·N_ma 는 각자 다른 그룹 없이 고른 값을 2차 사슬에 함께 씀 — 다른 그룹과 함께일 때 가장 좋은 값이 아닐 수 있음(§6 2-1·2-1b)
- 최종 판이 튜닝한 딥러닝 값(8-TD)을 쓰면 튜닝 검증 시료의 딥러닝 값이 train 에 들어감: 8-TD 대조 판(§7-3)
- 분할·블록 경계 gap 0일(§3)
- 딥러닝 조기 종료는 (`sgg`, d) 묶음 단위 무작위 10% — 날짜 순서는 안 따짐(부록 A-8)
- ExtraTrees 는 NaN 행을 무작위 방향으로 보냄(결측 방향을 학습 안 함)
- 해마다 T 05-02 ~ 06-30 은 채점 안 됨 — h 구간마다 보는 계절이 다름(h 1~20 엔 5월 하순 ~ 6월 d, h 41~60 엔 7월 ~ 8월 중순 d 가 없음)(§3)
- OOV 행은 학습 때 한 번도 안 나와 처음 나온 시군구·나라·품목 예측은 학습되지 않은 값(부록 A-8)
- 예보 칸 = 관측값(완전 예보 가정) → test 는 예보 오차가 없는 경우의 점수 — 좌표 차이 민감도로 관측 위치 차이만 확인(예보 오차는 못 잼, §1-3)

- ② 는 한 입력으로 모든 h 를 내므로 E = T + 1 — 예보 칸 T+2 ~ T+10 은 안 씀(부록 A-8)
- ①·② 는 단계 4 채택 여부와 관계없이 줄인 자료로 학습(줄인 뒤 당일 예측·60칸 출력을 보는 설계) — 비교 상대(① = 최종 모델, ② = 단계 4 판정 때 현재 최고 판)가 줄이지 않은 자료면 ① 의 h = 1 비교·② 판정에 다운사이징 효과가 섞임
