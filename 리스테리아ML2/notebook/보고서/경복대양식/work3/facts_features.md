**낱말 빈도 TF-IDF N0 — n0, 500칸**(`scripts\04_단위날짜_tfidf.py`)
- 설정 = 교수님 노트북 Listeria_05 와 같음: TfidfVectorizer(analyzer='char', ngram_range=(2, 4), max_features=300, min_df=5) + TfidfVectorizer(analyzer='word', ngram_range=(1, 2), max_features=200, min_df=3), 나머지 기본값(소문자, l2 정규화, smooth_idf). 입력 = prduct_nm 원문(fillna(''); 위 글 정리 규칙은 쓰지 않음).
- 어휘·IDF = 겹마다 그 겹 학습 끝 날까지 시료로만 fit, 전체 시료에 transform: 학습 끝 2022-06-30(시료 311,243건), 2023-06-30(382,125), 2024-06-30(458,572), 최종 2025-06-30(541,677). 네 판 모두 어휘 300 + 200 이 다 참. 파일 `ML2\data\데이터셋\제품명\단위날짜_tfidf_train<날짜>.parquet`·`단위날짜_tfidf_어휘_train<날짜>.csv`(열이름·종류·어휘·idf·학습 끝 기준일·학습 행 수).
- 단위 × 날짜 값 = 그 단위·그날 시료들의 TF-IDF 벡터 평균. 칸 tf_c_000~tf_c_299, tf_w_000~tf_w_199(500칸, h 와 무관). n_rows 는 입력에서 뺌. 실험은 겹 k 에 그 겹 파일, 최종·시험에 2025-06-30 파일(`final_cat\config.json` tfidf fold_specific true).
- 예: 최종 판 IDF 가 가장 낮은(가장 흔한) 낱말 "1차, 완제품, 가열후, 가열전, 가열, 살균전, 살균후, 살균".

**운영 전제**: N2·N0 는 맞히려는 날 d 의 그 단위 시료 제품명으로 만든 값 → 운영에서 예측할 때 그날 검사할 제품명을 입력받아야 쓸 수 있음(사양 2절 "운영 때 그날 검사할 제품명을 입력한다는 전제(보고 때 명시)", 코드 묶음 표시 premise). 입력받지 않는 운영이면 과거 시료만 쓰는 N1 만 해당. 튜닝 '변수 전부'에 처음부터 넣음(사용자 10-20).

**쓸 수 있는 시점**: N1 = T−1 까지(학습 행) / 학습 끝 날(맞혀 보는 행·시험 행). N2·N0 = 그날(d) 제품명 — 운영 전제.

**결측과 이유**
- N1 비율 = 창 안 그 단위 시료 0건이면 결측: 5년 학습 3.434% · 겹1 2.102% · 겹2 1.679% · 겹3 1.444% · 시험 1.594%, 1년 학습 4.490% · 겹1 3.367% · 겹2 3.102% · 겹3 3.121% · 시험 3.015%.
- N1 스무딩 검출률 = 같은 창 전국에 그 뭉치 시료 0건이면 결측: 학습 행만(행 기준 31.444%, 칸 기준 5년 1.873%·1년 1.875%), 겹·시험 0%. 늦게 처음 나온 뭉치 때문: 첫 시료 버섯재배_작업장 2019-12-02, 소독_헹굼 2017-03-07, 팽이버섯 2017-03-02, 날수산물_회 2017-02-24, 시설환경_검체 2016-08-29 등(그 전 예측일의 학습 행; `work3\ff_scripts\ff_nb_facts.py`).
- N2·N0 결측 없음(0 = 그날 그 단위 시료에 그 뭉치·그 조각 없음; N0 파일 nan 칸 0 — `results\nb_preflight.json`).

## 13. 이상치 점수(AE·VAE) — 묶음 ae4, 4칸

**왜 넣었나**: 계획서(readme) 8절 "검출 사례가 극소수라는 점을 고려해 비지도 이상 탐지 모델도 비교한다", "정상 데이터 중심으로 학습한다", "AE 또는 VAE 이상 점수를 기존 XGBoost 피처에 추가한다", 주의 "정상 데이터에서 벗어나는 패턴이 반드시 리스테리아 검출을 의미하지는 않는다". 교수님 10-12 통화(메모): "Variational Autoencoder(정상 데이터만 학습 → threshold 바꿔가며 검증, false negative 보완 목적)". 교수님 10-20 통화: 학습 자료 정상만 학습 → 비정상 맞춰 보기 → 홀드아웃. 사양 4절 10번(사용자 확정 10-21: 점수를 최종 CatBoost 입력으로 넣어 보기).

**어떻게 만들었나**(`ML2\exp\3_시간순교차검증\src\ae3.py`, 부품 `e2ae.py`, 설정 `e2cfg.py` AE)
- 모델 4개: 표 AE(AEt)·표 VAE(VAEt) = 완전연결 [숫자 입력 + 범주 임베딩(각 8차원)] → 128 → 64 → 잠재 16 → 64 → 128 → 숫자 입력 복원. 시퀀스 AE(AEs)·VAE(VAEs) = 기상 창 T−80…T−1 의 18개 변수 표준화 값 + 결측 표시 18 = 36채널, 1D 합성곱(36 → 32 → 16채널, 길이 80 → 40 → 20) → 전치 합성곱으로 복원(AEs 매개변수 25,220 = 36채널 구조와 맞음).
- 표 입력(3차): 그 실행 숫자 칸 가운데 그날 제품명 칸(n2·n0)과 거른 기상 변수(CO) 칸을 뺀 것 + 범주 5칸(sido·sgg·p2·p3·aw_label) 임베딩. 최종 = 숫자 473칸(h 1 + 기상 요약 234 + 과거 이력 15 + WOE 4 + SPI 26 + 토양 3 + 식품 3 + 생장식 16 + 이동평균 차감 57 + 생장 범위 19 + 외부 지표 3 + N1 92). 숫자는 칸별 표준화 뒤 결측 = 0(평균 자리).
- 점수(클수록 이상 = 검출 쪽): AE = 복원 오차 평균제곱(MSE), VAE = 음의 ELBO(0.5·Σ 복원 오차² + KL, 점수 계산 때 z = 잠재 평균).
- 학습: 범위마다(겹 k = 그 겹 학습 행 / 최종 = 학습 자료 전체) 학습 행 전부를 5겹에 무작위 배정, 겹 모델 m 은 자기 겹 밖 학습 행 중 불검출(y = 0)만으로 학습·정규화(10% 는 조기 종료용). 학습 행 점수 = 그 행을 안 본 겹 모델 점수, 맞혀 보는 행·시험 행 점수 = 겹 모델 5개 평균. Adam lr 1e-3, 배치 1,024, 최대 50에폭, 인내 5. 크기·학습률은 기본값(조정 안 함). 그 범위 밖 정답은 학습·정규화·어휘에 안 들어감.
- 최종 범위: 학습 정상 행 256,069, 검출 973.
- 원본 판과 지터링 판(사양 4절 10번): 지터링 = 겹 모델 학습 행을 한 벌 더 붙이고 그 벌의 표준화 입력에 N(0, 0.03²) 잡음. 단독 점수(교차검증 세 겹 평균 구간 가중 PR-AUC) 원본 AEt 0.0201·VAEt 0.0233·AEs 0.0037·VAEs 0.0040, 지터링 0.0194·0.0234·0.0037·0.0039; 4개 평균 원본 0.012783 > 지터링 0.012593 → 원본 점수를 씀(`tables\이상치단독.csv`, `post_cat\summary.json` ae_into_model).

**모델에 어떻게 들어가나**: ae_AEt·ae_VAEt·ae_AEs·ae_VAEs(4칸), 숫자 칸 맨 끝. 묶음 빼기 동안에는 처음 계산한 점수를 고정 묶음으로 씀.
