## 5. 고도화 ②: 튜닝

○ 튜닝은 70개 설정 비교의 1위 모델에 추가 데이터·파생변수까지 모든 변수를 넣고 함. 변수 선택보다 먼저 한 것은 변수 제외 판단을 실제로 쓸 하이퍼파라미터 위에서 하려는 것임
○ Optuna(하이퍼파라미터 자동 탐색 도구)의 TPE 방식(앞선 후보의 점수를 보고 점수가 높을 법한 하이퍼파라미터를 고름)으로 후보 30개를 평가함(아래 표[16] 참고)

| 하이퍼파라미터(뜻) | 탐색 범위 | 고른 값(18번 후보) |
|:---|:---:|---:|
| learning_rate(트리 하나를 추가할 때 예측을 고치는 폭) | 0.01 ~ 0.3(로그 스케일) | 0.1408 |
| depth(트리 깊이) | 4 ~ 10(정수) | 4 |
| l2_leaf_reg(리프 값에 거는 벌점, 클수록 보수적) | 1 ~ 30(로그 스케일) | 2.311 |
| random_strength(트리 분할(split)을 고를 때 주는 무작위성의 크기) | 0.1 ~ 10(로그 스케일) | 2.885 |
| bagging_temperature(행마다 무작위 가중치를 줄 때의 세기) | 0 ~ 1 | 0.796 |

○ 상위 5개 후보는 Recall 이 0.80 으로 같아 오탐(FP)을 바로 견줄 수 있음(아래 표[17] 참고)

## 6. 고도화 ③: 변수 선택

○ 18번 후보의 하이퍼파라미터 그대로 기상 변수 거르기와 같은 방법으로 변수를 골랐고, 회차마다 permutation importance 를 다시 잼
- 여러 컬럼으로 된 변수는 그 컬럼들을 한꺼번에 뒤섞음. 함께 만든 컬럼들은 정보가 겹쳐, 한 컬럼만 섞으면 다른 컬럼이 그 정보를 대신하기 때문임
- 범주 4개와 h 는 예측 단위·거리를 나타내는 입력이라 후보에서 제외함
○ WOE 만 제외되어 21개 변수(숫자형 995개 + 범주형 1개 컬럼, h·범주 4개를 더한 최종 입력은 숫자형 996개 + 범주형 5개 컬럼)가 남음(아래 표[18] 참고, 변수별 결과는 부록 표[24]). WOE 는 permutation importance 가 22개 중 5번째로 컸지만 제외하니 점수가 오름

| 회차 | 후보 변수 | 제외한 변수(점수 변화) | 유지한 변수의 제외 후 점수 |
|:---|:---|:---|:---|
| 1회차 | 22개 | WOE(18번째, 0.0857 → 0.0927) | 21개 0.0649 ~ 0.0843 |
| 2회차 | 21개 | 없음 | 21개 0.0654 ~ 0.0894(기준 0.0927) |
[표] 변수 제외 요약(교차검증 구간 가중 PR-AUC)

## 7. 최종 모델 결과(test 1년)

○ 최종 모델은 CatBoost(18번 후보의 하이퍼파라미터)에 WOE 를 제외한 추가 데이터·파생변수까지 모든 변수(숫자형 996개 + 범주형 5개 컬럼)를 넣은 것임
- 운영 조건과 같게 train 전체로 다시 학습했고, test 정답을 보지 않도록 반복 수(트리 수)는 3개 fold 최적 반복의 평균(127회)으로 고정함
- threshold(0.004895)는 3개 fold 의 validation 행 예측을 합쳐 정했고 test 에 그대로 씀
○ test 구간 가중 PR-AUC 는 0.0785(교차검증 0.0927)이고, 교차검증에서 정한 threshold 로 test Recall 0.80 을 지킴(아래 표[19] 참고)

## 8. 추가 실험

### 8.1 고위험 품목 전용 모델

○ train 검출 시료 1,578건의 91.1%(1,437건)가 몰린 상위 5품목의 행만으로 따로 학습한 전용 모델은, 같은 품목 행에서 전체 모델보다 구간 가중 PR-AUC 가 낮아(교차검증 0.0732 대 0.0946·test 0.0634 대 0.0766) 최종은 전체 모델 하나로 둠

### 8.2 이상치 탐지(AE·VAE)

○ 이상치 점수 4개를 그대로 검출 예측값으로 쓰면 교차검증 구간 가중 PR-AUC 가 0.0037 ~ 0.0233 으로 최종 모델(0.0927)보다 낮지만, CatBoost 입력으로 넣으면 안 넣은 판보다 높아(교차검증 0.0927 대 0.0718·test 0.0785 대 0.0700) 넣은 판을 최종으로 함

### 8.3 딥러닝(BiLSTM·트랜스포머)

○ 기상 일별 순서를 그대로 읽는 신경망이 요약 입력 트리보다 나은지 보려고, 구조 2개(BiLSTM, 트랜스포머 = 모든 날의 값을 서로 견주어 읽는 신경망) × 방식 2개(A = h 를 입력으로 넣고 값 1개 출력, B = 60일을 값 60개로 출력) × train 행 순서 2개(에폭(train 행을 한 번 다 도는 것)마다 셔플(shuffle), 시간 순서) = 8개를 교차검증으로 견줌
○ 8개의 구간 가중 PR-AUC 는 0.0472 ~ 0.0855 이고, 가장 높은 트랜스포머·방식 A·에폭마다 셔플(0.0855)은 같은 입력(기상 + 범주)의 1차 베이스라인(0.0740)보다 높지만 최종 CatBoost(0.0927)보다 낮음

## 9. 소결 및 향후 계획

### 9.1 요약

○ 교차검증 구간 가중 PR-AUC 는 1차 베이스라인 0.0740 에서 최종 0.0927 로 올랐고, test 1년 구간 가중 PR-AUC 는 0.0785(60일 평균 PR-AUC 0.0772)임(아래 표[20] 참고)

| 단계 | 한 것 | 구간 가중 PR-AUC |
|:---|:---|---:|
| 1차 베이스라인 ① 70개 비교 | CatBoost·기상 요약·80일 1위(기상 19변수, 기본 하이퍼파라미터) | 0.0718 |
| 1차 베이스라인 ② 기상 변수 거르기 | 일산화탄소 제외(기상 18변수) | 0.0740 |
| 고도화 ① 스무딩 계수 고르기 | 1차 베이스라인 + 과거 검출 이력 9개 컬럼, k = 200 | 0.0696 |
| 고도화 ② 튜닝 | 추가 데이터·파생변수까지 모든 변수(숫자형 1,000개 + 범주형 5개 컬럼), 튜닝 후보 18번 | 0.0857 |
| 고도화 ③ 변수 선택 | WOE 제외(숫자형 996개 + 범주형 5개 컬럼) = 최종 모델 | 0.0927 |
| 최종 모델 test 1년 | train 전체로 다시 학습, 한 번 채점 | 0.0785 |
[표] 단계별 점수(마지막 줄은 test, 나머지는 교차검증 3개 fold 평균)

○ test 1년에 Recall 0.80·검사축소율 84.4% 이고, 확률 상위 20% 행만 검사해도 검출의 86.0% 를 잡음. 추가 실험은 모두 최종 모델보다 낮음

### 9.2 한계

○ 그날 제품명 두 변수는 운영 때 그날 검사할 제품명을 입력해야 쓸 수 있는데 입력 여부는 확인되지 않았고, 하나씩 제외하면 교차검증 구간 가중 PR-AUC 가 0.0927 → 0.0706·0.0741 로 낮아짐
○ 제품명 뭉치와 식품 속성 대표값은 train 기간 안의 자료로 한 번만 만들어 교차검증 fold 에는 validation 연도의 정보가 섞이므로, fold 점수에서 제품명 변수가 좋게 나올 수 있음(test 는 해당 없음)
○ 과거 검사 결과로 만든 값은 그해 내내 학습 끝 날 값이라 뒤쪽 날일수록 오래된 값이고, 검사 결과가 분기마다 늦게 반영되는 시차는 넣지 않음
○ 부스팅 반복 수를 fold 의 validation 행 점수로 정해 교차검증 점수가 실제보다 높게 나올 수 있으므로, 성능은 test 점수(구간 가중 PR-AUC 0.0785, 60일 평균 PR-AUC 0.0772)로 봄

### 9.3 운영

○ 매년 6월 30일까지의 자료로 교차검증 → threshold → train 전체로 다시 학습을 되풀이하고, 과거 검출 이력·제품명 변수·이상치 점수 모델도 함께 다시 만듦
○ 운영 전에는 그날 검사할 제품명을 입력하는지, 기상·표준강수지수·토양·외부 지표가 예측하는 날 전날까지 들어오는지 확인해야 함
