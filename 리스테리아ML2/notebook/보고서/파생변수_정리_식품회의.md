## 공통 규칙

- 날짜가 있는 값은 예측하는 날 T 의 전날(T−1)까지 나온 자료로만 만듦. 예외는 그날 제품명 변수 2개(그날 제품명 유형·TF-IDF)로, 운영 때 그날 검사할 제품명을 입력한다는 전제임
- 날마다 있는 기상·표준강수지수 값은 80일 window(T−80 ~ T−1)로 요약함. 과거 검사 결과로 만든 값은 train 행에서는 T−1 까지의 rolling window 로, validation·test 행에서는 train 끝 날 값을 1년 내내 그대로 씀(1년마다 다시 학습하는 운영과 같은 조건)
- 결측은 채우지 않고 그대로 입력함(CatBoost 입력 기준, 결측을 CatBoost 가 직접 다룸). 외부 자료의 업소 수·면적·검정 건수처럼 해마다 커지는 건수는 날짜를 대신 알려 줄 수 있어 비율·중앙값으로만 입력함
- 변수 선택: 여러 컬럼으로 된 변수는 컬럼 전체를 한 변수로 다룸. 후보(이 문서 21개 + 기상 요약)를 permutation importance 낮은 순으로 하나씩 제외해 다시 학습한 교차검증 구간 가중 PR-AUC 가 오르면 제외, 아니면 유지하고, 제외된 변수가 없는 회차까지 되풀이함. 범주 4개(시도·시군구·품목 2·3단계)와 h 는 후보 아님
- permutation importance(Breiman, 2001) = validation 행에서 한 변수의 컬럼 값만 h 마다 행끼리 뒤섞었을 때 구간 가중 PR-AUC 가 줄어든 양(3개 fold 평균, 다시 학습 안 함 → 제외해 볼 순서에만 씀). 0 = 뒤섞어도 점수 그대로, 음수 = 뒤섞었더니 점수가 오름
- 내장 중요도 = 최종 CatBoost 가 그 변수 컬럼으로 분할해 예측을 바꾼 정도(PredictionValuesChange)의 전체 대비 비중(%). 0% = 최종 모델 트리 127개에서 그 컬럼으로 분할한 곳 없음. scikit-learn 공식 문서는 내장 중요도가 값 종류가 많은 변수에 치우칠 수 있다고 경고함
- 점수 흐름: 교차검증(시간순 3개 fold 평균) 1차 베이스라인(LIMS 기본 입력 + 기상 요약, 기본 하이퍼파라미터) 0.0740 → 변수 전부 추가 + 하이퍼파라미터 튜닝 0.0857 → WOE 제외 최종 0.0927 / test 1년(T 2025-07-01 ~ 2026-05-01) 1차 베이스라인 0.0362 → 최종 0.0785

## 1. 표준강수지수(26, `spi3_*`·`spi6_*`)

**만든 이유**
- 1차 실험 뒤 다음 과제로 정한 추가 자료(입력이 지역·품목군·기상뿐이라 표준강수지수·토양·식품 속성을 붙여 성능 변화를 비교) 중 하나
- 식품안전정보원 제공 예측인자 정리 자료(예측인자 정리 ppt.jpg)의 리스테리아 예측인자 우선순위에서 강수가 9위라, 지역·날짜별로 만들 수 있는 표준강수지수를 추가함
- SPI3·SPI6 = 최근 3·6개월 누적 강수량이 평년보다 많은지 적은지를 표준화한 값. SPI6 은 기상청 기상가뭄 판단 기준, SPI3 은 보조 지표라 둘 다 씀

**만든 방법**
- 원자료: 기상청 기상자료개방포털 표준강수지수 일자료(66지점, 2014-01-01 ~ 2026-10-06) 값 그대로. 시군구 값 = 날마다 시군구 대표 좌표에서 가까운 3지점 평균(지점까지 평균 거리 중앙값 27.21km)
- 80일 window(T−80 ~ T−1)를 10일 구간 8개 평균 + window 평균·표준편차·최소·최대·기울기로 요약함(T 당일 값은 안 씀)
- 결측 train 0.34% / test 5.15%: 원자료에서 모든 지점 값이 빈 날(SPI3 42일·SPI6 41일)이 10일 구간을 통째로 덮은 경우(test 는 2025-05 의 빈 날이 앞쪽 window 에 들어감)

**사용 방법**
- 숫자형 26컬럼(지수 2개 × 13)을 그대로 입력, 변수 선택에서 26컬럼을 한 변수로 다룸

**효과**
- permutation importance 1회차 −0.000293 · 2회차 −0.000728
- 제외 후 점수 1회차 0.0800(기준 0.0857) · 2회차 0.0732(기준 0.0927) → 유지, 최종 모델 사용
- 최종 모델 내장 중요도 비중 1.14%

- 한계: 포털에는 조회한 날 2일 전 값까지 있어, 운영 때 T−1 값을 받을 수 있는지 확인되지 않음

**사용 방법**

## 14. 과거 검출 이력(9, `hist_rate5y_*`·`hist_logn5y_*`·`hist_rate1y_*`)

**만든 이유**
- 품목·지역의 과거 검출 이력이 새 예측 정보를 주는지 보려고 추가함(「리스테리아 검출 예측 모델 성능 개선 실험 계획서」의 스무딩 검출률·로그 검사 수 항목)

**만든 방법**
- LIMS 시료 자료로 세 수준(컬럼명 끝 p3·sgg·unit = 품목 3단계 전국·시군구·예측 단위)마다 5년·1년 window 의 시료 수 n·검출 수 s → 스무딩 검출률 = (s + k·p0) ÷ (n + k)(p0 = 같은 window 전국 검출률, 검사 수가 적을수록 p0 쪽으로 당겨짐)
- 5년 로그 검사 수 = log(1 + n)(검사 수가 0건 ~ 18만여 건이라 줄여 입력). k = 200: 1차 베이스라인 + 이 9컬럼으로 k 10·30·50·100·200 을 비교한 교차검증 0.0591·0.0617·0.0683·0.0678·0.0696 중 가장 높은 값
- train 행은 T−1 까지 rolling window, validation·test 행은 train 끝 날 값을 1년 내내 씀. 결측 train 0.001% / test 0%(전국 window 시료 0건일 때만, 로그 검사 수는 결측 없음)

**사용 방법**
- 숫자형 9컬럼(3수준 × 5년 검출률·5년 로그 검사 수·1년 검출률), 한 변수

**효과**
- permutation importance 1회차 0.026935 · 2회차 0.022026
- 제외 후 점수 1회차 0.0775(기준 0.0927, WOE 제외 뒤) · 2회차 0.0775(기준 0.0927) → 유지, 최종 모델 사용. 1차 베이스라인(0.0740)에 이 9컬럼만 추가했을 때는 0.0696(k = 200)
- 최종 모델 내장 중요도 비중 32.27%(최종 모델 입력 변수 중 가장 큼)

- 한계: 검사 결과가 분기마다 늦게 DB 에 들어오는 시차는 반영하지 않았고, validation·test 행은 뒤쪽 날일수록 오래된 값임

## 17. WOE(4, `woe_sido`·`woe_sgg`·`woe_p2`·`woe_p3`, 최종 제외)

**만든 이유**
- 실험 계획서: 스무딩 검출률과 같은 시간 분할에서 견주려고 WOE(범주별 검출군·불검출군 분포 차이를 숫자 하나로 만든 값)를 추가함

**만든 방법**
- woe = ln((s + 0.5) ÷ (S + 0.5)) − ln((n − s + 0.5) ÷ (N − S + 0.5)), 5년 window, 네 수준(시도·시군구·품목 2단계·3단계), N·S = 같은 window 전국 시료·검출 수, 검출 쪽 비중이 클수록 양수. window 규칙은 과거 검출 이력과 같고 결측 없음

**사용 방법**
- 숫자형 4컬럼, 한 변수. 최종 CatBoost 입력에서는 제외했고, 이상치 점수의 표 입력에는 남아 있음

**효과**
- permutation importance 1회차 0.007628(22개 중 5번째로 큼)
- 1회차 18번째로 제외해 보니 0.0857 → 0.0927 로 올라 제외(2회차 후보 아님)
- 최종 모델 내장 중요도: 해당 없음(최종 모델에 없음)

- 값 = 맞히려는 날 d 의 그 예측 단위 시료 벡터 평균(h 와 무관), 결측 없음

**사용 방법**
- 숫자형 500컬럼, 한 변수

**효과**
- permutation importance 1회차 0.025581 · 2회차 0.031051
- 제외 후 점수 1회차 0.0741(기준 0.0927, WOE 제외 뒤) · 2회차 0.0741(기준 0.0927) → 유지, 최종 모델 사용
- 최종 모델 내장 중요도 비중 12.14%

- 한계: 그날 제품명 유형과 같은 운영 전제(그날 제품명 입력 여부 미확인)

## 21. 이상치 점수(4, `ae_AEt`·`ae_VAEt`·`ae_AEs`·`ae_VAEs`)

**만든 이유**
- 검출이 train 행의 0.38% 뿐이라, 불검출 행만 배운 모델이 잘 복원하지 못하는 정도(평소와 다른 정도)를 점수로 만들어 추가함(실험 계획서: 정상 데이터만 학습한 AE·VAE 의 이상 점수를 입력에 추가)

**만든 방법**
- 오토인코더(AE, 입력을 작게 줄였다가 복원하도록 배우는 신경망)와 변분 오토인코더(VAE, 줄인 값을 확률 분포로 두는 AE)를 표 입력과 기상 80일 시퀀스에 하나씩 둬 4개. 운영 때 늘 쓸 수 있도록 그날 제품명 변수는 입력에서 제외
- 표 입력 = 숫자형 473컬럼(최종 제외한 WOE 4컬럼 포함, 컬럼별 표준화 뒤 결측 = 0) + 범주형 5컬럼, 기상 시퀀스 = 18개 변수(결측 표시 채널 포함). 점수를 쓸 수 있는 시점 = 입력과 같음(1년마다 다시 학습)
- 점수 = AE 복원 오차, VAE 음의 ELBO(복원 오차 + 줄인 값 분포와 표준정규분포의 차이). train 행을 5개 fold 로 나눠 다른 fold 의 불검출 행으로만 학습하고, train 행 점수는 그 행을 안 본 모델로, validation·test 행 점수는 5개 모델 평균으로 냄(교차검증 fold 마다 다시 학습). 결측 없음

**사용 방법**
- 숫자형 4컬럼, 한 변수(변수 선택 동안 점수는 처음 계산한 값으로 고정)

**효과**
- permutation importance 1회차 −0.000093 · 2회차 0.000222
- 제외 후 점수 1회차 0.0657(기준 0.0857) · 2회차 0.0718(기준 0.0927) → 유지, 최종 모델 사용
- 최종 모델 내장 중요도 비중 0.24%. 점수만으로 검출을 예측하면 교차검증 0.0037 ~ 0.0233, CatBoost 입력에 넣은 판과 안 넣은 판은 교차검증 0.0927 대 0.0718·test 0.0785 대 0.0700

- 한계: 표 입력에 최종 CatBoost 에서 제외한 WOE 4컬럼이 남아 있음(변수 선택 전 입력으로 계산)
