사용자가 1차 보고서 116쪽 초안(교수님 「1차 고도화 전략」 1~12절 틀)을 보고 지적([종합] 전달, 10-19):
1. "계획서 n절의 ~" 같은 다른 문서 언급 금지 — 보고서만 읽어도 이해되게.
2. 우리 실험이 빠지고 교수님 양식만 들어감 → 베이스라인 = LIMS+기상, 그다음 = LIMS+기상+외부 수집 데이터+파생변수, 우리 실험을 다 넣기.
3. 분량을 지금의 1/10 이하로(그것도 길다고 함) — 글은 최소, 짧은 글 + 그걸 보여 주는 표·그림.
4. 순서는 우리가 실제로 한 대로 점진적으로(토양·식품·표준강수지수 등을 넣을 때마다 점수가 어떻게 바뀌었는지).

**Why:** 남의 문서 틀을 따라가다 보고서가 길어지고 정작 우리 작업이 안 보였음. 받는 사람은 이 보고서 한 부만 읽음.

**How to apply:** 보고서·요약 문서를 쓸 때 다른 문서의 절 번호·제목을 근거처럼 끌어오지 말고 내용으로 직접 설명한다. 실험은 기준 → 데이터·변수 추가 순서로 단계별 점수 표·그림으로 보여 주고, 문장은 표·그림을 읽는 데 필요한 만큼만. 에이전트에 보고서를 맡길 때 이 네 가지를 지시에 그대로 넣는다. 관련 [[feedback-report-plain-language]], [[feedback-no-stddev-caveats]], [[listeria-1017-professor-call]].
