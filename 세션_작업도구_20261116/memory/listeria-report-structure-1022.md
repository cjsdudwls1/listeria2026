**틀**: 경복대 양식(`문서/영진문서/경복대학교 2차 보고서(전처리 수정 후).hwp`, 아플라톡신 하이브리드 예측모델 연구 보고서 54쪽; 변환본 `리스테리아ML2/notebook/보고서/경복대양식/template/kb.txt`)의 I 데이터 전처리·II 예측모델 개발, III 시스템 구현은 뺌. 1·2차(검증 한 해 방식) 실험은 뺌. 분량 15~20쪽(특성 설명 늘어 20쪽 안팎).

**순서(사용자 제안 수용)**: 1차 베이스라인은 LIMS+기상만 쓰므로 특성공학보다 앞. I = 기본 데이터(수집·병합·정제, EDA, 베이스라인용 데이터) / II = 서론 → 실험 설계 → 3 베이스라인(70개·기상 거르기) → 4 고도화① 추가 데이터·특성공학 → 5 튜닝 → 6 변수 선택 → 7 최종 시험 → 8 추가 실험(고위험·이상치·딥러닝) → 9 소결(요약·한계·운영·앞으로 할 실험) / 부록 입력 변수 기록표.

**특성공학 서술 규칙(사용자)**: 묶음마다 왜 넣었나·어떻게 만들었나·모델에 어떻게 들어가나를 짧지만 납득되게. 친환경·지하수·HACCP 은 과거 식품안전정보원 과제(식품안전지수)와 이번 과제의 연결이 의미 있다고 강조. 제품명 뭉치는 구성(글 정리 → 정규식 23개, 선정 기준·검수 원칙, 뭉치 목록 표)과 쓰임(과거 유형·그날 유형·TF-IDF, 운영 전제)을 소상히.

**방법 서술 규칙(사용자 10-22)**: 조인·정제·나누기·변수 만들기 등 방법을 쓰는 곳마다 "왜 그렇게 했는지" 타당한 근거를 1~2줄 이내로 짧게 붙인다(예: 시군구 배정 → 운영 예측 단위가 시군구라서 / 결측을 채우지 않음 → 채운 값이 실제 관측으로 오해되지 않게, 트리 모델은 결측을 그대로 다룸).
