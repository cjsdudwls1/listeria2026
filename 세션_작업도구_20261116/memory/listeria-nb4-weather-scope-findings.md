2026-09-15 `리스테리아ML/notebook/4_기상_가공식품_타겟범위.ipynb` (1~14절, 커밋 a3d5e55). 사용자 초점: "기상 시계열이 가공식품과 연결되나, 타겟 범위 설정". 모든 해석은 추정이며 질문 리스트 v0.3 으로 담당자·전문가에게 넘김.
- 기상 연결: 국내 가공식품 294,421행 → 원본 제조일 222,607 → ASOS 7일 창 213,220행. 같은 달 안 기온 OR 1.184(업체 p 0.032, 검사기관 p 0.218) → +시도 1.053(p 0.51). 봄(4월) 최고, 가장 더운 8월 7위; 비가열 식육 봄 초과는 자가품질위탁 층에서 안 보임(p 0.83).
- 기준 날짜: 원본 제조일 기준 7일 창은 기준규격외 19.8%·원물 33.1%만, 의뢰일 기준 97.6%·82.6%.
- 구성 착시: 검출 82.2% 가 검사목적 '기타'. 비가열 식육 검출 66% 가 '기타', 자가품질위탁 층에선 가열 식육과 비슷(0.128 vs 0.111%). 국내 가공식품 '결과 1개·기준없음·기타' 8.5% 행에 검출 45.6%.
- 학습용 parquet 은 DB 리스테리아 765,891행 중 89,354행(검출 93) 제외, 97% 가 주소 출처 '검사기관' → 국내 원물 DB 9,246 → 3,533행.
- 원자료: ASOS 대구(기)(176) 운영 종료가 최근접 빈칸 17,317행 중 74.2%. 농업기상 −40℃ 근처·40℃ 넘는 일평균 있음(±50 경계값과 별개).
- 기상 원형 파일은 다른 세션 `scripts/report/raw_download.py` 가 `SELECT * FROM api_data_info.<테이블>` 로 받은 `data/collected/raw/raw_*.parquet` (이 브랜치에 커밋 안 함).
- 제작 방식: tmp/nb4 파트(parts/*.py) + 워크플로 작성·검증·수정 → nb_build 로 조립. 사용자가 "적당히해라 너무 오래한다"고 해 마지막 일관성 검증 단계는 중단하고 편집자 빌드(에러 0) 기준으로 마감.
