2026-10-20 사용자([종합] 전달): "계획서 확정된 것도 아닌데 자꾸 시작한다" → [종합]이 전면 중단을 지시. 그날 오후 사양이 몇 시간 사이에 여러 번 바뀌었는데(F2 → Recall 0.8 기준, 다목적 → 단일 목표, 모델 5개 → 4개, 결과 시차 90일, 섞기 중요도 등), 나는 메시지가 올 때마다 바로 실행 에이전트에 넘겨 코드 수정·서버 실행이 계속 다시 시작됨.

**Why:** 계획이 굳기 전에 손대면 버려지는 계산·코드가 쌓이고, 사용자는 결정하는 도중에 일이 멋대로 진행된다고 느낌("멋대로 하지 말고 같이 결정을 하고 해"도 같은 날).

**How to apply:** [종합]이 사양·결정을 보내도 '계획 확정' 또는 '시작'이라는 말이 없으면 기록만 하고(메모리·답장으로 이해한 내용 확인), 실행 에이전트에는 넘기지 않는다. 한 메시지가 '이것은 확정'이라고 명시하면 그 항목만 반영. 확정되지 않은 상태에서 일하던 에이전트가 있으면 멈추게 하고 현재 상태만 보고받는다. **2026-10-26 재발:** 사용자 "더 정할 거 없나? 없으면 검수시키고" → 미결 13개가 남았는데 '이것도 검수에서 보게 하겠다'며 검수 에이전트를 바로 띄움 → "정할 거 없으면 하라 했는데 왜 그냥 해? 나랑 정하고 해". 조건부 지시("~없으면 해")는 조건이 안 맞으면 실행하지 말고, 남은 결정을 먼저 같이 정한 뒤 실행. 관련 [[feedback-ask-via-jonghap-session]], [[feedback-ask-consent-for-new-changes]], [[listeria-1017-professor-call]].
