2026-10-20 사용자([종합] 세션): "보고서 작성은 대기. 결과보고 한번에 적자".

**Why:** 실험 배치마다 숫자가 오는 대로 보고·보고서 재빌드를 하면 사용자가 따라가기 어렵고 사용량도 낭비됨.

**How to apply:** 여러 단계 실험이 도는 동안에는 중간 결과를 하나씩 전하지 말고, 남은 실행·재채점이 모두 끝난 뒤 한 번 정리해 보고한다. 보고서(HWP) 다시 빌드도 사용자가 작성하라고 할 때 한 번에. 세션들에도 같은 규칙(중간 보고 금지, 마지막에 한 번)을 전한다. 계산 오류·결정이 필요한 문제는 예외로 바로 알림. 관련 [[listeria-reports-1019]], [[feedback-ask-via-jonghap-session]].
