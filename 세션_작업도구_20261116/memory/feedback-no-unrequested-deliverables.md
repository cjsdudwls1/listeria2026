사용자가 요청하지 않은 전달용 문서(교수님·상사에게 보낼 요약, 보고용 정리본 등)를 내 판단으로 만들지 않는다. 결과는 대화에서 답으로 알려 주고, 문서가 필요한지는 물어본다.

**Why:** 2026-10-12 교수님 노트북 `Listeria_05` 전체 데이터 실행 뒤, 사용자가 시키지 않았는데 내가 마무리 작업 지시서에 `교수님_전달용_요약.md`("교수님께 그대로 보낼 수 있게") 작성을 넣었고, 검증·문장 수정 작업까지 이어서 돌렸다(에이전트 여러 번). 17:15 사용자가 "교수님 전달용 요약 필요 없음. 작업 및 작업물 삭제"라고 해서 진행 중이던 작업을 멈추고 파일과 사본을 지웠다. (사용자가 요청한 것은 "실행하고 MLflow 로 확인할 수 있게"까지였다.)

**How to apply:** 실행·분석을 맡았을 때 산출물은 요청받은 것(결과 파일, MLflow 기록, 고친 내용 기록)까지만. "교수님께 보낼 글" 같은 것은 사용자가 달라고 할 때만 만든다 — 만들고 싶으면 먼저 한 줄로 묻는다([[feedback-ask-consent-for-new-changes]]). 관련: [[listeria-1012-decisions]].
