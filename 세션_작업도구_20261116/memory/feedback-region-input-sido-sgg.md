2026-10-20 사용자([종합] 세션): "다 시도+시군구 기준 맞지? 이건 절대 원칙임".

**Why:** 예측 단위가 시군구 × 품목 2·3단계이고, 10-16 결정(지역 입력 = 시도 + 시군구)을 모든 실험의 기본으로 삼음. 옛 1번 실험에서 '시도만' 판이 나은 결과가 있었어도 원칙은 시도+시군구.

**How to apply:** 범주 입력 = sido(sgg_code 앞 2자리)·sgg(5자리)·p2·p3 를 모든 모델에 넣는다. 변수 선택(중요도로 빼기 등)의 후보에서 시도·시군구는 제외한다. 실험 점검에 '모든 실행 config 의 범주 입력 = sido, sgg, p2, p3' 확인을 넣는다. 10-20 확인: 1차 실행 9개 모두 이 입력. 관련 [[listeria-task2-model-window-exp]], [[listeria-1020-professor-call]].
