제품명(`prduct_nm`)에서 나온 정보는 어디에도 쓰지 않는다 — 모델 변수만이 아니라 품목 코드 정체를 추정하는 근거, 계획서 서술, 교수님께 알릴 주의점 목록까지.

**Why:** 2026-11-03 밤, 130행(C0111 코드)의 분류를 제품명(닭다리·메추리알 등)까지 근거로 들어 추정하고, 교수님께 알릴 주의점에 '제품명 TF-IDF 칸 누수'를 넣자 사용자가 "제품명 관련 정보는 싹다 안쓰기로했잖아"라고 함. 11-02 결정("제품명은 예측단위에서 못쓰니까 아예 제외")과 11-03 "관련된 건 코드등 모두 삭제"의 연장.

**How to apply:** 품목·라벨 판단은 코드 체계(`t_prdlst_cl` 계층·유효 기간)와 모델팀 라벨로만 한다. 제품명을 봐야만 풀리는 문제면 쓰지 말고 "제품명 없이는 확인 불가"로 적는다. 예외(11-04 밤 확정, 결정 29): 단계 4 다운사이징의 train 행 고르기에만 제품명을 씀 — 교수님 방식(원 칼럼 Theil's U 1위 = 제품명, 검출이 한 번도 없던 제품 행을 train 에서 뺌, validation·test 는 전부). 사용자 "어차피 많은 다운사이징 방식 중 하나니까 교수님 방식으로 ㄱㄱ 하자". 입력 변수·채점·라벨 추정 근거·보고 주의점엔 여전히 안 씀. 관련 [[listeria-1102-final-integrated-plan]], [[listeria-item-code-tables]].
