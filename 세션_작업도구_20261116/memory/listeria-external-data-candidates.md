상세는 `리스테리아ML/docs/00_보고서/작업기록.md` 의 "2026-10-06 — (추가) 식정원 DB 밖에서 수집할 자료 후보" 항목(공개 자료 24종 확인 표·수치·재현 코드). **사용자 결정은 아직 없다**(2026-10-06 현재 후보 제안 단계, 외부 파일은 `data/` 에 저장하지 않음).

- 제약(같은 날 작업기록 수치): 검출 1,969건 중 1,431건이 국내 기준규격외 묶음이고 품목제조번호 결측 99.6%·영업 인허가 대장 연결 결측 89.9% → 번호로 붙는 외부 자료는 검출 행에 거의 안 닿는다. 넓게 닿는 키는 `addr`·좌표, 기준일, `prduct_nm`, 수입 행의 국가 코드.
- 미국 FDA Import Refusal: `https://www.accessdata.fda.gov/scripts/ImportRefusals/downloads/Import_Refusal_2014-2018.zip` (`2019-2023`, `2024-present` 도 같은 꼴), 로그인 없이 받음. 사유 `LISTERIA-295`. 한국 팽이버섯 151건·업체 22곳(첫 거부 2020-04-15). `FDA_SAMPLE_ANALYSIS` 가 Yes 인 건은 28건뿐이라 거부 건수 ≠ 검출 건수.
- FDA Import Alert 25-21 = 한국·중국산 팽이버섯 리스테리아 수입경보(`accessdata.fda.gov/cms_ia/importalert_1177.html`).
- 그 밖 확인된 것: EU RASFF(공개 JSON, 이용 조건 미확인), 일본 후생노동성 輸入食品違反事例(Excel), 국민연금 가입 사업장 내역(data.go.kr 15083277, 주소·법정동·월별 가입자 수), 식품안전나라 I0490 회수(품목코드 14자리·품목제조보고번호·업체주소), 특일 정보(15012690), 질병관리청 장관감염증 표본감시(전국 주별만).
- 식품안전나라 I0490 실제 형태(2026-10-06 샘플 응답): `total_count` 379건·19항목, `ADDR` 은 시도+시군구까지만(사업장 주소 단위로는 못 붙음 — 처음에 "업체주소로 붙는다"고 잘못 말함), `PRDLST_CD` 14자리는 우리 `prdlst_code` 앞 14자리와 같은 체계, `CRET_DTM` 조건은 "그 날짜 이후". 샘플 주소(`/api/sample/I0490/json/1/5`)는 항상 맨 앞 5건만 줘서 379건의 기간은 미확인 — 인증키(사용자 회원가입, 자동 승인) 필요. I2620 검사부적합 534건, I0470 행정처분 5,380건, I2810 해외 회수 532건(= DB `ba_data_info.global_risk_food_recall` 건수).
- **I0490 은 후보에서 내림(2026-10-06 확인)**: 379건이 서비스가 주는 전부인데 등록일이 2024년 하반기 이후에 몰려 있다(train 기간 2015-04~2024-06 은 46건, 2021년 0건, test 기간 171건, 리스테리아 사유 4건·한 업체). 화면 목록 주소 `foodsafetykorea.go.kr/portal/fooddanger/searchSuspensionList.do`(POST, `start_idx`=쪽 번호, `show_cnt`=60)는 키 없이 전부 주고 `addr` 이 전체 주소다. 식정원 DB 에는 국내 회수 자료가 없고 `ba_data_info.global_risk_food_recall` 은 해외 회수(I2810 과 같은 자료)다.
- **해외 통보 3종 형태·시험 결과(2026-10-06, 작업기록 같은 날 "해외 통보 자료 3종" 항목)**: 셋 다 받을 수 있고 2015~2026 을 덮는다. FDA = 256,518행·18열(리스테리아 1,265건, 육류 제품 0건). RASFF = 2020년까지 data.europa.eu xlsx `RASFF notifications pre-2021 public information.xlsx`(76,284행, CC BY 4.0) + 2021년부터 RASFF Window export JSON(`POST …/rasff-window/backend/public/notification/search/export/en/`, 본문 `{"parameters":{"pageNumber":1,"itemsPerPage":25}}`), 리스테리아 통보 2,710건. 일본 = 회계연도별 Excel 8,842행(리스테리아 39행: 이탈리아 27·스페인 7·프랑스 5, 치즈 24·비가열 식육제품 15; .xls 는 xlrd 없어 별도 해석기 필요). **수입 행에 "같은 나라·품목군 직전 365일 건수"로 붙여 보면 train 검출 비율 차이는 나라 차이(이탈리아 치즈)일 뿐 나라 안·시군 안에서는 차이 없음** — 기대 낮춤. 수입 행 나라는 `ba_data.s_org_lims_data_info.mnf_nation_cd`(2자리, X.parquet 에 없음).
- **RASFF 쓰임 시험(2026-10-06, 작업기록 "EU RASFF 를 변수로 쓰는 방법 세 가지" 항목, 결정 전)**: 통보 건수를 그대로 변수·가중치로 쓰는 것은 안 맞음(치즈·유제품은 RASFF 많고 우리 검출 낮음, 순위 상관 0.237). 차이가 보인 쓰임은 제품명(`prduct_nm`) 0/1 낱말 변수의 **낱말 목록 근거**로 쓰는 것 — `Z3800100000000` train 행에서 RASFF 식품 낱말이 걸린 행 0.759% 대 안 걸린 행 0.201%. 낱말은 train 종료일(2024-06-30)까지의 통보에서만 고를 것. 낱말 대응표 21묶음은 Claude 임시안(사용자 확인 필요). 유통국에 한국이 든 리스테리아 통보는 3건뿐.
- **리스테리아 특성 기반 3묶음 조인 가능성(2026-10-06, 작업기록 "리스테리아 특성에 맞춘 외부 자료 3묶음" 항목, 결정 전)**: 우리 국내 주소는 98.7%가 도로명 표기(고유 37,854곳), `legal_dong_code` 100%. ① 건축인허가 API(data.go.kr 15136267, 자동승인·일 10,000건, 시군구+법정동+번·지로 조회, 대수선·허가일·사용승인일) — 도로명↔지번 대조가 관건, 인증키 필요. 국민연금 사업장은 주소 상세도·과거 달 파일 미확인. ② 정전은 한전 공개가 연 단위 15행뿐이라 불가, 폭염 특보(기상자료개방포털, 171 시군, 로그인)는 가진 기온과 겹침. ③ 원재료: 식품안전나라 C002(`PRDLST_REPORT_NO`·`RAWMTRL_NM`), HACCP 포장지표기정보(15033307) — 키는 품목제조번호(숫자 12~15자리, 값 있음 30.2%·검출 행 11.4%). DB 에 `ba_data_info.lcns_ledg_hist_rawmtrl`("인허가 대장 이력 원재료", 5,148만 행, 원료명·배합비·시작/종료일자)가 이미 있음(사용 여부 모델팀 질문 중).
- **건축 인허가·건축물대장 API 활용신청 승인(2026-10-06, 사용자 계정 개발계정, 만료예정 2028-10-06)**: `apis.data.go.kr/1613000/ArchPmsHubService`(기본개요 `getApBasisOulnInfo`: `archGbCdNm`·`archPmsDay`·`realStcnsDay`·`useAprDay`·`platPlc`·`bun`·`ji`, 도로명 없음; 대수선 `getApImprprInfo`)와 `…/BldRgstHubService`(표제부 `getBrTitleInfo`: `newPlatPlc` 도로명대지위치·`bun`·`ji`·`useAprDay` — 도로명↔번지 연결용). 조회는 `sigunguCd`+`bjdongCd`. **인증키는 `리스테리아ML/.env` 에 없음**(사용자가 넣어야 함, 화면에서 읽지 말 것).
- **DB `ba_data.t_bsn_lcns_ledg` 는 주소로 붙는다(2026-10-06)**: `site_addr`("영업소재지_복사값")를 우리 `addr` 과 "첫 괄호·쉼표 앞까지 + 공백 제거"(Claude 임시 규칙)로 맞추면 국내 행의 79.2%(번호 조인은 32.9%), 기준규격외 79.0%, train 검출 행의 51.3%. 한 주소에 대장 행 여러 개(중앙값 3) → 고르는 규칙 필요. 건축 인허가보다 이것이 먼저라고 제안함(결정 전).
- **건축HUB API 실제 응답 시험(2026-10-06, 작업기록 "HACCP 표준기준서 확인 / 건축HUB OpenAPI 실제 응답" 항목, 결정 전)**: 키는 `리스테리아ML/.env` 의 `DATA_GO_KR_KEY`(URL 인코딩 꼴 → `unquote` 후 params 로). 도로명 대조는 "도로명+본번-부번" 규칙으로 9개 법정동 585주소 중 96.6% 일치. **걸림돌은 조회 단위** — 읍·면은 리 단위 코드가 있어야 나오는데 우리 `legal_dong_code` 는 읍·면 수준 59.8%·시군구까지만 9.0%(행 기준). 리 코드는 DB `ba_data_info.korea_region_code`("법정동_코드", 리 39,244개)에 있음. `bun`·`ji` 4자리 0 채움, `numOfRows` 최대 100, `startDate`·`endDate` 는 `crtnDay`(생성일자)에 걸려 허가일 기간 조회 불가, 대수선 API 에는 날짜 없음(`mgmPmsrgstPk` 로 기본개요에 연결). 전체 수집은 표제부만 약 7.5만 회(8일가량).
- **건축 자료 전체 수집은 하지 않기로 함(사용자 결정 2026-10-06 "건축 자료 전체 수집은 ㄴㄴ")** — 다시 제안하지 말 것. 영업 인허가 대장 주소 조인은 진행하기로 함(같은 날, 규칙은 사용자가 선택지에서 고름 → [[pending-lcns-ledg-address-join]]).
- **HACCP 관리 표준기준서(식약처 2016, PDF 3권)는 변수로 부적합(2026-10-06)**: 살균·가열 한계기준이 식품유형과 무관하게 같은 예시 문구("120~130℃, 3~5분" 등) 반복, 리스테리아가 124개 절 전부에 위해요소로 적힘, 품목코드 없음. 쓸 수 있는 것은 "열처리 CCP 예시 유무"(103/21) 정도.
- **수질오염원 자료(축사·하수 등 점오염원·비점오염원 포함)는 수집·조인하지 않기로 함(사용자 결정 2026-10-08)** — 다시 제안하지 말 것. 근거(작업기록 2026-10-08 항목): `prduct_nm` 낱말로 나눈 날 채소·과일 32,752행에 검출 6건(전체 검출의 0.30%), 검출은 버섯 422·시설 표면 검체 133·날 식육 316·날 수산물 182·가공·조리 474에 있고 주소는 업소주소 위주(국내 검출 1,844 중 1,348). `api_data_info.water_pollution` 은 주소로 0.8~3.9%, 좌표 3km 로 국내 95.8%에 붙지만 시설이 의원·안경점·정비소 위주인 장소 변수. 지하수 오염예측도·오염취약성도는 DB 에 없음(10-08 재확인). 낱말 묶음 규칙은 Claude 임시안.
- 쓸모없다고 확인된 것: 식중독 통계(리스테리아 항목 없음), 식중독 예측지도(과거값 없음), 도축 실적(시도×월뿐), EFSA(원산국 없음), openFDA 리콜(국가=미국 업체 주소).
