실험 점수를 보고할 때 "시드 표준편차(0.004~0.008) 안", "잡음 폭 안", "95% 신뢰구간", "부트스트랩", "우연과 구별 안 됨", "흔들림" 같은 단서를 달지 말 것. 기준(예: A3) 대비 점수가 오르면 "좋아짐", 내리면 "낮아짐"으로 숫자와 함께 그대로 말한다. 선정 방법을 제안할 때도 시드 수 늘리기·신뢰구간 하한 같은 통계적 판정 규칙을 꺼내지 말고 점수 기준으로만.

**Why:** 사용자 2026-10-19 "표준편차 드립 치지 마라 제발, 좋아지면 좋아진 거고 낮아지면 낮아진 건데 계속 헷갈리게 한다". 같은 날 [종합] 세션이 이 규칙이 저장된 뒤에도 신뢰구간·흔들림으로 보고해서 다시 지적: "그 신뢰 구간이나 표준편차로 흔들리는 점수 뭐 이런 거 생각하지말고 점수만 보고싶음. 메모리에 기억하셈".

**How to apply:** 결과 표는 기준 점수 → 새 점수 → 좋아짐/낮아짐(검증·시험 점수 칸 둘 다 보여 줌). 위약판 같은 내부 실험 장치 이름은 되도록 빼고, 쓸 때는 처음에 한 줄로 뜻을 풀 것(사용자가 "위약은 또 뭐야"라고 물음). 데이터 누수·날짜 시계처럼 점수 자체가 잘못 계산될 수 있는 문제는 이 규칙과 별개라 계속 알린다. 관련 [[listeria-name-external-features-1019]], [[feedback-report-plain-language]], [[listeria-exp2-review-1019]].
