2026-10-27 교수님 통화(전사본은 사용자가 대화에 붙임)·카톡:
- 교수님은 데이터셋(3.5GB)을 못 받아 직접 못 돌림 → 실험은 전부 사용자가 돌림. 컬럼설명서에서 직접 만든 컬럼(aw_label, 식품 속성 food_aw·food_ph·food_na)에 설명이 없어 헷갈려 함 → 설명 붙여 달라. 변수 그룹 ID 는 보고서에 안 써도 됨.
- 보고서 변수 설명: 묶음별로 앞에 크게(예: 기상 요약 = 19종을 10일 구간·80일 평균·최대·최소·편차로), 긴 목록은 별첨. 외부 지표는 출처·공간 단위·기간만. WOE·HACCP 는 "해봤더니 효과 없어 제외". 일별 원값 칸은 설명 불필요. TF-IDF 쓰인 110개 엑셀 요청 → `ML2/exp/교수님데이터셋/TF-IDF_컬럼설명_3차사용표시.xlsx` 만듦. 카톡: "데이터 입력변수 설명은 내가 작성해서 보내줄게".
- 검사 안 한 날 vs 불검출: 교수님 "검사했는데 없다고 치고 그냥 예측"(우리 행은 검사한 단위·날짜만이라 해당 없음).
- 교수님 1번 보고서 = 홍 선생님 양식 중간점검(10-30 제출): 사용자가 빈칸 채워 교수님께 → 교수님 검수·제출. 모델은 CatBoost(3차, 제품명 포함).
- 내 2번 = CatBoost 튜닝·불균형 처리로 마무리(제품명 없음) — 교수님 동의.
- 교수님 2번 실험(카톡, 노트북 https://github.com/ancestor9/Listeria/blob/main/20261027_practice.ipynb — 가상 데이터 예제): ① CatBoost LIMS+시계열 ② LIMS 만 스태킹(RF·GBM→로지스틱, 층화 5겹 OOF) ③ 시계열만 LSTM(GRU)+어텐션(focal loss) ④ LIMS Dense + 시계열 RNN·Transformer concat ⑤ 두 모델 결합(노트북은 test F1 로 가중치, 두 확률에 softmax). ①은 "내 2번 CatBoost 에 제품명 넣어서". 더 좋으면 그 모델, 아니면 CatBoost. 교수님: 시간순 분할 말고 표본 단위로 섞어도 됨(노트북은 test 는 12월로 떼고 그 안만 섞음). 핵심 = 부적합률 대비 PR-AUC 몇 배.
- 최종 보고서(11월): 지난 40쪽의 반, 논문처럼 입력 변수·연구 설계·모델·결과만("너무 자세히 쓴다").
- 결정 대기(10-27 기준): test 1년 고정 여부, 결합 방식(노트북 softmax([p_lims, p_ts])[1] = sigmoid(p_ts − p_lims) 라 LIMS 확률 높을수록 점수 내려감 → 검증으로 정한 가중 평균·로지스틱 메타 제안), 시계열 창 80일 vs 100일.

**Why:** 교수님 1번 보고서 방향과 교수님 2번 실험 설계가 이 통화로 바뀜(4차 계획 1-6 '딥러닝 2개만·앙상블 없음' 대체).
**How to apply:** 계획 갱신·보고서 수정은 사용자 승인 뒤. 배수는 평가 행 검출률 0.465%(test 1,737,545쌍 중 8,080)로 계산 — 1차 7.8배·내 1번 10.1배·3차 최종 16.9배(초안의 0.31%는 시료 기준이라 배수에 쓰면 안 됨). 관련 [[listeria-4th-exp-plan]], [[listeria-experiments-schedule-1026]], [[feedback-midcheck-report-rules]].
