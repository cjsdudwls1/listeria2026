외부 전문가(리서치팀 식품 선임연구원 등)가 준 문헌 식·계수·정의에서 오류를 찾으면 우리가 고친 식으로 바로 쓰지 않는다. 무엇이 왜 틀린지(재현 계산·참고 출처)를 정리해 사용자에게 주고, 사용자가 전문가에게 알려 고친 판을 받아 그대로 쓴다. 받기 전엔 그 변수는 보류.

**Why:** 2026-11-04 밤, Koutsoumanis(2004) 식의 PDF 오류(aw 자리·a₃ 부호)를 GroPIN 식으로 고쳐 쓰기로 계획에 넣었더니 사용자가 "우리가 임의로 식품전공자가 준 문헌을 수정해서 사용 하면 안될거같에 생각해보니까", "이거 틀린거 지적하면 선임연구원 분이 수정해서 주실거야"라고 함.

**How to apply:** 오류 발견 → 근거 정리 → 예의 있는 확인 요청 문안 초안 → 사용자가 전달 → 받은 식 그대로 적용, 보고에 '연구원이 고친 식으로 적용' 명시. 관련 [[pending-research-variables-report]], [[listeria-1102-final-integrated-plan]].
