10-19 외부 지표 조사에서 친환경 인증 면적을 공공데이터포털·농림축산식품 공공데이터포털 파일(2016~)로만 찾고 "2014~2015 시군구 못 찾음"으로 끝냄. 10-26 재탐색에서 같은 파일의 원천인 친환경 인증관리 정보시스템(enviagro.go.kr 인증통계, 로그인 없음)에 2014·2015 시군구 값이 있었고, KOSIS 시·도 기본통계 17개 표에도 2013~2015 시군별 값이 있었음. 사용자: "이 데이터를 처음엔 왜 못 찾았지?"

**Why:** 공공데이터 파일은 원천 시스템의 일부 기간만 잘라 올린 경우가 많음. 파일만 보면 없는 기간이 원천 화면에는 있음.
**How to apply:** 외부 자료의 기간·지역이 모자라면 ① 파일 설명의 수집방법(예: "시스템 추출")으로 원천 시스템을 찾아 조회 화면을 보고 ② KOSIS 지역통계(시·도 기본통계 표)를 확인한 뒤에 "없음"으로 결론. 관련 [[listeria-4th-exp-plan]], [[listeria-external-data-candidates]].
- 10-27: 사용자가 2014~2015 수집 자체를 취소함 → [[listeria-prof-dataset-1027]]. 원천 시스템까지 확인하는 이 규칙은 그대로.
