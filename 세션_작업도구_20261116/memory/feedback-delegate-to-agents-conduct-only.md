여러 갈래로 나뉜 큰 작업에서는 실제 작업(조사·코드 수정·브라우저 조작·실행)을 에이전트(워크플로·서브에이전트)에게 맡기고, 나는 지휘만 한다 — 작업 지시서 작성, 결과 점검, 순서 조율, 사용자에게 물어 동의받기.

**Why:** 2026-10-12, 울트라코드(워크플로) 모드에서 내가 가뭄지수 수집용 브라우저 조작을 직접 하고 있자 사용자가 "아니 모든 작업은 에이전트 시키고 너는 지휘만 ㄱㄱ"이라고 함. 내가 직접 하면 내 문맥이 작업 내용으로 차서 전체 조율이 느려지고, 그 전에 세션이 한 번 끊겨 조사 3건이 날아갔다.

같은 날 추가 지시: "에이전트들 모델도 오푸스 5.5로" — 에이전트를 띄울 때 모델을 Opus 로 명시한다(Agent 도구 `model: "opus"`, 워크플로 `agent(..., {model: 'opus'})`).

**How to apply:** 울트라코드/워크플로를 켠 세션이거나 사용자가 여러 일을 한꺼번에 맡겼을 때 적용(내 해석 — 작은 단발 질문에는 해당 없음). 에이전트 지시서에는 사용자 규칙(DB 읽기 전용, 프로세스는 자기 것만 종료, 원자료 그대로, 임의 결정 금지 → 질문 목록으로 반환)을 직접 적어 준다. 에이전트가 보고서를 파일로 중간 저장하게 해서 세션이 끊겨도 남게 한다. 사용자 결정이 필요한 것은 내가 모아서 묻는다 — [[feedback-ask-consent-for-new-changes]].
