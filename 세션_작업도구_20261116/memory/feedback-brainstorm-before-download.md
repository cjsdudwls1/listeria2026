"또 다른 외부 변수 추가할 만한 거 없나"라는 질문에 후보 자료를 곧바로 내려받아 붙여 보려고 조사 작업 2개와 내려받기를 시작했다가, 사용자가 작업을 모두 멈추고 "아니 데이터 다운 받지 말고 브레인스토밍부터하자"라고 했다 (2026-10-06).

**Why:** 사용자는 방향을 같이 고르는 단계였다. 받아서 시험하는 작업은 시간이 오래 걸리고(조사 작업 1개에 10분 이상), 고르지 않은 후보에 쓰면 낭비다. (이유는 Claude 의 해석 — 사용자가 직접 말한 것은 "다운 받지 말고 브레인스토밍부터"뿐이다.)

**How to apply:** "뭐가 좋을까", "다른 거 없나" 같은 열린 질문에는 먼저 생각을 정리해 대화로 답한다(확인 안 한 것은 그렇게 표시). 내려받기·DB 조회·조사 작업은 사용자가 후보를 고르거나 확인을 요청한 뒤에 한다. "형태 확인해 줘", "DB 에 있는지 확인해 줘"처럼 확인을 직접 요청한 경우는 바로 해도 된다. 관련: [[feedback-own-ideas-not-user-memo]]
