2026-10-26 사용자(내 1번 "지금 시작할까요?" 질문에 대한 답): "총 4개 실험의 모든 과정과 설정을 html로 비교해가면서 볼 수 있게 만들라고. 전부 보고 일괄 승인한다고. 진빠가 어디서 어떻게 났는지 알려면 이렇게 봐야 한다고"

2026-10-26 저녁 재발: 내가 질문 선택지에 "지금 시작(권장)"을 걸었고, 사용자는 설계 선택("변수 빼기도 기본값·제품명 없이 다시 ㄱㄱ 대신 woe도 포함")만 답했는데 그걸 실행 승인으로 읽고 서버 에이전트를 띄움 → 사용자 "실행하지마 내가 검수해야함". 에이전트 중지, 서버에서 띄운 시험 실행(우리 것만) 종료.

**Why:** 3차 실험을 검수 없이 돌렸다가 문제(고르기·early stopping 지표 혼용, 시료 단위 셈, 사람이 튜닝 trial 고름, test 여러 번 채점 등)가 나서 재작업 중.
**How to apply:** 설계 질문에 대한 답('ㄱㄱ' 포함)은 실행 승인이 아님 — 질문 선택지에 '지금 시작'을 섞지 말 것. 계획이 바뀌면 HTML 을 갱신해 보여 주고, 사용자가 '승인'·'실행해'라고 분명히 말한 뒤에만 서버 실행(시험 실행 포함). 새 실험은 계획을 정한 뒤에도 실행 여부만 묻지 말고, 과정·설정 비교 HTML 을 갱신해 보여 주고 일괄 승인을 받은 뒤 실행. 소스 `리스테리아ML2/exp/실험비교/`(parts/*.json → `py build.py` 가 근거 줄 대조·비밀값 검사 → 실험비교.html), 게시본 https://claude.ai/artifact/VtAW4bZHwBUnYW6ZqMqku9 (같은 파일 경로로 다시 게시하면 같은 주소). 계획이 바뀌면 parts 를 고치고 다시 build·게시. 관련 [[feedback-wait-for-plan-confirmation]], [[listeria-experiments-schedule-1026]].
