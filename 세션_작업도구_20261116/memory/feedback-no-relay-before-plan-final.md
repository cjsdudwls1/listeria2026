2026-10-20 [종합] 세션: 3차 계획을 사용자와 검수하는 동안, 결정이 하나씩 정해질 때마다 asdqwrf 에 "고치기에 넣어 주세요"를 보냄(계획 개정·재실행 보류·결정 2개·추가 2개). 실험 세션은 그걸 받아 코드 6개 파일을 고침(16:03~16:08). 사용자 앞선 말 "일단 다 확정되면 학습하자", 이어서 "아니 계획서 확정됀것도 아닌데 자꾸 시작해 왜".

**Why:** 사용자에게 '확정'은 계획서 전체 검수가 끝난 상태다. 검수 중 AskUserQuestion 답(개별 결정, "확정·전달" 같은 선택지 답 포함)은 최종이 아니다. 코드 고치기·자체 점검도 사용자에게는 '시작'으로 보인다.

**How to apply:** 검수 중 결정은 계획서 파일(과 메모리)에만 반영한다. 다른 세션에는 "멈춤·대기" 말고 어떤 작업 지시도 보내지 않는다. 사용자가 계획 전체를 확정한다고 분명히 말할 때 바뀐 점을 한 번에 전달한다. 선택지에 "확정·전달"처럼 실행까지 묶은 항목을 넣지 않는다. 관련 [[feedback-ask-consent-for-new-changes]], [[listeria-1020-professor-call]].
