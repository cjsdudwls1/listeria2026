### 8-3. 교수님 질문 '0 이냐 1 이냐' 답 (보고 문안)
- 트리: 결측을 NaN 그대로 둠(§4-11 — CatBoost Min 처리로 '모든 해외 행에 같은 값'과 같은 효과, 0 을 넣으면 강수 0mm 등 실제 0 인 국내 행과 섞임).
- 딥러닝: 결측 표시 칼럼(또는 `src_route`)을 같이 넣으면 0 이든 1 이든 같음 — 첫 층 출력 w·c + v·m 에서 결측 행은 c 가 고정·m = 1 이라 w·c 가 편향에 흡수됨(식의 성질, 수치 실험 기록 없음). 표시 칼럼 없이 상수만 넣으면 0(표준화 뒤 = train 평균)은 '평균 국내 값'과 구분 안 됨 → 표시 칼럼 필수.
- 사용자 11-02 "못 채워 넣으면 그냥 nan으로"와 같고, 교수님 "왜냐면 그래야지 모델을 하나로 만들지"(1558줄) 취지(국내·해외 한 모델)도 만족. 교수님 "그럴 경우 뭐가 좋은지 한번 내가 물어봐야겠다."(1573줄) — 교수님 쪽 답 대기.

## 9. 딥러닝 세부

### 9-1. 입력 텐서

| 입력 | 모양 | 내용 |
|---|---|---|
| x_seq | (N, W_DL, C) | 기상 19변수 C_f 개(결정 5 — 예보 있다고 가정, SPI 는 T−1 이라 시퀀스에서 뺌)(train 평균·표준편차로 표준화, 결측 0) + 결측 표시 C_m 개(결측 생기는 변수만) |
| x_static | (N, 2) | g ÷ 49, `src_route`(0/1) — 계절은 안 씀(결정 7, 11-04 밤 2) |
| x_cat | (N, 2) | `sido`·`sgg` 정수 번호 → 임베딩(각 8차원, 지난 설계) |
| y | (N,) | 0/1 |

- W_DL = 그 딥러닝 설정의 W(10~100 탐색, 단계 1-2).
- 학습 N = 블록 학습 시료 수(시료당 h 1개). refit 규모 585,111 × 100일 × 19채널 × 4바이트 ≈ 4.4GB(계산, W_DL = 100·학습분만) — 서버 RAM 94GB·GPU 40GB 안에서 배치 학습. 추론 규모는 설정 하나당 §3-7(3,379만 시퀀스), 40 설정 탐색 때 예측 범위는 §3-7·[결정 59].
- 예측: 시료 × g 50가지(g = 0~49), h 1~11 은 g = 0 의 같은 예측. 트리 train 행의 딥러닝 OOF 값 = 그 행 h 의 g 로 예측한 값, validation·test 쌍 = 쌍의 h 의 g 값.
- 고정 규칙 [권고, 결정 55-13]
  - 범주 번호표는 전체 범주(국내 256 + 해외 나라 코드)로 고정하고 학습에 없던 범주용 번호(OOV) 1개를 둠 — 블록 OOF 는 블록 하나를 빼고 학습하므로 그 블록·test 에만 있는 `sgg` 가 생김.
  - 결측 표시 채널 목록은 test 전 전체 자료로 한 번 정해 모든 블록·test 모델에 같게 씀(입력 차원 고정). 학습 행에서 전부 결측이거나 분산 0 인 변수는 표준화 생략·0.
- 결합 모델(단계 2-4)의 LIMS 갈래: 범주 4 임베딩 + h·g·`src_route`(단계 2 엔 파생변수 없음 — 규칙 결과).

### 9-2. 구조 후보

| 구조 | 내용 | 근거 |
|---|---|---|
| LSTM | LSTM(64) 마지막 은닉 → 정적·임베딩 concat → Dense 64 → sigmoid | 유의사항 2번 DL LSTM |
| GRU | 같은 틀, GRU(64) | 교수님 11-02 "GRU? 그거 LSTM이지 뭐."(694줄) |
| 트랜스포머 인코더 | 선형 투영 64 + 위치 인코딩 → 인코더 1~2층(헤드 2~4) → 평균 풀링 → concat → Dense → sigmoid | 교수님 11-02 "트랜스포머 얹어서"(782줄) |
| LSTM + attention | LSTM(64, 시퀀스 출력) → Dropout 0.3 → MultiHeadAttention(헤드 2, key 32) + 잔차 + LayerNorm → Dense 64(relu) → Dropout 0.3 → 잔차 + LayerNorm → 평균 풀링 → Dropout 0.4 → concat → Dense 1(sigmoid) | 교수님 practice 셀 5(원래: 입력 (11, 2), 값 없는 window 는 zeros·표시 칼럼 없음, focal loss γ 2·α 0.75, Adam 0.001, 에폭 20, 배치 32, EarlyStopping val_loss 인내 3) |

- 교수님 "GRU가 LSTM이야. 대신 얘는 이제 뒤로도, 뒤로도 가는 거지, 뒤로도."(780줄) — 양방향 구조를 뜻하는지 원문만으로 확정 불가. 양방향(BiLSTM)은 사용자 10-30 "2.추가 x" → 지금은 단계 1-2 에 넣지 않음, '뒤로도'가 양방향 뜻인지 교수님 확인 필요 [결정 38].
- 이상 점수(단계 2-1): 표 AE Linear 128→64→16→64→128, 시퀀스 AE Conv1d(32·16, 커널 7, 보폭 2, 드롭아웃 0.2) + 전치 합성곱, VAE = 같은 틀 + μ·로그분산·재매개변수(11-02 [교수님 실험 2번] 세션 설계).
- 결합(단계 2-4): 결합-기본 = LIMS Dense 128→64 와 시계열 LSTM(64) → 트랜스포머 인코더 1블록 → 풀링 → 64 를 concat → Dense 64 → 출력. 결합-VAE = 결합-기본 + VAE 인코더 갈래(잠재 μ 16 + 복원 오차 1칼럼).

### 9-3. 학습·섞기
- 섞기: 에폭마다 train 행 전체를 날짜와 무관하게 무작위 순서로(교수님 11-02 "순번 단위를 섞어서 막 넣어도 된다고. 날짜랑 상관없이."(1476줄), 10-27 카톡 "100일(timestep)로 썩으면 계절도 섞이니 상관없을 듯"(30줄)). 2차 코드도 에폭마다 `torch.randperm`(`e2dl_impl.py:333`).
- 기본값(지난 설계): Adam 1e-3, 배치 1024, 최대 50 에폭, 인내 5. 조기 종료 = §3-7 [결정 55-6].
- 손실: 단계 1~7 은 이진 교차엔트로피, focal(practice γ 2·α 0.75 — 교수님 practice 셀 5 기본) 등 손실 함수 비교는 단계 8 [확정, 결정 22 — 사용자 11-04].
- 씨앗 고정, GPU 서버.
- 교수님 "배치 사이즈를 ... 3개월을 넣을까? 예를 들어 뭐 계절별로 넣을까? ... 한 달 단위로 넣을까?"(1498~1503줄): batch_size 는 한 번 갱신에 쓰는 표본 수이고, 섞으면 배치가 계절 단위가 아님 → 배치 크기는 숫자 후보(256~4096)로 탐색.

### 9-5. 튜닝 도구 [결정 21]

## 10. 계산 순서·자원

### 10-1. 순서

```
단계 0 ──┬── 단계 1-1 트리 갈래 (CPU) ──────┬── 단계 2 ── 단계 3 ── 단계 4 ──┬── 단계 5 ──┬── 단계 8 튜닝(마지막)
         │      └── (미리보기 4-a, 결정 31)  │                              └── 단계 6 ──┤
         ├── 단계 1-2 딥러닝 갈래 (GPU) ─────┘                                           │
         │      (0-3·0-4 뒤 바로, 단계 1-1 과 나란히)                                    │
         └── 단계 7 (0-10 에서 미리 계산, 정식 보고는 단계 6 뒤) ────────────────────────┘
단계 2 안: 2-1 이상 점수 → 2-2 스태킹·2-3 앙상블, 2-4 결합 모델(결정 25)
단계 8 = 단계 1~7 판 중 CV 1위 판의 트리 모델 튜닝(채택은 결정 28-b)
최종 고르기 ← 후보 판 CV
```

- 단계 1-2(딥러닝, GPU)와 단계 1-1(트리, CPU)은 나란히 돌릴 수 있음. 단계 2 는 두 갈래 상위 모델이 다 나온 뒤.

### 10-2. 서버·환경 (기록값)
