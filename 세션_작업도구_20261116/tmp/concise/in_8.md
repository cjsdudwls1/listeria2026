## 13. 한계
- 학습 = 관측, 운영 = 예보: 예보 구간을 학습 땐 관측값으로 넣음 — 예보 오차가 운영 때만 생김. 2015~ 과거 예보 없음(국내 보관 2회, Open-Meteo 과거 예보는 대부분 2024~, Previous Runs 는 1~7일 앞만). 점검은 [결정 39]. SPI 를 뺀 일 단위 변수는 예보가 있다고 가정(결정 5) — 실제 11일 예보에 없는 변수(목록 기록 없음)는 운영 때 예보 구간을 다른 값으로 채워야 해 학습과 더 달라짐.
- 국내·해외 같은 칼럼 다른 정의: 국내 관측소 3곳 평균, 해외 ERA5(Open-Meteo Historical Weather API) 좌표 1곳 값. 토양수분·일조·풍향·지중온도·SPI 는 근사.
- 해외 자료 지연: ERA5 약 5일 지연 → 운영 때 T−5 ~ T−1 은 다른 출처로 채움([결정 53]).
- 나라 대표성: 큰 나라 한 점(시료 좌표까지 중앙값 431km, 미국 1,386km). 통화도 "말도 안 되지만 그냥 퉁쳐서"(851줄).
- 해외 자료가 적음: 검출 125, fold 1 validation 해외 검출 4건, 최근 몰림.
- 기준일 d 가 섞임: 제조일·의뢰일·선적일(`date_basis`), 의뢰일 비중이 해마다 늚 — 운영 때 '그날'의 뜻이 하나가 아님(해외는 선적일 그대로 — 결정 40-b 확정, 뜻은 확인 안 함).
- 시료 단위 학습 기록: 단위×날짜 학습보다 test 가 낮았던 기록(`5_시료단위y`: test 구간 가중 0.03616 → 0.02040, AP·단위 기준) — 이번 시료 단위 결과도 낮을 수 있음.
- 연도 구분: 11-02 적대적 검증은 '기상·이력·토양·연 단위 지표가 연도를 가름'으로 나왔으나 무작위 겹 설계라 AUC 1.0 이 자동으로 나옴(조사: review) → CV 와 test 차이(사용자 11-02 "val에선 오르는데 test에선 왜 자꾸 떨어지지?")의 원인은 확인 안 됨, 이 계획으로 없어진다는 보장도 없음.
- 고르기를 여러 번 하면 CV 가 부풂: 같은 fold validation 으로 공통 반복 수·단계 1-1 의 90~120 설정·단계 2 결합 판·k·빼기·튜닝·최종 고르기를 모두 함. 기록 — 3차 튜닝 30회 CV 중앙값 0.0807·최댓값 0.0899(AP). 단계마다 test 를 같이 기록(판단에는 안 씀). 고르기 전용 기간은 [결정 47].
- 중요도 이중 사용: 같은 fold validation 으로 π(시도 여부·순서)·채택·공통 반복 수를 모두 정함 — 남김 규칙·'2/3 fold' 채택은 시도 수를 줄일 뿐 없애지 못함([결정 48]).
- 중요도는 범주·h·g·딥러닝·이상 점수 칼럼이 고정으로 들어 있는 상태에서 잰 값이라, 이 칼럼들이 메워 주는 기상·이력 그룹의 중요도는 낮게 나옴(딥러닝 값은 엄격 OOF 로 씀 — 결정 48 확정).
- 섞기는 계절과 대상일의 관계를 깨는 비현실적 조합을 만듦(Hooker·Mentch·Zhou 2021).
- 그룹은 기상 요소로 미리 정함(결정 48) — 다른 그룹에 있는 비슷한 칼럼(기온 ↔ 지중온도)과 하나씩 둔 비기상 칼럼끼리(같은 품목 1년·5년 검출률 ↔ WOE)는 서로 메워 중요도가 낮게 나옴.
- trapz 동점 부풂: 점수 종류가 적은 판은 trapz 가 크게 나옴(상수 점수 0.50, §1-5, [결정 46]). trapz 는 선형 보간이라 AP 와 값·순위가 다를 수 있음(scikit-learn 문서) — 지표는 사용자 결정대로 trapz.
- 이력 칼럼 고정: validation·test 행 이력이 fold 끝 값이라 그해 뒤쪽일수록 오래된 값. train 행 이력은 h 에 따라 달라지고 평가 행은 안 달라짐(§4-5). 결과 시차 90일 미반영이라 운영보다 이력이 새것.
- 블록 OOF 시간 무시: 딥러닝 값이 들어간 판(스태킹·딥러닝 포함 앙상블) CV 낙관 가능(test 는 깨끗). 단계 1-2 구조·W_DL 고르기도 시간 무시 점수. 딥러닝 튜닝을 블록 5(= fold 2·3 validation 해)로 고르면 fold 2·3 CV 가 한 번 더 낙관적([결정 20-b·21]).
- 딥러닝 조기 종료: 같은 입력 행이 학습 90%·조기 종료 10% 에 함께 들어가 늦게 멈출 수 있음([결정 55-6]).
- CatBoost 범주 통계: 기본(`has_time` False)은 train 행 순서를 섞어 범주 정답 통계를 만듦 → train 안 미래 날짜 정답이 과거 행 통계에 들어감(이력 칼럼의 'T−1 까지' 원칙과 다름, split 넘는 누수는 아님)([결정 55-12]).
- 단기 파생 h ≥ 12 의미: R ≠ d 라 '채취 k일 전'이 아니라 '마지막 예보일 근처'(사용자 10-29 'd 기준' 정의와 다름).
- SPI: 기상청 SPI 는 2019-03-01 에 누적 기간 정의(30n일 → 달력 n개월)와 ±3.09 자르기가 바뀜 → 학습 기간 안에 정의가 다른 두 구간. 오류로 보이는 날도 받은 값 그대로. 해외 SPI 는 같은 식이지만 보정 기간·추정법이 기상청과 다를 수 있음(국내 ASOS 12년 재계산 시 기상청과 r 0.94~0.96).
- 낙농장: 자료 시점 미확인, 대표값 방식에 따라 의미가 다름.
- 식품 고정표 결측: aw 시료 53.22%·검출 시료 79.39%(Z 행).
- 07-01 시료 미사용(RR6): d = 2025-07-01 은 학습·채점 모두 빠지고, fold 마다 validation 해 07-01 은 그 fold 채점에서 빠짐.
- Theil's U 는 고유값 많은 칼럼에 유리.
- 식정원 '단계마다 test 상승' 요구는 보장 못 함(교수님 "어쩔 수 없지").

## 부록 B. 사용자 질문 답

### B-1. src_route 입력 변수로 쓰나? 써도 되나?
- 써도 됨, 넣음 [확정] — 예측 시점에 정해지는 값(운영 단위가 시군구인지 나라인지)이라 누수 아님. 지난 실험은 직접 안 넣음. → §2-5.

### B-2. 해외에서 결측인 파생변수 채우기
- 채움: 기온·강수·평균풍속·일사·습도(새 수집), 이력·식품. 근사로 채움: SPI·지중온도·토양수분·일조·최대풍속·풍향·토양 pH. NaN: NAS 지중온도·대기 3종·토양 유기물·유효인산·외부 지표·낙농장. 처리 = 트리 NaN·딥러닝 0 + 표시 칼럼. → §8-1·§8-2, 국내 SPI 는 기상청 값 그대로(결정 17 확정).

### B-3. 리서치팀 PDF 에 뭐가 있고 뭘 적용할 수 있나
- 문헌 요약 + 적용 방향, 직접 대입 가능한 식은 없다고 PDF 스스로 판정(p4·p5). 새로 적용(11-04 사용자 지정): p12 표 1~7번(72시간 기온·2일 전 강수·2일 전 풍속·25일 평균 강수·2~3일 전 일사·7일 기온 변동폭·24시간 습도·이슬점)·낙농장 밀도·Koutsoumanis 2식(연구원이 고친 식을 받은 뒤). 계절은 안 씀(11-04 밤 2). 비교·보고 = §7-4. → §7-2, 낙농장은 §7-3 [결정 35].

### B-4. 해외 기상 수집 방안
- 권고 A: 나라마다 DB 나라 좌표 1곳에서 Open-Meteo Historical Weather API 로 2014-04-07 ~ 현재(+ SPI 용 1991~ 강수) 수집, 운영 땐 같은 좌표 ECMWF 예보 11일. 약 11만 가중 호출, 무료 한도로 약 11일(추정). → §4-9 [결정 15·16·41·53].

### B-5. 딥러닝 NaN
- 인지함. 처리 = 표준화 → 0 + 결측 표시 칼럼 [결정 19]. 해석 B 라 시퀀스 안 빈 날 없음, SPI 는 T−1 이라 시퀀스에서 빼고 트리 요약 칼럼으로만, 나머지 일 단위 기상은 시퀀스에 넣음(결정 5, 11-04 밤). 정적 입력(g·`src_route`·`sido`·`sgg`)은 결측 없음, 학습에 없던 `sgg` 는 OOV 번호. → §4-11·§9-1.

### B-6. 수분활성도 DB 조인·중앙값
- 3단계 코드 대표값 = 자기값 → 하위 코드 값 중앙값 → 2단계 자기값 → 결측, 모든 fold·test·운영 공통 표, 해외 전용 3종까지 확장. 같이 다시 계산: gr2·rg_aw·rg_ph. 결측: aw 시료 53.22%·검출 시료 79.39%(Z 행). → §7-1 FD1.
