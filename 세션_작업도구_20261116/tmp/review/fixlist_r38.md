# 38차 검수 반영 지시 (plan_v38.md → plan_v39.md)

전체 원칙(28~37차와 같음). 아래와 어긋나는 문장은 이 취지대로 고치거나 지움. 본문(요약 제외) ≤ 300줄.

## A. 3차 사슬 규칙 정리(중)
1. §6 3차 공통에 표 하나(단계마다 후보 만드는 법·물려받는 것)를 넣고 그 표만 기준으로 함:
   | 단계 | 후보 | 물려받는 것 |
   |---|---|---|
   | 3-0 | 10 알고리즘 × 변수 전체 | 출발(1위 = 첫 현재 최고 판) |
   | 3-0b | 현재 최고 판 알고리즘으로 변수 빼기(부스팅이면 반복 수 §3 규칙, 그 밖은 기본 설정 fold 모델) | 현재 최고 판 설정 |
   | ⑤ 1·2차 몫 | 3-0 직후 3-0 1위와 비교(채택돼도 3-0b 는 3-0 1위 알고리즘으로) | 없음(교체 후보) |
   | ⑥·⑦ | 3-0b 뒤, 정해 둔 구성 | 없음(교체 후보) |
   | 3-1 | 현재 최고 판 + 이상 점수 4칼럼 | 현재 최고 판 전부 |
   | 3-2(④ 같이) | 3-0 트리 상위 3개를 현재 입력(채택한 칼럼 포함)으로 다시 학습한 트리마다 (a)~(e) + ④ — 같은 판이 되면 학습 없이 다시 씀(예: 3-1 채택 뒤의 (a)·(b), 3-1 판과 같은 (c)) | 현재 입력 |
   | 3-3 | 현재 입력의 트리 상위 3개 평균, 그것 + 딥러닝 상위 3개 평균 | 현재 입력 |
   | 3-4 | 결합 모델 2종(정해 둔 구성) | 없음(교체 후보) |
   | ⑤ 3 몫 | 3-4 뒤 같이 비교 | 없음 |
   | 단계 4 | 트리 대상 판에 4-a·4-a0(부스팅은 반복 수만 다시) + ② + ⑤ 4 몫 | 트리 대상 판 전부 |
   | 5·6 | 트리 대상 판의 train(줄였으면 줄인 train, h 규칙·CatBoost 범주 숫자 인코딩도 그 판 그대로)에서 해마다 양성 전부 + 음성 4배 | 트리 대상 판 전부 |
   | 7-b | TE 2칼럼 트리(정해 둔 구성) | 없음(교체 후보) |
   | 단계 8 | 단계 시작 때의 현재 최고 판에 8-T → Focal → 8-TD 차례로(각각 그 앞까지 채택한 판 위에) | 전부 |
   - 채택 판정 = 그 단계 후보 중 val 1위가 현재 최고 판보다 val 이 높으면(소수 4자리, 같으면 안 오름) 새 현재 최고 판. 5·6 의 판정 점수 = 씨앗 0~4 평균 CV(씨앗 0 단독 줄은 보고용 비교만)
   - ① 은 h = 1 비교만(사슬 밖), ③·7-a·4-c·4-c-L·미리보기·이상 점수 단독·2-R 은 비교만
2. 트리 대상 판 = 현재 최고 판이 트리·스태킹이면 그 판, 앙상블이면 기법을 구성 트리 모두에 적용해 다시 평균한 판(딥러닝 구성은 그대로), 딥러닝 단독·결합 모델·④ 이면 3-0~3-3 트리 판 중 CV 1위(그 트리 판 기법 전후 val 도 기록). 부록 A-12 '현재 최고 판이 앙상블일 때' 의 대표 트리 규칙은 이것으로 바꿈.
3. 사슬 시작: 3-0 1위 val 이 2차 베이스라인보다 낮으면 기록·알림(사슬은 그대로 3-0 1위에서).
4. ⑤ 8 몫 지움(8-T 와 같은 자료·알고리즘·기본 설정이라 4·3 몫과 같은 판) — ⑤ 몫 = 1차·2차·3·4.
5. 3-1·3-2·3-3 의 표 AE·VAE 입력 = 현재 최고 판(트리 대상 판)의 숫자 칼럼에서 h·g 뺀 것(3-0b 뒤면 그 묶음), 시퀀스 AE·VAE x_seq 도 현재 변수 묶음.
6. 단계 8 대상은 단계 시작 때 고정. 부록 A-12 단계 4 train 행 추론 줄에 ⑥ 2종(3-2 (d)·(e) 입력)도 h 1~60 으로 추론한다고 넣음.

## B. 횟수(중)
