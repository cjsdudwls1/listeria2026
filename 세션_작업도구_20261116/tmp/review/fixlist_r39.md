# 39차 반영 지시 — 담당자 결정: 0.2 빼기·기한 무시(정확도 우선) (plan_v39.md → plan_v40.md)

전체 원칙(28~38차와 같음). 38차 지시(fixlist_r38.md)는 plan_v39.md 에 반영됨 — 이 판은 그 위에 아래만 바꿈.

1. 변수 빼기 지름길 'π ≤ 0.2 묶음 함께 빼기' 지움(요약·§8·어디에도 없게). 변수 빼기는 하나씩 빼서 CV 평균이 오르고 3 fold 중 2개 이상 오를 때만 채택하는 규칙 그대로(건너뛰기 ψ_f ≥ 0.8 도 그대로).
2. 기한에 맞춰 판을 줄이는 절차 전부 지움: §8 의 기한 줄·줄이기 (가)·(나) 목록·담당자 승인 문구, 요약 24·25번(기한·줄이기), §1-3 판단 목록의 '줄이기 목록·단위 빼기 여부·§8 줄이기 순서', 2-3·3-0b 줄의 '기한·줄이기 = §8 (나)', 부록 A-9 '(가) 전부 줄이면 1,906'. 섞기 횟수 M = 5 고정(줄이기 땐 3 지움), 2-3·3-0b 단위 빼기는 늘 함(최대 20바퀴).
3. 남김: 단계 0-9 시간 측정과 0-9 뒤·1-3 뒤 예상 끝 날짜 알림(보고용 — 줄이기 판단 없음), 2-3·3-0b 도중 바퀴마다 남은 일정 다시 추정해 알림.
4. 요약: 23번 = "규모: 예상 4,272회, 최악 20,048회(양방향 추가 시 20,056) 학습이다(변수 빼기를 2차·3차 두 번 함). 기한에 맞춰 줄이는 판은 없고, 시간 측정 뒤 예상 끝 날짜만 보고한다.", 옛 24·25번 지우고 26·27번을 24·25번으로.
5. 부록 A-11 넣음: "기한에 맞춰 판을 줄이는 절차는 두지 않음(담당자 결정 — 정확도 우선)".
