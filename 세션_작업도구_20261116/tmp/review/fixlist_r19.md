# 19차 검수 반영 지시 (plan_v19.md → plan_v20.md)

전체 원칙(1~18차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 학습 횟수 숫자는 바뀌지 않음.

## A. 교수님 말씀
1. 추가 판 ② 입력: "② 의 X = 4-a 와 같은 칼럼(단계 3 최종 판 입력 — 숫자는 표준화·결측 0 + 표시, 범주는 임베딩 각 8), window 칼럼만 [T − W + 1, T] 로 다시 계산(h 방식 4-a 와 y 방식만 다르게)". 부록 A-8 60칸 신경망 줄도 이렇게(Dense 128 → 64 → Dense 60 그대로).
2. 구간 가중 Recall(§1-2 threshold 지표·부록 A-12 표 칼럼): "Recall 은 test 쌍 전체와 구간 가중(h 구간별 Recall 을 0.5·0.3·0.2 로, 같은 threshold) 둘 다 보고".
3. ⑦-T 입력: "기상 19변수 원값 lag(트리 갈래 1위 W) + 차감 19(N_ma 30, window 평균·최근 10일·최대) + SPI3·SPI6 원값 lag + h·g(지역·범주 없음)" — ⑦-D 와 같은 시계열 정보.

## B. 중
4. 결측 표시 칼럼(§4-2·부록 A-8): "결측 표시 칼럼·채널 = 그 모델 train 에 결측이 있는 칼럼(표준화 통계와 같게 모델마다) — 같은 행 모델을 여러 fold 에 같이 써도 그 모델 것 그대로, 목록에 없는 칼럼의 결측은 0(표시 없음)". 18차 8번의 'fold(refit) train 기준 하나로' 문구 지움. B-9 에 "블록 모델마다 결측 표시 채널 구성이 다를 수 있음(부록 A-8)".

## C. 하·정리
5. 0절 지역 입력 제외 목록에 ⑦ 추가: "(2-1·⑤·⑥·⑦·7-a·7-b 제외)".
6. B-9 계절 줄 → "해마다 T 05-02 ~ 06-30 은 채점 안 됨 — h 구간마다 보는 계절이 다름(h 1~20 엔 5월 하순 ~ 6월 d, h 41~60 엔 7월 ~ 8월 중순 d 가 없음)(§3)".
7. ⑦-D: §6 단계 8 딥러닝 줄 '딥러닝 단독 후보(1-2 상위 3·⑥)' → '(1-2 상위 3·⑥·⑦-D)'. 부록 A-11 딥러닝 test 모델 줄 → "상위 3개·⑥·⑦-D·결합 모델은 test 전 전체로 1회 학습, 그 밖 구조별 1위 test 는 블록 5 모델(…)". §7-2 구조 목록의 트랜스포머 인코더 → '(단계 1-2·⑦-D)'.
8. '단위 빼기 상한 약 6,620회' 의 '약' 지움(모든 곳 6,620).
9. 3-3 상한 기준(요약 일정 줄·§8 예상 줄): "3-3 은 상한(20바퀴) 기준으로 셈 — 실제는 채택 없는 바퀴에서 끝나 더 적음".
10. 3-3 건너뛰기(§6 단계 3-3 중요도 줄): 'fold 평균 I > 0' → '15칸(3 fold × 5) 평균 I > 0'.
11. refit 반복(§3 refit 문장): "refit 도 최대 2,000 반복까지 학습한 뒤 트리 수 지정 예측(규칙 판·-n 판이 같은 refit 모델을 각자의 N 으로 씀)".
12. 2-3 앙상블 대조(부록 A-12): "2-3 앙상블마다 백분위 평균(각 모델 예측을 같은 채점 쌍 안 백분위로 바꿔 평균) 대조 — 기록용(학습 없음, 후보 아님)". 최종 고르기 '후보 아님'에도.
13. 단계 8 씨앗 평균 판(부록 A-12 단계 8 점수 줄): "씨앗 평균 판이면 채택 직전 '고른 설정 대 기본 설정' 을 씨앗 0~4 평균 CV 로 한 번 더 비교(고른 설정 씨앗 학습은 A-9 미포함 +16 에 들어 있음)".
14. §1-3 사람 판단 줄의 'test 를 보기 전에 기록' → "그 세부가 영향을 주는 단계의 test 채점 전에 기록".
15. 본문 → 부록·정리: §6 단계 1-1 범주 처리 세부(pandas category·정수 번호·원핫·OOV 처리) → 부록 A-12(본문엔 "범주 처리는 부록 A-12"), §4-3 관측소·좌표 파일 규칙 세부 → 부록 A-2, 단계 4 줄이기 줄 끝의 끊긴 구절 '이력·인코딩(§5-1)(CatBoost 면 …)' 을 문장으로 고쳐 쓰기, §8 끝 학습 횟수 줄 지움(요약·부록 A-9 에 있음 — 요약 규모 줄에 '세부 부록 A-9'), 요약 '승인할 것' 에 (가)·(나) 목록을 한 줄로 적음: "(가) ③ → RF·ExtraTrees·로지스틱 원값 → W_DL 20 간격 → Optuna 100 → 50 → 3-3 단위 빼기 생략 → 섞기 3회, (나) 3-3 도중 π ≤ 0.2 그룹 함께 빼기 → 단위 빼기 생략 → 섞기 3회".
