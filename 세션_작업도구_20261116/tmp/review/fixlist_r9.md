# 9차 검수 반영 지시 (plan_v9.md → plan_v10.md)

전체 원칙(1~8차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 아래 지시가 앞 차수·옛 판보다 우선. 바뀐 숫자는 요약·본문·부록 모든 곳에서 같게.

## A. 교수님 말씀
1. '알릴 확정 사항'을 새 부록 A-11(줄마다 한 항목, 짧은 구절 + 위치)로 옮기고 §9 교수님 줄은 "알릴 확정 사항(부록 A-11)"만. A-11 항목: 지금 §9 칸의 항목 전부(뜻 되살림 — '다운사이징 기준 칼럼'·'검사 안 한 날 칸'·'나라 전체 평균 아님'·'범주·범주에서 정해지는 칼럼은 기준 행 값'·'트리 기반이라'·'딥러닝은 CV 없이 9년 전체 학습 말씀과 다름' 등 앞 차수 문구) + 새로 "확률 보정(calibration)은 안 함(지표가 순위 기반 PR-AUC·threshold 규칙)", "외부 지표(X1·X2)는 사용가능한 가장 최근 자료연도 값 1칼럼(여러 해 평균 안 냄)".
2. 품목 묶음별 보조 표(§1-3 마지막 줄): "최종 모델 test 를 품목 최상위 분류(`p2` 를 `ba_data.t_prdlst_cl.hrnk_prdlst_cd` 로 따라 올라간 1단계) × 국내·해외 묶음별로도 채점(보조 표, 고르기에 안 씀)".

## B. 중
3. 앙상블과 3-R 기준(용어 표 '3-R 기준' 칸): "… — 단계 3 대상이 앙상블이면 3-R 변수 비교는 대표 트리 단독, 3-3 끝 판과의 비교는 앙상블". §6 단계 3-R 줄의 '기준 = 3-R 기준' 은 그대로.
4. 단계 8 딥러닝 조건: "대상 판에 딥러닝 확률 칼럼이 있거나 대상이 트리 + 딥러닝 앙상블일 때만 그 딥러닝 모델(상위 3개면 3개)을 튜닝, 이상 점수(AE·VAE)는 튜닝 안 하고 그대로, 딥러닝 단독 후보는 튜닝 안 함". 앙상블의 8-TD = "딥러닝 구성 예측을 튜닝한 모델 예측으로 바꾼 평균". '딥러닝 칼럼 빼고 튜닝' 의 '딥러닝 칼럼' = 딥러닝 확률·이상 점수 칼럼 전부(튜닝 때 빼고 다시 붙임) — 문구로 구분.
5. 3-3 2단계 기본(§8 줄이기 절차 줄): "3-3 2단계 기본 = 진행(최대 20바퀴). 0-9 예상 끝 날짜에 2단계 상한(20 × (다단위 그룹 단위 수 × 3 + 1), 단위 수는 0-8 에서 확정)을 넣고, 기한을 넘으면 줄이기 절차(3-3 기한 규칙 → 2단계 생략 …)". §6 단계 3-3 2단계 줄의 '할지는 §8 줄이기 절차대로' 와 §1-3 사람 판단 줄의 '§8 3-3 2단계 절차' 는 이 줄을 가리키게(§8).
6. 동점 많은 판: "후보 그대로(빼지 않음), CV 1위면 확정 전 알림(기록용 — 고르기 안 바뀜)". '담당자·교수님이 빼라고 하면 다음 순위' 지움, §1-3 사람 판단 목록에서 '동점 많은 판 처리' 지움. 1% 기준 = "가장 큰 동점 묶음 크기 ÷ CV fold validation 쌍 전체 ≥ 1%(test 는 기록만)".
7. 축사 모집 지역(부록 A-4 국내 줄·B-6): "모집 지역 = 엑셀에 농장이 1곳 이상 있는 시군구(단계 0-6 에서 목록 확정·기록), 모집 지역 안에서 그 축종 0곳 = 0, 모집 지역 밖 = NaN". §9 담당자 축사 줄에 덧붙임: "모집 지역 안 빠진 축종을 0 으로 둘지(한 축종만 있는 홍천·영월·양산·김제, 축종 빈칸 논산·창녕·순천) — 기본 0".
8. 단계 5·6 씨앗(공통 줄): "씨앗 s = 음성 뽑기·모델 학습 모두 s, 반복 수 N 은 씨앗 0~4 평균 예측 곡선으로 §3 함수 1회".

## C. 하·정리
9. threshold 줄(§1-2): 뒤 문장을 "refit 은 공통 반복 수 N, fold 별 교차 N 과 공통 반복 수 N 을 표에 같이 기록" 으로 줄임.
10. 단계 0-9 '공통 반복 수 채점' → '반복 수 채점(56개 시점)'.
11. 단계 4 Theil's U 줄의 '이름 목록은 단계 0-1 에서 적어 고정' 지우고 "대상 칼럼은 부록 A-6" 만(0-1·A-6 에 있음). 단계 4·5·6 의 '이력·인코딩은 §5-1(줄이기 전 시료로 계산)' → '(§5-1)'.
12. RR1 처리 칸의 '배정 안 되면 RR2 처럼 제외' → "단계 0 대조에서 78행·9곳과 다르면 보고". RR4 처리 끝에 "그래도 못 정하면 제외(수 기록)".
13. §7-3 대조 판·B-9 의 튜닝 검증 시료 조건 → "최종 판이 튜닝한 딥러닝 값(8-TD)을 쓰면".
14. A-9 미포함 끝에 "단계 8 대상이 5·6 이면 8-TD·다시 붙인 판·Focal 비교도 씨앗 5배, 단계 8 대상이 앙상블이면 8-TD 도 다른 구성 트리 수 × 4".
15. 민감도 판(단계 0-3): 0-3 은 차이 측정·담당자 보고만, 민감도 판은 §1-3 마지막 보고로 옮김 — "최종 모델 test 입력에 0-3 에서 잰 시군구·변수별 평균 차이를 날마다 더한 민감도 예측 1개(학습 없음)".
16. 공개 지연(단계 0-3): "지연이 있으면 담당자 보고 → 승인되면 그 원천은 관측 끝 = T − 지연, 그 사이 날은 예보 칸으로(학습 땐 관측값)".
17. §4-1 시간 칼럼 줄에 "(2-1 표 AE·VAE 는 트리 갈래 1위 설정의 숫자 칼럼이라 h·g 둘 다)".
18. B-8 재현: "재현은 d ≤ 2025-06-30 국내 시료로(코드 확인용, 고르기에 안 씀 — 값이 0.79·0.50 과 조금 다를 수 있음)".
19. 상위 q% 포착률(§1-2): "경계 동점 묶음은 상위 q% 안에 든 비율만큼 그 묶음 검출을 나눠 셈(기대값)" 로 바꿈('경계 동점은 모두 포함' 지움).
20. B-9 추가·고침: "토양검정 값은 검정일 기준(DB 등록 지연은 모름)", "SMOTENC 합성 행의 생장식 칼럼은 기상 보간과 정확히 맞지 않음(gr2 는 식품값이 들어가 기준 행 값)", 씨앗 줄 → "씨앗 1개 학습(단계 5·6 제외, 정해진 방식)". §1-3 사람 판단 줄의 기본값 목록은 6번에 맞춤.
