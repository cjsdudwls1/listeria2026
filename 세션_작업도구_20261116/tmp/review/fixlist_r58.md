# 58차 반영 지시 (plan_v58.md → plan_v59.md)

전체 원칙(28~57차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(번호 이어지게).

## A. 중
1. 시간 측정(§6 0-9): 측정 목록에 '딥러닝 구조마다 1 fold 학습 1회(LSTM·GRU·트랜스포머·LSTM + attention·TCN)·딥러닝 1 구조 그룹 중요도 1회·RF·로지스틱 그룹 중요도 1회' 를 넣고, '(이 셋은 대리 설정 = … — A·window 가 정해지기 전이라)' 의 '— A·window 가 정해지기 전이라' → '— window 가 정해지기 전이라'. §8 일정의 '단위 빼기·2-R1 중요도는 그룹 중요도 1회 시간 × 섞는 묶음 수 비례' → '3-0b 중요도는 구조 종류별(부스팅·RF·로지스틱·딥러닝) 그룹 중요도 1회 시간 × 섞는 묶음 수 비례, 3-0b 학습은 구조별 측정값'.
2. 결합 구조 입력(구성 구조의 묶음을 그대로 — 담당자가 고른 원칙): 2차 공통 표 3-4 줄의 '기상·차감·SPI 채널 전부(⑥·⑦ 과 같음)' 와 부록 A-8 2차 딥러닝 줄의 '결합 모델·3-1 시퀀스 AE·VAE = 기상·차감·SPI 채널 전부' → '결합 모델 시계열 갈래 = LSTM 구조의 3-0b 변수 묶음(시퀀스 채널), 3-1 시퀀스 AE·VAE = 트리 대상 판 변수 묶음의 시퀀스 채널'. ⑥·⑦ 은 채널 전부 그대로.
3. 리서치팀 보고(부록 A-10, §6 2-R 끝 문장): '최종 모델 구조의 3-0b 빼기 결과' 뒤에 '(앙상블·스태킹이면 구성 구조마다, 3-0b 를 안 거친 판(교체 후보·1차 베이스라인)이면 해당 없음)'. 최종 모델 안 순열 중요도에 '(계산법 = 부록 A-5 — M = 10·`h_block`, 씨앗 = B-5 의 새 번호대 20000 + 칼럼 번호)' 넣고 B-5 씨앗 줄에도 그 번호대를 적음.
4. 결측 표시 목록 만드는 때(§4-2 결측 줄·§6 0-6): 목록은 원 변수(일자료 변수·표 칼럼) 단위로 0-6 에서 정함 — '그 차수 입력 표(1차 표·2차 표 각 1개)의 d ≤ 2025-06-30 자료에 결측이 있는 원 변수 → 그 변수에서 나온 window·요약·차감 칼럼·채널 전부에 표시(표시 칼럼은 원 칼럼마다)' 뜻으로 고침.

## B. 하
5. ② 입력(§6 추가 판 ② 줄·부록 A-8 ② 입력): '단계 4 시작 때 트리 대상 판의 입력' 뒤에 '(앙상블이면 구성 트리 중 3-0b CV 1위 트리의 현재 입력)'.
6. §0 test 를 안 매기는 목록에 '③ 의 고르지 않은 설정' 넣음.
7. 부록 A-11: '2차 = 단계 2 준비 뒤 정한 순서의 사슬' → '2차 사슬 = 단계 2 준비 뒤 정한 순서의 사슬'. 같은 수거 건·제품 줄의 '(제품명 정보는 쓰지 않음)' → '(제품명은 다운사이징 행 고르기에만 씀)'. 한 줄 추가: "제품명은 다운사이징 행 고르기(Theil's U 줄이기 칼럼)에만 쓰고 모델 입력(TF-IDF 등)에는 넣지 않음(담당자 결정 — 교수님 08 다운사이징 코드와 다름)".
8. 3-0b 절에 '(§9 양방향 추가 시 13 구조·딥러닝 7)' 한 구절.
9. B-9: 마지막 줄 '…3-0 비교·3-3 앙상블·교체 후보 판정에 섞임' → '…3-0·3-0b 비교·3-3 앙상블·교체 후보 판정에 섞임'. 한 줄 추가: "첫 현재 최고 판은 구조마다 여러 바퀴 고르고 11 끝 판 중 다시 골라 val 이 높게 나옴 — 3-0b 를 안 거친 교체 후보는 이 높은 기준을 넘어야 해 판정이 기울 수 있음".
10. 부록 A-15: '사슬' run = `listeria-2차` 최상위(단계 run 들과 같은 층 — 부모 없음), '단계 4 run 은 미리보기 때(2-1 뒤) 만듦' 한 구절.
11. 요약:
   - 10 '2차 준비(단계 2)' → '단계 2 준비(2차 맨 앞)'
   - 11 을 세 문장으로: (판정) '2차 사슬(12~18 을 차례로 — 12·13 은 판정 없이 첫 1등을 정함): 14~18 은 단계마다 후보를 만들어 val 이 현재 최고 판보다 오르면 채택해 새 현재 최고 판으로 삼고, 안 오르면 버린다(test 는 기록만, 한 단계에서는 쌓는 후보 1위 → 교체 후보 1위 순으로 한 번씩).' (교체 후보) '교체 후보(⑥·⑦ 시계열만(14)·④ LIMS 만 스태킹과 3-2 (e)(15)·결합 모델(15)·② 60칸 출력(16))는 이기면 현재 최고 판이 되지만 그 위에 3-1~3-4 를 쌓지 않는다.' (바탕) '트리 대상 판(3-1·② 입력·4-c-L 의 바탕)은 채택된 판 가운데 교체 후보가 아닌 트리·스태킹·앙상블 판 중 가장 최근 것이고, 단계 4~6·8 은 그때의 현재 최고 판(1등)에 — 교체 후보여도 — 한다.' — 지금 요약 11 의 다른 뜻은 빠뜨리지 말고, 항목 번호(14·15·16)는 다시 쓴 요약에 맞게

   - 18(튜닝) 끝에 '② 는 튜닝 안 하고, 트리 튜닝은 딥러닝 칼럼을 빼고 한 뒤 다시 붙인다'
