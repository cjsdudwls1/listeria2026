## A. 담당자 결정 — 확인 대기(§9) 없앰, 모두 지금 확정
1. §9 절 통째로 지움(제목·표). 문서 구성 줄(3행)의 '→ 9 확인 대기' 지움. 요약 24('남은 확인(§9): …') 지우고 뒤 번호를 당김(25 → 24). 문서 안 '§9' 참조는 아래 결정값으로 바꾸거나 지움 — 고친 뒤 '§9'·'회신'·'확인 대기' 가 남지 않게.
2. 부록 A-11 제목 'A-11. 알릴 확정 사항(§9)' → 'A-11. 확정 사항'. A-11 고위험 품목 줄 끝 '(§9 확인)' 지움.
3. 고위험 품목 수 = 상위 5개: §6 단계 4 의 '상위 10개 3단계 품목' → '상위 5개 3단계 품목', 부록 A-11 고위험 품목 줄의 '상위 10개'·'10개 품목 = refit train 기준 상위 10개' → 5, 부록 A-12 4-c 줄의 '10개 품목 = refit train 기준 상위 10개'·'상위 10 품목 밖' → 5, 요약 19 '상위 10 품목 시료로' → '상위 5 품목 시료로'. 문서 전체에서 4-c 뜻의 10 이 남으면 5 로.
4. 양방향 모델 추가 안 함(BiLSTM·BiGRU 없음 — 조건부 문구 전부 지움): 요약 21 '(양방향 추가 시 172,667)' 지움, §6 3-0b '(§9 양방향 추가 시 15 구조 — 딥러닝 7·결합 2)' 지움, §8 순서 '3-0(§9 의 BiLSTM·BiGRU 회신 또는 회신 전 기본값 확정 뒤)' → '3-0', 부록 A-7 대응 블록 목록의 '양방향 추가 시 BiLSTM·BiGRU' 구절 지움, 부록 A-8 2차 딥러닝 줄 '딥러닝 구조(양방향 추가 시 7)' → '딥러닝 5구조', 구조 표 LSTM·GRU 행의 'BiLSTM·BiGRU(§9 회신이 '양방향'일 때) = …' 문장 지움, 부록 A-9 'BiLSTM·BiGRU 가 추가되면(§9) …' 줄 지움, 부록 A-14 약어의 '·BLSTM·BGRU(양방향)' 지움.
5. 그대로 확정(§9 행만 지움): 손 교수 방식 음성 = 그해 양성 수 × 4, 단계 6 범위 = 3단계 × 시군구, 방식 이름 = '손 교수', 해외 결측 = 트리 NaN·딥러닝 0 + 결측 표시. §0 결측 줄 '(§4-2, §9 해외 결측 회신으로만 바뀜, 단계 1 전)' → '(§4-2)'.
6. Open-Meteo = 학습용 수집만(운영 수집은 이 계획 밖) — §4-4 의 '운영 예보는 지금 수집 안 함(해외 운영 입력은 운영 준비 때 정함)' 이 이미 그 뜻이면 그대로 두고 §9 행만 지움.

## B. 담당자 결정 — d 당일 기상을 예보 칸으로 씀(빈 날은 지금처럼 window 밖)
8. 정의: §1-1 'E = window 끝 = min(d − 1, T + 10), S = …, g = window 끝과 d 사이 빈 날 = max(0, h − 11), R = 단기 파생 기준점 = E + 1' → 'E = window 끝 = min(d, T + 10)(d 당일도 예보 칸), S = …, g = window 끝 다음 날부터 d 까지 날 수 = d − E = max(0, h − 10), R = 단기 파생 기준점 = min(d, E + 1)'. 요약 6 의 'g = window 끝과 d 사이 빈 날 수' → 'g = window 끝 다음 날부터 d 까지 날 수', 'window 끝 = min(d − 1, T + 10)' → 'window 끝 = min(d, T + 10)(d 당일도 예보 칸)'. §0 '…, d 당일 기상은 안 씀(§4-1, §9 window 해석 회신으로만 바뀜, 단계 1 전)' → '…, d 당일 기상도 예보 칸으로 씀(h ≤ 10, §4-1)'.
9. §4-1 'h ≤ 11 이면 E = d − 1, h ≥ 12 면 E = T + 10 이고 T+11 ~ d−1 의 g 일은 window 밖(입력 없음)' → 'h ≤ 10 이면 E = d(d 당일 = 예보 칸), h ≥ 11 이면 E = T + 10 이고 T+11 ~ d 의 g 일은 window 밖(입력 없음)'. '관측 일수 = max(0, W − min(h, 11))' → '관측 일수 = max(0, W − min(h + 1, 11))'. §5 'WX5·WX6 기준점 R = E + 1(h ≤ 11 이면 R = d)' → 'WX5·WX6 기준점 R = min(d, E + 1)(h ≤ 11 이면 R = d — 단기 파생은 d 전날까지)'.
10. 딥러닝 g 정규화 'g ÷ 49' → 'g ÷ 50'(g 최대 50) 모두.
11. 추가 판 ① '(T = d − 1, window d−1 끝)' → '(T = d − 1, window d 끝 — d 당일 예보 포함)'.
12. ② 입력(부록 A-8): 'E = T 로 다시 계산(② 는 한 입력으로 모든 h 를 내므로 d 당일을 넘지 않게 E = T — 예보 칸 가운데 T 하루만 쓰고 T+1 ~ T+10 은 안 씀, …)' → 'E = T + 1 로 다시 계산(② 는 한 입력으로 모든 h 를 내므로 가장 이른 d(= T + 1)를 넘지 않게 — 예보 칸 가운데 T·T+1 만 쓰고 T+2 ~ T+10 은 안 씀, …)', 같은 줄 'window = [T − W + 1, T]' → 'window = [T − W + 2, T + 1]', WX5·WX6(R = T + 1)·season 은 그대로. B-9 '② 는 한 입력으로 모든 h 를 내므로 E = T — 예보 칸 T+1 ~ T+10 은 안 씀' → '… E = T + 1 — 예보 칸 T+2 ~ T+10 은 안 씀'.
13. 부록 B-7 검산 예시(d = 2025-11-01, W = 60)를 새 규칙 값으로: 'h 1 → T 10-31, 09-03 ~ 11-01(관측 58·예보 2) / h 10 → T 10-22, 09-03 ~ 11-01(49·11) / h 11 → T 10-21, 09-02 ~ 10-31(49·11, 밖 1일 = d) / h 12 → T 10-20, 09-01 ~ 10-30(49·11, 밖 2일) / h 30 → T 10-02, 08-14 ~ 10-12(49·11, 밖 20일) / h 60 → T 09-02, 07-15 ~ 09-12(49·11, 밖 50일) / W = 100·h = 13 → 07-22 ~ 10-29(89·11, 밖 3일)' — 날짜·일수를 직접 다시 세어 확인.
14. B-9 'h ≤ 11 은 입력이 거의 같음(완전 예보 가정)' → 'h ≤ 10 은 입력이 거의 같음(완전 예보 가정)'. 문서 전체에서 옛 window 끝 규칙('window d−1 끝'·'h ≤ 11 이면 E'·'h ≥ 12 면 E'·'max(0, h − 11)'·'min(h, 11)'·'÷ 49'·'d 당일 기상은 안 씀')이 남으면 새 규칙으로. R 쪽 'h ≤ 11 이면 R = d'·'h ≥ 12 면 R ≠ d' 는 맞으니 그대로, RR8 'S = d − 149'(h 60 기준)도 그대로.
