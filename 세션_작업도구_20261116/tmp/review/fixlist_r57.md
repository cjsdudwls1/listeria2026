# 57차 반영 지시 (plan_v57.md → plan_v58.md) — 담당자 결정: 옛 2차 없앰, 변수 빼기는 구조 11종마다

전체 원칙(28~56차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(항목 수는 바뀌어도 됨 — 번호 이어지게).

## 뜻(담당자 결정)
- 차수는 1차·2차 둘: 1차 = 단계 1(지금 그대로), 2차 = 단계 2 ~ 8(지금의 3차 전체 + 앞에 단계 2 준비). 단계 번호(2-0·2-1·2-1b·2-R·3-0·3-0b·3-1~3-4·4·5·6·7·8)는 그대로 둠.
- 없앰: 옛 2차의 2-2(전부 넣은 4판)·2-3(A 로 변수 빼기)·2-4(2차 최종 판)·2차 베이스라인(9판 중 1위)과 그것을 가리키는 모든 문구(표의 '2차 베이스라인 줄', 사슬 시작 비교, 최종 모델 후보, B-9 줄 등).
- 남김(단계 2 준비, 2차 맨 앞): 2-0(A 의 1차 최고 설정을 2차 기상으로 다시 학습 — 2-1·2-1b·2-R 의 바탕), 2-1(k), 2-1b(N_ma 트리·LSTM), 2-R(리서치팀 변수 비교, 비교만). 이 넷은 라이브러리 기본 설정(반복 수 고르기 없음 — 1차와 같은 규칙).
- 3-0b = 구조 11종마다 변수 빼기: 3-0 의 11 판(트리 6·딥러닝 5) 각자 자기 3-0 판에서 시작해 지금 2-3 규칙(그룹 빼기 → 단위 빼기, M = 10·ψ_f ≥ 0.8·CV 평균 상승 + 3 fold 중 2개 이상·바퀴 상한 없음, 부스팅이면 §3 반복 수 규칙, 그 밖은 기본 설정 fold 모델)으로 뺌 — 딥러닝도 같은 규칙. 끝 판마다 '그 구조의 변수 묶음'. 첫 현재 최고 판 = 11개 끝 판 중 CV 1위(끝 판은 자기 3-0 판보다 낮지 않음).
- 그 뒤: 3-2·3-3 의 트리 상위 3개·딥러닝 상위 3개 = 3-0b 끝 판 중 CV 순(트리는 알고리즘별 1판), 각자 자기 묶음. 딥러닝 상위 3개의 블록·엄격 OOF 는 3-0b 끝 판으로 만듦(옛 '3-0b 묶음이 채택되면 딥러닝 상위 3개 다시 학습' 규칙·A-9 '3-0b 뒤 딥러닝 재학습 0~57' 줄은 지움). 현재 입력 = 그 트리의 변수 묶음 + 채택된 3-1 이상 점수 칼럼. ⑥·⑦ 은 기상·차감·SPI 채널 전부(구조별 빼기 없음). 트리 대상 판 대체(채택된 트리 판이 없을 때) = 3-0b 끝 판 트리 중 CV 1위.
- 최종 모델 = 2차 사슬 끝 판·1차 베이스라인 둘 중 CV 1위. 사슬 시작: 3-0b 1위 val 이 1차 베이스라인보다 낮으면 기록·알림.
- 리서치팀 보고(부록 A-10): '2-3 빼기 결과' → '최종 모델 구조의 3-0b 빼기 결과(그룹째 빠짐·단독으로 빠짐·남음)', 그리고 '최종 모델 안 칼럼·그룹별 순열 중요도(최종 모델 validation 쌍의 구간 가중 PR-AUC 하락, 학습 없음)' 를 표에 더함 — PDF 변수가 최종 모델에 쓰였는지·얼마나 쓰였는지.
