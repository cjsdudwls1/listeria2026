# 32차 검수 반영 지시 (plan_v32.md → plan_v33.md)

전체 원칙(28~31차와 같음). 학습 횟수 숫자는 바뀌지 않음(L1 을 빼면 2-3 은 더 적음 — 상한은 G 47 기준 그대로). 요약 목록은 28차 C 를 29~31차·이번 지시대로 고친 것이 기준.

## A. 중
1. 축사(L1): 국내 모집 지역을 고른 기준이 검출과 무관하다고 확인되기 전엔 2-2·2-3 후보에서 빼고 2-R 비교(기록용)에만 씀 — 모집 기준이 검출을 보고 정해졌다면 '모집 지역 안 0·밖 NaN' 이 미래 검출 정보가 됨. §5 L1 칸·§6 2-2·§9 데이터 팀 줄(회신 전 기본값)·부록 A-11(알릴 사항)·부록 B-6(fold 1 train 으로 모집 지역 여부와 검출률 관계 점검·기록)·요약 10번 "(축사는 모집 지역 기준 확인 뒤)"·부록 A-9 2-3 줄 "(L1 을 빼면 G 43 이라 더 적음 — 상한은 G 47 기준)".

## B. 하·정리
2. 부록 A-12 단계별 표 칼럼에 "(단계 4·5·6 판) 합친 threshold 의 fold 별 Recall", B-9 해당 줄 참조 "(§1-2·부록 A-12)".
3. 부록 A-8 AE·VAE "d = 입력 칼럼 수(숫자 칼럼 + 결측 표시 칼럼)", 표 입력 = "3-0 트리 CV 1위 판의 숫자 칼럼에서 h·g 를 뺀 것(…, 복원 대상 = 입력 전체)", §4-1 시간 칼럼 "3-1 표 AE·VAE 는 h·g 를 뺀 숫자 칼럼 — h 는 무작위 배정이라 복원 대상에서 뺌".
4. 부록 A-9 학습 아닌 계산: 반복 수 채점은 줄 끝에 "0-9 의 3차 부스팅 측정에 들어 있어 따로 안 곱함" 으로 따로.
5. §0 h 1~60 판 "(미리보기·⑤ 4 몫·그 판을 튜닝한 8-T 와 그때의 ⑤ 8 몫)", 요약 2번 "(h 1개 — 단계 4 의 일부 판만 h 1~60 전부)".
6. 요약 15번 대상 "(앙상블 포함 — 앙상블이면 대표 트리)", 18번 "(앙상블 포함)". 15번 뜻풀이: Theil's U(칼럼이 검출을 설명하는 정도), 4-a0 = h 1개 대조, 점수 0·1 규칙(학습 기간 검출 0 품목 = 0, 검출만 있는 품목 = 1), SMOTENC(양성 합성). 14번 "AE·VAE(자기부호화기) … — 다른 모델에 넣는 딥러닝 값은 시간 블록으로 나눠 미리 예측해 만듦". 11번 채택 규칙 "(빼서 CV 평균이 오르고 3 fold 중 2개 이상 오르면 채택)". 19번 "(…, ①·③ 은 비교만·나머지는 최종 후보)". 3번 "(변수 빼기·튜닝의 중간 시도 등 몇 가지만 제외 — 0절)".
7. §0 test 제외 = "test 를 안 매기는 것은 다음뿐: 2-3 바퀴 안 시도 판·③ 의 고르지 않은 설정·7-a 격자의 고르지 않은 값·Optuna 와 딥러닝 튜닝 시도".
8. §3 "④ 와 ⑤ 의 1·2차 몫은 예외 — 라이브러리 기본 반복 수 …". ⑤ 줄 대표 트리 = "(부록 A-12)".
9. ③ test = "1-1·1-2 의 같은 설정 refit 예측 그대로, 추가 학습 없음", 부록 A-9 미포함의 '③ refit' 지움.
10. 부록 A-12 범주 처리: "로지스틱 = 원핫(0/1 그대로 — 표준화는 숫자 칼럼만, 없던 범주 전부 0)".
11. 단계 5·6 씨앗 0 단독 줄 = "다른 판과 뽑기 방식을 비교할 때는 이 줄을 주 비교로(씨앗 평균 효과를 빼려고)".
12. 부록 A-12 '같은 validation 으로 고른 횟수' = "그 판 앞까지 같은 3 fold 로 CV 점수를 낸 모든 판·설정 수의 누적(1차 70 설정부터 — 2-3 시도·7-a 격자 75·Optuna 시도·Focal 포함, 반복 수 56 시점은 안 셈), 실험 로그에서 자동으로 셈".
