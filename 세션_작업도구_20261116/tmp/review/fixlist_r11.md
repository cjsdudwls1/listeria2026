# 11차 검수 반영 지시 (plan_v11.md → plan_v12.md)

전체 원칙(1~10차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 아래 지시가 앞 차수·옛 판보다 우선. 바뀐 숫자·이름은 요약·본문·부록 모든 곳에서 같게.

## A. 교수님 말씀
1. 2-2 스태킹에 판 (d) 추가: "(d) 트리 입력 + ⑥(시계열만 딥러닝) 확률 2칼럼(엄격 OOF)". 그래서 ⑥ 은 다른 모델 입력이 됨 — ⑥ 도 전역 블록 OOF + 엄격 OOF(§7-3 대상에 ⑥ 2종 추가), ⑥ 단독 CV·threshold = 엄격 OOF 의 fold train 전체 모델 예측(1-2 상위 3과 같게). '⑥ … 시간순 3 fold + refit(다른 모델 입력 아님)' 문구 고침. 단계 3 대상 목록 '2-2 (a)(b)(c)' → '2-2 (a)(b)(c)(d)'. 단계 8 딥러닝 튜닝 대상에 "(d) 면 ⑥ 2종".
   - A-9: ⑥ = 38(2 × 19), 2-2 스태킹 = 48(트리 3 × 판 4 × 4). 합계 = 1,573(단계 8 딥러닝 없음)·1,690~1,720, 최악 = 1,720 + 2,840 + 6,620 = 11,180. BiLSTM·BiGRU 추가 시 1,593·1,710~1,740, 최악 11,200. 요약·§8 숫자도 같게.

## B. 중
2. 동점 풀기(10차 1번을 대신함, §1-2 PR-AUC 칸·B-3·A-1): "PR-AUC·상위 q% 는 쌍마다 한 점씩(동점 없이) 계산 — 정렬 = 원 예측값(float64) 큰 순 → 같으면 모델 확률 p 큰 순(점수 0·1 판정 행) → 그래도 같으면 u 작은 순. 이 순위를 점수(n − 순위)로 바꿔 `precision_recall_curve`·`auc`. threshold 는 원 예측값으로(같은 값 묶음은 함께, 점수 0·1 판정 행 값 = 0·1)". 부록 A-1 에 "u = int.from_bytes(hashlib.md5(f'{lims_data_key}|{h}'.encode('utf-8')).digest()[:8], 'big') / 2**64". '1e-9·1e-12' 문구 전부 지움. '동점 많음' 묶음은 원 예측값으로 잼. 단계 4 보고 = "threshold ≤ 0(점수 0 묶음 값)이면 전부 양성 판정 — 표시·알림".
3. 민감도 예측(§1-3 마지막 줄): 이름 = '좌표 차이 민감도'. "국내 행 예보 칸(T ~ E) 날마다 시군구·변수별 평균 차이를 더하고, SPI 예보 칸·WX2~WX6 은 다시 계산, 딥러닝 값·시퀀스는 test 모델로 다시 추론(학습 없음), 해외 행은 그대로". B-9 완전 예보 줄 → "… test 는 예보 오차가 없는 경우의 점수 — 좌표 차이 민감도로 관측 위치 차이만 확인(예보 오차는 못 잼)".
4. §9 표에 '회신 전 기본값' 칸 추가(모든 줄): 딥러닝 튜닝 = 안 함(단계 8 은 트리만) / GRU 양방향 = 추가 안 함 / window 해석 = 지금 해석 / 해외 결측 = 지금 방식(트리 NaN, 딥러닝 0 + 표시) / 송 교수 음성 수 = 4배 / 단계 6 범위 = 3단계 × 시군구 / 알릴 확정 사항 = 해당 없음 / 축사 엑셀 = 새 `축사 현황 데이터(8.24).xlsx`, 빠진 축종 = 0 / Open-Meteo = 학습용 수집만 / 해외 축사 = 안 오면 해외 L1 NaN / 국내 전국 목록 = 없으면 모집 지역만. 확인할 것 칸의 '— 4배로 진행'·'기본 0' 같은 기본값 문구는 새 칸으로 옮김.
5. 4-a0 대조(단계 4): "단계 3 최종 판에 점수 0·1 규칙만 얹은 판(예측만 바꿈, 학습 없음, 기록용, 후보 아님)" 추가, 최종 고르기 '후보 아님'에도. 단계 4 보고 줄의 섞인 변경 = "점수 0·1 규칙·(CatBoost 면) 범주 인코딩".
