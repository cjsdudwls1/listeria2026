# 28차 반영 지시 — 차수(1·2·3차) 구조로 다시 짜기 (plan_v28.md → plan_v29.md)

전체 원칙: 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음, 본문(요약 제외) ≤ 300줄(넘으면 세부를 부록 A 로). 아래 번호 바꾸기를 본문·부록 A·B 전체에 빠짐없이. 표 칸 수(`|`) 유지.

## A. 담당자 지시와 회신(이번 판에서 정한 것)
- 1차: LIMS 기본 + 식정원 DB 에서 모은 기상만으로, 간단한 알고리즘(CatBoost·XGBoost·LightGBM·LSTM)으로 기상 window(원값·요약 통계 둘 다)와 베이스라인 모델을 정함. 점수 모두 기록, 이후 모든 판은 1차 베이스라인을 넘는 것이 기준
- 2차: 1차 window 고정, LIMS + DB 기상 + 그 밖 모든 변수, 1차의 4 알고리즘만으로 변수 넣고 빼기 → 2차 베이스라인
- 3차부터 지금 계획의 실험
- 1·2·3차 모두 test 채점·기록, 1·2차는 튜닝 일절 없음
- 회신: (1) 3차에서 새로 넣는 알고리즘(RF·ExtraTrees·로지스틱·GRU·트랜스포머·LSTM + attention) = 1차 window 고정 (2) 1·2차는 부스팅 반복 수도 라이브러리 기본값(검증으로 고르는 설정 없음), 반복 수 고르기(§3)는 3차부터 (3) 1차 해외 기상 = DB 값만(Open-Meteo 로 채운 칸은 NaN), 채운 값은 2차부터 (4) 2차 변수 빼기 = 1차 트리 1위 알고리즘 하나로, 고른 변수 묶음을 4 알고리즘에 같이 씀

## C. 요약 = 아래 목록으로 통째로 바꿈(제목 '## 요약(순서대로 읽기)', 하위 글머리 없이 1~25, 문구·숫자 그대로)
1. 목적: 리스테리아 검출을 운영 단위(국내 시군구·해외 나라 × 품목 2·3단계)로 1~60일 앞(h 1~60) 예측
2. 자료: LIMS 시료 676,520건(검출 1,969), 국내·해외 한 모델, 학습 행 = 시료 1건(h 1개)
3. 평가: 시간순 3 fold CV 로만 고르고, test 1년(d 2025-07 ~ 2026-06)은 모든 차수의 모든 판을 채점해 기록만
4. 지표: 구간 가중 PR-AUC(h 1~20·21~40·41~60 = 0.5·0.3·0.2), threshold = Recall 0.8 이상 중 Precision 최대
5. 준비(단계 0): 행 수 대조, 기상·파생변수 표, 평가 틀, 시간 측정 → 예상 끝 날짜 보고
6. 1차 입력: LIMS 기본(시도·시군구·품목 2·3단계·국내/해외 + h·g) + 식정원 DB 기상 19변수(해외는 DB 값만)
7. 1차 알고리즘: CatBoost·XGBoost·LightGBM·LSTM, 라이브러리 기본 설정 그대로(튜닝·반복 수 고르기 없음)
8. 1차 window: 트리 W 10~100 × 원값·요약 통계 = 60 설정, LSTM W 10~100 = 10 설정
9. 1차 결과: 70 설정의 CV·test 표, CV 1위 = 1차 베이스라인(이후 모든 판이 넘어야 할 기준), 트리·LSTM window 고정
10. 2차 입력: 1차 입력 + 나머지 모든 변수(검출 이력·SPI·이동평균 차감·생장식·생장 범위·단기 기상·습도·이슬점·계절·식품 aw·pH·토양·지하수·친환경·축사), 해외 기상은 Open-Meteo 로 채운 표
11. 2차 방식: 1차 window·같은 4 알고리즘·기본 설정 그대로 — 이력 k·차감 길이 고르기 → 전부 넣기 → 중요도 낮은 변수 묶음·단위 빼기(1차 트리 1위 알고리즘으로) → 리서치팀 변수 비교
12. 2차 결과: 고른 변수 묶음을 4 알고리즘에 넣어 비교, CV 1위 = 2차 베이스라인, 3차 변수 고정
13. 3차 시작(단계 3-0): 부스팅 반복 수 고르기 시작, RF·ExtraTrees·로지스틱·GRU·트랜스포머·LSTM + attention 추가(1차 window·2차 변수)
14. 3차 결합(단계 3-1 ~ 3-4): AE·VAE 이상 점수, 스태킹, 앙상블, 결합 모델
15. 3차 다운사이징(단계 4): Theil's U 1위 칼럼에서 검출 없는 값의 행을 학습에서 빼기, SMOTENC, 고위험 품목 모델
16. 3차 손 교수 방식(단계 5·6): 해마다 양성 전부 + 음성 4배를 무작위로 뽑는 2종
17. 3차 타겟 인코딩 단독(단계 7): 과거 검출률만으로 예측(모든 표의 기준 줄)
18. 3차 튜닝(단계 8, 맨 끝): 트리 Optuna 100회·Focal 손실 비교, 딥러닝 튜닝은 교수님 회신 뒤
19. 추가 판 ①~⑦: 당일 예측, 60칸 신경망, 시료 무작위 나누기 비교, LIMS 만 스태킹, 단계별 TE 단독, 시계열만 모델 2종
20. 최종 모델: 모든 후보 중 CV 1위, 1차 → 2차 → 3차 단계별 → 최종 test 변화 표로 보고
21. 규모(회 = 모델 1개 학습, 세부 부록 A-9): 예상 2,800회(변수 빼기 각 3바퀴 가정), 다 줄이면 1,427회, 최악 10,960회(변수 빼기 20바퀴 상한)
22. 기한 2026년 11월 중순(판정 2026-11-20): 넘을 것 같으면 승인 받고 ③ → LSTM window 20 간격 → Optuna 50회 → 단위 빼기 생략 → 섞기 3회 순으로 줄임
23. 변수 빼기 도중 늦어지면(승인 뒤): π ≤ 0.2 묶음 함께 빼기 → 단위 빼기 생략 → 섞기 3회
24. 승인할 것(실험 시작 = 승인 뒤): 0절 고정 조건, §8 줄이기 순서·기본값, §9 질문 보내기와 회신 전 기본값
25. 교수님께 물을 것(§9): 딥러닝 튜닝 여부·도구, GRU 양방향, window 해석, 해외 결측 방식, 줄인 자료 딥러닝 재학습, 손 교수 음성 수, 단계 6 범위

## D. 본문
### D-1. 1차(단계 1)
- 1-1 트리: 입력 = 범주 `sido`·`sgg`·`p2`·`p3`·`src_route` + h·g + 1차 기상 19변수(국내 = §4-3 표, 해외 = DB 값만 §4-4), 알고리즘 = XGBoost·LightGBM·CatBoost, 라이브러리 기본 설정 그대로(반복 수·학습률 포함 — CatBoost 학습률은 학습마다 라이브러리 자동값, 검증으로 고르는 값 없음, 범주 처리 부록 A-12), W 10~100(10 간격) × 입력(요약·원값) = 60 설정, 모든 설정 3 fold + refit·test
- 1-2 LSTM: 구조·학습 = 부록 A-8 LSTM·학습 줄 그대로(튜닝 없음), 입력 = 부록 A-8 1차 입력, W_DL 10~100 = 10 설정, 모든 설정 3 fold + refit·test
- 1-3 정하기: 트리 window = 1-1 CV 1위 설정의 (W, 입력 방식), 딥러닝 window = 1-2 CV 1위 W_DL(2·3차 모든 딥러닝·⑥·⑦), 1차 베이스라인 = 70 설정 중 CV 1위, 2차 기준 알고리즘 A = 1-1 CV 1위 설정의 알고리즘. 산출 = 알고리즘 × W × 입력 표(70 설정 CV·test 전부)
- 1·2차 threshold = 그 fold 모델 예측을 합쳐 §1-2 규칙(반복 수 고르기가 없으니 공통 N 따로 없음)

### D-2. 2차(단계 2)
- 공통: 1차 window 고정, 기상 = 2차 기상(해외 = Open-Meteo 로 채운 표), 알고리즘 = 1차 4종, 기본 설정(튜닝·반복 수 고르기 없음), 모든 판 3 fold + refit·test(2-3 바퀴 안 시도 판은 지금처럼 채택 있던 바퀴의 기준 판만 refit)
- 2-0 기준 판: A 의 1차 최고 설정을 2차 기상으로 다시 학습(파생변수 없음) — 2-1·2-1b·2-2 의 출발 판, 2-R 기준
- 2-1 k / 2-1b N_ma: 옛 3-1·3-1b 와 같고 출발 판 = 2-0, refit·test 도 함
- 2-2 전부 넣은 판: 2-0 + §5 후보 전부, 4 알고리즘 각각(LSTM 입력 = 부록 A-8 2차 입력)
- 2-3 변수 빼기: 옛 3-3 규칙 그대로, 모델 = A(시작 판 = A 의 2-2 판), 재학습·중요도는 기본 설정 fold 모델로(교차 N 없음)
- 2-R: 옛 3-R 그대로, 기준 = 2-0
- 2-4 2차 최종 판: 2-3 끝 변수 묶음을 4 알고리즘에(A 는 2-3 끝 판 그대로)
- 2차 베이스라인 = 2-0·2-2(4판)·2-4(4판) 9판 중 CV 1위, 3차 변수 묶음 = 2차 베이스라인 판의 변수 묶음. 표에 1차 베이스라인과 비교

### D-3. 3차(단계 3-0 ~ 8, 추가 판)
- 공통: 1차 window·3차 변수 묶음 고정, 부스팅은 §3 반복 수 규칙(교차 N·공통 N·CatBoost 학습률 평균)을 여기부터, 튜닝은 단계 8 만
- 3-0 알고리즘 넓히기: 트리 6종 = XGBoost·LightGBM·CatBoost(§3 반복 수 규칙 — 2-4 와 반복 수 규칙만 다름) + RandomForest·ExtraTrees·LogisticRegression(기본 설정, max_iter 2,000·`n_iter_` 기록) / 딥러닝 4구조 = LSTM(3차 변수 묶음의 2차 LSTM 판 재사용, 없으면 학습 4)·GRU·트랜스포머 인코더·LSTM + attention(1차 W_DL, 기본) — 모두 3 fold + refit·test. 산출 = 트리 상위 3개(알고리즘별 1판, CV 순), 딥러닝 상위 3개(CV 순) → 딥러닝 상위 3개에 전역 블록·엄격 OOF 추가(§7-3)
- 3-1 ~ 3-4 = 옛 2-1 ~ 2-4 그대로: 트리·딥러닝 상위 3개 = 3-0 산출, 이상 점수 표 입력 = 3-0 트리 CV 1위 판의 숫자 칼럼, 시퀀스 = 3-0 딥러닝 CV 1위 구조의 x_seq(W_DL = 1차), 결합 모델 시계열 window = 1차 W_DL
- 단계 4 대상 판(옛 '단계 3 최종 판' 자리) = 3-0 트리 6·3-2 (a)~(e)·3-3 앙상블 2종 중 CV 1위(결합 모델·딥러닝 단독·④·⑦ 이 1위여도). 단계 4~7 = 이 판 설정(튜닝 전, 부스팅은 반복 수만 다시), 앙상블이면 대표 트리(구성 트리 중 3-0 CV 1위)

- 미리보기 4-a = 1차 직후 1-1 트리 1위 설정으로(반복 수는 3차 규칙, 보고용, test 채점은 단계 4 보고 때)
