# 22차 검수 반영 지시 (plan_v22.md → plan_v23.md)

전체 원칙(1~21차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 바뀐 숫자는 요약·본문·부록 모든 곳에서 같게.

## A. 중
1. ELBO 정의(용어 표 약어 칸): "ELBO = VAE 목적함수(클수록 좋음), 음의 ELBO = VAE 손실(재구성 MSE + KL) = 이상 점수의 원 점수(클수록 이상, 넣을 때는 robust z)".
2. 단계 6 음성 풀(§6 단계 5·6): "6: 해마다 그해 양성 전부 + 그해 양성 수 × 4 개 음성을 '그해 양성이 나온 칸' 들의 그해(d 가 그해인) 음성 풀에서 무작위, 모자라면 풀 전부. 5·6 모두 refit train 에도 같은 규칙".

## B. 교수님 말씀
3. ⑦-T 차감 입력: "차감 19 도 lag 원값(날짜별, lag001~lagW, N_ma 30)" — ⑦-D 의 날마다 차감 채널과 같은 정보(‘window 평균·최근 10일·최대’ 문구 지움).

## C. 하·정리
4. robust z(§6 단계 2-1): "IQR = 기준 행 원 점수의 75% 분위 − 25% 분위, IQR = 0 이면 기준 표준편차로 나눔(그것도 0 이면 1)".
5. 최종 고르기 '후보 아님': '2-1·2-3 백분위 평균 대조' → '2-1 이상 점수 단독·2-3 백분위 평균 대조'.
6. 3-R1 중요도: 3-R 줄에 "중요도 계산법 = 부록 A-5 와 같음", 끝 문장 '단계 3 대상에 딥러닝 칼럼이 있으면 …' → "(딥러닝 칼럼이 있을 때 부록 A-12)". A-9 학습 아닌 계산에 "3-R1 중요도 1회".
7. 부록 A-12 동점 많은 판: "(동점 많은 판이 1위면 2위와 0.001 안일 때)".
8. §0 의 결측 줄·d 당일/예보 줄 끝에 "(§9 회신으로만 바뀜, 단계 1 전)".
9. §8 예상 셈: "병렬 구간(1-1 CPU·1-2 GPU)은 긴 쪽만, 잰 적 없는 W 의 판은 칼럼 수 비례로 보간".
10. 섞기 횟수 일반식(§6 단계 3-3·부록 A-5): "섞기 횟수 R(기본 5, 줄이기 땐 3): r = 1~R, ψ_f = fold f R 회 중 I > 0 비율, π = 3R 칸 중 I > 0 비율, 기준 ψ_f ≥ 0.8 그대로(R = 3 이면 3회 모두)", '15칸'·'5회' 문구를 R 로.
11. 용어 표에 "트리(갈래) = 1-1 알고리즘 6종(로지스틱 포함)".
12. 단위 빼기 상한 다시 셈(그룹 마지막 단위는 안 빼므로 바퀴당 시도 단위 = 110 − 다단위 그룹 8 = 102): 단위 빼기 상한 = 20 × (102 × 3 + 1) = 6,140(단위 수는 0-8 에서 확정). 최악 = 1,705 + 2,840 + 6,140 = 10,685, 0-9 예상 기준 = 1,594 + 2,840 + 6,140 = 10,574, 다 줄여도 3,814(그대로), BiLSTM·BiGRU 추가 시 최악 10,705. 3-3 합 = 8,980(최악의 약 84%), 단위 빼기 = 6,140(약 57%). 요약·§8·A-9 모두. 요약에 "회 = fold 하나 또는 refit 한 번의 학습, 조건부 = 부록 A-9 미포함 항목" 한 구절.
13. '코드없음' 집계 키(§2-2 RR3): "'코드없음' 3단계 칸은 이력·타겟 인코딩 집계에서 (p2, '코드없음') 로 나눠 셈".
14. B-6 에 "SO1: 단계 0 에서 원천 `soil_ph_info` 로 몇 시군구·날짜를 다시 계산해 기존 표(date = T 행)와 맞는지·검정일 ≤ T−1 인지 assert".
15. ② window(부록 A-8 ② 입력 목록·B-9): "② 는 한 입력으로 모든 h 를 내므로 d 당일을 넘지 않게 E = T — 예보 칸(T ~ T+10) 안 씀, 표에 '예보 칸 미사용' 표시", B-9 에 같은 한계 한 줄.
