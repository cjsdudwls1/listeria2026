# 29차 검수 반영 지시 (plan_v29.md → plan_v30.md)

전체 원칙(28차와 같음): 같은 내용은 한 곳에만, 이력·날짜·인용·결정 번호 없음, 본문(요약 제외) ≤ 300줄. 학습 횟수 숫자는 바뀌지 않음. 요약 목록은 28차 C 를 아래 4·5번대로 고친 것이 기준.

## A. 중
1. 단계 8 대상 = 3차 트리 판(3-0 트리 6·3-2·3-3·4-a·4-a0·4-b·4-a-n·4-a0-n·4-b-n·5·6·7-b·⑤ 의 3·4 몫) 중 CV 1위 — 1·2차 판은 튜닝 대상 아님(기본 설정 그대로 후보).
2. 부록 A-8 2차·3차 딥러닝 채널 대응: 기상·SPI 채널 = 그 변수의 window 단위가 남으면, 차감 채널 = 그 변수의 차감 칼럼(평균·최근 10일·최대) 중 하나라도 남으면, 계절 원핫 = season 이 남으면, 표 칼럼 = 그 칼럼의 단위가 남으면 넣음. 딥러닝 표 칼럼의 window 요약은 W_DL window 로 다시 계산, 3-1 시퀀스 AE·VAE 입력 = x_seq 만.
3. 단계 0-9: 2-2 전부 넣은 판·그룹 중요도·Optuna 는 1-1 측정에서 가장 느린 트리 알고리즘의 W 100 원값으로 잼(A·window 가 정해지기 전), §8 순서 1-3 에 "A·window 로 남은 일정 다시 추정, 아직 시작 안 한 줄이기 (가) 항목은 이때 다시 정함".
4. 단계 4 대상이 앙상블이면 단계 4~7 표에 대표 트리 단독(3-0 판) 줄을 비교 기준으로 넣고, 단계 4 보고 차이 원인 문구에 '앙상블 → 대표 트리'.

## B. 하·정리
5. 요약: 2번에 "(h 1개 — 단계 4 의 4-a·4-b 만 h 1~60 전부)", 7번 "CatBoost·XGBoost·LightGBM(라이브러리 기본 설정)·LSTM(정해 둔 기본 구조·학습 설정), 튜닝·반복 수 고르기 없음", 9번 "1차 베이스라인(이후 모든 표에 넣는 비교 기준, 최종 후보에도 있어 최종 모델은 CV 로 이 판 이상)", 12번 "2-0(파생 없음)·2-2(전부)·2-4(고른 묶음) 9판 중 CV 1위 = 2차 베이스라인, 그 판의 변수 묶음을 3차에 고정", 15번에 "학습 행에 h 1~60 전부, 점수 0·1 규칙 판과 원 예측(-n) 판 둘 다", 19번 = 추가 판마다 하는 때(③ 1차 뒤, ⑥·⑦ 3-0 뒤, ④ 3-2, ①·② 단계 4, ⑤ 차수·단계마다).
6. §0 차수 줄 "(… ③ 은 1차 뒤)", 1차 베이스라인 = "이후 모든 표의 비교 기준(최종 후보에도 있음)", 용어 표 "(이후 모든 표의 비교 줄, 고르기 규칙 아님 — 최종 후보에 들어 있음)".
7. ⑦-T 입력 = ⑦-D 의 x_seq 채널(3차 변수 묶음의 기상·차감·SPI 채널) 그대로를 원값 lag(W = ⑦-D 의 W_DL) + g.
8. 단계 8 딥러닝 단독 후보에 '2-2·2-4 LSTM', ⑥ 줄 괄호 '(3-0 딥러닝 상위 3과 같게)' 지움, ⑤ 넣는 곳 '1차·2차·3-0~3-4·단계 4·8', A-12 범주 처리 '(§6 1·2·3차 모든 트리 판)', '3-0 10판(BiLSTM·BiGRU 추가 시 12)', B-9 의 공통 N 두 줄에 '(3차)', B-9 '(3-0 부스팅 판과 같은 변수 묶음의 2차 판으로 따로 봄)'.
9. A-11: '1·2차(보고서 형식)' 줄 지움(0절에 있음), 딥러닝 줄 = "딥러닝 구조·window 고르기 = 다른 모델과 같은 시간순 3 fold CV".
10. 단계 5·6: "씨앗 0 단독 예측의 CV·test 도 같이 적음(학습 추가 없음)". 부록 A-12 단계 8 점수: "앙상블 대상이면 채택 직전 '튜닝 설정 앙상블 대 기본 설정 앙상블' CV 도 기록". 부록 B-9: 1·2차 CatBoost 학습률이 fold·refit 마다 자동값이라 threshold 크기가 어긋날 수 있음(실제 학습률을 덤프에 적고 표 주석에 표시).
