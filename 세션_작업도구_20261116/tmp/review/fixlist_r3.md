# 3차 검수 반영 지시 (plan_v3.md → plan_v4.md)

전체 원칙(1·2차와 같음) + 이번 추가: 본문은 승인 판단용으로 ≤ 300줄 목표. 공식·칼럼 정의·딥러닝 구조·학습 횟수 세부 같은 구현 사양은 '부록 A. 구현 사양'으로, 점검 목록은 '부록 B. 구현 점검'으로 옮김(본문엔 한 줄 요약 + '(부록 A-n)'). 같은 내용은 한 곳에만.

A. 교수님 말씀 반영(가장 중요)
1. 이력(HIS1~HIS4)·타겟 인코딩(7-a·7-b·⑤) 값 = 그 행의 T 직전 06-30(= 연 1회 갱신 시점, C)까지 d 가 있는 시료로 계산. train·validation·test·운영 모두 같은 규칙(운영은 1년마다 다시 계산·재학습). validation·test 행의 C = 그 fold(refit) train 끝이 됨. 5년 = [C−1825, C], 1년 = [C−364, C], p0 = 같은 기간 전체 검출률. 'rolling T−1'·'T 이전 validation·test 시료까지 집계' 문구는 모두 이 규칙으로 바꿈. 7-a 도 같은 규칙이라 따로 예외 없음. 창이 자료 시작(2015-04-07) 전으로 넘어가면 logn 은 실제 일수로 연 환산, 창 전체가 자료 시작 전이거나 n = 0 이고 N_all = 0 이면 그 칼럼 NaN.

B. 방법론
2. SPI 감마 적합 기간 = 2015-01-01 ~ 2022-06-30 하나로 고정(모든 fold·모델·refit·test·운영 같은 값 — 어느 fold validation 보다 앞). 모델별 적합 기간 문구 전부 지움.
3. 단계 3-3 섞기 블록 = (h, `src_route`) 같은 행끼리(`h_block` 정의도 고침). SMOTENC 이웃도 (h, `src_route`) 같은 행끼리.
4. Theil's U 후보에서 고유값 비율 0.5 넘는 칼럼(식별자 성격)은 뺌. refit 기준 칼럼 = refit train Theil's U 1위.
5. 단계 4 점수 0·1 판정 = 줄이기 전 fold(refit) train: 검사 1건 이상·검출 0 → 통째로 빠진 품목 = 0, 검사 1건 이상·불검출 0 → 검출만 있는 품목 = 1.
6. threshold 용 fold 예측 = fold 별 교차 N 예측(씨앗 42). 최종 고르기의 '씨앗 43 재실행' 규칙은 지움(0절에 '고르기 = CV 평균 1위, 재실행·여유 규칙 없음'). '같은 validation 으로 고른 횟수' 칼럼 정의 = 그 판에 이르기까지 같은 3 fold 점수로 비교한 판 수(누적).
7. 보고: h 별 PR-AUC 그림에 h 마다 채점 d 범위·검출 비율을 같이 표시.
8. 단계 0-3 에 '예보 좌표 가까운 관측소 값과 3곳 평균의 차이 측정 — 크면 담당자 보고' 한 구절.
9. 딥러닝 OOV 벡터 = 0 고정. 단계 8 딥러닝 튜닝: 표준화 통계는 2021-06-30 까지, 검증 채점 쌍 = T ∈ 2021-07-01 ~ 2022-05-01 인 (시료, h) 쌍 전부(구간 가중), 튜닝 대상 = 최종 판에 들어간 딥러닝 모델(상위 3개면 3개).
10. 추가 판 ④: 부스팅 반복 수 = 라이브러리 기본값, OOF 블록 = §7-3 fold 안 블록(fold 1·2 = 4, fold 3 = 5), validation·test = fold train 전체 모델 → 횟수 132(6 × (5 + 5 + 6) + refit 6 × 6).
11. 단계 2-1 이상 점수 단독 판 CV·threshold = 엄격 OOF 의 fold train 전체 모델 예측. 단계 1-2 '상위 3개 밖 설정의 threshold' 문구 지우고, 구조별 1위 test 는 블록 5 모델의 test 예측으로 보고만.
12. 블록 5 모델(블록 1~4 = d ≤ 2023-06-30 학습) = fold 2 의 fold train 전체 모델과 같으니 다시 학습하지 않고 같이 씀(딥러닝 상위 3·이상 점수 4종 각 1회 줄임, 합계 −7).

C. 사양 보완
13. rg 품목 4칼럼은 새 식품 고정표(해외 3종 포함)로 다시 계산 — 기존 `생장범위_품목3단계.parquet` 는 안 씀. 토양 pH 3칼럼 = SO1 과 같은 값(시군구 일별 토양의 date = T 행).
14. 0절: '지역 입력 = 모든 모델 시도 + 시군구' 에 '(⑤·⑥·7-a·7-b 제외)'.
15. 학습 횟수 기준 통일: 3-1b = 12(3 fold, refit 없음 — 3-1 과 같게). '1-1 요약만이면' → 'RF·ExtraTrees·로지스틱 원값 빼면'. 합계에 3-3 상한(20바퀴 × 141 = 2,820)을 넣은 총 상한도 한 줄. 기한 규칙 발동 = 단계 0-9 측정으로 낸 예상 끝 날짜가 기한(2026년 11월 중순)을 넘을 때 → §8 줄이기 절차(담당자 확인). 3-3 2단계 '남은 기한으로' → '§8 줄이기 절차대로'.
16. §3 기록값 = 규칙 적용 전 수 — 단계 0 에서 규칙 적용 전 셈과 같아야 함(다르면 멈춤), 적용 후 수는 새로 기록.
17. test 막기 = 고르는 코드가 test 정답(y)을 읽으면 멈춤(예측 생성·저장은 허용). §1-3·부록 문구 맞춤.
18. CatBoost 학습률: fold 마다 반복 1번 학습으로 자동 학습률을 읽어 평균 → 그 값으로 모든 fold·refit 학습.

20. SMOTENC 거리 = 두 행 모두 값 있는 숫자 칼럼만으로 표준화 유클리드(쓴 칼럼 수로 나눔) + 범주 불일치는 SMOTENC 기본 벌점. 합성 행의 딥러닝 값·이상 점수는 합성 전에 붙인 엄격 OOF 값을 다른 숫자 칼럼처럼 보간.
21. 추가 판 ② 구조를 딥러닝 구조 표에: 범주 4 임베딩(각 8) + 기상 요약(트리 갈래 1위 W 의 요약 칼럼, window = [T − W + 1, T]) → Dense 128 → 64 → Dense 60(sigmoid), 손실 = 자기 h 칸 이진 교차엔트로피, 학습 설정은 다른 딥러닝과 같음.
