# 59차 반영 지시 (plan_v59.md → plan_v60.md)

전체 원칙(28~58차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(번호 이어지게).

## A. 담당자 결정 — window 하나로(트리·딥러닝 같은 W)
1. §6 1-3 정하기 줄 = "1-3 정하기: window W = 1차 70 설정 중 CV 1위 설정의 W(트리·딥러닝 모든 판에 같음 — W_DL = W), 트리 입력 방식 = 1위가 트리면 그 방식, LSTM 이면 그 W 의 트리 설정 중 CV 1위 방식, 1차 베이스라인 = 70 설정 중 CV 1위, A(단계 2 준비 판의 바탕 알고리즘) = 그 W·입력 방식의 트리 설정 중 CV 1위 알고리즘. 산출 = 알고리즘 × W × 입력 표(70 설정 CV·test 전부)" 뜻으로(지금 줄의 다른 내용은 살림).
2. §0 window 줄에 '(트리·딥러닝 같은 W)' 넣음. 요약 9 의 '트리 window = 트리 60 설정 1위, LSTM window = LSTM 10 설정 1위로 고정한다' → '그 1위의 W 를 트리·딥러닝 모든 판의 window 로 고정한다(트리 입력 방식은 1위가 트리면 그 방식, LSTM 이면 그 W 의 트리 1위 방식)'. 부록 A-14 'W·W_DL' 뜻 = 'window 길이(W_DL 은 딥러닝 쪽 이름, 값은 W 와 같음)'. §6 2-0 'A 의 1차 최고 설정을 2차 기상으로 다시 학습' → 'A 의 (W, 입력 방식) 판을 2차 기상으로 다시 학습'. B-9 'window 는 1차 4 알고리즘으로만 찾음 — 3-0 의 다른 알고리즘은 자기에게 맞는 window 를 따로 찾지 않음' → 'window 는 1차 4 알고리즘 결과로 하나만 정함 — 트리·딥러닝·3-0 의 다른 구조 모두 자기에게 맞는 window 를 따로 찾지 않음'. 문서 전체에서 '트리 window'·'딥러닝 window'·'LSTM window' 를 따로 정한다는 뜻이 남으면 같은 뜻으로(1차 1-1·1-2 의 W 탐색 자체는 그대로).

## B. 중
3. §8 일정에 '2-R1·최종 모델 안 순열 중요도 = 그 모델 구조 종류의 그룹 중요도 1회 시간 × 섞는 묶음 수 비례' 넣음.
4. B-5 씨앗 줄에 최종 모델 안 그룹 중요도 씨앗 '21000 + 그룹 번호' 넣음(칼럼은 '20000 + 칼럼 번호' 그대로). 부록 A-10·B-5 의 '새 번호대' → '번호대'.
5. 리서치팀 보고 '해당 없음' 범위(부록 A-10): '3-0b 를 안 거친 판(교체 후보·1차 베이스라인)이면 해당 없음' → '⑥·⑦·④·3-2 (e)·1차 베이스라인이면 해당 없음, ② 는 트리 대상 판 구조의 결과, 결합 모델은 LSTM 구조의 결과'. §6 2-R 끝 괄호는 '(부록 A-10)' 참조만. B-9 '3-0b 를 안 거친 교체 후보는 이 높은 기준을 넘어야' → '3-0b 를 안 거친 교체 후보(⑥·⑦·④·3-2 (e))는 이 높은 기준을 넘어야'.
6. B-9 한 줄: "딥러닝 상위 3개·W·N_ma 는 fold 2 validation 정답으로도 골랐는데, 같은 행 모델 재사용(부록 A-12)으로 fold 3·refit train 의 옛 fold 2 validation 시료 행에 그 모델 예측이 딥러닝 칼럼으로 들어감 — 그 train 행 딥러닝 칼럼이 실제보다 잘 맞게 보일 수 있음(B-6 에 블록별 OOF PR-AUC 기록)". B-6 의 딥러닝 값 분위수 비교 줄에 '·옛 validation 시료 블록 대 나머지 블록 OOF PR-AUC' 넣음.
