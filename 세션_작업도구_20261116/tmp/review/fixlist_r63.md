## B. 상·중
5. 줄인·뽑은 자료로 다시 학습하는 값 모델은 같은 행 모델 재사용 안 함: 부록 A-12 같은 행 모델 재사용 줄에 '— 줄인·뽑은 자료로 학습하는 모델(단계 4~6·4-c 의 다시 학습한 값 모델, 그 위 단계 8 의 값 모델 고른 설정)은 fold·refit 마다 학습 행이 달라 재사용 안 함: fold f 의 블록 모델·train 전체 모델 = fold f 의 줄인·뽑은 행으로, 전역 블록·test 전 모델 = refit 의 줄인·뽑은 행으로'. 부록 A-7 끝 '고른 설정의 d ≤ 2021-06-30 모델은 같은 행 모델 재사용 규칙(부록 A-12)으로 … 같이 씀' 에 '(줄인·뽑은 자료 대상이면 재사용 안 함)'. 부록 A-9 미포함의 값 모델 다시 학습 셈 '× 19 × 자료 벌 수(단계 4 = 1, 5·6 = 2 방식 × 씨앗 5 = 10) — 최대 1,463' → '× 22(재사용 없음 — 전역 6 + 엄격 16) × 자료 벌 수(단계 4 = 1, 4-c = 1, 5·6 = 2 방식 × 씨앗 5 = 10) — 최대 1,848', 같은 미포함에 '그 값 모델이 단계 8 대상이면 고른 설정 OOF 3 × 22(3 × 18 대신, +12)'. 부록 A-9 의 '흔히 붙는 미포함(…)만큼 실제는 조금 더 많을 수 있음' → 괄호 목록에 '단계 4~6·4-c 값 모델 최대 1,848' 넣고 '조금' 지움.
