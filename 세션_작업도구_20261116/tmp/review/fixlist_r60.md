## A. 담당자 결정 — 결합 모델 2종을 3-0·3-0b 구조로(13 구조), 3-4 단계 없앰
결정 내용: 결합-기본·결합-VAE 를 3-0 의 구조로 넣어(트리 6 + 딥러닝 5 + 결합 2 = 13 구조) 다른 구조처럼 3-0b 에서 자기 변수 빼기를 함. 결합 모델 입력 = 2차 딥러닝 입력 그대로(정형 갈래 = x_static(그 판 변수 묶음의 표 칼럼·계절 포함) + x_cat 임베딩, 시계열 갈래 = x_seq) — 그래서 리서치팀 변수(WX5·WX6·L1)도 결합 모델 입력 후보. 결합 모델 끝 판도 첫 현재 최고 판 후보. 딥러닝 상위 3개(3-2 (a)·(b) 확률 칼럼·3-3 앙상블 구성) = 딥러닝 5 + 결합 2 끝 판 전부 중 CV 순. 단계 3-4 는 없어지고 결합 모델은 교체 후보가 아님.
