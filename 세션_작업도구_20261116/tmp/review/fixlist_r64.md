# 64차 반영 지시 (plan_v64.md → plan_v65.md)

전체 원칙(28~63차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(번호 이어지게). 확인 대기 없음.

## A. 담당자 결정
1. 3-1 후보 3개: 3-1 판 = 트리 대상 판 + 이상 점수 묶음 3 후보 — '+AE 2칼럼(표 AE·시퀀스 AE)'·'+VAE 2칼럼(표 VAE·시퀀스 VAE)'·'+4칼럼'. 셋 중 CV 1위를 현재 최고 판과 판정(쌓는 후보). 이후 '이상 점수 칼럼' 은 그 묶음: 현재 입력 정의의 '3-1 이상 점수 4칼럼 — 3-1 판이 채택될 때만' → '3-1 에서 채택된 이상 점수 묶음 — 채택될 때만', 3-2 (b)·(c) 의 '이상 점수 4칼럼' → '이상 점수 묶음(3-1 후보 중 CV 1위 묶음, 채택 여부와 무관)'. §6 2차 공통 표 3-1 행·§6 3-1 줄·요약 15('AE·VAE 이상 점수 더하기(3-1)' → '…(3-1 — +AE·+VAE·+둘 다 3 후보)') 같게. 문서 전체 '이상 점수 4칼럼' 이 남으면 뜻에 맞게(3-1 의 원 점수 모델 4종·이상 점수 단독 판은 그대로). 부록 A-9 3-1 행 = '88 | 4 × 19(…그대로) + 3판 × 4', 합계 1,067~1,476(트리만 1,365, 트리 + 딥러닝 확률 칼럼 3개 1,476, ⑥ 2종이면 1,439, 딥러닝 단독·결합 모델 1,090, ② 1,067), 0-9 예상 = 1,476 + 13 × 1,068 = 15,360, 최악 = 1,476 + 13 × 11,413 = 149,845(요약 21·§8 일정도). 부록 A-14 이름 꼴에 '3-1 = 3-1-<알고리즘>-AE·-VAE·-ALL'.
2. ⑧ 정형만 = 계절 남김: §6 추가 판 ⑧ 의 '기상 9그룹(부록 A-5) 칼럼을 모두 뺀 판(남는 것 = 그 판의 비기상 칼럼 + 범주 5 + h·g)' → '기상 8그룹(부록 A-5 의 기온·강수·바람·햇빛·지중온도·토양수분·습도·대기질) 칼럼을 모두 뺀 판(남는 것 = 그 판의 비기상 칼럼·계절 + 범주 5 + h·g)'. 요약 19 의 ⑧ 설명도 같게. B-9 한 줄: '⑧ 은 기상이 있는 상태에서 고른 변수 묶음에서 기상만 빼므로 기상과 겹쳐 빠진 비기상 칼럼이 돌아오지 않음 — 기상의 추가 예측력이 크게 나올 수 있음'.

## B. 상·중
3. 블록 모델 학습 행(세 검수 공통 — 부록 A-12 같은 행 모델 재사용 줄): 'fold f 의 블록 모델·train 전체 모델 = fold f 의 줄인·뽑은 행으로, 전역 블록·test 전 모델 = refit 의 줄인·뽑은 행으로' → 'fold f 블록 모델·전역 블록 모델 = 줄이기·뽑기 전 행 중 그 모델의 학습 블록 시료로 다시 정한 줄인·뽑은 행(§6 2차 공통), fold f train 전체 모델 = fold f 의 줄인·뽑은 행, test 전 모델 = refit 의 줄인·뽑은 행'.
4. 블록마다 다시 정하는 범위(§6 2차 공통 끝 문장): '블록 OOF 모델마다 줄이기(Theil's U 1위 칼럼·검출 0건 값)·뽑기(해마다 양성 수·양성 칸)·4-c 품목 고르기를 그 모델의 학습 블록 시료로만 다시 정함(예측할 블록의 정답을 안 씀)' → '블록 OOF 모델마다 검출 0건 값 판정·해마다 양성 수·양성 칸을 그 모델의 학습 블록 시료로만 다시 정함(예측할 블록의 정답을 안 씀) — 줄이기 칼럼(Theil's U 1위)·4-c 품목은 그 fold(refit) 것 그대로'. B-9 두 줄: '블록 모델의 줄이기 칼럼·4-c 품목은 fold(refit) 것이라 그 고르기에 예측할 블록의 정답이 조금 들어감' / '블록 모델은 더 짧은 기간으로 검출 0건 값을 정해 더 많이 줄일 수 있어, 단계 4~6·4-c 에서 train 행 딥러닝 값(블록 모델)과 validation·test 값(전체 모델)의 눈금이 체계적으로 다를 수 있음 — 메인 트리가 그 차이를 그대로 배움'. 기존 B-9 '딥러닝 확률은 모델마다 눈금이 조금 다를 수 있음' 줄에 '(단계 4~6·4-c 는 아래 줄)' 정도로 이어 줌.
5. ④ 트리 OOF 도 같은 규칙: §6 2차 공통 '④ 처럼 여러 모델 판 = 모델마다(OOF 블록 §7-3 그대로, …)' 에 '— 단계 4~6 에서는 블록 모델을 위 값 모델과 같은 규칙(블록마다 다시 정함·재사용 없음)으로'. 부록 A-9 미포함 '④ 면 판마다 118(5·6 은 × 씨앗 5)' → '④ 면 판마다 136(= 6 × 22 + 메타 4, 5·6 은 × 씨앗 5)'.
6. 4-a m 대체 정리(§6 단계 4 4-a 괄호):
   - '디스크 기반 학습(XGBoost)' → '디스크 기반 학습(바탕 트리가 XGBoost 일 때만, 아니면 바로 다음 단계)'
