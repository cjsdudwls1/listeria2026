# 20차 검수 반영 지시 (plan_v20.md → plan_v21.md)

전체 원칙(1~19차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 학습 횟수 숫자는 바뀌지 않음.

## A. 상
1. ② 입력(부록 A-8 60칸 신경망 줄 아래에 목록, 본문 ② 칸은 "입력 = 4-a 칼럼을 한 T 기준으로 바꾼 것(부록 A-8)" 한 줄만):
   - 뺌: h·g·딥러닝 확률·이상 점수((시료, h) 쌍마다 값이 달라 한 T 입력으로 못 씀)
   - E = T 로 다시 계산: 기상 window 칼럼·WX1~WX4 의 window 칼럼(window = [T − W + 1, T], W = 4-a 의 W), WX5·WX6(R = T + 1), season(T 의 달)
   - 그대로: 범주·이력·타겟 인코딩(C 는 T 기준 그대로)·FD1·SO1·X1·X2·L1·rg 품목·rg 토양 pH
   - 숫자는 표준화·결측 0 + 표시, 범주는 임베딩 각 8. Dense 128 → 64 → Dense 60(sigmoid)

## B. 중
2. 이상 점수 눈금 맞추기(§6 단계 2-1·부록 A-8): "이상 점수는 각 모델 자기 train 불검출 행 점수 분포의 백분위(0~1)로 바꿔 넣음 — 블록 모델·fold train 전체 모델·test 모델 사이 크기 차이를 없앰". B-9 에 "딥러닝 확률은 모델마다 눈금이 조금 다를 수 있음(이상 점수만 백분위로 맞춤)".
3. 교수님 말씀(다운사이징 구조): 부록 A-11 에 "단계 4~6 은 트리 부분만 줄인 자료·뽑은 자료로 다시 학습, 딥러닝 부분(확률·이상 점수)은 전체 자료 모델 값 그대로(§6 단계 3·4)". §9 교수님 줄 추가: "줄인 자료로 딥러닝·결합 모델도 다시 학습할지 | 회신 전 기본값 = 안 함 | 단계 4 전".
