# 23차 검수 반영 지시 (plan_v23.md → plan_v24.md)

전체 원칙(1~22차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 바뀐 숫자는 요약·본문·부록 모든 곳에서 같게.

## A. 중
1. 섞기 횟수 기호 M 통일: 부록 A-5 "(M = 3 이면 3회 모두)", 부록 A-9 "중요도 예측 G × M × 3". R 은 단기 파생 기준점(E + 1)만.
2. 단위 빼기 상한 되돌림(22차 12번을 대신함): 첫 바퀴는 110단위 전부 시도 가능('그룹 마지막 단위는 안 뺌'은 그룹에 한 단위만 남았을 때만 걸림) → 상한 = 20바퀴 × 첫 바퀴 최대 (110 × 3 + 1) = 6,620. 최악 = 1,705 + 2,840 + 6,620 = 11,165, 0-9 예상 기준 = 1,594 + 2,840 + 6,620 = 11,054, BiLSTM·BiGRU 추가 시 최악 11,185, 3-3 합 9,460(최악의 약 85%), 단위 빼기 약 59%, 다 줄여도 3,814(그대로). 요약·§8·A-9 모두.
3. 생장식 결측(부록 A-3 WX3): "결측은 식마다 자기 입력만 봄 — gr1 = θ, gr2 = θ·aw·pH, gr3 = rain[t − 2] 가 그날 하나라도 결측이면 그날 값 결측. 요약은 결측인 날을 빼고 계산(sum = 값 있는 날 합, npos = 값 있는 날 중 γ_T(θ) > 0 인 날 수), 값 있는 날이 0 이면(mean10 은 최근 10일 안에서) 결측" (구현 참고 e2fg.py 와 같음).

## B. 하·정리
4. 요약 '회' 정의: "회 = 모델 1개 학습 — fold·refit·블록·겹 하나".
5. 요약 규모·일정·줄이기를 짧은 목록으로: 규모 아래 "예상 11,054 / 최악 11,165 / 다 줄이면 3,814", "그중 3-3 9,460(약 85%), 단위 빼기 6,620(약 59%) — 20바퀴 상한 기준", 승인할 것 아래 (가)·(나) 각 한 줄. 본문 줄 수를 맞추려고 0절의 '튜닝·손실함수 비교 = 맨 끝 단계 8' 을 고르기 줄 끝에, '시료당 train h 1개'·'W 10~100 탐색'·'결과 시차 90일 반영 안 함' 을 한 줄로 합침.
