# 66차 반영 지시 (plan_v66.md → plan_v67.md)

전체 원칙(28~65차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(번호 이어지게). 확인 대기 없음.

## A. 담당자 결정 — ⑥ 에 TCN 추가(3종)
1. ⑥ = LSTM + attention·GRU + attention·TCN(시계열만 — 입력 = 기상 시퀀스 + g, 지역·범주·계절 없음; TCN 구조 = 부록 A-8 TCN 행, x_static = g 만·x_cat 없음). 고칠 곳: §6 추가 판 ⑥ 행, 요약 14('딥러닝 2종(⑥)' → '딥러닝 3종(⑥ — LSTM·GRU + attention·TCN)'), 요약 15·§6 3-2 (d)·(e) 의 '⑥ 확률 2칼럼' → '⑥ 확률 3칼럼', §7-2 구조 줄 'TCN(3-0)' → 'TCN(3-0·⑥)', §7-3 엄격 OOF 대상 '⑥ 2종' → '⑥ 3종', 부록 A-8 TCN 행 끝에 '(⑥ 는 x_static = g 만, x_cat 없음)', 부록 A-7 AutoKeras 대응 목록·§6 단계 8·부록 A-12 의 '⑥ 2종' → '⑥ 3종', 부록 A-14 추가 판 이름에 'x6-TCN'. 문서 전체 '⑥ 2종'·'⑥ 확률 2칼럼' 이 남으면 같은 뜻으로.
2. 부록 A-9: ⑥ 행 = '57 | 3 × 19(…그대로)', 8 딥러닝 행의 '⑥ 2종((d)·(e)) = 2 × 19 + 2 × 18 = 74' → '⑥ 3종((d)·(e)) = 3 × 19 + 3 × 18 = 111', 합계 행 = '1,086~1,495 | … 트리만 1,384, 트리 + 딥러닝 확률 칼럼 3개(또는 ⑥ 3종) 1,495, 딥러닝 단독·결합 모델 1,109(1,384 − 298 + 23), ② 1,086. 예상에는 상한 1,495', 0-9 예상 = 1,495 + 13 × 1,068 = 15,379, 최악 = 1,495 + 13 × 11,413 = 149,864(요약 21·§8 일정도), 미포함 '+12(딥러닝 확률 칼럼 3개)·+8(⑥ 2종)' → '+12(딥러닝 확률 칼럼 3개·⑥ 3종)'. 고친 뒤 표를 다시 더해 확인.

## B. 중
3. 최대 반복 판정(§3·§6 0-9·부록 A-12): 0-9 의 '2차 사슬 부스팅 학습 1회(…대리 설정 = 1-1 측정에서 가장 느린 트리 알고리즘…)' → '2차 사슬 부스팅 학습 1회씩(XGBoost·LightGBM·CatBoost 마다, 대리 설정 = W 100 원값·§5 후보 전부)', §3 의 최대 반복 늘리기 규칙에 '알고리즘마다 따로 정함(그 알고리즘의 모든 2차 사슬 부스팅 학습에 씀)' 넣음. CatBoost 학습률은 최대 반복을 늘려도 2,000 기준 자동 학습률 그대로(부록 A-12 학습률 읽기의 iterations = 2,000 고정 — '그때의 최대 반복' 이면 '2,000' 으로 고침).
4. 4-a 메모리 판정 자료(§6 단계 4 4-a 괄호·§6 0-9): 'refit train(가장 큰 train)으로 학습 1회를 시도해' → 'fold 1~3·refit 중 줄인 뒤(h 복제 포함) 행 수가 가장 큰 train 으로 학습 1회를 시도해', 0-9 의 4-a 대리 측정 '가장 큰 줄인 train × h 60' 도 같은 말로, 0-9 머리 괄호 '(fold 3 — 가장 큰 train, …)' → '(fold 3 — fold 중 가장 큰 train, …)'.
5. 단계 8 시도 메모리 오류(§6 단계 8 Optuna 줄 또는 부록 A-7 끝): '시도가 메모리 오류면 그 시도는 실패로 기록(점수 없음, TPE 이력에 실패로 알림)하고 다음 시도로 — float32·디스크 기반·m 은 바꾸지 않음'.
