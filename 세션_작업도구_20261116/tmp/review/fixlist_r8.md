# 8차 검수 반영 지시 (plan_v8.md → plan_v9.md)

전체 원칙(1~7차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 아래 지시가 앞 차수·옛 판보다 우선. 바뀐 숫자는 요약·본문·부록 모든 곳에서 같게.

## A. 중
1. CatBoost 범주 숫자의 계산 시료(7차 2번을 고침): "값 = 줄이기 전 fold(refit) train 시료(시료 1개 = 1번, 합성 행·h 복제 제외)로 §5-1 C 규칙 그대로" — '줄인 train 시료' 문구를 이것으로(줄인 집합에 남는지가 C 뒤 검출로 정해지므로). §5-1 마지막 줄은 그대로 맞음(예외 없음).
2. 딥러닝 튜닝 겹침(§7-3 블록 5 줄·§6 단계 8): 블록 5 대조 판을 넓힘 — "최종 판에 딥러닝 값이 있으면 블록 5 train 행(+ 단계 8 딥러닝 튜닝을 했으면 튜닝 검증 시료 d 2021-07-02 ~ 2022-06-30 의 train 행)의 딥러닝 값을 결측으로 둔 대조 판 1회(3 fold + refit = 4, 기록만, 후보 아님)". 단계 8 의 '튜닝 전후 PR-AUC 기록' 은 그대로. B-9 둘째 줄에 '단계 8 딥러닝 튜닝 검증 시료' 도 넣음.
3. 단계 8 판 두 개(§6 단계 8·최종 고르기·A-9): "8-T = 트리 튜닝 설정(딥러닝 칼럼이 있으면 기존 딥러닝 값을 다시 붙이고 N 다시) — 후보, Focal 비교는 8-T 에서(대상이 CatBoost·지원될 때). 8-TD = 8-T 에 튜닝한 딥러닝 값으로 바꾼 판(N 다시) — 후보, 단계 8 딥러닝 튜닝을 했을 때만. 둘 다 3 fold + refit". 최종 후보 목록의 '8 튜닝 판' → '8-T·8-TD'. A-9 미포함의 '단계 8 딥러닝 뒤 트리 재학습' → '8-TD 4', '다시 붙인 판 3 fold(+3)' 는 그대로.
4. N 이름 정리(용어 표·§3·A-5·단계 8): "공통 반복 수 N = 세 fold 평균 최고 N(refit 에 씀), 교차 N = fold f 점수에 쓰는 N(나머지 두 fold 평균 최고)". A-5 중요도 = "fold f 모델은 교차 N 트리로 예측", 단계 8 = "§3 교차 N 규칙". '교차 N 규칙(공통 반복 수 N)' 같은 섞인 표현 없앰.
5. 추가 판 ② 점수 0·1: ② 칸에 "점수 0·1 규칙 같음", 단계 4 의 '4-a·4-a0·4-b·① 모두 같게' → '4-a·4-a0·4-b·①·② 모두 같게'.
6. 추가 판 ⑤ 설정: "⑤ = 그 단계 트리 판 1위의 알고리즘·설정(단계 8 몫은 8-T 튜닝 설정, 그 밖은 기본 설정), 입력만 HIS1 6칼럼, 부스팅은 반복 수만 다시. 1위가 앙상블이면 대표 트리(구성 트리 중 단계 1 CV 1위)".
7. threshold 와 refit N(§1-2 threshold 줄): "threshold 는 교차 N 예측으로 정하고 refit 은 공통 반복 수 N — fold 별 교차 N 과 공통 N 을 표에 같이 기록".

## B. 하·정리
8. 앙상블 재학습 셈(A-9 미포함): "앙상블이 단계 3 대상이면 다른 구성 트리 수(딥러닝 부분은 다시 학습 안 함) × 4 × (3-2 판·3-3 끝 판), 단계 8 대상이 앙상블이면 8-T 도 같음". 단계 8 대상이 트리 + 딥러닝 앙상블이면 "딥러닝 구성 모델도 단계 8 딥러닝 튜닝 대상".
9. 3-R 기준(앙상블일 때, §6 단계 3 모델 줄): "3-R 비교의 기준 = 대표 트리 단독, 3-3 끝 판과 비교하는 3-R 기준 = 앙상블".
10. 동점 많은 판 1% 기준(§1-2): "CV fold validation 쌍 합침 기준(test 는 기록만)".
11. 보조 지표(§1-3 표 칼럼): "공통 d 범위(08-30 ~ 05-02) 구간 가중(CV·test, 보조)" 칼럼 하나 추가(고르기에 안 씀).
12. 사람 판단 기본값(§1-3 사람 판단 줄): "기본값(§8 줄이기 기본 순서·§1-2 그대로 확정·§8 3-3 2단계 절차)을 따르고, 바꿀 때만 이유를 기록".
13. 단계 0-3: '크면 담당자 보고 + 민감도 판' → "차이를 담당자에게 보고하고 test 입력에 그 차이를 더한 민감도 판 1개(예측만)"('크면' 기준 없앰).
14. RR1 판별(§2-2 RR1 대상 칸): "해외 행 중 시료 `lat`·`lon` 이 `02_시군구_배정.py` 규칙으로 국내 시군구에 배정되는 행(주소가 로마자 한국 주소 — 기록 78행·좌표 9곳·검출 0, 단계 0 대조)".
15. A-9 셈 칸 '엄격 13' → "엄격 14 중 전역 블록 5 와 같은 1 제외 = 13"(1-2·2-1·④·8 딥러닝 줄 모두).
16. 중복 줄이기: 본문 단계 4 CatBoost 줄 = "CatBoost 면 범주 칼럼을 C 규칙 스무딩 검출률 숫자로(대상·식 부록 A-6)". 0절 기준 칼럼 줄 = "`prduct_nm` 등 단계 4 기준 칼럼 = 행 고르기용(§2-1)". 부록 A-3 WX4 첫 줄의 '기상 6 × 요약 2 = 12칼럼' 지움(아래 줄에 있음). §9 '알릴 확정 사항' 칸은 항목마다 짧은 구절 + 위치(§·부록)로 줄임(뜻은 그대로).
17. B-9 정리: 제목 = "B-9. 받아들인 한계(보고서에 적음)", 줄마다 한계 + 근거 위치만(이유 괄호 지움), '(고정 조건)' → '(§3)', 끝에 "씨앗 1개 학습(정해진 방식)" 한 줄.
