# 13차 검수 반영 지시 (plan_v13.md → plan_v14.md)

전체 원칙(1~12차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 아래 지시가 앞 차수·옛 판보다 우선. 바뀐 숫자·이름은 요약·본문·부록 모든 곳에서 같게.

## A. 중
1. 점수 0·1 규칙 없는 판을 후보로(단계 4): "4-a·4-a0·4-b·② 마다 같은 모델의 원 예측 그대로인 판(4-a-n·4-a0-n·4-b-n·②-n)도 후보(학습 없음 — 반복 수 N 은 원 예측으로 따로 고름)". 기존 '참고 판(… 4-a 모델 확률로 둔 판, 기록용)' 은 4-a-n 으로 대신해 지움. 최종 후보 목록·단계 8 대상 목록에 -n 판 추가.
2. 점수 0·1 덮어쓰기와 N(단계 4): "규칙 판(4-a·4-a0·4-b·①·②)의 반복 수 곡선·교차 N·공통 반복 수 N·threshold 는 모두 점수 0·1 을 덮어쓴 예측으로 계산".
3. 줄이기 (가) 에 3-3 항목 넣기(§8): "(가) 단계 0-9 예상으로 정할 때: ③ → RF·ExtraTrees·로지스틱 원값 → W_DL 20 간격(20·40·60·80·100) → 단계 8 Optuna 100 → 50 → 3-3 단위 빼기 생략 → 3-3 섞기 5회를 3회로". (나) 는 그대로(3-3 도중). 요약 규모 줄 = "학습 최악 11,151회(그 가운데 3-3 그룹 빼기 2,840·단위 빼기 6,620, 조건부 제외) — …" (아래 4번 숫자).
4. 딥러닝 튜닝 사양 보완(부록 A-7 딥러닝 아래): "구조별 대응: 은닉 = 순환 유닛 수·d_model, FF = 2 × 은닉, 층 = 순환층·인코더 층 수, 드롭아웃 = 그 구조의 모든 Dropout 칸에 같은 값, attention key = 은닉 ÷ 2". "첫 시도 = 기본 설정(부록 A-8), 기본보다 낮으면 기본 유지(트리와 같음) — 기본 설정 점수는 이미 학습한 d ≤ 2021-06-30 모델로(학습 없음)". 고른 설정의 d ≤ 2021-06-30 모델은 같은 행 모델 재사용 규칙으로 fold 1 넷째 블록·fold 2 블록 4 OOF 에 같이 씀 → A-9: 8 딥러닝 = 114(3 × 20 + 3 × 18) / 76((d) 면 2 × 20 + 2 × 18). 합계 = 1,577(단계 8 딥러닝 없음)·1,653~1,691, 최악 = 1,691 + 2,840 + 6,620 = 11,151, BiLSTM·BiGRU 추가 시 1,597·1,673~1,711·최악 11,171. 요약·§8 같게.

## B. 하·정리
5. 4-c 품목 고르기(단계 4·A-11): "refit·test 의 5개 품목 = refit train 기준 상위 5개" 덧붙임.
6. DB 에 없는 나라(부록 A-2): "보정 없음(Open-Meteo 그대로). 좌표 = 그 나라 다각형(`리스테리아ML2\data\외부_수집\축사\나라경계_NaturalEarth_v5.1.2_10m.geojson`) 안에 찍힌 d ≤ 2022-06-30 시료 좌표 중앙값, 없으면 다각형 대표점".
7. §5-1 NaN 줄: 기호 ①·② 빼고 "창 전체가 자료 시작(2015-04-07) 전이거나, 그 기간 전체 검사 수 n_all = 0 이면 그 칼럼 NaN".
8. Theil's U·줄이기 결측(단계 4·A-6): "기준 칼럼 값이 NaN 이면 한 범주로 셈(Theil's U·줄이기 모두)".
9. 단계 0-1 에 "월별 시료 수·검출률을 이전 해와 비교해 끝 3개월(2026-04 ~ 06)이 비었는지 점검·보고".
10. 부록 A-7 트리 범위의 learning_rate 하한 0.005 → 0.01(CatBoost·XGBoost·LightGBM 모두).
11. B-9 추가: "교차 N 은 나머지 두 fold(뒤 기간 포함)로 고름 — 앞 fold 점수에 뒤 기간 validation 정보가 들어감(§3)", "옹진군 대표 좌표는 기존 산출물(전 기간 시료 좌표 중앙값) 그대로(§4-3)", "튜닝 학습률 하한 0.01 은 반복 2,000 상한에서 덜 학습될 수 있음(부록 A-7)".
