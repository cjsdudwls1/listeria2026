# 2차 검수 반영 지시 (plan_v2.md → plan_v3.md)

전체 원칙은 1차와 같음(본문 ≤ 330줄 목표, 구현 세부는 부록 A, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음, 0절은 한 줄씩).
본문과 부록에 같은 내용이 두 번 나오면 한 곳에만 두고 다른 곳은 '(§n)'으로 가리킴. 이미 판단이 끝난 지시이니 그대로 반영.

A. 상
1. 딥러닝·시퀀스 AE·VAE 입력 시퀀스는 (시료, h) 쌍마다 만듦 — 국내 SPI 채널은 과거 = 기상청 값, T 부터 = 우리 식이라 이음 위치(T)가 h 마다 다름. 그래서 'h 1~11 은 g = 0 한 번 예측'·'시료 × g 50가지' 를 '(시료, h) 60가지'로 바꿈(트리 train 행 값 = 그 행 h, validation·test = 쌍의 h). 학습 행도 자기 h 로 만든 시퀀스. 모델 입력 시간 칼럼은 그대로 g 만.
2. WX4 생장 범위 = 원천 정의 `리스테리아ML2\data\데이터셋\생장범위\생장범위_정의.csv` 그대로 13개 기본값 → 칼럼:
   - 날마다 기상 6: rg_tmax_opt(30 ≤ max_temp ≤ 37 → 1), rg_tavg_opt_dist(avg_temp 와 30~37 사이 거리, 안이면 0), rg_t_out_lim(min_temp < −2 또는 max_temp > 45 → 1), rg_soilt_opt(8 ≤ soil_t5 ≤ 15), rg_soilt_lim(8 ≤ soil_t5 ≤ 30), rg_soilt_opt_dist(soil_t5 와 8~15 거리) → 각각 window 평균·최근 10일 평균 = 12칼럼
   - 토양 pH 3(T−1 의 [T−1095, T−1] 중앙값 soil_ph 로): rg_soilph_opt(6.5~7.0)·rg_soilph_lim(5.0~8.0)·rg_soilph_opt_dist
   - 품목 4(식품 고정표 aw·ph 로): rg_aw_lim(0.90~0.997)·rg_aw_opt_dist(|aw − 0.97|)·rg_ph_lim(4.0~9.6)·rg_ph_opt_dist(|ph − 7.0|)
   - 합 19칼럼. 그룹: 기온 6 → 기온, 지중온도 6 → 지중온도, 토양 pH 3 → 토양(비기상), 품목 4 → 식품(비기상).
3. SMOTENC(4-b) 결측: 칼럼마다 기준 행·이웃 둘 다 값이 있으면 거리·보간에 쓰고, 한쪽만 있으면 그 값을 복사, 둘 다 없을 때만 NaN. 합성 전후 칼럼별 결측률 대조를 부록 점검에 추가.

B. 중
4. WX3 생장식: 온도 입력 = 날마다 avg_temp(기호는 θ — 예측일 T 와 겹치지 않게). mean = window 평균, mean10 = 최근 10일(E−9 ~ E) 평균, sum = window 합, npos = f > 0 인 날 수. gr1 = f(θ) 4칼럼, gr2 = µmax·P_scottA·P_L5 × (mean·mean10·max) 9칼럼(θ + 식품 고정표 aw·pH), gr3 = 날마다 rain 으로 낸 검출확률 × (mean·mean10·max) 3칼럼. 계수 = `리스테리아ML2\data\데이터셋\리스테리아 생장식.xlsx`.
5. 7-b = 7-a 에서 고른 (길이, k, k′) 의 p̂_u·p̂_p3 2칼럼만 넣은 트리(단계 3 최종 판 알고리즘, 기본 설정, 반복 수만) — 4회. ⑤ = HIS1 스무딩 검출률 6칼럼(1년·5년 × 3수준)만(7-b 와 입력이 다름 — 이 6칼럼이 맞음), 자료·알고리즘 = 그 단계 1위. ⑤ 는 각 단계 판 목록에 미리 적어 둠(계산 시점만 늦음: 1-1·2 몫 = 3-1 직후, 3 몫 = 단계 3 끝난 뒤, 4·8 몫 = 그 단계 1위 정해진 뒤).

11. Theil's U 대상 칼럼 = 시료 파일 칼럼 중 식별자(`lims_data_key`)·정답 관련(`judge_result`·`result_value`·`result_value_num`·`judge_stdr`·`judge_stdr_num`)·한 값뿐인 칼럼을 뺀 전부, 숫자·날짜도 값 그대로 범주로. 칼럼별 고유값 수를 Theil's U 표에 같이. validation·test 의 학습에 없던 제품도 그대로 예측. 점수 0·1 규칙(통째로 빠진 3단계 = 0, 검출만 있는 3단계 = 1)은 fold train(refit 은 refit train)만으로 판정.
