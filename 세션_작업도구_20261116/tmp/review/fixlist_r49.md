## A. 바꾸는 것
1. Optuna 튜닝 설정 고르기(§6 단계 8 Optuna 줄): '튜닝 설정 = 시도 중 CV 1위(기본 설정보다 낮으면 기본 유지)' 뒤에 ' — 상위 5개 시도의 CV 표를 함께 보고'.
2. PR-AUC: §1-2 표 PR-AUC 줄 끝에 ', sklearn 기본(같은 값 묶음) PR-AUC 도 같이 기록(고르기엔 안 씀)'. 부록 A-15 metric 줄에 '·PR-AUC(sklearn 기본)'.
3. CatBoost 탐색 범위(부록 A-7 CatBoost 줄): 'learning_rate 0.01~0.3(로그)' → 'learning_rate 0.005~0.3(로그)'. B-9 '튜닝 학습률 하한 0.01 은 반복 2,000 상한에서 덜 학습될 수 있음' → '튜닝 학습률 하한(CatBoost 0.005, 그 밖 0.01)은 반복 2,000 상한에서 덜 학습될 수 있음'.
4. 결측 표시 칼럼은 한 번 정해 모든 모델에 같게:
   - §4-2 결측 줄 '결측 표시 칼럼·채널 = 그 모델 train 에 결측이 있는 칼럼(표준화 통계와 같게 모델마다 — 같은 행 모델을 여러 fold 에 같이 써도 그 모델 것 그대로)' → '결측 표시 칼럼·채널 = d ≤ 2025-06-30 전체 자료에 결측이 있는 칼럼으로 한 번 정해 모든 모델에 같게(표준화 통계는 모델마다 그 모델 train 으로 — 같은 행 모델을 여러 fold 에 같이 써도 그 모델 것 그대로)'
   - 부록 A-8 '결측 표시 채널·표준화 통계 = 모델마다(§4-2)' → '표준화 통계 = 모델마다, 결측 표시 채널 = §4-2 의 한 목록'
   - B-9 '블록 모델마다 결측 표시 채널 구성이 다를 수 있음(부록 A-8)' 줄 지움
5. 트리 입력의 이동평균 차감은 판의 입력 방식을 따름: 원값 판 = 날마다 차감값 lag(`<변수>_anom{N_ma}_lag001` ~ `lagW`, 원 변수 lag 와 같은 날), 요약 판 = 지금의 3칼럼(window 평균·최근 10일 평균·최대).
   - §4-2 이동평균 차감 줄의 '→ window 평균·최근 10일 평균·최댓값(NaN 무시, 값 있는 날 0 이면 결측), 칼럼 이름 `<변수>_anom{N_ma}_*`' 를 위 뜻으로(요약 판 3칼럼 정의는 그대로 두고 원값 판 lag 를 더함)
   - §4-2 원값 줄 '다른 파생(WX2~WX7)은 방식 무관' → 'WX2(차감)도 판의 방식을 따르고, 다른 파생(WX3~WX7)은 방식 무관'
   - §5 표 WX2 줄 '변수마다 3칼럼' → '변수마다 판 방식대로(요약 판 3칼럼·원값 판 W 칼럼)'
   - 부록 A-8 '차감 채널 = 그 변수의 차감 칼럼(평균·최근 10일·최대) 중 하나라도 남으면' → '차감 채널 = 그 변수의 차감 칼럼(요약 3칼럼 또는 원값 lag) 중 하나라도 남으면'
   - 빼기 단위·그룹(부록 A-5)은 그대로(변수의 차감 칼럼 묶음이 한 단위)
6. 딥러닝 학습(부록 A-8 학습 줄): 'Adam 1e-3·배치 1024·최대 50 에폭·인내 5' → 'Adam 1e-3·배치 1024·최대 20 에폭·인내 3'. 부록 A-7 '에폭은 탐색 안 함(최대 50·인내 5 조기 종료 그대로)' → '(최대 20·인내 3 조기 종료 그대로)'. 문서 다른 곳의 '50 에폭'·'인내 5' 도 같이.
7. 조기 종료 떼기: 부록 A-8 학습 줄 '조기 종료 = train 안 무작위 10%' → '조기 종료 = train 의 (`sgg`, d) 묶음 단위 무작위 10%(같은 시군구·같은 날 시료가 학습과 조기 종료에 갈리지 않게)'. 부록 A-7 '시도도 train 안 무작위 10% 로 조기 종료' → '시도도 같은 (`sgg`, d) 묶음 10% 로 조기 종료'. 이상 점수 기준 '조기 종료용 무작위 10% 중 불검출 행' → '조기 종료용 (`sgg`, d) 묶음 10% 중 불검출 행'. B-9 '딥러닝 조기 종료는 날짜 무관 무작위 10%(부록 A-8)' → '딥러닝 조기 종료는 (`sgg`, d) 묶음 단위 무작위 10% — 날짜 순서는 안 따짐(부록 A-8)'.
8. 범주 임베딩 차원: 부록 A-8 '임베딩 각 8차원'(1차 LSTM x_cat 줄)·결합-기본 줄 '임베딩 각 8차원'·② 입력 '범주는 임베딩 각 8' → '임베딩 차원 = min(50, (범주 수 + 1) // 2)(범주 수 = 그 칼럼 범주 번호표 크기, OOV 포함)'. 처음 나오는 곳에 정의, 나머지는 '같은 규칙'.
9. AutoKeras 시도 수(부록 A-7): 'max_trials 19' 뒤에 '(단계 0-9 시간 측정 뒤 담당자 확인으로 늘릴 수 있음, 횟수 셈은 19)'.
10. 변수 빼기 섞기 횟수 M = 5 → M = 10(문서 전체 — §6 2-3, 부록 A-5, 그 밖 'M = 5'·'섞기 5회' 가 있으면 모두). 건너뛰기 ψ_f ≥ 0.8 은 그대로.
11. 빼기 바퀴 상한 없앰: §6 2-3 '채택 없는 바퀴에서 그룹 빼기 끝(최대 20바퀴)' → '채택 없는 바퀴에서 그룹 빼기 끝', 단위 빼기 '(…·채택 없는 바퀴에서 끝, 최대 20바퀴)' 의 '최대 20바퀴' 지움, 3-0b·부록 A-5 등 다른 곳의 '최대 20바퀴' 도 지움. 부록 A-9 2-3·3-0b 줄 = "2-3·3-0b 각각: 그룹 빼기 바퀴당 ≤ 남은 그룹 수 × 3 + 1(채택 있던 바퀴의 기준 판 refit 1, 중요도 예측 G × M × 3 은 학습 아님), 단위 빼기 바퀴당 ≤ 남은 다단위 그룹 단위 수 × 3 + 1. 상한(바퀴마다 하나씩만 빠지는 최악, 바퀴 상한 없음) = 그룹 Σ(3k + 1, k = 1~44) = 3,014 + 단위 Σ(3k + 1, k = 1~110) = 18,425 → 각 21,439(단위 수는 0-8 에서 확정, 실제는 훨씬 적음), 각 예상(그룹·단위 각 3바퀴) = 3 × 133 + 3 × 331 = 1,392". 최악 = 1,541 + 2 × 21,439 = 44,419, BiLSTM·BiGRU 추가 시 = 1,549 + 2 × 21,439 = 44,427. 요약 23 = '예상 4,325회, 최악 44,419회(양방향 추가 시 44,427)' 로 숫자만 바꿈(문장 틀 그대로). 학습 아닌 계산 줄의 '상한은 각 ≤ 21' 같은 20바퀴 기준 숫자도 맞게 고침(상한 = 그룹 44·단위 110 바퀴).
