# 67차 반영 지시 (plan_v67.md → plan_v68.md)

전체 원칙(28~66차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(번호 이어지게). 확인 대기 없음.

## A. 중
1. 단계 8 고른 설정의 메모리 오류(§6 단계 8, 지금 Optuna 줄 끝의 시도 메모리 오류 구절에 이어서): '고른 설정이 시도 밖 학습(8-T refit·딥러닝 칼럼 다시 붙인 판·Focal 판·④ 의 OOF·메타 다시 만들기)에서 메모리 오류면 그 시도를 실패로 바꾸고 CV 다음 순위 시도로, 남은 시도가 없으면 기본 유지(Focal 이면 Focal 판 없음으로 기록)'.
2. AutoKeras 시도 메모리 오류(부록 A-7 딥러닝 줄): '시도가 메모리(GPU) 오류면 실패로 기록하고 계속(`max_consecutive_failed_trials` = 19), 성공한 시도 + 기본 설정 중에서 고름, 시도가 전부 실패면 그 모델은 기본 유지로 기록'.
3. ⑥·⑦-D 의 '해외 구조적 결측' 칼럼: 부록 A-8 의 ⑥·⑦-D 입력 줄 'x_seq(…) + g 만' → 'x_seq(…) + g·해외 구조적 결측 1칼럼(§4-2)', TCN 행 끝 '(⑥ 는 x_static = g 만, x_cat 없음)' 과 트랜스포머 행 '(⑦-D 는 x_static = g 만, x_cat 없음)' → 'x_static = g·해외 구조적 결측 1칼럼, x_cat 없음'. §6 추가 판 ⑥·⑦ 행에 입력이 'g 만' 으로 적혀 있으면 같은 뜻으로(⑦-T 트리는 NaN 그대로라 그대로). B-9 의 '⑥·⑦ 의 시계열만 입력에도 결측 표시 채널(해외 구조적 결측 포함)…' 줄은 이 규칙과 맞는지 보고 필요하면 문구만 맞춤.
