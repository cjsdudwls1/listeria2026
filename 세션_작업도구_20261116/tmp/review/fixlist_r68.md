# 68차 반영 지시 (plan_v68.md → plan_v69.md)

전체 원칙(28~67차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(번호 이어지게). 확인 대기 없음.

## A. 상·중
1. Focal 메모리 오류(§6 단계 8 Optuna 줄 끝): '고른 설정이 시도 밖 학습(8-T refit·딥러닝 칼럼 다시 붙인 판·Focal 판·④ 의 OOF·메타 다시 만들기)에서 …(Focal 이면 Focal 판 없음으로 기록)' → '고른 설정이 시도 밖 학습(8-T refit·딥러닝 칼럼 다시 붙인 판·④ 의 OOF·메타 다시 만들기·5·6 씨앗 1~4 학습)에서 메모리 오류면 그 시도를 실패로 바꾸고 CV 다음 순위 시도로, 남은 시도가 없으면 기본 유지. Focal 판이 메모리 오류면 Focal 판 없음으로 기록(8-T 의 고른 시도·판정은 그대로)'.
2. AutoKeras 다시 학습 메모리 오류(부록 A-7 딥러닝 줄의 메모리(GPU) 오류 구절 뒤): '고른 설정 다시 학습(또는 기본 설정 후보 새로 학습)이 GPU 메모리 오류면 그 후보를 실패로 바꾸고 1년 검증 다음 순위 후보로, 다음이 기본 설정이면 기본 유지'.
3. 부록 A-12 단계 8 점수 줄 '대상이 씨앗 평균 판이면 시도는 씨앗 0 자료(뽑기)로(AutoKeras 씨앗은 부록 A-7)' → '대상이 씨앗 평균 판이면 시도의 뽑기·모델 학습 씨앗 = 0(Optuna TPE 씨앗 42 는 그대로, AutoKeras 는 부록 A-7)'.
4. 해외 구조적 결측 칼럼을 모든 딥러닝 입력에(부록 A-8): 1차 LSTM x_static 'g ÷ 50·`src_route`(0/1)' 뒤에 '·해외 구조적 결측 1칼럼(§4-2)', 2차 딥러닝 x_static 'g ÷ 50·`src_route`·계절 원핫 4칸' 뒤에 '·해외 구조적 결측 1칼럼', AE·VAE 표 입력 줄의 '결측 표시 칼럼' 에 '(해외 구조적 결측 1칼럼 포함)'. ⑥·⑦-D 의 'g·해외 구조적 결측 1칼럼' 은 'g ÷ 50·해외 구조적 결측 1칼럼' 으로(§6 추가 판 ⑥·⑦ 행과 부록 A-8 의 ⑥·⑦-D 입력 줄·TCN·트랜스포머 행).
5. 부록 B-6 나중 기간 점검: '나머지 d ≤ 2025-06-30 은 확인만 — 그 결과로 목록을 바꾸지 않고 기록만(판단 자료로 안 쓰고 최종 보고 전까지 담당자에게 보여 주지 않음)' → '나머지 d ≤ 2025-06-30 도 같은 지표로 재되, 담당자에게는 수치 없이 'd ≤ 2021-06-30 때보다 검출·불검출 간 빈 칸 비율 차이가 커진 칼럼·원천' 이름만 알리고 같은 확인으로 대상·순서에서 뺄지 정함(수치는 판단 자료로 안 쓰고 최종 보고 전까지 안 보여 줌)'.
