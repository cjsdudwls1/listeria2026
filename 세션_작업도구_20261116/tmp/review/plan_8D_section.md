### 단계 8-D. 딥러닝 튜닝(단계 8 뒤)
- 대상 = 단계 8 판정 뒤의 현재 최고 판(단계 안에서 안 바꿈). 그 판의 딥러닝 부분(딥러닝 단독·결합 모델·⑥·⑦-D와 그 5·6 판)의 설정만 탐색한다. 딥러닝 부분이 없는 판(트리·트리 앙상블·④·②)은 판 없이 '튜닝 안 함'으로 사슬 상태를 그대로 넘긴다.
- 그대로 두는 것: 학습 자료(5·6 판이면 뽑은 자료 — 음성 4배 고정)·입력·h 규칙·최대 20 에폭·인내 3·조기 종료 묶음과 감시 손실(가중 없는 이진 교차엔트로피)·평가 쌍·채점·threshold·학습 씨앗(대상 판 씨앗 하나 — 씨앗 평균 안 함).
- 탐색 범위(기본값 = 부록 A-8):

| 설정 | 범위 | 기본 |
|---|---|---|
| 학습률(Adam) | 1e-4 ~ 3e-3(로그) | 1e-3 |
| 배치 크기 | {256, 512, 1024, 2048} | 1024 |
| 은닉 크기(시퀀스 갈래 폭 — LSTM·GRU 은닉, 트랜스포머 d_model(FF = 2배), TCN 채널, attention·결합 모델의 시퀀스 갈래) | {32, 64, 128, 256} | 64 |
| 층 수(RNN 층 — LSTM·GRU·LSTM + attention·결합 모델 / 트랜스포머 인코더 층) | 1 ~ 2 / 1 ~ 3(TCN 은 블록 5개 고정 — 받는 범위) | 1 / 2 |
| dropout(LSTM·GRU = 마지막 은닉 뒤·Dense 64 뒤, 트랜스포머·TCN·결합 = 그 구조의 dropout, LSTM + attention = 세 자리 한 값) | 0 ~ 0.5 | 0 / 0.1 / 0.3·0.3·0.4 |
| 양성 가중(양성 행 손실 배수) | 1 ~ 4(로그) | 1 |
| 손실 | 이진 교차엔트로피 또는 focal(γ ∈ {1, 2}, α ∈ {0.25, 0.75}) | 이진 교차엔트로피 |

- Optuna 20회: 첫 시도 t000 = 대상 판 설정(점수 = 대상 판 CV, 학습 없음 — 후보 비교에만, TPE 이력엔 안 넣음) + TPE(씨앗 42) 19회. 시도는 10·3·3·3 개씩 묶어 묻고(앞 10회 = TPE 무작위 시작, 뒤 9회 = 3개씩), 한 묶음은 fold 마다 평가 쌍 입력을 한 번 만들어 묶음의 모델이 함께 예측한다. 목표 = CV 평균 구간 가중 PR-AUC. 첫 묶음에서 t000 설정도 다시 학습해 대상 판 CV 와 같은지 기록한다(고르기엔 안 씀).
- 튜닝 설정 = 시도 중 CV 1위(t000 보다 소수 4자리로 오를 때만, 아니면 기본 유지 — 판 없음). 상위 5개 시도의 CV 표를 함께 보고.
- 판 8-D-<바탕>(3 fold + refit) = 튜닝 설정으로 다시 학습. 판정: CV 평균이 현재 최고 판보다 소수 4자리로 오르면 채택(2차 공통)(새 현재 최고 판), 아니면 그대로. 최종 모델 고르기는 이 판정 뒤의 사슬 상태를 읽는다.
- 보고: 1차 베이스라인·대상 판·8-D 판의 CV·test(test 는 판정 뒤 보고 때만).
- 시도·fold 마다 기록해, 멈추면 끝난 (시도, fold) 는 건너뛰고 그 자리부터 다시(부록 B-1). GPU 메모리 상한 0.25.
- 학습 횟수: 시도 19 × 3 + t000 대조 3 + 판 4 = 64(기본 유지면 60, 딥러닝 부분이 없으면 0).
