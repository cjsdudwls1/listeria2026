## 0. 고정 조건
- 학습 행 = 시료 1건, 입력은 예측하는 날 T 에 운영 단위에서 만들 수 있는 값만
- 출력 단위 = 국내 시군구 × 2단계 × 3단계, 해외 나라 × 2단계 × 3단계
- 해외 행 포함·국내와 한 모델, 해외 지역·기상 = 나라 단위(나라 대표 좌표 1곳), 해외 d = 선적일 그대로
- 지역 입력은 모든 모델에서 시도 + 시군구 둘 다
- 일 단위 변수는 전부 예보가 있다고 가정, 예보 칸(T ~ E)은 학습 땐 관측값, 예보 길이 = 발표 당일 포함 11일
- SPI 예보 칸은 학습 때도 늘 우리 계산값(그 날짜 기상청 값이 있어도 안 씀)
- 대상일 d 당일 기상은 안 씀(window 는 d−1 에서 끝)
- 제품명은 단계 4 다운사이징 train 행 고르기에만(입력·채점·보고엔 안 씀)
- 시간순 3 fold + test 1년 고정, 채점은 T 기준
- 지표 = trapz PR-AUC 하나(구간 가중이 주 지표), AP 는 계산·저장·보고 어디에도 안 씀
- 고르기는 CV 로만, test 는 단계마다 보고만, 전 단계 수행 뒤 CV 로 고름(중간 중단 없음)
- 튜닝(트리·딥러닝)·손실함수 비교는 맨 끝 단계 8
- 시료당 train h 1개(단계 4 만 h 1~60 전부)
- window W 는 10~100 다시 탐색(지난 결과 안 가져옴), 결과 시차 90일 반영 안 함
- 결측: 트리 NaN 그대로(0 채움 금지), 딥러닝·로지스틱은 표준화 → 0 + 결측 표시 칼럼
- 실험 코드는 처음부터 새로 작성(지난 실험 스크립트 안 씀), 데이터 산출물은 그대로 씀

## 1. 예측 대상·평가
### 1-1. 정의
- d = 대상일(시료 기준일), h = 예측 시차 1~60, T = 예측하는 날 = d − h, W = 기상 window 길이(10~100, 10일 간격)
- E = window 끝 = min(d − 1, T + 10), S = 시작 = E − W + 1, g = window 끝과 d 사이 빈 날 = max(0, h − 11), R = 단기 파생 기준점 = E + 1
- y = 시료 `judge_result`(검출 1·불검출 0, 해외도 시료 단위), 평가 행 = (시료, h) 쌍(validation·test 는 h 1~60 전부 예측)

### 1-2. 지표
```python
from sklearn.metrics import precision_recall_curve, auc
p, r, _ = precision_recall_curve(y, s); pr_auc = auc(r, p)   # drop_intermediate 기본값
```

| 지표 | 정의 |
|---|---|
| h 별 PR-AUC | h 마다 채점 쌍으로 계산, 검출 0건·전부 검출인 h 는 NaN |
| 구간 가중 PR-AUC(주 지표) | 0.5 × 평균(h 1~20) + 0.3 × 평균(h 21~40) + 0.2 × 평균(h 41~60), NaN 인 h 는 그 구간 평균에서 뺌. 고르기·반복 수·튜닝 목표·보고 모두 이것 |
| 60일 통 PR-AUC | 모든 (시료, h) 쌍을 이어 한 번 계산 |
| 부적합률 대비 배수 | PR-AUC ÷ 같은 채점 쌍 검출 비율(구간 가중·60일 통 둘 다) |
| threshold 지표 | test 쌍 전체 Recall·Precision·F2·혼동행렬(TP·FN·FP·TN) |
| 상위 k% 포착률 | 예측 상위 1·5·10·20% 쌍이 잡은 검출 비율 |

- threshold: 모든 fold validation 예측(모든 h)을 합쳐 Recall ≥ 0.8 인 값 중 Precision 최대(같으면 Recall 큰 쪽) → refit 모델 test 예측에 그대로 적용
- 동점 많은 판(단계 7-a·검출만 있는 품목 점수 1·기준 줄): 표에 '동점 많음 — trapz 부풂' 표시, 후보 유지, CV 1위면 확정 전 담당자·교수님께 알림. 확률보정 지표 없음

### 1-3. 보고 형식
- 단계마다 판 목록·고르기 규칙을 그 단계 test 전에 적어 둠, test 를 본 뒤 추가한 판은 기록만(고르기 대상 아님)
- 단계별 표 칼럼: 단계·판 | 입력·모델 | CV 구간 가중(평균) | fold 1~3 | test 구간 가중 | test h 1~20·21~40·41~60 평균 | test 60일 통 | 배수 | threshold | Recall | Precision | F2 | TP·FN·FP·TN | 상위 10% 포착률. test 점수는 국내 + 해외 전체 하나
- 표마다 기준 줄 = 타겟 인코딩 단독(단계 7-a 방식), 단계마다 h 별 PR-AUC 그림 1장(단계 1 은 h 별 평균 예측 확률 그림도)
- 마지막: 단계 1 → 최종 대표 판 test 변화 표 1개 + 최종 모델 test 전체 지표. 판 이름 = 단계-판(예: 1-CAT-W060-raw, 4-b)

## 3. 분할
| 판 | train(d) | 채점 T(T ∈ …인 (시료, h) 쌍) | T 일수 |
|---|---|---|---:|
| fold 1 | ≤ 2022-06-30 | 2022-07-01 ~ 2023-05-01 | 305 |
| fold 2 | ≤ 2023-06-30 | 2023-07-01 ~ 2024-05-01 | 306 |
| fold 3 | ≤ 2024-06-30 | 2024-07-01 ~ 2025-05-01 | 305 |
| refit·test | ≤ 2025-06-30 | 2025-07-01 ~ 2026-05-01(test 기간 2025-07-01 ~ 2026-06-30) | 305 |

- gap 0일, 모든 h 가 같은 T 범위로 채점
- train 행: d ≤ train 끝인 시료마다 h 1개 무작위(1~60 균등, 씨앗 고정), T = d − h. 시료별 h 는 한 번 뽑아 모든 fold·refit·딥러닝에 같이 씀
- 이력 칼럼: train 행 = rolling(T−1 까지), validation·test 행 = 그 fold(refit) train 끝 값 고정
- 부스팅 반복 수: 모든 fold 최대 2,000 반복·같은 학습률 → 50 트리마다 fold validation 구간 가중 PR-AUC(40개 시점, 트리 수 지정 예측: CatBoost `ntree_end`·XGBoost `iteration_range`·LightGBM `num_iteration`) → fold 평균 최고 N 하나 → fold 점수·refit 모두 N
- 학습률: XGBoost·LightGBM 기본값, CatBoost 는 fold 별 자동 학습률 평균 하나로 고정(모든 fold·refit). RF·ExtraTrees·로지스틱은 기본 설정, 반복 수 고르기 없음
- refit: d ≤ 2025-06-30 전체로 CV 에서 고른 설정·N·학습률 그대로 재학습 → test 1회

## 4. 기상 입력
### 4-1. window
- [S, E]: S ~ T−1 = 관측, T ~ E = 예보(학습 땐 관측값, 운영 땐 예보값). h ≤ 11 이면 E = d − 1, h ≥ 12 면 E = T + 10 이고 T+11 ~ d−1 의 g 일은 window 밖(입력 없음)
- 일 단위 변수 전부(기상 19·습도·이슬점·SPI·단기 파생·생장식) = E 끝. 일 단위 아닌 칼럼(토양 검정·외부 지표·이력) = T−1 에 쓸 수 있는 가장 최근 값
- 한 설정 안에서는 모든 h 가 같은 W. 시간 칼럼: 트리 = h·g 둘 다, 딥러닝 = g 만
- 검산 예시(d = 2025-11-01, W = 60, 단계 0-5 에서 생성기와 대조): h 1 → T 10-31, 09-02 ~ 10-31(관측 59·예보 1) / h 11 → T 10-21, 09-02 ~ 10-31(49·11) / h 12 → T 10-20, 09-01 ~ 10-30(49·11, 밖 1일) / h 30 → T 10-02, 08-14 ~ 10-12(49·11, 밖 19일) / h 60 → T 09-02, 07-15 ~ 09-12(49·11, 밖 49일) / W = 100·h = 13 → 07-22 ~ 10-29(89·11). 관측 일수 = max(0, W − min(h, 11))

### 4-2. 요약값·원값·시퀀스·결측
- 요약(변수마다): E 부터 거꾸로 10일 구간 평균 W/10 개(b01 = E−9 ~ E, b02 = E−19 ~ E−10, …) + window 평균·표준편차(ddof 0)·최소·최대·기울기, NaN 무시. 관측·예보 칸을 한 줄로 이어 계산
- 원값: lag001 = E, lag002 = E−1, …, lagW = S. 시퀀스(딥러닝): S ~ E 시간순 W일
- 이동평균 차감(wxanom): a_t = x_t − (t 앞 30일 평균) → window 평균·최근 10일 평균·최댓값
- 결측: XGBoost·LightGBM(`zero_as_missing=false`)·CatBoost(`nan_mode=Min`, 범주는 문자열)·RF·ExtraTrees 는 NaN 그대로. 로지스틱·딥러닝은 train 평균·표준편차(NaN 빼고)로 표준화 → 결측 0 → 결측 표시 칼럼(결측이 실제로 있는 칼럼만, 해외 구조적 4변수 soil_t_nas·no2·co·so2 표시는 1개로 합침)
- fold 마다 'train 엔 NaN 없고 평가에만 있는 칼럼' 점검, 0 이 실제 값인 칼럼(강수·지중온도) 0 채움 금지

- 순서: 0 준비 → 1 알고리즘 × window → 2 상위 모델 결합 → 3 파생변수 → 4 다운사이징 → 5·6 송 교수 방식 → 7 타겟 인코딩 단독 → 8 튜닝. 모든 단계 고르기 = CV 평균 구간 가중 PR-AUC

- 2-2 스태킹: 트리 상위 3개마다 (a) + 딥러닝 상위 3개 OOF 확률 3칼럼 (b) (a) + 이상 점수 4칼럼 (c) + 이상 점수만
- 2-3 앙상블(추가 학습 없음): (시료, h) 쌍마다 확률 단순 평균 — 트리 상위 3개 / 트리 상위 + 딥러닝 상위, threshold 는 평균 예측으로
- 2-4 결합 모델: 결합-기본·결합-VAE(§7), 블록 OOF + 시간순 3 fold → 최종 고르기 후보
- 단계 3 대상 = 트리 갈래 1위 단독·스태킹 판·앙상블 판 중 CV 1위. 1위가 딥러닝 값이 들어간 판이면 그 판만 엄격 OOF 로 CV 다시 내어 비교

- 기준 칼럼: fold 마다 그 fold train 의 원 칼럼(더미 전, 숫자·범주 그대로, ID 칼럼 제외, 교수님 노트북과 같은 칼럼 묶음)으로 Theil's U 계산·표 기록 → 1위 칼럼(예상 `prduct_nm`). 1위가 다른 fold 가 있으면 그 칼럼 판도 같이
  - 코드는 교수님 노트북 `alone_in_the_woods…` 13·14번 셀을 옮기고, 먼저 국내 전체로 `prduct_nm` 0.79·`addr` 0.50 재현 확인
- 줄이기: fold train 기간에 검출 0건인 기준 칼럼 값의 행을 train 에서 뺌(제품명은 문자열 그대로), 검출 1건 이상인 값은 남김, validation·test 는 전부. 이력·인코딩 칼럼은 줄이기 전 fold train 전체로 계산
  - train 에 한 행도 안 남은 3단계 품목: 점수 0 + 참고 판(4-a 모델이 그 행까지 예측한 점수). 검출만 있는 3단계 품목: train 에서 빼고 점수 1
- 4-a: 줄인 train + 단계 3 최종 판 설정, 줄인 train 행에 h 1~60 전부 / 4-b: 4-a + SMOTENC(fold·refit train 안에서만, 결측 칼럼은 거리 계산에서 빼고 만든 행은 그 칼럼 NaN, 양성 비율 20%, h·g 는 원 행 값 복사)
- 미리보기: 단계 1 직후 트리 갈래 1위 설정으로 4-a 1판(고르기에 안 씀, 교수님 보고용)
- 산출: 판별 CV·refit·test, fold 별 줄인 행·검출 수, Theil's U 표

### 단계 5·6. 송 교수 방식
- 5: fold train 의 해(d 의 달력 연도)마다 양성 전부 + 그해 음성 무작위 4 × 양성 수
- 6: 음성을 그해 양성이 나온 3단계 × 시군구(해외 3단계 × 나라) 안에서만 4 × 양성 수
- 공통: 씨앗 5개 예측 평균, 단계 3 최종 판 설정(반복 수만 다시), 이력·인코딩은 단계 4 규칙, validation·test 전부 예측

### 단계 7. 타겟 인코딩 단독
- p̂_u = (s_u + k·p̂_p3) ÷ (n_u + k), p̂_p3 = (s_p3 + k′·p0) ÷ (n_p3 + k′); u = (3단계, `sgg`), s = 검출 수, n = 검사 수, p0 = 전체 검출률
- 기간 = fold train 끝(refit 2025-06-30)까지, 길이 1년·5년·전체와 k·k′ ∈ {10, 30, 50, 100, 200} 은 CV 로
- 7-a 식 그대로(validation·test 쌍 모든 h 같은 값), 7-b 타겟 인코딩 칼럼만 넣은 트리 모델

### 단계 8. 튜닝·불균형(마지막)
- 대상: 단계 1~7 판 중 CV 1위 판의 트리 모델(1위가 7-a 면 트리 판 중 1위), 딥러닝 칼럼 빼고 튜닝 → 고른 설정에 다시 붙임
- Optuna TPE(씨앗 42) 100회, 목표 = CV 평균 구간 가중 PR-AUC, 시도마다 공통 반복 수, 첫 시도 = 기본 설정. 상위권 중 담당자가 고른 튜닝 판 채택(기본보다 낮으면 보고에 적음)
- CatBoost 범위: learning_rate 0.005~0.3(로그)·depth 2~10·l2_leaf_reg 0.1~100(로그)·random_strength 0.01~20(로그)·subsample 0.5~1(`bootstrap_type` 명시)·rsm 0.1~1·scale_pos_weight 1~300(로그). CatBoost 가 아니면 같은 뜻 설정으로, 대응 설정 없는 RF·ExtraTrees·로지스틱은 범위를 그 단계 test 전에 적음
- 손실: Logloss 기본, CatBoost Focal 지원 확인 뒤 후보
- 딥러닝(최종 판에 딥러닝 값이 있을 때만): 손실 비교(교차엔트로피·focal γ 2·α 0.75) + 소규모 튜닝(도구는 확인 대기 — 안: PyTorch + Optuna 20~30회, 배치 크기 256~4096·은닉 크기·층 수·드롭아웃·학습률·에폭, 블록 1~4 학습 → 블록 5 점수) → 고친 설정으로 블록 OOF 재학습 → 트리 재학습

- 실행마다 설정·fold 별 점수·test 점수·예측값 저장(다시 채점 가능), 실험 로그, 결과마다 code_md5·입력 md5·스레드 수·설정 덤프(이어하기 판정에 code_md5), 서버는 코드 사본 하나·결과 폴더에 실행 코드 사본

- 모든 refit 경로가 같은 함수로 학습률·반복 수를 정함, threshold 모델 ≠ test 모델이면 그 사실과 test Recall 보고. CatBoost `bootstrap_type` 명시·학습 뒤 `get_all_params()` 기록
- 설정 파일의 모르는 칸은 오류로 멈춤, Windows 절대 경로 금지. 입력 캐시를 쓰면 모든 입력 파일·코드 md5 를 이름표에
- 조인 `validate="many_to_one"`·조인 뒤 결측 수 assert·키 중복이면 멈춤. 좌표 매칭은 시료 파일 `lat`·`lon`(float32 → double 범위 검색 + float32 등호 재확인). 칼럼 순서 한 기준으로 정렬, 씨앗 고정(h 배정·모델·딥러닝 Generator)
- 행 수·검출 수를 기록값과 자동 대조(모수 함께), 같은 validation 으로 고른 횟수 기록, test 행은 test 단계에서만 만들고 고르는 단계에서 접근하면 멈춤
