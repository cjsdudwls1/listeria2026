### 국내만 버전
- 목적: 같은 실험(단계 0 ~ 최종 모델, 비교만 판 ③·⑧·4-c·7-a 포함)을 국내 행(`src_route` = 'domestic')만으로 한 벌 더 해, 지금 판(국내 + 해외 한 모델)과 국내 test 성능을 비교한다.
- 행: 단계 0-1 시료 표(행 처리 RR1~RR8 뒤 — RR1 로 국내로 옮긴 행 포함)의 국내 행만 쓴다(기록값 628,586행·검출 1,844). 학습 행·평가 쌍·이력·타겟 인코딩 모집단·7-a·CV·test 채점·threshold 가 모두 이 표만 쓴다. 덜 찬 달은 §3 규칙의 국내 몫 그대로다.
- 칼럼: 해외 정보만 담는 칼럼을 뺀다 — 트리 범주 `src_route`(범주 5 → `sido`·`sgg`·`p2`·`p3` 4개), 딥러닝 x_static `src_route` 0/1(② 포함), '해외 구조적 결측' 1칼럼. 구조적 결측 대상 변수(§4-2)의 결측 표시는 국내 행 규칙대로 칼럼마다 붙는다. 단계 4 Theil's U 대상에서 `src_route` 를 뺀다. 그 밖 칼럼·변수 묶음·알고리즘·설정·고르기·채택 규칙은 지금 판과 같고, 값이 하나뿐인 칼럼도 그대로 둔다.
- 단계 0: 시료와 무관한 결과(국내·해외 일자료표, SPI, 식품 고정표, 축사 표)는 지금 판 것을 그대로 쓴다. 식품 고정표는 3단계 → 2단계 짝을 국내 행으로 다시 세어 같은지 확인하고, 다르면 국내 행으로 다시 만든다. 시료에 따라 정해지는 결과(시료 표·fold 별 셈·덜 찬 달·Theil's U 대상 목록·결측 표시 목록·단계 0-8 표·이력 점검·0-10 7-a)는 국내 행으로 다시 만든다.
- 순서: §8 순서 그대로(단계 0 국내 준비 → 0-10 → 1-1·1-2 → 1-3 → ③ → 단계 2 준비 → 미리보기 4-a → 3-0 → ⑥·⑦ → 3-1 ~ 3-3 → 3-0b → ⑧ → 4 → 5·6 → 8 → 최종 모델). 다음 단계는 앞 단계의 결정 파일이 생긴 뒤에만 시작한다.
- 분리: 결과·실험 로그·사슬 기록은 국내판 결과 뿌리에만 쓰고, 지금 판 결과에는 쓰지 않는다. MLflow 는 같은 저장소에 experiment 를 따로 둔다(`listeria-준비-국내`·`listeria-1차-국내`·`listeria-2차-국내`). 판 이름 규칙은 지금 판과 같다.
- 비교: 지금 판의 판들(최종 모델 포함)을 학습 없이 국내 test 시료 쌍으로만 다시 채점해(같은 지표·threshold 규칙, threshold 는 국내 CV 예측으로 다시 정한 값과 지금 판 원 값 둘 다) 국내만 버전의 같은 단계 판·최종 모델과 CV·test 표로 비교한다. test 채점은 각 단계 보고 때만 한다.
