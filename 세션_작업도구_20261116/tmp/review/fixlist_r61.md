# 61차 반영 지시 (plan_v61.md → plan_v62.md)

전체 원칙(28~60차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~n 목록(번호 이어지게). 부록 A-11 은 '교수님께 알릴 확정 사항' 목록이라 교수님 말씀과 다른 줄에는 짧은 표시를 붙임(이 문서의 허용 꼴: '(담당자 결정 — …)'·'(교수님 … 와 다름 — …)').

## A. 중 — 구현 모호함
1. 결합-VAE VAE 갈래(부록 A-8 결합-VAE 행): 'VAE 갈래(시퀀스 VAE 인코더·디코더, …)' 에 'VAE 갈래 입력 = 그 판 x_seq(시계열 갈래와 같은 텐서 — 3-0b 빼기·섞기도 같이)' 와 '머리 concat = 정형·시계열 갈래 출력 + μ(학습·추론 모두 μ)·복원 오차 1칼럼' 뜻을 넣음.
2. 딥러닝·결합 모델 순열 중요도(부록 A-5 중요도 계산 줄): '그룹 칼럼 전부를 같은 행 순서로 섞음(`h_block`)' 뒤에 '— 딥러닝·결합 모델은 그 그룹에 속한 x_seq 채널(시퀀스 통째)·x_static 칼럼·결측 표시 칼럼·채널을 같은 순열로 행끼리 바꿈'. §6 0-8 의 '(부록 A-5, 소속 칼럼 목록은 요약·원값 두 방식 다)' → '(부록 A-5, 소속 칼럼 목록은 요약·원값 두 방식과 딥러닝 채널·x_static 칼럼 다)'.
3. 최종 모델 안 순열 중요도(부록 A-10 해당 괄호 뒤 또는 부록 A-5 끝에 한 줄): '판 종류별 — 같은 원 변수에서 나온 칼럼·채널이 여러 구성 모델(트리·딥러닝 확률·이상 점수를 만드는 모델 포함) 입력에 있으면 모두 같은 순열로 섞고, 구성 모델을 섞인 입력으로 다시 추론(학습 없음)해 스태킹·앙상블 예측을 다시 만듦, 딥러닝 확률·이상 점수 칼럼 자체는 섞는 대상 아님, 씨앗 평균 판은 씨앗 0~4 예측 평균'. 부록 B-5 의 '칼럼 번호 = 최종 모델 입력 칼럼을 아래 칼럼 순서 기준으로 1부터' → '칼럼 번호 = 최종 모델 설정 덤프(B-4)의 입력 칼럼 목록 순으로 1부터', 그 아래 '- 칼럼 순서 한 기준으로 정렬' 줄이 뜻 없이 남아 있으면 지우거나 'B-4 설정 덤프 칼럼 목록 순' 으로.
4. 단계 8 딥러닝 튜닝 범위(부록 A-7 딥러닝 줄 '블록 대응·범위는 단계 0-9 AutoKeras 확인 때 정해' 와 §6 0-9 'AutoKeras 시도 1회'): '0-9 에서 단계 8 대상이 될 수 있는 딥러닝·결합 구조 전부(LSTM·GRU·트랜스포머·LSTM + attention·TCN·결합-기본·결합-VAE·⑥ 2종·⑦-D, 양방향 추가 시 BiLSTM·BiGRU)의 대응 블록을 정함, 못 만드는 구조는 기록하고 튜닝 안 함' 뜻으로. §6 단계 8 의 8-TD 줄에 '튜닝 못 한 모델의 확률 칼럼·앙상블 구성 예측은 원 값 그대로, 하나라도 튜닝되면 8-TD 판을 만들고, 전부 못 하면 8-TD 없음(기록)'.
5. 3-0b 바퀴 이름: §1-3 예시 '3-0b-CAT-r03' → '3-0b-CAT-g03'. 부록 A-14 '판 이름 조각' 행의 'r = 바퀴' → 'g·u = 그룹 빼기·단위 빼기 바퀴 번호(각각 01 부터)'(부록 A-5 의 섞기 번호 r 과 겹치지 않게). 부록 A-15 에 '3-0b 바퀴 run 이름 = 3-0b-<구조>-g<2자리>·-u<2자리>, 그 바퀴 끝 기준 판을 그 run 이름으로 가리킴' 넣음.
6. 단계 4~8 판 이름(부록 A-14 '판 이름 꼴(나머지)' 행): 끝 구절 '바탕이 스태킹·앙상블이면 <…> 자리에 바탕 판 이름' → '단계 4~8 판·①·4-c 의 알고리즘 자리 = 바탕 판의 구조 약어(바탕이 스태킹·앙상블·교체 후보면 바탕 판 이름)', '4-a0 = 4-a0-<…>' 넣음. 부록 A-15 '이름 = 판 이름(§1-3)' → '이름 = 판 이름(§1-3·부록 A-14)'.
