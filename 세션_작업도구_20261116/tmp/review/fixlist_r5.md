전체 원칙(1~4차와 같음): 본문 ≤ 300줄(넘으면 세부를 부록 A 로 옮겨 맞춤), 같은 내용은 한 곳에만, 이력·날짜·인용·누가 말했는지·결정 번호·안 쓰는 항목 없음. 아래 지시가 앞 차수·옛 판보다 우선. 바뀐 숫자는 요약·본문·부록 모든 곳에서 같게.

## A. 교수님 말씀
1. §9 첫 줄(딥러닝 튜닝)에 덧붙임: "한다면 d ≤ 2021-06-30 학습 + 1년 검증으로 고른 뒤 전체로 다시 학습 — '딥러닝은 CV 없이 9년 전체 학습' 말씀과 다름". §9 '알릴 확정 사항'에 "딥러닝 test 모델은 test 전 전체로 한 번 학습, 시간순 CV 는 다른 모델과 같은 기준으로 고르기 위한 점수용" 추가.

## B. 방법론
2. 다운사이징 기준 칼럼(4차 5번을 대신함): "기준 칼럼 = 그 fold(refit) train 의 Theil's U 1위 — fold 마다 따로 정함(CV 가 검증하는 것은 '그 train 의 1위 칼럼으로 줄이기' 절차), 칼럼별 Theil's U 표는 fold·refit 마다 저장". '후보 칼럼 … 후보 칼럼마다 … 판 … CV 로 고름 …' 문구와 A-9 미포함의 '후보 칼럼이 둘 이상일 때의 추가 판' 지움. 기준 칼럼은 무엇이든 행 고르기에만 쓰고 단계 4 끝까지 시료 표에 남김(입력 안 씀) — §2-1 에 이 뜻으로, 0절 줄 = "`prduct_nm` 등 단계 4 기준 칼럼은 행 고르기에만(§2-1)". B-8 끝에 "(재현은 코드 확인용, 고르기에 안 씀)".
3. 점수 0·1(단계 4): "3단계 품목 집계로 판정(기준 칼럼과 무관)" 으로 쓰고 '(줄이면 통째로 빠짐)' 지움. 보고: "점수 0 묶음의 validation·test 검출 수·비율, threshold 가 점수 0 이하가 되는지(그러면 전부 양성 판정) 표에 표시·담당자 알림".
4. 동점 많은 판(§1-2): 고정 목록(7-a·⑤·검출만 있는 품목 점수 1 판) 대신 "모든 판: 가장 큰 동점 묶음(같은 예측값) 크기·그 안 검출 비율 기록, 채점 쌍의 1% 이상이면 '동점 많음 — trapz 부풂' 표시·알림 규칙 적용". 기준 줄(7-a) 표시는 이 규칙으로 자동.
5. 평가 쌍의 예보 칸: §4-1 에 "validation·test 쌍도 예보 칸 = 관측값(완전 예보 가정)", §1-3 에 "test 표 제목에 '(예보 칸 = 관측값)' 표시".
6. '같은 validation 으로 고른 횟수'(§1-3): "딥러닝 값·W_DL 을 물려받는 판은 1-2 의 40 을 더함".
7. 3-3 바퀴별 test: "채택 있던 바퀴마다 기준 판 refit 1회 → test 예측". 3-3 1단계 바퀴당 ≤ 142(G 47 × 3 fold + refit 1), 상한 20 × 142 = 2,840, 2단계 바퀴당 ≤ 단위 수 × 3 + 1·최대 20바퀴(따로). 총 상한 = 1,674 + 2,840 = 4,514. 요약 줄 = "3-3 1단계 상한 2,840회(2단계 따로)".
8. threshold 용 예측(§1-2): "그 판 CV 점수와 같은 예측(교차 N, 씨앗 평균 판은 씨앗 평균)".
9. 사람이 정하는 판단(§1-3): "줄이기 목록·3-3 2단계 여부·§9 회신 반영·동점 많은 판 처리는 CV·시간 자료만 보고 정함(test 점수 안 봄), 판단 시점·본 자료 기록".
10. 단계 8 딥러닝 튜닝: "튜닝 검증 쌍과 겹치는 블록(fold 1 넷째 블록·fold 2 블록 4) OOF 의 PR-AUC 를 튜닝 전후로 기록".
11. 단계 0-3: "원천별 공개 지연(일) 확인 — 지연이 있으면 담당자 보고" 추가.
12. SMOTENC(부록 A-6·본문 4-b·§9 알릴 줄):
   - 칸 = (h, `src_route`, season), 이웃 = 같은 칸 양성, 합성 수 = ⌊0.25 × 음성⌋ − 양성(0 이하면 안 함)
   - 보간 칼럼 = 기상 window 칼럼·WX1·WX2·gr1·gr3·WX5·WX6·rg 기상 12·딥러닝 값·이상 점수(합성 전에 붙인 엄격 OOF 값)
   - 기준 행 값 그대로 = 범주 5·h·g·season·HIS1~HIS4·FD1·gr2(식품 aw·pH 가 들어감)·rg 품목 4·SO1·rg 토양 pH 3·X1·X2·L1
   - 거리: P·J 의 숫자 칼럼 = 보간 칼럼, 범주 불일치 = `sido`·`sgg`·`p2`·`p3`
   - §9 알릴 줄 = "SMOTENC 는 같은 (h, 국내·해외, 계절) 칸 안에서, 범주·범주에서 정해지는 칼럼은 기준 행 값으로 두고 기상 등 숫자만 보간"
