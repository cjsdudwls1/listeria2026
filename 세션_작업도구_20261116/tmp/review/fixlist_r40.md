3. 교수님 지시(타겟 인코딩 단독 판을 1 기본·2 파생변수·3 스태킹·4 튜닝·5 다운사이징마다): ⑤ 8 몫 다시 넣음 = ⑤ 4 몫의 판(과거 검출률 6칼럼)을 단계 8 과 같은 Optuna 규칙(100회, 첫 시도 = 기본 설정)으로 튜닝한 판, 단계 8 뒤 교체 후보로 따로 판정. 부록 A-9 ⑤ = 16(4몫 × 4) + 8 몫 298(99 × 3 + 1) → 합계(2-3·3-0b 제외) 1,675~1,786(딥러닝 튜닝 없을 때 1,675), 0-9 예상 = 1,786 + 2 × 1,392 = 4,570, 최악 = 1,786 + 2 × 9,280 = 20,346, BiLSTM·BiGRU 추가 시 1,794·20,354. 요약 23번·§8 숫자도.
4. 실험 관리 = MLflow(담당자 지시 — 확인하기 편하게). §8 에 한 줄 + 새 부록 A-15:
   - 저장소 = `리스테리아ML2\exp\mlflow\mlflow.db`(SQLite 백엔드) + `리스테리아ML2\exp\mlflow\artifacts\`, git 제외. 서버에서 돌린 run 은 단계가 끝날 때마다 이 로컬 저장소로 옮김(run id 그대로). 확인 = 로컬에서 `mlflow ui --backend-store-uri sqlite:///리스테리아ML2/exp/mlflow/mlflow.db` → 브라우저 [IP 가림]:5000
   - experiment = 차수별(`listeria-1차`·`listeria-2차`·`listeria-3차`), run 하나 = 판 하나(run 이름 = 판 이름, 예: 1-CAT-W060-sum). 2-3·3-0b 바퀴·Optuna·AutoKeras 시도 = 그 단계 부모 run 아래 자식 run
   - tag: 차수·단계·판 이름·후보/비교만/기준 줄·사슬(채택/버림/현재 최고 판)·현재 입력 묶음 id·코드 검수 완료 여부
   - param: 알고리즘·W·입력 방식·W_DL·변수 묶음 id(칼럼 목록은 artifact)·반복 수(교차 N·공통 N)·학습률·씨앗·라이브러리 버전
   - metric: CV 구간 가중(평균·fold 1~3)·60일 통·h 구간 3개·공통 d 범위·threshold·Recall·Precision·F2·TP·FN·FP·TN·상위 q%·배수·같은 validation 으로 고른 횟수·학습 시간, test 지표는 그 단계 보고 때 같은 run 에(§1-3 test 막기 그대로)
   - artifact: fold·test 예측(parquet)·설정 덤프(`get_all_params()`)·변수 목록·중요도 표(2-3·3-0b)·Theil's U 표(단계 4)·코드 검수 결과·단계별 표(부록 A-12 칼럼, csv)·사슬 변화 표(1차 → 2차 → 3차 채택마다 → 최종)

## B. 하·정리
5. §6 3차 공통 표: ⑤ 1·2차 몫 줄을 3-0b 위로 옮기고, 3-0b 줄 = "3-0 1위 알고리즘(딥러닝이면 3-0 트리 1위)으로 변수 빼기 | 3-0 의 그 판 설정", 단계 8 줄 = "트리 대상 판에 8-T → Focal, 대상의 딥러닝에 8-TD(각각 그 앞까지 채택한 판 위에)", ⑤ 3 몫 줄 = "3-4 채택 판정 뒤, 그때의 트리 대상 판으로 만들어 따로 판정", ⑤ 8 몫 줄 추가(단계 8 뒤 따로 판정, 교체 후보).
6. 트리 대상 판 정의 = "현재 최고 판이 트리·스태킹이면 그 판, 앙상블이면 구성 트리 모두, 그 밖(딥러닝 단독·결합 모델·④·교체 후보)이면 그때까지의 트리 판(3-0~3-3, 단계 4 이후 트리 판 포함, 교체 후보 제외) 중 CV 1위". 교체 후보가 채택되면 현재 최고 판(비교 기준)만 바뀌고, 쌓는 단계는 트리 대상 판·현재 입력 그대로.
7. ⑤ 1·2차 몫이 채택되면 그 뒤 판은 §3 반복 수 규칙(반복 수만 다시).
8. 단계 5·6: 뽑기는 시료 단위 — 뽑은 시료에 그 판의 h 규칙(4-a 면 h 1~60) 적용. 7-b: 자료 = 트리 대상 판의 train(줄였으면 줄인 train·h 규칙 그대로), 앙상블이면 구성 트리마다 만들어 평균.
9. 단계 8 AutoKeras(부록 A-7): 시도도 train 안 무작위 10% 로 조기 종료(1년 검증 쌍은 시도의 학습·조기 종료·목표에 안 씀), 시도 점수 = 학습이 끝난 뒤 1년 검증 쌍 구간 가중 PR-AUC 로 따로 매김 — assert.
