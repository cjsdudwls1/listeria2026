전체 원칙(28~50차와 같음): 할 일·방법만, 본문(요약 제외) ≤ 300줄, 표 칸 수 유지(tablecheck 0), 같은 내용 되풀이 금지, 요약은 하위 글머리 없는 1~26 목록 그대로.

## A. 50차 지시 4(2차 베이스라인을 3-0 후보에 넣기) 되돌림(중)
1. §6 3차 공통 '사슬 시작' 줄 = "- 사슬 시작: 3-0 1위 val 이 2차 베이스라인보다 낮으면 기록·알림(사슬은 그대로 3-0 1위에서)". §6 단계 3-0 본문에서 50차에 넣은 2차 베이스라인 구절을 지움. 요약 14 끝 '2차 베이스라인 판도 후보로 넣고, 1위가 첫 현재 최고 판이다' → '1위가 첫 현재 최고 판이다'. 그 밖에 '3-0 1위가 그 판이면 현재 변수 묶음 = 그 판의 묶음' 같은 50차 지시 4 의 흔적이 남으면 모두 지움(3차 공통 첫 줄의 변수 묶음 정의는 '3-0 은 변수 전체(2-2 입력), 3-0b 뒤는 현재 변수 묶음(3-0b 에서 채택한 묶음, 채택 없으면 변수 전체)' 그대로).
2. 부록 A-9: 3-0 줄 85 → 81(2차 베이스라인 다시 학습 4 지움), 합계 = '1,075~1,541 | 단계 8 대상에 따라 — 트리만 1,373, 트리 + 딥러닝 확률 칼럼 3개 1,484(⑥ 2종이면 1,447), 딥러닝 단독·결합 모델 1,098(1,373 − 298 + 23), ② 1,075, 3-0b 묶음이 채택되면 + 57. 예상에는 상한 1,541', 0-9 예상 = 1,541 + 2 × 1,068 = 3,677, 최악 = 1,541 + 2 × 11,413 = 24,367, BiLSTM·BiGRU 추가 시 1,083~1,549·최악 24,375. 요약 23·§8 일정 숫자도(예상 3,677, 최악 24,367, 양방향 24,375).
3. B-9 한 줄: "3-0 1위가 2차 베이스라인보다 val 이 낮아도 사슬은 3-0 1위에서 — 3차 기법은 2차 베이스라인 판에 적용되지 않음(최종 모델 고르기에는 2차 베이스라인이 들어감)".

## B. 하·정리
4. §6 단계 8 Optuna 줄: 괄호 안 '첫 시도 = 기본 설정' 과 뒤의 '첫 시도 = 라이브러리 기본 설정 그대로(…)' 를 하나로 합침(뜻 그대로).
5. §6 0-8 줄에 '소속 칼럼 목록은 요약·원값 두 방식 다' 넣음.
6. 3차 공통 표 3-3 줄 '물려받는 것' 칸 = '현재 입력(3-2 채택 시 그 방식의 입력)'.
7. 부록 A-9 2-3·3-0b 줄의 '상한(바퀴마다 하나씩만 빠지는 최악, 바퀴 상한 없음)' → '상한(위 한계 — 바퀴마다 하나씩만 빠지는 경우, 바퀴 상한 없음, 그룹 마지막 단위는 안 빼므로 실제 최악은 조금 작음)'.
8. F1 기록: §1-2 threshold 지표 줄 'Recall·Precision·F2·혼동행렬' → 'Recall·Precision·F1·F2·혼동행렬', 부록 A-12 단계별 표 칼럼 '| F2 |' → '| F1·F2 |'(표 칸 수가 바뀌지 않게 같은 칸 안에), 부록 A-15 metric 줄 'F2' → 'F1·F2'.
9. 고위험 품목(부록 A-12 4-c 줄): 보고 세부에 '상위 10 품목 밖 검출 수·전체 검출 중 비중(fold 별·test)' 넣음.
10. B-9 한 줄: "딥러닝은 train 의 90% 로 학습(10% 는 조기 종료) — 트리(100%)와 학습 행 수 차이가 3-0 비교·3-3 앙상블·교체 후보 판정에 섞임".
11. 부록 A-12 3-3 앙상블 대조 줄 끝에 '(기록용 대조 — 운영에서는 이 기준 분포를 만들 수 없음)'.
12. §6 2-1b LSTM '(부록 A-8 1차 입력, 기상은 2차 기상)' → '(부록 A-8 1차 입력, 기상·결측 표시 목록은 2차 표)'.
13. 반복 수 상한(§3 반복 수 줄): '(단계 0-9 측정에서 최적 N 이 2,000 근처에 걸리면 담당자 확인 뒤 늘림)' → '(모든 3차 부스팅 판에서 교차 N·공통 N 이 마지막 시점(최대 반복)이면 표에 "상한" 표시하고 알림, 0-9 측정에서 그러면 담당자 확인 뒤 최대 반복을 늘림)'.
14. 변수 빼기 채택 조건: §0 '고르기·채택 = CV 평균(val), 재실행·여유 규칙 없음' 뒤에 '(변수 빼기 바퀴 안 채택만 3 fold 중 2개 이상 상승도 필요)'. 요약 11 '중요도 낮은 변수 묶음·단위를 뺀다' → '중요도 낮은 변수 묶음·단위를 하나씩 빼 CV 평균이 오르고 3 fold 중 2개 이상 오를 때만 뺀다'.
15. 추가 판 표 ④ 줄 방식 칸 끝 '튜닝 안 함' → '3-2 에서는 튜닝 안 함(단계 8 은 §6 단계 8 규칙)'.
16. 부록 A-15 experiment 줄: 자식 run 구절을 "단계마다 '단계 run' 1개(단계별 표 csv 는 그 run 의 artifact) — 2-3·3-0b 바퀴 run 의 부모 = 그 단계 run(그 바퀴 시도별 점수는 바퀴 run 의 표 artifact), Optuna·AutoKeras 시도 run 의 부모 = 8-T·8-TD 판 run" 으로 바꿈('부모 = 그 단계 끝 판 run' 지움).
