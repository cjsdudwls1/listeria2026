# 1차 검수 반영 지시 (plan_v1.md → plan_v2.md)

전체 원칙
- 승인용 본문은 짧게(목표 ≤ 330줄), 구현 세부(패키지 버전·md5/assert 점검표·도구 설명)는 맨 끝 '부록 A. 구현 점검'으로 옮김.
- 0절 '고정 조건'은 한 줄씩, 본문과 같은 세부를 되풀이하지 말고 필요하면 '(§n)'만.
- 이력·날짜·인용·안 쓰는 항목은 계속 넣지 않음. 결정 번호도 안 씀.
- 1-1절에 짧은 용어 표 추가: LIMS(식품 검사 결과 DB 시료), ASOS·NAS(기상청 종관·농업기상 관측소), 식정원(과제 발주 기관), 판(한 실험 설정), 바퀴(단계 3 빼기 한 번 돌기), 해(달력 연도), W·W_DL(트리·딥러닝 window 길이), 검출률(= 부적합률, 검출 ÷ 검사), 베이스라인(단계 1-1 1위), 기준 줄(표마다 넣는 타겟 인코딩 단독 7-a 점수), 3-R 기준(단계 2 최종 판).

A. 누수·검증 (반드시)
1. 딥러닝 값(딥러닝 확률·이상 점수)이 들어가는 모든 CV(스태킹·앙상블·결합 비교·단계 3~8·최종 고르기)는 처음부터 '엄격 OOF': fold k 마다 train 행 값 = fold train 안 블록 OOF, validation 값 = fold train 전체로 학습한 모델. fold 안 블록 = 전역 블록 경계를 fold train 끝에서 자름(fold 1 = 블록 1·2·3 + 2021-07-01~2022-06-30 의 4블록, fold 2 = 블록 1~4, fold 3 = 블록 1~4 + 2023-07-01~2024-06-30 의 5블록). 대상 = 딥러닝 상위 3개 + 이상 점수 4종(+ 추가 판 ⑥). refit·test 값 = 전역 블록 OOF(train 행) + test 전 전체 학습 모델(test 행). '1위가 딥러닝 값이 들어간 판이면 엄격 OOF 로 다시' 문구는 모두 지움. 딥러닝 상위 3개의 시간순 CV 점수 = 엄격 OOF 의 fold train 전체 모델 점수(따로 학습 안 함).
2. 단계 1-2 딥러닝 구조·W_DL 순위와 상위 3개 밖 설정의 threshold = 블록 5 예측(블록 1~4 로 학습 — 과거만)만으로, 채점 쌍 = fold 2·3 채점 T 범위의 쌍. 그래서 40 설정은 각 1회(블록 5 모델)만 학습, 상위 3개만 나머지 블록·test 모델 추가. 0절에 '딥러닝 구조·W_DL 순위만 블록 5 점수(예외)' 한 줄.
3. 이력(HIS1~HIS4)·타겟 인코딩(7-b·⑤) 칼럼: 모든 행(train·validation·test·운영)을 그 행의 T−1 까지 d 가 있는 시료로 rolling 계산(자기 행·T 이후 제외). 집계 대상 = 그 판에서 쓸 수 있는 시료(train + T 이전 validation·test 시료 — 운영과 같음). p0 도 같은 범위. 'validation·test = train 끝 값 고정' 규칙은 지움(7-a 기준 줄만 'train 끝까지 자료로 낸 값, 모든 h 같은 값' 그대로). 단계 4·5·6 은 '줄이기 전 전체 시료로 rolling 계산한 뒤 행을 줄임'. 추가 판 ③ 은 그 겹 train 시료로만 rolling. §4-1 의 이력 언급은 이 규칙을 가리키게.
4. HIS 정의 보완: 3수준 = 3단계 전국(국내·해외 전체 시료), 시군구 전 품목(해외는 나라 전 품목), 단위 = (3단계, `sgg`). s = 검출 수, n = 검사 수, m = 1년 검출률. WOE = ln((s + 0.5)/(S + 0.5)) − ln((n − s + 0.5)/(N − S + 0.5)), S·N = 같은 기간 전체 검출·검사.
5. 부스팅 반복 수: fold k 에 보고하는 점수는 나머지 두 fold 평균으로 고른 N(그 fold 자기 점수로 안 고름), refit N = 세 fold 평균 최고. 추가 학습 없음. refit 도 같은 N(행 수가 늘어도 그대로).
6. SPI 감마 적합 기간 = 2015-01-01 ~ 그 fold(refit) train 끝(운영 = refit 값). 고정 하나 쓰던 문구 고침.
7. 단계 8: 대상 = CV 1위 판, 트리 없는 판(7-a·딥러닝 단독·결합 모델·②)이 1위면 트리 판 중 1위. 채택 = Optuna 시도 중 CV 1위(기본 설정보다 낮으면 기본 유지) — 담당자가 고르는 문구 지움. 딥러닝 튜닝(최종 판에 딥러닝 값이 있을 때만): 자료 = d ≤ 2021-06-30 학습 / 2021-07-01 ~ 2022-06-30 검증(모든 fold validation 보다 앞), 고른 설정으로 전역·엄격 OOF 다시 → 트리 다시 붙여 CV·test 다시. 도구는 §9 확인 뒤(본문엔 이 한 구절만).
8. test: 예측은 단계마다 만들어 저장해도 되나 test 정답 채점은 각 단계가 끝난 뒤 보고 때만. 3-3 바퀴별 test 는 단계 3 끝난 뒤 한꺼번에.
9. 추가 판 ⑤ 는 단계 3-1(k 정해진 뒤)에 한꺼번에 계산. 입력 = HIS1 스무딩 검출률 3칼럼(3단계 전국·시군구 전 품목·단위)만, 학습 자료·알고리즘 = 그 단계 1위 판과 같음. 7-b 와 차이 = 자료가 그 단계 것.
10. 추가 판 ②: window = [T − W + 1, T](모든 h 같은 입력, d−1 을 넘지 않음), W = 단계 1-2 1위 W_DL, 학습 행 = 시료당 자기 h 1칸.
11. SMOTENC(4-b): h 마다 따로(같은 h 행끼리만 이웃), k = 5, 씨앗 42, 결측 있는 칼럼은 거리 계산에서 빼고 합성 행의 그 칼럼 NaN, 범주는 SMOTENC 범주. 점수 0·1 규칙(통째로 빠진 3단계 = 0, 검출만 있는 3단계 = 1)은 4-b·① 에도 같게.
12. 딥러닝 범주 번호: 모델마다 그 모델 train 에 없는 범주 → OOV 번호. 결측 표시 채널 목록·표준화 통계 = 각 모델 train 행으로.
13. 결합 모델 시간 입력 = g 만(h 넣지 않음 — 딥러닝 규칙과 같게).
