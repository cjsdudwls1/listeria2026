# 천영진 작업 폴더 안내

2026-10-13 폴더 정리 뒤 기준.

## 최상위 폴더

- `문서/` — 받은 문서·양식·명세서·월간보고
  - `개별보고서_양식/`, `리서치팀문서/`, `센터_발표자료_사업보고서/`, `테이블명세서(모델팀)/`, `모델팀_공유문서/`
  - `가이드.txt` — 팀에서 받은 안내문. git 에 올리지 않는다(PC 에만 둔다)
- `모델 학습시 유의사항.md` — 모델 학습 공통 규칙. 실험 코드가 이 자리에서 읽는다
- `리스테리아ML/` — 1차 작업 + 공용 기반
  - `.env`, `.venv-exp2/`(가상환경), `mlflow.db`, `mlruns/`, `output/` — 경로가 묶여 있어 자리를 옮기지 않는다
  - `data/` — 시료 파일 `listeria_data.parquet`
  - `EXP/` — 실험 1~3, `notebook/` — 탐색 노트북·메모, `scripts/` — 확인·보조 스크립트, `docs/` — 작업기록·메모·참고자료
- `리스테리아ML2/` — 2차 작업
  - `data/` — 데이터셋(`데이터셋/`), DB 원자료(`raw/`), 변수별 조인 결과(`중간/`), 외부 수집 자료(`외부_데이터/` — 표준강수지수·관측지점 정보)
  - `exp/` — 새 실험(실험마다 폴더 하나)
  - `notebook/` — 분석 노트북
- `보관/` — 안 쓰지만 지우지 않는 것(옛 MLflow 기록 `mlflow_backup_20261001/`). 여기에 넣는 파일은 git 에 올라가지 않는다
- `Listeria/` — 교수님 레포(자체 저장소. 안의 파일은 고치지 않는다)
- `toxin_2026/` — 자체 git 저장소가 든 폴더(2026-10-13 정리에서 손대지 않음)

## 규칙

- 접속 정보 파일(`.env`, `database계정.txt`, `가이드.txt`)은 git 에 올리지 않는다
- DB 에서 받은 원자료·조인 결과·모델 파일은 git 에 올리지 않는다(각 폴더의 `.gitignore`)
