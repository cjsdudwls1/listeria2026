### 한글 이름 보는 법
- `컬럼사전.xlsx` 첫 시트를 보면 됨.
- parquet 안에도 들어 있음: 스키마 메타데이터 `column_dictionary`(JSON), 각 열의 메타데이터 `한글명`·`명세서_설명`·`DB_설명`·`원표`·`연결 방법`.
  ```python
  import pyarrow.parquet as pq, json
  s = pq.read_schema('LIMS조인_데이터셋.parquet')
  print(json.loads(s.metadata[b'column_dictionary'])[:3])
  print({k.decode(): v.decode() for k, v in s.field('asos_avg_ta').metadata.items()})
  ```

### 열 접두어
`db_` 전처리 시료표(연결 키·참고) · `morg_` 식약처 검사 원본 · `cl_` 식품공전 분류 · `aw_` 수분활성도 표 · `ledg_` 품목제조대장 · `sorg_` 수입 검사 원본(수입 시료 전용) · `asos_` 종관기상 · `nas_` 농업기상 · `air_` 에어코리아. 접두어 없는 23열은 시료 파일 원본. (`fmi_` 수분 문헌값은 DB 복구 후 추가)

### 연결 규칙(값을 바꾸지 않는 '어느 행을 붙일지' 규칙)
- 국내 기상·대기: 시료 파일(listeria_body.parquet)의 lat·lon 좌표에서, 기준일(mnfctur_de) 당일 자료가 있는 관측소 중 가장 가까운 1곳의 그날 값. 관측소 번호·이름·거리(km) 열을 같이 둠. 수입 시료는 빈 값. DB 전처리 시료표 좌표(`db_lat`·`db_lon`)는 참고로만 두고 조인에 쓰지 않음(두 좌표 일치 비율은 `데이터품질진단.md` 2-1절).
- 품목제조대장: 품목제조번호 원문 일치 → 없으면 숫자만 일치. 같은 번호 여러 행이면 삭제 안 된 행 우선 → 최신 수정일시 → 대장 번호 큰 행.
- 수입 검사 원본: 수입접수번호 일치. 여러 행이면 리스테리아 시험 행 우선.
- 식품공전 분류·수분활성도 표: DB 전처리 품목코드(mapped_prdlst_code) 정확 일치.
