### 2-1. 좌표 — 관측소 찾기에 쓴 좌표: 시료 파일(listeria_body.parquet) lat·lon (좌표 없는 행 0행)
같은 시료 고유키로 시료 파일 lat·lon 과 DB 전처리 시료표 lat·lon 을 맞대어, 위도·경도가 **둘 다** 정확히 같은 행을 셈.

- 저장값 그대로 비교가 0%인 이유: 자료형이 다름(시료 파일 float32 / DB 전처리 시료표 float64). 시료 파일은 소수 아래 자리를 줄여 저장해서 DB 값과 끝자리가 다름. DB 값을 float32 로 맞추면 일치하는 행도 저장값 차이는 최대 0.0000076도(약 0.8m)
- 불일치 행의 주소 출처 값(시료 파일 addr_source / DB 표 ready_data.hazard_preprocessed_data 의 addr_source 원값): 업소주소 / 제조사소재지(보완) 290행. 두 좌표 거리 중앙값 114.5km, 최대 332.3km
- '제조사소재지(보완)'은 시료 파일 addr_source(값 4개: 제조사소재지·업소주소·해외제조업소·인허가대장)에는 없고 DB 표 addr_source 에만 있는 값(2026-09-14 추출본 기준 리스테리아 688행). 모델팀 테이블정의서의 addr_source 설명과 DB 열 설명에는 '보완'의 뜻이 적혀 있지 않음. 이 데이터셋은 이 값과 DB 좌표를 조인에 쓰지 않음

## 6. 결정이 필요한 것
- 종관기상 강수 빈 값을 0mm로 볼지
- 관측소 고르는 방식: 이번은 "기준일 당일 자료 행이 있는 관측소 중 가장 가까운 곳". ① 그날 항목이 전부 빈 관측소를 후보에서 뺄지 ② 종관기상 관측소 이전 이력(현재 위치 대신 당시 위치)을 반영할지 ③ 섬 시료의 거리 상한 ④ 시험용 관측소 제외 여부
- 기준일 하루 값만 쓸지, 기준일 전 며칠을 묶어 요약할지
- 토양 pH: 같은 동·연도의 여러 필지를 한 값으로 줄이는 방법
- 수분활성도 표: 쓸지, 쓴다면 리서치팀 파일 원래 값 기준으로 할지 / 수분 문헌값 품목명 매칭 규칙
- 수질오염원 시설 표: 좌표계 확인 후 거리 계산 방식(이번 판에는 표 자체가 없음)
